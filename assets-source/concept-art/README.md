# UNWRITTEN 2027 雪镇概念图

48 张原始 PNG 按下表编号保存。先查 [中央广场总图](central-square-plan.png)，再看 [G01 全镇母图](town/G01.png)、[M04 山谷剖面](terrain/M04.png) 和 [M05 广场第一人称](terrain/M05.png)。[G04](town/G04.png) 用于深夜灯光。

地形灰盒按总图定位，暂按 448 × 384 米和 60 × 43 米广场净空。锁定钟楼北缘、四条回广场短路、四处跨河桥头和东北两级台地。M01 带有透视，部分概念图的桥位有漂移。钟楼的表盘层与钟室按 B01 的剖面分开，B04 用于钟和梁架。建筑开工先核对入口、楼梯、窗列和层高，逐层走通后再加道具。
