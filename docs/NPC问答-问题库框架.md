# NPC 问答 ·「关于托马斯」问题库框架

用途：小镇 NPC 不讲纪念馆，只回答关于托马斯本人的问题——朋友点链接进来，能在镇上打听他、了解他，熟人还能被"只有亲密的人才知道"的问题考一考。
**答案只能由 Thomas 本人提供**：Muse 只搭框架和问题，绝不编造关于他的事实。每位 NPC 的答案按该 NPC 与他的关系分别写，同一个问题不同 NPC 可以有不同说法，这正是好玩的地方。

## 一、NPC 人设（先定人，再填答）
每位 NPC 需要四项（Thomas 定）：
- 名字与身份（镇上的角色，如酒馆老板、邮差、灯塔看守、火车站站长……）
- **与托马斯的关系**（发小 / 老同学 / 同事 / 家人 / 球友……可影射真人，但是否用真名、用不用，由 Thomas 决定）
- 性格与说话风格（一句话即可，如"嘴硬心软，爱损他"）
- 常驻地点与作息（白天在哪、晚上在哪，沿街区路线走动）

建议首批 5–8 位，覆盖不同关系类型：一位"认识最久的"，一位"最损他的"，一位"最护着他的"，反差越大越好玩。

## 二、问题分类（每位 NPC 从各档选答，不必全答）
### A 档 · 相识（新朋友也能听）
1. 你是怎么认识托马斯的？
2. 你们认识多久了？第一次见面是什么场合？
3. 你对他的第一印象是什么？后来变了吗？
4. 你们最近一次见面/联系是什么时候，干了什么？

### B 档 · 关系（半熟的人能聊）
5. 你们算是什么关系？（一句话定位）
6. 你们关系怎么样？他对你好吗，你对他呢？
7. 他遇到事会找你吗？你遇到事会找他吗？
8. 你们吵过架/闹过别扭吗？怎么和好的？
9. 你觉得他这人最大的优点和最大的毛病各是什么？

### C 档 · 日常与喜好（熟人门槛）
10. 他平时最喜欢干什么？有什么雷打不动的习惯？
11. 他的口头禅是什么？学一句。
12. 他最近在忙什么？（科研/保研/这个小镇——NPC 口吻版）
13. 他喜欢吃什么、讨厌吃什么？
14. 他熬夜吗？作息什么样？

### D 档 · 只有亲密的人才知道（压轴，生人勿近）
15. 说一件只有你们几个才知道的他的糗事。
16. 他有什么小毛病/怪癖，从来不对外说？
17. 他真正开心的时候是什么样？真正低落的时候呢，谁能看出来？
18. 他有没有什么一直想做但还没做的事？
19. 如果只能用一句话向陌生人介绍他，你会说什么？
20. （彩蛋题）他有什么事是连他自己都不知道你知道的？

## 三、玩法形态（建议）
- **闲聊模式**：走到 NPC 面前按 E，从他答过的问题里选着问；没录入答案的问题，NPC 用性格化的话术挡回去（"这个啊，你得自己去问他"）。
- **考验模式**（可选）：把 C/D 档做成"你有多了解托马斯"问答，访客答题、NPC 判分，成绩进戳册/点亮进度——和 PLAN 既有的"昵称关系问答"是一回事，正好落地。
- **边界**（PLAN 已定，沿用）：问答允许跳过和不再提示；答案按游戏昵称口径提供；不承诺昵称无法关联现实身份。D 档内容上线前 Thomas 逐条过目，只有他写进本库的才进游戏。
