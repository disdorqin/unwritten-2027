## 验收连续性

- 旧镇 A4 仍是回归基线。Muse 已独立走通酒馆二楼长凳和纪念馆露台外梯，并在 [PR #1](https://github.com/disdorqin/unwritten-2027/pull/1) 更正。酒馆从东梯上到北端再西转，纪念馆从西门出露台向南下梯，穿前庭回正门。
- P1 测原坐标和新区接缝。P2 按原址验新立面、门洞和楼梯。P4 用 [Muse 四机位旧图基线](交流区/Muse/性能基线-ea3548b.md) 做同机位对比。广场和纪念馆旧版三角形超 150 万，即使旧版 draw calls 至多 234，扩图也要随同时分块剔除、地标批绘与按街区加载。
- 现镇和外扩地共享同一个 `town-blockout.html`。模型概念落位与可玩的建筑、过山车成品按各自工作包验收。
