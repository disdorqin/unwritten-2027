# ZB-42 · 雪地追踪（窗 B 系统主建；地表件已由窗 C 登记入仓，批10）

来源：《设计-精选三案实现规格-2026-11-21》案三（Thomas 2026-11-21 圈选），本单为其施工转写，口径与源规格一致。定位：把景物册的足印装扮件升级为可玩的实景引导——新雪起链、步行跟踪、断点接续、望见窝点，全程无 UI 标记。排位：坑山专攻期间列候补·预挂，ZB-41 完工后由窗 B 续领（ZB-41 单尾「完工即领」已登记）。

## ①落点（物种×区域定表）
狐——B4 西北缘（狐狸洞，第八版已上线）；兔——古松林缘；獾——B1 东北野地溪岸；羊（野山羊）——B3 山裙上沿；鸟群（雪雁）——镜湖南岸芦苇荡（第八版已上线）。每区一条链的起点带（区缘）＋终点窝点，链长 150–300 m。

## ②场景构成
足印链（实景贴花，非 UI 标记：兔＝Y 形跳印、狐＝直线小印、獾＝五趾拖印、羊＝双瓣印、鸟＝三趾印＋羽痕）、次级痕迹（树干爪痕/蹭痕、粪粒、啃过的枝条、窝点本身）、窝点（狐洞 3 处预置轮换；兔的凹窝；獾洞；羊的背风石窝；雁的芦苇深处巢）。地表件（足印贴花五式、窝点五处、次级痕迹件）已由窗 C 登记入仓（批10），本单只建规则与状态机，不重造地表件；缺件回执登记，不许自补建模。

## ③玩法流程
1. 触发：ZB-20 天气出「新雪」后，各区缘随机起 1–2 条新鲜链（全服同源，链头有小未偶尔驻足盯看的软线索）。
2. 跟踪：玩家沿足印步行跟进；足印新鲜度随游戏时衰减（边缘由锐转糊），大风提前吹散暴露段。
3. 断点三类，须用真办法接续：①过冻溪——对岸偏置处续印，要自己找；②针叶林地——印变淡，须慢走（潜行键）贴近才显（与地下慢走潜行同一输入）；③石砾带——无印，靠次级痕迹（爪痕/粪粒）指向下一段。
4. 终点：望见窝点与动物一面（动物在玩家进入其警戒距前逃离，只给望见——地面和平红线，不可猎不可伤）；该物种图鉴页点亮，窝点有一件「藏物」（狐狸藏的亮物：玻璃珠/铜扣/旧纽扣，收集品，进老宅储物箱陈列格）。
5. 链终结：动物搬家（狐洞在 3 处间轮换；其余物种换链路），图鉴页记本次的链长与断点接续数。

## ④交互规格
无专用键——走、慢走潜行、望筒（高点找续印/望窝点）即全部操作；跟丢无惩罚，回链头或等下一场新雪。单人可成；多人同跟同一条链时，藏物只有先到者一份（其余人图鉴照点）。

## ⑤系统结合
ZB-20 天气（新雪起链/大风散链，同源状态机，本案只读不另算）；足印链仍不设任何 UI 箭头与地图标记（故事暗线口径）；小未行为表（ZB-25）加一条：新鲜链头附近驻足（窗 B 在 ZB-25 侧登记）；图鉴物种页五页（文本归图鉴既有口径，物种页名与窝点记述由总控随图鉴批交，本单先挂结构）；藏物接老宅储物（ZB-22 背包/储物箱口径，藏物占肩扛位）。

## ⑥验收
新雪后第一人称跟完 B4 狐链全程（区缘→过溪断点→狐洞），图鉴点亮、藏物入箱；回访见狐洞已轮换；大风日验一条链暴露段被吹散、靠次级痕迹接上；全程无 UI 标记出现。回执附四齐自查与挂载状态（文齐：图鉴物种页文本待总控批交一项单独标注，同 ZB-41 交班文本例）。
