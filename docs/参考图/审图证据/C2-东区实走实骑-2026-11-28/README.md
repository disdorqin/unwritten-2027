1. 把雪橇包全部构件当碰撞体后，179 站里 170 站被判堵：28m 长的雪槽厚板被方形包围盒当成墙。改为只有 `rail/pole/rune/sock` 竖实体参与碰撞；铺面、甲板、埋地石基保留可见但不再是 blocker。
