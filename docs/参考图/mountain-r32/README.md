## 共用检查
同一用户视角，白天和夜晚，从远、中、近距离观察；脚下实际地面与碰撞对齐，不以图册或独立模型渲染替代正式游戏。视觉可用细纹理/分块实例/局部几何，非全域高密度。外图为参考，不能证明作者使用何种渲染优化算法。
