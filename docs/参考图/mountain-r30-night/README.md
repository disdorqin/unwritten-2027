## 统一视觉要求
- 复用旧图册中的云海与山地材质语汇；自然山脊/冲沟/山裙、雪岩分带和组团植被，禁止整圈悬空路、巨大平面幕墙、均匀重复树木。
- 远处使用低模/组团，近处保留木石细节；真正落地的路基、塔架与屋基。跨域位置取正典锚点。此图册不增加新玩法和新建筑需求，已有设施优先修复接入。
