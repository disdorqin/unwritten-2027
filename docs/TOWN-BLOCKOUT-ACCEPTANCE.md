## 更正记录（2026-11-17 晚，GPT 反驳 → Muse 仿真复验）
复验方法：逐行复刻 ea3548b 版 viewer.ts 语义（supportAt/obstructed/tryMove/stepJump、0.43 m 步高容差、0.27 m 身体圆、掉落物理、滑动回退），按真实帧循环（dt=1/60、步长 0.125 m）驱动；场景按 viewer 同路组装（829 floors / 3 ramps / 1,893 colliders + 四层 blocked）。脚本与逐腿数据在验收方工作区 `reports/route-disputes-recheck.md`。

1. **酒馆 2F 长凳"退化"——撤销，原结论错误。** GPT 定案路线（东梯 → 北端 → 西转 → 长凳）去程 6 腿 + 返程 6 腿仿真全通，脚高 16.90 → 21.40，下行无坠落；长凳触发点（tavern-activity.ts:15 换算世界 [154.19, 229.64]、ground 21.4）与路线终点距 0.01 m。原探针错在：酒馆模型经 `tavernModelToPlot` 横向缩放（sx = 22/17.7），楼梯 20 级踏步实际位于 E164.282–166.147；原探针沿 E163.7 攀爬，身体圆西沿距踏步西沿还差 0.312 m，全程未压到任何踏步，脚高始终 16.90——探针一直在**一楼**，其在 [163.0, 233.9] 测得的"向西 0.00 m"是**一楼吧台隔断**所致（复验在同点同脚高重演 8 秒，移动 0.00 m，与原测量逐字吻合，只是归因错了）。教训：无头 HUD 不显示脚高时，探针结论必须先核对模型缩放与脚高再下判断。
2. **纪念馆 2F 露台"回程存疑"——撤销，推论不成立。** GPT 七点路线（西门 → 露台中段 → 缺口平台 → 外梯底 → 前庭 → 正门 → 一楼）逐腿仿真全通（30.65 → 24.96 → 25.28）。外梯确实存在：`landmark-museum.ts:78` 的 `addStairs()` exterior flight（世界 E307.75–312.25、N256.05–265.20、y25.03–30.65），南栏开口在 `museum-terrace.ts:136-137` 且与外梯轴线对齐。我方初版的事实陈述"terrace 文件里没有外梯"本身没错，但据此推论"回程存疑"是检索范围过窄（只查了一个文件）导致的错误结论。
