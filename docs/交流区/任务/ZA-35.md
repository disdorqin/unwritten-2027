# ZA-35 · 独立客栈（总控 2026-11-21 立书，分区一登记）

状态：未领（立书·候规格批）

## 立书缘由（总控裁定，2026-11-21）

全镇待客是开镇前提——朋友们来过年，不能全挤共享屋。客栈**另立书建独立建筑**；现共享屋代行状态登记为「**兼营·临时**」，独立客栈落成后兼营登记撤销。修订单-03 C 级第 3 条（客栈缺位登记）由此结案转本書。

## 目标

一座独立客栈：生人落脚点，与老宅「自家」相对——大堂/客房/灶间三件齐，迎客动线顺。

## 已知约束（先行，规格明早补全）

- **选址候选：汽车站旁**（总控口径：迎客动线最顺——下车即落脚）；最终落位以总控明早规格为准，落位前过 clearance 全断言（街道/铁路/住宅区/水面）。
- **规格（间数/层数/三栏细目）由总控明早随批一并出**，本文件先行登记，窗口不得凭本页开工。
- 三栏齐备（前言附一）：活人层玩法（投宿/堂食）/ 灵魂层痕迹（留白候规格）/ 故事线接口（白晓棠守站线相邻、车票「留位」母题隔站相望）。
- 色板九色正板 + 《民间色组变体表》（候裁）登记范围内变体；第一人称动线；构建/定向/挂载自审三件套。
- 兼营衔接：客栈落成并挂载之日，共享屋「兼营·临时」登记撤销（由落成窗口在 ZA-04 登记行追记）。
