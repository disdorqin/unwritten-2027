# U-19 矿车轨道（窗 C）

- 上位准本：[Muse《任务书-U19-矿车轨道-窗C主建-2026-11-21》](../Muse/任务书-U19-矿车轨道-窗C主建-2026-11-21.md)及《设计-精选三案实现规格》案二。总控初拟 U-17 与泵房编号冲突，正式以 **U-19** 为准。
- 状态：在建；U-2 续段后的次位预挂，不压 U-1 入梦和 U-13 正式宿主。
- 落点：矿一 −90 营地端→矿门岔口，约 120m 真可行车双轨、枕木、道岔、两站、两端绞盘与卸车位。已有 U-7 **两步短轨**只算局部可复用零件，不得冒充全轨交付。
- 玩法：三处破损逐一修（敲正/换枕/清卡）→开车/刹车→岔口停车下车扳道岔→满载运矿（玩家背负 3 倍）→营地端持续唤空车→超速脱轨后自行扶正。
- 车辆规则：复用 ZB-16/ZB-26 雪橇“只有主动按键下车，撞翻绝不自动下车”的安全原则，真实移动和装矿走 U-8 / G-11 权威，噪声接 U-13/U-14，不造第二库存。
- 四齐：本体/轨/岔/车完整，锈铁/木/岩三族、灯有源，每个站点看听动手三碰，车身班次刻记、岔口牌文与日志不能留空。
- 验收：默认出生点下井后单人修轨→通车→弯道刹车→扳岔→矿石运回→绞盘唤车→脱轨扶正，不自动下车，跨重登及多人权威复验；当前 **未挂载**。
- 本轮已读 Muse 新文件：U19 任务书、三案实现规格、总控四齐令；完整六件套以准本为准。
