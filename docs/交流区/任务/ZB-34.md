# ZB-34 · 雪堡攻防战（窗 B 规则主建，窗 A 场地件）

来源：《设计-交互玩法八案-2026-11-21》案三，Thomas 2026-11-21 批准。本书按设计书六件套格式出单。链：ZB-33 完工即领本单；本单完工即领 ZB-35（第十三声跑图，总控另行出书）。

## ①落点
全图自由形态（Thomas 2026-11-19 裁定：取消正式模式与开局/截止，全图任意位置堆雪打仗）。另设官方演练场两处，仅作场地平整与界桩、不限定玩法：镜湖冰面北段、广场东侧空地。

## ②场景构成（窗 A）
- 演练场界桩一圈＋记分牌 1 面（复用雪仗榜的榜面与广播）。
- 「金铃」道具：小号版大金铃铛，可抱持——抱铃转向半径 ×1.5、受击 2 次掉落、3 秒后可再抢，与镜湖冰上夺宝同一套判定，两处共用代码，不另写一份。
- 堡体无预制件：全由玩家用现行雪墙系统现堆现拆。

## ③玩法流程
1. 布防：攻守双方各在自家区域堆堡、藏铃，无时限；双方队长在记分牌按 E 确认「开战」。
2. 攻防：夺得对方金铃并送回本方记分牌 ＝ 1 分；守方守满 10 分钟 ＝ 守方 1 分。
3. 结算：先 3 分胜，成绩入雪仗榜广播。
4. 单人模式：对面堡由雪人队守（接 ZB-29 行为层：雪人抱团守铃，被雪球命中 2 次「散架」出局本局）；玩家单人任选攻或守。红线：地面永远和平——全程是节庆打闹，无血条、无伤害数值、无淘汰惩罚出局（「散架」仅限雪人）。

## ④交互规格
- 操作零新增：堆墙＝现行雪团系统（放一块花 3 团、叠高 3 层、堵门堵路口禁放）；投雪球＝现行雪仗规则（命中计分/击退）；拆墙＝雪橇撞墙分档（<8 / 8–15 / 15–22 / >22 m/s → 0 / 1 / 2 / 全层），全部沿用现行口径，不改一行数值。
- 开战/计分/结算只经记分牌 E 互动完成；任何显示模式不弹卡（ZB-21 口径）。
- 状态（服务器权威）：布防/攻防/结算三态挂记分牌 id；断线玩家按现行雪仗口径处理，本局不作废。

## ⑤系统结合
- ZB-27 雪墙/雪团、ZB-16 雪橇、镜湖冰上夺宝判定、雪仗榜：四套既有系统拼装，本单只写对局状态机与记分牌对接。
- ZB-29 雪人行为层：单人模式守方；ZB-29 未落地前，单人模式以静态雪人靶＋铃架占位跑通双人全流程，守方行为留接口后补（回执须写明此项状态，不许含糊报全完工）。
- ZB-20 天气：大雪档的能见度即天然难度，不另设规则。
- 图鉴：新增「雪堡攻防」条目，首胜点亮。

## ⑥验收（第一人称实走）
- 双人实测一局全程：布防 → 开战 → 夺铃 → 送回计分 → 结算上榜，逐环见证。
- 雪橇撞墙拆层任选一档复验；抱铃转向/掉落/再抢三判定各验一次。
- 单人模式开一局，雪人守方状态如实报告（已接行为层/占位）。
- 回执附：对局记录、记分牌登记、四齐自查行（形/饰/互/文）。
