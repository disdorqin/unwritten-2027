# ZB-33 · 环镇雪橇大奖赛（窗 B 系统主建，窗 A 赛道件）

来源：《设计-交互玩法八案-2026-11-21》案一，Thomas 2026-11-21 批准。本书按设计书六件套格式出单（总控首拆，后续八案拆书以此为模板）。链：ZB-31 完工即领本单；本单完工即领 ZB-34（雪堡攻防战，总控另行出书，分区一可按本模板先拆）。

## ①落点
环镇一圈，起点/终点＝广场东缘雪橇架旁（现有架位）。赛道走向（沿现成地形与路网，不新开路）：广场 → 北路 → 山口 → B3 山裙缓坡段 → 西行至陨石坑沿隆起环外坡（ZA-34 地形件，先用现地形占位跑通，隆起环落地后只改门位高程）→ 南下镜湖东岸上冰 → 镜湖冰面横穿 → 古松林间道 → 回广场。全程约 1.6–2.0 km，标定单人完赛 3–5 分钟。

## ②场景构成（窗 A）
- 起点拱门 1 座（木构＋红绸＋铜铃，镇节庆制式）＋出发雪橇架（复用现有架）。
- 检查点光门 10–12 座：双木柱＋横梁＋小灯笼对；未开赛时是路边木架（不发光、不违和），开赛后本圈待过之门亮暖光、已过之门转绿——全为实景物，无 UI 箭头、无地图标记。
- 冰面段两岸各 1 座引道门＋防撞雪垛列（软碰撞）。
- 终点与起点同拱，反向冲线判定。

## ③玩法流程
1. 玩家在起点架取橇、上橇即待发；穿过起点拱门自动开赛（计时起）。
2. 依次穿光门，漏门＝本圈无效（已亮之门不倒扣，可从下一门续跑但成绩记「未完赛」）。
3. 冲线停表：成绩入个人最佳＋全镇榜（复用雪仗榜的榜面与广播机制，榜挂集市口）。
4. 第二次起：自己的最佳成绩生成「幽灵橇」陪跑（半透明、仅本人可见、无碰撞）。
5. 多人同场：真车同跑，碰撞按现行雪橇规则（不打人、不下车，ZB-16 口径）。

## ④交互规格
- 操作零新增：上/下橇、加速、刹车全用 ZB-16 现行键位；开赛/过门/冲线全由穿门触发，不设按钮。
- 状态（服务器权威）：待发/赛中（已过门序）/完赛/未完赛；断线＝本圈作废（不惩罚），橇按现行规则留在原地。
- 幽灵橇数据：个人最佳圈的轨迹采样（1 Hz 位置＋朝向），存服务器按玩家 id 一份，跑完即覆盖更优圈。
- 天气联动：ZB-20 大雪档赛道冰面段摩擦按现行冰面参数，不另设规则；夜赛可跑（光门暖光即路引）。

## ⑤系统结合
- ZB-16 雪橇物理与上下橇：原样调用，不改一行手感参数。
- 雪仗榜机制（窗 B 既有）：榜面数据结构与广播文案套用，新增「大奖赛榜」一面。
- 图鉴：新增条目「环镇大奖赛」（首次完赛点亮，记个人最佳）。
- ZA-34 隆起环：门位高程以 `grid.heightAt` 采样，隆起环落地后自动贴合，不写死高度。
- ZB-21 显示模式：任何模式不弹卡；成绩只在冲线时以一行近场提示＋榜面呈现。

## ⑥验收（第一人称实走）
- 全圈实跑一圈：开赛、逐门变色、冲线停表、成绩上榜四步逐一见证。
- 第二圈见幽灵橇同行且无碰撞；故意漏一门，本圈判未完赛且可续跑。
- 夜里（夜钟相位）跑一圈，光门路引可读。
- 回执附：全圈用时、门数与门位表、绘制账（光门＋拱门新增 draws/tris）、四齐自查行。
