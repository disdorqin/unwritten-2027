# ZB-35 · 第十三声跑图（窗 B 系统主建，分区一锚点装扮）

来源：《设计-交互玩法八案-2026-11-21》案五，Thomas 2026-11-21 批准。本书按设计书六件套格式出单。链：ZB-34 完工即领本单；本单完工即领 ZB-36（冰雕敲制，总控另行出书）。

## ①落点
五个锚点，全在地表、夜窗内可达：钟楼下（广场）/ 镇公所星石环 / 镜湖冰心 / 山口 / 陨石坑口。每锚点设一圈锚点环（小石环＋一圈矮灯，属分区一夜间回补的暖光链点位，白天是普通石圈摆设）。

## ②场景构成（分区一装扮，B 接线）
- 锚点环 ×5：石环直径约 3 m，矮灯 6 盏环列；未激活时灯灭、石环如常。
- 激活态：当前目标锚点的环灯亮起暖光微闪（全镇锚点里只有「下一站」亮，靠光找路，无 UI 箭头、无地图标记——故事是暗线口径不变）。
- 完成态：本夜已点亮的锚点环灯转常亮，留到天亮晨钟熄。

## ③玩法流程
1. 夜窗开启（第十三声响起）后跑图自动可玩：本夜的锚点顺序由信标同一份漂移时刻表导出（环序固定：钟楼→镇公所→镜湖→山口→坑口，起点随夜数轮转，公式与 ZB-17 共用一份，不许另写第二份）。
2. 玩家以雪橇/步行赶往亮着的锚点，站进石环按 E ＝ 点亮，转下一站。
3. 摸错锚点（走进未轮到的环按 E）：刚点亮的那一站熄灭，退回一站重跑。
4. 天亮晨钟前点齐五站 ＝ 完赛：全镇广播登记（复用雪仗榜广播），五环常亮至晨钟；没跑完不惩罚，进度随天亮清零，明晚再来（错过就错过口径）。
5. 单人可完赛：站间距离按雪橇常速标定，全程约 2 分钟，夜窗约 3 分钟留容错。

## ④交互规格
- 操作零新增：移动用现行雪橇/步行，点亮只用 E。
- 判定（服务器权威）：玩家 id × 本夜状态（已点序/当前目标）；多人同夜各跑各的进度，互不可见对方的目标灯（个人显示，ZB-21 口径）。
- 山口、坑口两锚点依赖 ZB-28 夜班守卫缺席才可达——白天锚点环在，灯不亮、E 无反应，不做时间锁（拦人的是人，不是墙）。
- 与钟楼调查三步的关系：跑图是信标之上的游戏层，不替代「听/守/验」旗标；但完赛一夜计入图鉴信标页的旁注（见过锚点全亮的人）。

## ⑤系统结合
- ZB-17 信标事件：时刻、相位、漂移全部取现行共享时刻表（第九版起已 live 开机）；本单只消费，不新造时钟。
- ZB-16 雪橇 / ZB-28 守卫夜班 / ZB-21 显示模式 / 雪仗榜广播 / 图鉴「第十三声」页。
- 分区一夜间回补：五处锚点环即回补清单里的暖光链节点，两边对齐点位一次施工。

## ⑥验收（第一人称实走，须夜里走）
- 等一个完整夜窗实跑：按序点齐五站，见逐站转常亮＋完赛广播。
- 故意摸错一站：上一站熄灭、退一站，复验。
- 白天到任一锚点：E 无反应、灯不亮。
- 回执附：本夜顺序与夜数对照（验证起点轮转）、全程用时、四齐自查行。
