# ZD-06 · 轨道舱五舱与太空门概念图

状态：未领 · 窗 D · 六张分镜已整理，首批待网页端出图。

依据《任务总表》《主窗口令-细节补充一》《风格打造规范-粘土工厂味》《设计-天空之城》。五舱的视觉锚沿用《任务书-轨道舱五舱细化》，船徽参照《工包-S-11-未央号船徽与舱内标识》。五舱只做概念图。图批分段交分区二编号，由总控与 Thomas 过目后锁图。

地盘：本工单与窗 D 概念图交付目录。城顶门取 ZD-05 已验模型，天层由《设计-天空之城》定版。云海台星港坪用于装配和起飞。

统一镜头：平视、复古低多边形大面、16/32 像素颗粒纹理。轨道舱设备与个人物品保持过度整齐，灰蓝压暗，分开小范围火光橙与晶辉青光池，光清楚照到辨识物。画面只出现船内需要的铭牌和徽记。百年广播的运转感由仍在工作的扬声器与两类状态信号体现，广播词留给太空章。
