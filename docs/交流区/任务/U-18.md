# U-18 篝火远征链（窗 C）

- 上位准本：[Muse《任务书-U18-篝火远征链-窗C续单-2026-11-21》](../Muse/任务书-U18-篝火远征链-窗C续单-2026-11-21.md)及《设计-交互玩法八案》案八。
- 状态：在建；尾链 U-17 之后施工。U-12 单独回血圈已被分区二裁定退役并吸收到 U-13，不得新增平行火圈算法。
- 落点：地下各层经移动权威认定的平整地面；固定 U-2 营地为首点，其他前进营地为玩家自选点，不使用评审随意坐标。
- 玩法：备柴/拾火种→手动建营→点火 8m 安全区→添柴保持→火弱、熄火后停止回血与驱怪→残烬复燃，营地链为下潜风险决策支点。
- 规则复用：只向现有 U-13 `fireAt` 与“火圈拒刷怪”权威注册火点，单一共用火状态机复用 U-16 勇士城炉火，库存/半矿损失遵照原账本。
- 场景：火塘、坐位、备料堆、营地文字牌、先人残烬、投影火光成簇，不能空房硬标完工。
- 验收：第一人称建营→防刷怪→回血→续柴→熄火失效→复燃，含多人共享快照、构建与四齐；当前 **未挂载**。
- 本轮已读 Muse 新文件：U18 任务书、U12 收口裁定、总控四齐令；细节见设计准本。
