# ZA-36 山体连通与陨石坑（窗 A · 队首，序：ZB-28 挂载 → ZA-36 → ZA-34）

立书：总控 2026-11-21。起因：Thomas 2026-11-20 夜亲测两条实感——①往山上走撞空气墙，镇与山不连通；②陨石坑又大又秃、毫无装扮，且一到附近帧率明显掉。两条都是实机结论，不待复验。

## 基线状态（开工前必读）
- 镇场景里的前山是**视觉壳**（town-front-ridge-proxy，冠位北移约 90 m、非真地形，ZA-30 接管包），真前山地形在缆车域场景；两域接缝从未修成可走路线——这就是空气墙的来源。
- 陨石坑本体与绞盘/井口在仓（ZA-31 线），坑内装扮密度远低于标准；坑口性能从未实测过。
- 本包与 ZA-34（地形起伏）的关系：连通先行，起伏后铺；本包若动到北带高度采样口径，须在回执里明示与 ZA-34 的衔接点。

## 一、山体连通（镇 ↔ 前山）
- 目标：第一人称从广场出发，经山口、山裙（B3 带），步行抵达前山山脚带，全程无空气墙、无浮空、无穿模。
- 跨域只许发生在设计关口（山口/缆车下站），用既有转场包装（「醒」口径）；关口之外不许出现隐形阻挡。若某段现行实现是硬边界，先报总控裁定改法（扩地形 / 设关口），不许自行围墙了事。
- 视觉壳与可走地面的关系必须自洽：玩家能走到的地方不许只剩壳面；壳的南趾与山脚带地面衔接处做过渡（碎石/雪檐遮缝），不许露出悬空边缘。
- 与 ZB-28 守卫口径联动：山口守卫拦的是「人」，不是墙——夜里无人时路线本身必须通。

## 二、陨石坑性能
- 先测后修：在坑沿、坑底两点位实测帧率（对照广场基线），把吃帧构成测清（装扮件数/绘制调用/粒子/光源数）写进回执，再动手。
- 手段按性能纪律：实例化、同簇静态合并、远近分模；不许靠删内容换帧率——装扮只增不减（见第三节），性能靠结构不靠削减。
- 验收线：坑沿帧率不低于广场基线的 80%（实机感为准，数字为参考线）。

## 三、陨石坑装扮（本包重点）
- 标准：装扮密度 ≥ 老镇同面积 2.0 倍、**成簇**分布（密度标准本就源于坑的教训，本包是坑自己的补课）。
- 内容挂故事钩，逐簇登记：撞击焦土与碎裂岩（坑心）、黑石带（坑沿一圈，镇侧接缝）、绞盘与井口作业面（一代人工程痕迹：枕木、缆绳桩、工具棚残件）、坑壁先人刻痕/绳桩（与攀冰绳桩同系）、蛇石落点周边预装扮（落点表口径，只铺垫不放石）。
- 反全白：同框 ≥3 材质家族（焦土黑/岩灰/锈红/木构棕/晶辉青择用）；雪只作底。
- 红线：坑底不放散落船件残骸（残骸梯度口径：地面集中在冰晶宫，坑内只有撞击与工程痕迹）。
