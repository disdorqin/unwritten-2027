# 背景音乐先行施工回执

基线 `2b4505a`，按 Muse《给GPT-急-背景音乐先行》接入全镇底轨。无音频资源、网络依赖和额外绘制。

## 实现
- 32 秒八小节循环。三声部缓起落的和声垫、C 大调五声音阶稀疏拨弦、两秒贴边淡入淡出的风雪噪声。相邻小节垫音短叠，循环回到首小节。
- 玩家首次通过真实手势点第一人称或用「前往」进镇后启动 WebAudio。概览页未进镇时无 BGM 音频图。静音、0% 音量停止新乐句排程，取消静音可继续。
- 可折叠小镇控制面板新增静音和音量滑条，默认 32%，使用 `unwritten.town-bgm.v1` 保存两项偏好。音量与渐静用淡变。
- 室内沿用墙顶遮蔽检测与屋舍状态，最快每 180 ms 判一次；同一音频图仅渐变低通 3900→1150 Hz、主增益乘 0.82，出门恢复。乐句用 270 ms 的低频前瞻排程，与帧渲染分开。

## 自检结果
- Windows Chrome 本机实开浏览器，页面初始无 BGM，点「第一人称」后 WebAudio 运行。主输出节点 PCM 分析器测得默认音量 RMS **0.00810**、峰值 **0.02018**。静音衰减后 RMS **0.00000569**。
- 进入酒馆实际站位后，低通由 **3900 Hz** 降到采样时 **1250 Hz**（目标 1150 Hz），主增益趋近 **0.262**。回到室外恢复约 **0.32**、低通回升，音频上下文数量保持一致。刷新后静音与 **41%** 均保留，按取消静音恢复信号。页面错误 0。
- 14 次排程回调在 Chrome 主线程 **均值 0.028 ms，最大 0.150 ms**。该读数只覆盖合成调度 JavaScript，音频渲染线程未单独量化。
- BGM 模块与 viewer 单入口严格 TypeScript 通过，town-preview 构建通过。全量 Node **144/144**、服务端 **22/22**。
- 已验证数字音频信号。实体扬声器、耳机与手机的真人听感待实际试听。
