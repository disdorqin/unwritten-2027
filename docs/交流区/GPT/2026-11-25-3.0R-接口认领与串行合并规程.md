# 3.0-R 接口、认领、审核与串行合并规程（第一轮提案）
继承现行 11-21 多人并发规范及 11-24 二八定律；历史工程指导里的“自审自并/全量每包”与更新规范冲突时取总控唯一合入、日常定向检查。基线 23a36fd5。总控接纳后执行。
## 接口冻结最小集（名称为提案，不另起平行权威）
I1 地形：A 发布现有 grid/terrain surface 的扩展契约，D 发布山脚交界边界折线、采样、世界变换和路基剖面。输入 east,north,当前支撑高程/域、移动类型；输出有效支撑高程、surfaceId、法线/坡度、可达性、已就绪标记。具体 TS 类型由 A/D 基于原接口核对后钉版。一个 surfaceId 区分重叠道路层，不以无限高 hint 选择脚下。渲染 LOD 不改变碰撞正本。共享边坐标及高度一致；锚点用原正典 ID。
I2 坑井/地下：A 供坑沿与地表锚，C 供井口/凭证/进入与返回点及房间变换；C2 只消费 C 发布的锚、层界、碰撞和水位契约。现有 -140 注册 4b6b866b 复用，禁止另建。A 不挪井口锚；真需挪动由 C/A 一次协调。
I3 山/天：D 供星港坪、绝顶、缆车、飞行起点和云海归点；D2 供天空域接驳台、安全落脚、离岛与回归锚；C/B 只消费。B 用原旗标做材料和飞行器状态；坐标/域编码由 A/总控单写接线，严禁截断或绕过权限。
I4 故事：B 唯一规则/事件 ID 表、前置条件、多人作用域（全镇共享/玩家个人）、存档与重连、NPC 台词 ID；C、D2 提供触发场景锚。共同信标仍读 town-night-window，严禁复制公式。世界域时间和梦境时间分离；梦境一次性权限按正典，若多人不同进度共域如何呈现由 B/总控裁定（默认提案：个人已梦醒持久化，独立梦实例/按玩家状态呈现，不能全服一人完成就锁死所有玩家）。
I5 天气：B 提供时间连续光照权重、风雪、温度/寒冷暴露及庇护接口；A 单写 viewer 接入，D/C2/D2 各场景只消费。夜窗业务状态不随视觉插值漂移；地下恒暗/天空梦境独立，回归重新同步。
## 不互等
每接口发布一份短契约（编号、owner、基线、函数/事件字段、坐标、示例、验收），不等完整实现。生产锚待确认时，使用标记明确的测试 fixture/adapter 在自有预览做场景，不得提交虚假正式坐标、不得把 mock 当 live。接口供方先交最小可运行叶子；消费方先写自身几何/规则，随后只替换适配器。每卡含无依赖替代任务，遇阻写唯一阻塞记录（所需字段、责任人、当前可做项），继续下一项；不得全窗停等。真正跨文件冲突只暂停冲突子件，保全成果。
## 领地与锁
各自独立工作树，Windows 正式根 D:\computer learning\game_exe\kuanian；不得共用 checkout、强推、删除在飞目录。任务独立文件，按现行认领协议；纠正旧多分支文件锁无法天然原子互斥：总控在集成线/统一认领表串行确认任务编号与公共批，不能以各分支独立 .lock 当已抢占。45分钟租约沿用，活跃工作以回执/提交续租；过期先核实并保留在飞成果。既有锁与新任务冲突先完成或移交，不并行重写。viewer.ts / town-presence.ts / src/presence 协议入口 / terrain.ts 冻结基座由 A/总控公共批单写，其他窗只提交新模块及接线差分说明（具体冻结基座解冻仅总控确认）。C2/D2 不直接修改 C/D 旧文件，移交后才可改显式列表。
## 合并流水线
1. 施工窗 fetch integration、读新裁定，检查自有分支未提交内容；非破坏性同步，禁止 reset --hard/force push。认领并登记拥有/禁碰路径。
2. 独立包完成即 push 自有分支，写最短回执：任务ID、基线/候选SHA、diff路径、接口变动、接线增量及归属、构建/启动/实走/关键FPS、回退/欠账。可独立用的完成件先送；未完工功能默认关闭，不影响旧线上。
3. 配对窗审指定候选SHA与当前 integration 的实际 diff，审领地、正典、生产挂载、视觉、可走性、语义冲突，最多3轮；只审增量，存量缺陷另单。跨域高风险由消费方复核接口；拒绝明确原因和可重现路径，不写长卷宗。
4. 总控唯一合入人按依赖拓扑串行：先接口/独立叶子，后生产接线，再章节；无依赖包随到随合，不因别的章等待。合前确认候选仍是已审SHA且基线变更不破契约；在临时集成候选上合并/挑拣指定提交，不整分支盲合；冲突保双方功能，重新自验。合并后构建+启动0真错误+定向实走（涉presence加编译模拟/真实连接）；异常不推或回退该包。无强推，保持集成线绿色；出新的集成SHA，回填任务、接线状态和发布账。
5. 日常不全量、不重复哈希/大证据，切版前一次全量、presence 编译模拟、裸链接全新浏览器走关键上下行及双玩家跨域、PC/手机性能。总控独自切 town-release/回读 healthz；线上与集成分开报。默认主分支 main 不是现行集成目标，不擅自合 main。
## 质量四态
分支已建 / 已审入干 / 生产接线可达 / live可玩。只有最后一格是产品完成。mock、审查页、离线跳点仅前两格。每轮以真实同机位地形前后坡、坑沿及内部、室内入口、故事交互为准。已审未接线的包总控当轮登记接线所有者，接线不可无限滞留。
