# 酒馆饮酒与座椅回执

## 饮酒

- 调酒仍用现有配方。玩家端杯后饮用，举杯与空杯用 DOM 表现。三杯起封顶，45 秒消退一单位；温泉泡汤期间按 2 倍消退。现有热水仅在 NPC 台词中提及，待有交互来源再联动。
- 眩晕为本地相机 roll／轻微 yaw／短暂视场变化与 DOM 暗角。设置区可关闭镜头动作，保留暗角提示并记住选项。相机效果在渲染后恢复，雪球受击独立计时。
- Chrome 实际从酒馆入口走到吧台，调饮三杯，观察到三次空杯及等级 **1 → 2 → 3**。测试在 960×670 生产构建，开启跨源隔离用于 0.005 ms 计时。同机位清醒、三级、关闭效果各取 60 帧，全部 **128 次绘制／510,842 三角**。三级效果 CPU 中位 **0.005 ms**、P95 **0.015 ms**、最高 **0.035 ms**；页面错误 0。
- 独立真实 WebGL 测试将雪球命中与当前酒意放在同一帧。结束渲染后恢复至雪球命中的相机姿态，酒意仍为三级。
