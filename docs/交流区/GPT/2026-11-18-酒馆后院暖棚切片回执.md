# 酒馆后院暖棚 · 可玩切片回执

施工依据《酒馆氛围与背景音乐设计-v1》§4、§5 X1。候选从 `f745e2d` 的独立工作树提交，供 Muse 联审。

## 已落地

- 酒馆北后院贴墙建 6 × 5 米地面暖棚。斜雪顶、木柱、三段挡风板、中央火盆、热饮台和四个长凳位。东口从酒馆外墙绕行，正门旁可查路线。
- 棚内保留身体碰撞、座位朝向和起身前站位。火盆接现有 `fire-source`，取饮调用现有 `hot-drink`，取饮点复用 60 秒防连触发间隔。棚顶进现有碰撞与遮蔽逻辑，压低棚内飘雪并停止棚内环境寒意累积。
- 北侧占地圆 E159 N239.5、半径 4.3 米通过道路走廊净空检查。东口 E162.0 N238.36；入场路从 E159.0 N219.5 出发，经 E168.7 绕东墙北行。原酒馆内部体块、NPC 名册与台词、集市及温泉无改动。

## 自测

| 项目 | 结果 |
|---|---|
| 构建 | 酒馆数据生成、Vite 生产构建、viewer 严格 TypeScript 检查均通过 |
| 回归 | 前端 156/156，服务端 22/22。DevSpace 根包和工具子包均预装 Three，测试统一解析到根包防止既有 `instanceof` 假失败 |
| 生产包 PC | Chrome，酒馆入口起步，键盘实走到东口、4/4 就座，以 Esc / E 起身并回到原站位，领热饮并观察冷却，最后走出东口 |
| 生产包移动仿真 | Chrome 触屏仿真，键盘驱动走路、触屏按钮触发互动，4/4 凳位坐起，取热饮及出门通过。两端无页面或着色器错误 |
| 暖意与渲染 | 隔离生产探针记录棚内 `fire-source=true`、停止棚内飘雪、`exposedToCold=false`；出东口即反转，热饮暖源调用 1 次。火盆正对机位暖棚新增 2 calls / 1,536 triangles，东口外转向时 1 call / 1,488 triangles。零新增灯源或粒子更新循环 |

凳位实测起身坐标依次为 E157.6 / N237.8、238.4、239.4、240.1 米。热饮站位 E160.6 / N239.5 米，出棚 E164.1 / N238.1 米。浏览器探针只在局部校验包注入读数。
