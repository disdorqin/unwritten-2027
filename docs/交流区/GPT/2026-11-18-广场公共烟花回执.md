# 广场公共烟花回执

## 现状审计

仪式批已有广场、湖面、纪念馆方向三个正式发射区和三个 cue。预演与工坊奖励已有一套 Points 粒子池。平时缺玩家可触发的燃放点。

## 施工与实测

- 公共烟花台位于广场南缘 E204/N174。20 个盒子进原广场批次，+0 draws、+240 tris。按 E 选择金红、冰蓝或粉霞，每场 20 秒、15 发。种子确定生成时序、形状和配色，`startShow` 可注入发数、发射点、时长和颜色。仪式三处 cue 与原预演保留。
- 在线由服务端核对站位、90 秒个人冷却及全镇单场锁。以服务端时间加 250 ms 为开演时刻，一次序列化广播主题和种子。迟入不补播，断联可单人播放。共用原单一 Points 缓冲，容量 4,428 点（含工坊余量），141,696 字节属性，仅上传有效段。
- Chrome 146 双浏览器用真实同源本机 presence，在台前按 E 选冰蓝。两端各收到一次完全相同的种子、主题和开始时刻。点击至出现分别 358.5/358.3 ms，配对观测差 0.2 ms（仅回环）。本人再次触发显示 90 秒装填，另一玩家收到单场占用提示，高潮中间进来的第三端未看到补放。
- 同一广场机位 50 → 51 → 50 draws，三角面全程 282,020。离线分别实际选择金红与粉霞，49 → 50 → 49 draws、281,756 tris 不变。GL hook 和 renderer.info 一致，0 页面、Shader 或 WebGL 错误。实体手机与公网延迟未覆盖。
- Node **133/133**、服务端 **22/22**、服务端项目 TypeScript、viewer 严格 TypeScript 单入口检查和 town-preview 构建通过。

共享时钟由连接下发和周期校准建立，供列车班次复用。现有二进制 pose 未加字段。
