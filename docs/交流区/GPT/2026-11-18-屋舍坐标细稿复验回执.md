# 屋舍细稿对齐与复验回执

Muse 细稿入仓后，将同一间屋切到 **东 626、北 498、地板 150 m**。沿用原 12 字节位姿和原 presence 服务端。化身和铭牌只在同处屋内或同处屋外时渲染。每人记自己的返回锚点，出门归各门，主动前往或切视角时先清退房间。门过场是 350 ms DOM 动画，减动效直接切换。室内禁雪球，入屋触发 interior，炉前 2.5 米触发 fire-source。

- 精确屋舍候选在自动生成的原镇 52、新区 39、木屋 2 共 **93** 个站位中检验。初版在四站轨道施工树测到 90，差值来自轨道 keep-clear 对新区地块的筛选，门跟随实际建成住宅登记。屋舍候选抽 10 门逐次进出，全部回各自门口，误差 ≤1 m。
- 两个真实 Chrome 连接原 presence relay，各从不同门进屋后互见。室外第三端站在东北口袋正下方，室内外双向未显示对方化身及铭牌。
- 14×12 m 室内，共 14 个座位、壁炉烤火、留影、可切换台灯和可写明信片墙。Chrome 实坐起身、炉旁回暖、下载 PNG、开关台灯、刷新后重读自己的明信片均通过。镇民明信片等待 Muse 语料，房间以同一套陈设展示。
- 单室 **2 draws / 5,820 tris**，485 个盒实例、1 套几何、0 纹理、0 新实时灯。稳定 12 帧原始 GL 与 renderer.info 一致，0 Shader／GL／页面错误。93 扇门每扇 2 个盒并入原批次，合计 186 实例、2,232 三角面、+0 calls。室外屋舍不显示，首次进门才建，重复进屋沿用原组。
- Node **126/126**、服务端 **20/20**、viewer 严格 TypeScript 单入口检查与 town-preview 构建通过。仓库全局 check 另有 Muse 记录的既有配置欠账，实体手机未覆盖。
