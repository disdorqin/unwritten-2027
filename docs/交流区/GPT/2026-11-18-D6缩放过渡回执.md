# D6 缩放过渡回执

基于 `1ac0850` 与只修文档的 `4288f10`。本批独立生产构建 `--mode town-preview`，未并入年味、温泉或住宅改造。D6 路径仅优化航拍过渡带的提交。步行、室内、原有全景切换阈值、可见距离、材质与互动沿用既有路径。

- 详细地形共享原三角顶点、法线、颜色和积雪数据，用 4 米小块做保守视锥判断，地形过渡帧集中为一次索引绘制。典型过渡机位地形由 69 次 / 565,248 三角降至 1 次 / 459,872 三角。逐一枚举全图 655,360 个三角，保留原索引顺序或证明三个顶点在同一视锥平面外。静止相机复用已计算索引。
- 静态实例保留原坐标、纹理 UV 和面法线。按同材质合批，仅跳过已在视锥外的实例和 GPU 原本会剔除的背面，包括验证过的圆柱盖。静态地标只剔除可证明背向的三角。透明、动态以及自带实例属性或自定义着色器的实例走原路径。

## 同口径 Chrome WebGL A/B

1280 × 720，滚轮每步 120 单位，放大与缩小各 36 步、每步采两帧。比较同一产物 `?profile=1&viewBatches=off` 与 `?profile=1&viewBatches=on`。同时抓取 WebGL 底层调用和 Three 统计，各帧一致，0 页面错误。两项范围最大值可能来自不同帧，同帧数据单列。Muse 第四轮另测 519 次 / 2,094,278 三角，滚轮方案不同。

| 采样 | 改前 draws / tris | 改后 draws / tris |
| --- | ---: | ---: |
| 放大全程最大值 | 421 / 1,857,032 | 277 / 1,489,670 |
| 放大过渡第 14 步首帧 | 415 / 1,780,604 | 237 / 1,135,441 |
| 缩小全程最大值 | 549 / 2,172,114 | 279 / 1,489,670 |
| 缩小第 24 步首帧，相机高 246.46 米 | 549 / 2,172,114 | 279 / 1,472,898 |

本采样的提交数与三角数达到 ≤300 / ≤1,500,000。独立工作树小镇严格 TypeScript、生产构建和 Node 80/80 + 服务端 13/13 通过。

待联审复查不同滚轮速度、低配真机及后续批次合并后余量。本轮无头浏览器的滚轮帧间隔 p95 由约 16.7 ms 增至 25.0 ms，索引上传和分批准备有 CPU 开销，需要浏览器真机复测，暂未签核帧时间指标。
