# 窗 C · F-7 雪翼与助推器

工包交件包含两项可独立实例化的体素资产。源码 `tools/voxel-tavern/town-blockout/flight-equipment-visuals.ts`，调用 `createSnowWingVisual()` 和 `createFlightBoosterVisual()` 分别取得场景组、挂点、实测包络及释放方法。原稿索引列出的《飞行系统与飞行器细化-2026-11-19.md》在所读集成、窗 C 和本次可见 Git 路径历史未定位。体素局部尺寸据已入仓的工包和任务书登记为本次美术施工值。

## 两件资产

| 资产 | 体素构成 | 包络宽 × 高 × 深（m） | 实例 / 三角形 |
|---|---|---|---:|
| 雪翼 | 对称收窄的六段浅蓝帆布翼、翼骨与包边、双手杆、腹部助推器卡座 | 3.800 × 0.5835 × 1.454 | 119 / 1,428 |
| 散件助推器 | 陨铁层叠壳、星尘色窗格、顶插键、两处后向凹入喷口 | 0.863 × 0.410 × 1.050 | 42 / 504 |
| 挂接示例 | 插键上表面碰齐雪翼卡座底面，喷口位于翼缘之后 | 3.800 × 0.8315 × 1.564 | 161 / 1,932 |

包络由 Three 实例矩阵逐件合并，再用 `Box3.setFromObject` 对照。每资产使用一个带顶点实例颜色的盒体批次，材质受宿主灯光，星尘色来自材质。

## 验收

- 定向 `node --import tsx --test tests/town-blockout-flight-equipment-visuals.test.ts` 通过 5 项，覆盖实际包络、翼尖包边内缩和双手杆、两个喷口及卡合、资源独立和重复释放。
- 严格 TypeScript 对模型和定向文件均通过。共享树同时装根与预览各自的 Three，验收用资产自己的对象类型和矩阵，避免跨版本构造器误判。
- 同窗使用 Chromium 153 的 WebGL 2 渲染单件雪翼、散件助推器、挂接组合和挂点登记，共复拍 8 张。挂接组合实测两次绘制调用，卡座与插键形成 1 对接触，部件间无体积穿透。临时验收工程原件为 `f7-browser-audit/captures/` 的 PNG 和 `f7-browser-evidence.json`。
- 浏览器初检看到近侧翼尖和阶梯前缘的共面斑点。每段前后包边各侧内退 2 mm，白色翼尖装饰向内移 2 mm。修后对照同机位 `assembly-side.png`，原斑点消失，翼展仍为 3.800 m，挂点实测保持对齐。
