## 结论

**复现了出生点夜间近似空星空。主峰有实际绘制，背光坡面与天空对比过低。** 出生点 HUD E223/N180/Y12，眼高 13.65 m，偏航 0.06965 rad、俯仰 0。识别真实 WebGL 主峰索引指纹 `2706687782`，远裁约 2,400 m，每帧 1 draw / 1,450 tris。对同一个已确认 draw 前后读默认 framebuffer，614×345 画布有 72,991 个像素发生变化，半数以上的画面宽度进入山体覆盖。72,428 像素由天空 RGB (24,38,66) 变为山坡 (15,31,58)，全体变化的最大通道差为 9。深度测试开启，双面绘制，颜色通道正常写入，WebGL 错误 0。原生 WebGL 画布 PNG SHA-256 `2a61201715cdd791bbc6c137913772c29fd5f237ed5244c9f52fd512133d02ac`。

- **(a) 彩排时钟**：固定彩排时间 20:06，端点 200 且返回合法 epoch。清空彩排时间后同一入口返回 404，浏览器走 Presence 回退。两轮均收到真镇域 WS 自己的 join；相机、绘制指纹、72,991 像素及主色对逐项相同，两轮页面异常 0。404 是该组预期负对照。
- **(b) 高度场**：远景粗模顶点与索引从 TypeScript 常量同步生成，画面读回证实静态发布路径可取到并提交。同一程序中雪带 JSON 为构建时静态 import。
- **(c) 场景切换**：默认北望实际提交了镇域的天际线对象，且其平移复算与既定原点一致；山域换组须玩家实际登车，不能解释这一帧。

当前粗峰使用 `MeshLambertMaterial`。夜间背光坡面由低亮度环境散射主导，其解析色与实际读回相符。拟在独立候选上只给镇内远景粗峰补夜间底色，再同机位核夜景、白昼与典礼调暗。修法随公共批和第四版走，线上独立复验仍待发布窗口。钟楼侧板待拿实际现场定位图。
