## 6. 首发部署演练

在独立干净工作树完成 `8cb5265`、`5f95a77` 的依赖安装和构建，正式 Compose 文件通过配置校验并得到对应镜像标签。本机 Caddy 回环服务实跑 `8cb5265 → 5f95a77 → 8cb5265`，三次 `/healthz` 都返回 `town-preview <完整 SHA>`，首页均返 200，回滚后的 HTML、JS、CSS 哈希与起始版本一致。Windows Docker 引擎未运行，容器级 `compose up` 与容器回滚尚未实跑。六条命令已校验 Bash 语法，并用模拟命令覆盖正常上线、构建失败保留旧服务、健康检查失败回滚。

取得 SSH 后，在同一 Bash 会话中整块执行下列六条命令。实时抓取集成分支最新 SHA，先构建再切换。旧容器存在时，先确认旧镜像仍可用，切换或验活失败自动回滚。首发若无现役版本则无旧镜像可回滚。

```bash
(set -eu; cd /opt/apps/unwritten-2027; git fetch --no-tags origin refs/heads/town-blockout-integration; TOWN_RELEASE=$(git rev-parse --verify 'FETCH_HEAD^{commit}'); export TOWN_RELEASE TOWN_PREVIEW_SITE=town.disdorqin.cn
release="/opt/apps/unwritten-2027-release-$TOWN_RELEASE"; if [ ! -d "$release" ]; then git worktree add --detach "$release" "$TOWN_RELEASE"; fi; cd "$release"; test "$(git rev-parse HEAD)" = "$TOWN_RELEASE"; test -z "$(git status --porcelain)"
dc() { docker compose -p unwritten-preview -f tools/compose.town-preview.yaml "$@"; }; current=$(dc ps -q web); previous=''; if [ -n "$current" ]; then previous=$(docker inspect --format '{{index .Config.Labels "org.opencontainers.image.revision"}}' "$current"); docker image inspect "unwritten-town-preview:$previous" >/dev/null; fi
check() { reply=$(curl -fsS --connect-timeout 5 --max-time 12 --retry 10 --retry-all-errors --retry-delay 2 https://town.disdorqin.cn/healthz) && printf '%s\n' "$reply" && test "$reply" = "town-preview $1" && test "$(curl -fsS --connect-timeout 5 --max-time 12 -o /dev/null -w '%{http_code}' https://town.disdorqin.cn/)" = 200; }; rollback() { test -n "$previous" && test "$previous" != "$TOWN_RELEASE" && TOWN_RELEASE="$previous" dc up -d --no-build --pull never && check "$previous"; }
dc config --quiet; dc build web
if ! dc up -d --no-build --pull never || ! dc ps || ! check "$TOWN_RELEASE"; then rollback || printf '%s\n' 'Previous image unavailable or rollback failed' >&2; exit 1; fi)
```
