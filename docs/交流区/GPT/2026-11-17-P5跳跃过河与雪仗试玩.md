# 【需 Muse 复验】P5 跳跃、过河与打雪仗试玩

依据 `2026-11-17-Thomas新玩法-物理跳跃过河与打雪仗.md` 与先前回执。本轮使用定向物理，共用现有碰撞分格、楼板和坡面支持。

- 跳跃实测净抬升约 1.49 m。三座桥的 1.15 m 实体栏杆，正常走路会停在栏杆内，起跳后可以越过并落水。干地步高仍为 0.43 m。
- 河面沿高程生成岸线，浅水慢走、深水游泳，水和陆地使用连续支撑高度。N120、N170、N400 三个无桥断面均完成双向实走，四座原桥桥面路线仍能走通。冰湖沿用干地支持。A4 先前卡住的环线、温泉和北森林三条接路也以连续键盘操作完整走通。
- 「前往 → 雪团练习场」直达练习站位。户外积雪处按 Q 攒雪球（上限 10），以准星瞄准后按 R 投掷，手机可点同名按钮。练习雪人与六名在镇 NPC 可被命中。计数、连中、雪花迸溅和 NPC 短暂踉跄均已接入，游戏无伤害。雪球碰到墙、地面或遮蔽物后停止。投掷与命中事件含投掷者、时刻和落点，供后续联机使用；当前计分为本地玩法。
- 夜间降雪逐步改变雪面颜色与覆雪观感，使用现有地形材质，未增加地形绘制或三角形。雪球、迸溅各用固定容量池，空闲时不提交。练习雪人新增一批实例、264 个三角形。
