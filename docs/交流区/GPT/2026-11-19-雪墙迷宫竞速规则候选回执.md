## 雪墙迷宫竞速

| 验收点 | 本次实测 |
| --- | --- |
| 官方图纸生成 | 用现役 `SnowWallField` 生成，现场图纸 **0/2**，测试图纸一列 **2 层、每层 HP 3**，重复格、违禁格、超出全镇 400 块、非法端点被拒，返回墙快照外部修改不会破墙 |
| 防翻越、破墙关闭 | 生产雪墙单格 **0.5 m**，两层 **1.000 m**；现役步行跳高 **1.255 m**，且自由墙尚无步行碰撞。候选给局内独立水平扫掠入口，同共用墙高，夹具贴边 **0.25 m** 被挡、**0.28 m** 可走，越墙直穿被拒。未挂生产 `tryMove`，未验真人跳墙 |
| 入口→铃台→成绩 | 合法入口开计，连续占领缺 **1 ms** 不结算，离开计时清零，夹具第 **5000 ms** 读满，成绩为 **12,000 ms**。5000 ms 只借用现役占领常量做夹具；迷宫专用短读秒待定 |
| 自建图纸 | 本地成功保存、读回 **1** 份，复建墙快照一致；损坏数据及存储失败测试覆盖。实际 UI 筑造和读取、邀约、回传成绩分榜待接，GP 现役仅接受总时且下限 45 s、无挑战 ID |
| 阻塞 | 现役交流区只找到「施工单给格点表」，两张格点表、正式入口/铃台尺寸与迷宫读秒值均未找到。候选无生产图纸与实走线路 |
