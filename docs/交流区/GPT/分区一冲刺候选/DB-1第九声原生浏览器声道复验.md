# DB-1 · 第九声原生浏览器声道复验

- Windows Chrome 146.0.7680.178 通过原生 Web Audio HRTF/低通/卷积节点在 48 kHz 输出。浏览器离线图预先建立，适配层只让生产节点通过「已运行」检查；其余状态、定时、节点和输出走浏览器原生实现。
- 用 C-18 西偏上方向的两个镜像听者坐标 `[-30, 10, 0]` 与 `[30, 10, 0]`。两组前段近耳/远耳 RMS 分别是 0.02687850 / 0.01761122，强弱方向随听位翻转。坐标为取证输入，实际场景摄像机朝向与头顶听觉仍待验。
- 排程参数为 400 ms。两声道及纯干声实测首样本均为 450.6875 ms（包括节点内部 45 ms 前置和滤波/HRTF 过渡），两组湿声在 8.8–9.8 s 内仍有非零且衰减，11.6 s 起静音；纯干声的 5.8–6.8 s 已静音。−8 dB 和 0.3 湿声用于对照。
- 这轮核候选声道与时序。现场耳听、西向偏上的感知、双客户端真实第九声及正式 O1/TX2 与个人到场权威仍待验，生产 viewer 保持现役播放。
