# 受击反馈、铁路与镇民验收回执

基于 Muse 85917f5 开工。旧提交的操控提醒由 e5bdfe5 的长按 v2 实现核销，仍保留目标与真机复核。

- **受击反馈**。命中事件区分头部和躯干。仅受击者显示中心透明的 512×320 雪团贴图与指数衰减的相机偏移。没有实时模糊或额外 WebGL 绘制。头部与躯干实测峰值透明度 0.76 和 0.46，偏转约 0.65° 和 0.35°。连续五次命中刷新同一动画，强度封顶。减少动态效果时保留遮罩并停用晃动。关闭诊断开关后命中与计分仍工作。
- **反馈开销**。同广场机位无头 Chrome 交替开启／关闭各两轮，总计 560 帧。实际帧间隔中位差 +0.05 ms，直接反馈代码 p95 0.10 ms，单次峰值 0.40 ms，绘制调用均为 135。实机与多人满载还需独立验收。
- **D2 C1/C2**。站前路上方主梁抬高并接入静态碰撞，车厢按实时姿态注册碰撞。站前路全宽最小净空约 1.98 米，中心线两侧 2 米内约 2.12 米。温泉路两侧增设桥墩，占用范围避开路面，无墩跨从约 27.2 米缩至约 11.9 米。两处模拟抽样均无行走阻挡。
- **D2 C3/C4**。旧住宅选址按实际旋转占地消费轨道净空，筛除了 E390 N32 町屋和 E63 N194 高山木屋，其他 51 栋原址规格相同。大厅和运营站台保留各自位置，由三块路标接通约 147 米的现有道路。真实浏览器按七点从站厅连续步行至站台，另验证了大厅路线卡、直接前往、上车与下车。
- **D5**。六位镇民采用职业配件和 Muse 现有白天招呼。角色仍共用一个实例批，体素方块 276→228。四名雪仗 NPC 仍可参战。
