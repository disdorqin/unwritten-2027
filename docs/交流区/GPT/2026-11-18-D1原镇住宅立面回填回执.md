# D1 原镇住宅立面回填

把扩展区的四类立面处理移植到原镇住宅生成器。森林使用原木横带、陡坡雪顶和入口木廊。纪念馆片区使用混凝土框架、通高玻璃和天窗。集市使用三道砖拱、分层腰线和收分檐墙。湖岸使用错缝石基和高玻璃窗。九栋中央填充住宅保留原轮廓并匹配立面配色。春联层已由年味批次安装。

现行树实际有 52 栋，可复算为森林 11、纪念馆 5、集市 17、湖岸 10、中央 9。历史 `7a252f8` 与 `6740247` 枚举为 54，`cd1babc` 的铁路净空规则排除了 `[63,194]` 与 `[390,32]`，到 `1ac0850` 一直为 52。本批改造全部 52 栋，没有把两处铁路地块恢复。若验收要求现在精确补到 53 栋，请 Thomas 与 Muse 决定新地块。

真实道具碰撞与铁路规则下，改前改后选址、尺寸和朝向逐条相同。住宅近景实例批次 70、俯瞰 5，三角由 148,476 降至 126,480。独立 Chrome 检查四种立面无页面报错，每处房屋两次绘制，地面一次。专项 11/11 通过。

本批同一树的严格 TypeScript、town-preview 构建、Node 81/81 及服务端 13/13 已通过。
