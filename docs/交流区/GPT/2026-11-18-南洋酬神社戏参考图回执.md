# 南洋庙会酬神戏 · 戏台参考图

四张实景图送审。使用来源原图链接，游戏不使用新闻图片作贴图。

## 1. 新加坡，韭菜芭城隍庙酬神戏（首选）

![韭菜芭城隍庙棚下舞台、灯笼和观众席](https://static.zaobao.com.sg/s3fs-public/styles/article_large_crop/public/images/201707/20170710/ZB_0710_CJ_doc6udqp8fytmel8fer8t9_09151527_yingxuan.jpg?VersionId=ZgoAkDTLzYD98kYoOqkQvP2sUtgovF3h&itok=S2IzlmyW)

**取法**：四张中最接近 Thomas 说的「庙会看大戏」。舞台直面开放场坝，灯笼排过观众上方，棚子有顶、两侧透气。参考图里是座椅；0.35 m 宽浅阶梯和侧坡是小镇适配。外围摊位沿场坝侧边留通行，照片本身未拍到环场摊位。 [《联合早报》原页](https://www.zaobao.com.sg/news/singapore/story20170710-777714)

## 2. 新加坡，黄埔通道空地街戏

![黄埔通道空地的粤剧临时台与前场座席](https://static.zaobao.com.sg/s3fs-public/styles/article_large_full/public/images/201704/20170413/ZB_13_04_2017_CJ_6_35014801_35014776_zhangxh.jpg?VersionId=Duw9jhKQFlFLmKU3N9veIXEMsjEvnaeE)

**取法**：低台口、红台裙、彩棚直接覆盖座席，边侧留出口。从看戏转场合影时，保持前排离舞台近，中央主轴和巴掌大的台口都清楚。 [《联合早报》原页](https://www.zaobao.com.sg/zlifestyle/culture/story20170413-747991)

## 3. 马来西亚，槟城乔治市酬神戏舞台细节

![槟城乔治市戏台的红黄挂布与绘景台口](https://www.malaymail.com/uploads/imported_images/2017/2017-09/20170908_HUNGRY_GHOST_FESTIVAL_17.JPG)

**取法**：取台框的层次，红色软帘沿木台口落下，背板用横向绘景片。灯打亮台面，照片里的文字、庙名和人物留在原图。 [Malay Mail 原页](https://www.malaymail.com/news/malaysia/2017/09/08/hungry-ghost-festival-when-spirits-roam-penang-and-are-entertained/1460415)

## 4. 马来西亚，大山脚七月庙会观演视角

![大山脚庙会前场近距离观看传统戏曲](https://apicms.thestar.com.my/uploads/images/2024/07/26/2823243.webp)

**取法**：取低观众视点中演员与戏台的比例，前排能读到人物表情。把后排逐级抬高、用阶缘灯给找座和拍照划边是小镇设计。 [The Star 原页](https://www.thestar.com.my/news/nation/2024/07/26/ushering-in-the-hungry-ghosts)
