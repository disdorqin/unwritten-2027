## 接线证据

- 现役居民面板的问答由 `createTownResidentController` 下发，原入口按六个按钮的数组下标直接取字符串，新路由以显式话题 ID 取现有角色的同一稿源。只有近况与一句介绍可承接源稿「可答」项。其余及未知请求只能取角色已著录的「挡回」项。没有可用的已著录回避时，保留现有面板文本。保留 E 触发、既有出现条件、按钮顺序、场地活动及角色站位。
- 三条实际驻守入口用现有驻守控制器和按钮面板 DOM 替身逐项执行。樊樵、翁寒江、秦知礼每位分别命中原稿近况、重复触发原稿隐私回避。验证实际面板只装按钮，没有自由输入框。未知话题、错标私密来源及无合法回避都有定向断言，源稿 150 条和秦知礼 25 条继续逐字保留。面板替身覆盖按键回调与路由，现场真人走查仍待。
- 本件只改 `town-npc-dialogue.ts`、`town-npc-residents.ts` 和 `tests/town-blockout-npc-stations.test.ts`。六位现役基础个人问答、纪守信、小二及小未仍走原路径。无新增对话正文或 JSON，未开任何故事问法及真相层。
- 严格补丁检查与根 TypeScript 通过。三份定向回归 **11/11**，旧门册 92 门缺 0、增 0。生产预览构建成功，Vite 转换 240 模块。
