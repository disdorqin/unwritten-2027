# 左上控制面板折叠回执

新增「收起控制／展开控制」按钮。收起后只留左上方小条。状态存 `localStorage`，刷新恢复，浏览器禁止存储时当前页面仍可切换。按钮支持点击、触屏、Enter 与 Space，状态通过 `aria-expanded` 告知辅助技术。只改 DOM 和样式。

| Chrome 146 生产预览 | 展开 → 收起 | 俯瞰绘制次数／三角 |
| --- | --- | --- |
| 桌面 1280×720 | 320×291 → 74×40 px | 277／1,474,016 → 277／1,474,016 |
| 移动 390×844 | 304×271 → 74×52 px，触控按钮高 44 px | 236／1,400,270 → 236／1,400,270 |

两组各对照 10 帧，WebGL 与 Three 逐帧计数一致，增量均为 0。桌面触发开合、双向刷新恢复、复开进入第一人称，移动触屏开合和刷新恢复，存储阻断降级，均通过。三个页面环境的错误均为 0。面板独立生产构建通过。
