# 雪夜深雪减速回执

## 现状审计

地面的积雪量原来只管覆雪外观与攒雪球份数。步行速度是 7.5 m/s，疾跑是 11.3 m/s。涉水、游泳、滑冰和空中控制各有独立分支，已有固定物理步与视图插值。

## 施工

- 同一仪式雪势回调更新视觉和雪量。1 档平时为原速度，强度升高时野地先蓄雪，院落按半深。道路、广场、扫过的住宅门前铺地、桥口与室内保持正常。
- 积雪档步行 ×0.85，深雪 ×0.62。深雪疾跑按细稿封顶为基准步行 ×1.1，即 8.25 m/s。着地后按约 0.3 秒过渡。水、冰、空中、车辆和座位保持各自分支。
- 复用地表网格与铺地生成边界，零新增绘制。现有 3／4／5 球补给档位通过回归。

## 实测

Chrome 146 实际按 W，三条 20 米路，按游戏固定物理步计时。
