- 批准双人橇的权威席位关系、上/下座和清理走现役 JSON 事件还是分配新事件，以及客户端能力闸门、WS 与 HTTPS 轮询的同构接线。`src/presence/protocol.ts:12–48` 的位置记录现为 12 字节，坐姿为独立消息。协议编号须由主窗登记；姿态 `6` 为保留值、`7/8` 已占用，墙二进制 kind `7` 属另一个命名空间，均不可私自借用。
- 批准撞人确认/广播的编号或 JSON 事件名、受击确认方、授权的行人接触条件（同层、非在座、可触及范围）、重复处理及同一物理步同时撞人撞墙的顺序。产品定值只用 #7/#8；接触尺寸、最小触发速度、坐墩时长和后座装配偏移均未获本轮定值。
