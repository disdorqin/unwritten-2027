# 留言墙与时光信箱施工回执

依据 [时光信箱细化 v1](../Claude/2026-11-18-时光信箱细化-v1.md)。

- 邮局主箱和纪念馆新区分箱共用 `unwritten.timebox.v1`，开启时刻为设备本地 `2026-12-31T20:00:00`。邮局可写信、开启和重读，新区可写信及查看封存状态。开启前只呈现收信人、封存日期和倒计时，允许撤回；开启后已开记录刷新可追溯。旧信路径迁入草稿，原明信片和邮戳保留。
- 留言墙使用 `unwritten.wall.v1`，和信箱共用纯文本渲染、字段校验、损坏备份、联系方式/简表过滤及 3 秒冷却。公开栏只列已开启的「小镇」信。封存上限为 5 封，留言墙保留上限与置顶淘汰规则按原文。
- `wall.post`、`timebox.seal`、`timebox.open` 按原文事件字段接入。`NPC_LETTERS` 为空表，等 Muse 语料批次后再导入，NPC 的投信正文不入玩家 localStorage。P7 统一仪式编排与跨年后普通信箱模式留待明确。
- 邮局墙 E261.6/N210.0、主箱 E267.3/N201.1、新区分箱 E417.7/N334.1。首轮生产 Chrome 在三点完成电脑 E 与 390×844 触屏模拟点按。6 个用例通过，包含 19:59／20:00 边界、分箱正文隔离、私信与公开信分栏、联系方式拦截及三种事件。无 pageerror/WebGL 错误。面板纯 DOM，场景标记未新增光源。

最终暂存树严格 TypeScript、town-preview 构建、Node 91/91 和服务端 13/13 通过。新增六项专项测试含只存私人信的开启状态刷新持久化、五封与撤回、公开栏过滤、校验/冷却、200 条留言淘汰、两个损坏存档的独立恢复。场景另有分箱 84 个原始三角、最多两个状态红绸 48 个原始三角，输入、分页和读信的 DOM 面板绘制增量为 0。
