## 给朋友的转发文本

麻烦在腾讯云 Lighthouse 打开 `49.234.39.194` 的网页终端，用可以管理 Docker、写入 `/opt/apps` 的账户，把下面整段粘贴执行。它会现场拉取 GitHub 集成分支最新提交。预期最后打印实际部署的完整 SHA、单行 `town-preview <同一个 SHA>` 和「首页 HTTP 200，小镇场景与脚本已验证」。请把最后输出回传。首次拉取若提示 GitHub 私有仓库授权失败，请把报错回传 Thomas，由仓库管理员为这台服务器配好只读访问。

```bash
bash <<'TOWN_PREVIEW'
set -Eeuo pipefail
repo=/opt/apps/unwritten-2027
branch=town-blockout-integration
origin=https://github.com/disdorqin/unwritten-2027.git
site=town.disdorqin.cn
export GIT_TERMINAL_PROMPT=0 TOWN_PREVIEW_SITE="$site"

mkdir -p /opt/apps
exec 9>/opt/apps/.unwritten-town-preview.lock
flock -n 9
docker compose version
if [[ ! -e "$repo" ]]; then
  git clone --no-checkout --single-branch --branch "$branch" "$origin" "$repo"
fi
case "$(git -C "$repo" remote get-url origin)" in
  https://github.com/disdorqin/unwritten-2027|"$origin"|git@github.com:disdorqin/unwritten-2027.git|ssh://git@github.com/disdorqin/unwritten-2027.git) ;;
  *) printf '%s\n' '部署目录的 origin 与项目不符' >&2; exit 1 ;;
esac
git -C "$repo" fetch --no-tags origin "refs/heads/$branch"
sha=$(git -C "$repo" rev-parse --verify 'FETCH_HEAD^{commit}')
[[ "$sha" =~ ^[0-9a-f]{40}$ ]]
export TOWN_RELEASE="$sha"
printf '本次拉取的部署 SHA %s\n' "$sha"
tree="/opt/apps/unwritten-2027-release-$sha"
[[ -e "$tree" ]] || git -C "$repo" worktree add --detach "$tree" "$sha"
[[ $(git -C "$tree" rev-parse HEAD) == "$sha" && -z $(git -C "$tree" status --porcelain) ]]
cd "$tree"
dc() { docker compose -p unwritten-preview -f tools/compose.town-preview.yaml "$@"; }
dc config --quiet
live=$(dc ps -q web)
record="$repo/.deployed-sha"
previous=''
if [[ -n "$live" ]]; then
  previous=$(docker inspect --format '{{index .Config.Labels "org.opencontainers.image.revision"}}' "$live")
elif [[ -f "$record" ]]; then
  previous=$(<"$record")
fi
if [[ "$previous" != "$sha" ]] || ! docker image inspect "unwritten-town-preview:$sha" >/dev/null 2>&1; then
  dc build web
fi
dc up -d --no-build --pull never web

tmp=$(mktemp -d "$repo/.public-preview.XXXXXX")
trap 'rm -rf -- "$tmp"' EXIT
url="https://$site"
ok=0
for attempt in {1..24}; do
  if curl -fsS --connect-timeout 4 --max-time 8 -o "$tmp/healthz" "$url/healthz" &&
     { cmp -s "$tmp/healthz" <(printf 'town-preview %s' "$sha") ||
       cmp -s "$tmp/healthz" <(printf 'town-preview %s\n' "$sha"); }; then
    ok=1
    break
  fi
  sleep 3
done
if (( ! ok )); then
  dc ps
  dc logs --tail=30 web
  printf '验活失败，预期 town-preview %s\n' "$sha" >&2
  if [[ -f "$tmp/healthz" ]]; then cat "$tmp/healthz"; printf '\n'; fi
  exit 1
fi
status=$(curl -fsS --connect-timeout 5 --max-time 15 -o "$tmp/home" -w '%{http_code}' "$url/")
[[ "$status" == 200 ]]
grep -q 'id="scene"' "$tmp/home"
grep -q 'id="walk"' "$tmp/home"
asset=$(sed -nE 's/.*<script[^>]*src="([^"]+\.js)".*/\1/p' "$tmp/home" | sed -n '1p')
[[ -n "$asset" ]]
asset="${asset#./}"
curl -fsS --connect-timeout 5 --max-time 15 -o /dev/null "$url/${asset#/}"
if [[ "$previous" =~ ^[0-9a-f]{40}$ && "$previous" != "$sha" ]]; then
  printf '%s\n' "$previous" >"$tmp/prev"
  mv -f "$tmp/prev" "$record.prev"
fi
printf '%s\n' "$sha" >"$tmp/current"
mv -f "$tmp/current" "$record"
printf '\n实际部署 SHA %s\n/healthz 原文\n' "$sha"
cat "$tmp/healthz"
printf '\n首页 HTTP %s，小镇场景与脚本已验证\n' "$status"
dc ps
TOWN_PREVIEW
```

验活失败时保留当前容器与证书卷供诊断，不自动退版。收到成功输出后，从公网独立核对首页与同 SHA 健康响应，再将实测原文写回本页。
