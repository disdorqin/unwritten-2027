# ZB-21 显示模式挂载 · G-10

窗 A 在右上音乐按钮 `town-music-toggle` 同排挂模式选择。用 `createTownStoryDisplay()` 建本机状态，再用 `mountTownStoryControl(select, display)` 绑定既有选择框。三项为游客、探索、故事，首次与失效存档均进入探索，当前选择仅保存于本机。

用 `display.subscribe(...)` 在切换时即时重绘。原有授权结果先进入 `display.strength(authorized)`，再乘各自魂痕、夜痕与脚印的原始强度。实现采用 0.30、0.65、1.00 作为三档表现值；已授权的故事档保持原效果。共享活人批次需保留自身显示参数，魂痕只在自身效果上乘该值。

图鉴使用 `display.appendAtlasLine(authorized, silentUpsert)` 将已授权内容写入角落，按既有条目 ID 去重。第十三声使用已有 `thirteenth-bell` 条目，世界广播、夜窗及进度的消费继续读取原有服务器旗标。

窗 B 已验切档、非法存档回落、持久化、即时重绘、授权边界与静默入口；右上正式挂件和魂痕、图鉴在实际场景中的联合走查由公共批接线。
