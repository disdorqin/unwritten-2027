## 现役入口与接线

- `tools/voxel-tavern/town-blockout/town-passport.ts:7,67–124,127–168` 的 `createTownPassport` 用 `unwritten:2027-town-passport` 保存印章 ID 数组；目前只见印章、扩展收集与纪念卡。接图页时保留旧印章数组及领取语义，地图到访以最少且版本化的区域 ID 记录，按 CD1/CD2 归属确认保存；在 `viewer.ts:1793–1805` 的护照入口接投影，现役小地图与 HUD 沿用。自动翻页只在护照内描亮并轻响，闭合页时不得挡操作。
- 设计支持三层世界和独立主峰山域。地表护照初亮老镇并可显示陨星原，主峰作为独立升级区域，天空层不在本单新增开图触发。地图三种载体分别为远景地标（DT1 主窗）、路牌／站牌（DT2 分支、DT3 主窗）与护照内手绘图（DT4 分支），护照图与主窗广场站环线图共用车站 ID、地名和方向数据，禁止把现役房间专图或班次表当全镇地图。
- **主峰山门**：监听真步行跨越山门界线，点亮山门、登山道、绝顶小屋和主峰轮廓。前山北延规格 §1 的旧镇不位移、n 540→800 是北带，不把前山缆车登顶或载入地图当已经进过主峰。超规格的新点由主窗按区块化模块边界登记。
- **陨星原坑缘环台**：监听人物到达环台边缘，点亮坑体轮廓、三个下坑口、回纪念馆线，不露坑底设施。**井口**：亲身到达时只在地表地图添一枚「深井」点，绝无地下页面或巷道、层、房间详情。现役北带和坑底都不能靠图册 UI 自行推定触发坐标。
- 井口边矿工巷图残片作为固定读图陈设，残缺且留一处已与实地核对的偏差，无拾取或拓印。R3-68 的「陨石坑底」是 DT5 传送锚点，不更改 DT4 的井口标记。5255331 定版的井口深度线是 SM1 切换逻辑，潭边石阶是地表陈设，二者不作护照开图二次触发。
- 到访以当前玩家真正进入为准，其他玩家或调试跳转不写当前人的新到访。用幂等的个人记录区分首访、回访及旧档读回，再给 DT2 换牌和 DT5 到访投影；先验证设计 ID 与坐标表，再接交互。无已验世界坐标、事件宿主前只做接口确认。

## 合线后证据计划

1. 用两个浏览器档案分别走山门→回身、环台→退回、井口→往下过深度线。逐场登记前后护照页数、显示要素数、动画次数、两个玩家区域 ID；首访仅一次，回访无重复，另一玩家的记录增量为 0。
2. 井口场景以点击、触控及适用拓印入口验证残片无拾取/拓印，截图标记唯一一处与实际巷路不符；查看护照零地下页面、零巷道具体数据，过深度线不新增页。PC/触屏验证无打断走路。
