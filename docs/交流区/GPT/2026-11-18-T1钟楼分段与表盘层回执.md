## 本批范围

以 `d28028c` 为基线。钟室已有工具板、吊灯、铜钟和摆动，本批先补测钟室，再把静态楼梯与各楼层陈设按高度切分为七段。视锥能分别剔除各段。表盘层西栏杆旁加木桌、折页图册和钟面拓片，53 个盒件并入原有不透明材质批，另登记一处桌体碰撞。新增几何 636 tris，陈设增量 0 draws，材质色组与照明复用。

按施工单对本切片预告和对账的机位增量参考为 +5 calls / +5 万 tris。钟室、表盘、1F 和瞭望台的行走测试覆盖原有路线及新桌前，原钟体的单一可动批与摆动回归通过。

## 同机位对账

Windows Chrome 146 / WebGL，SwiftShader。本地完整小镇页 `town-frame-profile` 取稳定帧的 `renderer.info`。固定钟室机位东 225.5、北 222.5、脚高 96.71875、眼高 98.36875，朝钟仰角 0.30 rad。测试注入只用于摆放测量镜头和读取帧数据。
