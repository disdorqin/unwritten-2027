# B3b 雪橇动作 · 施工候选

施工基线 `06d8239`。引入已审 B3 接线与翻滚脱橇的原提交 `2b5fcd8`、`eac93b6`，在施工分支落为 `eec03f4`、`d88cf27`。本批相对 B3 使用已有姿态 7、12 字节位置记录与原消息格式。

## 代码与接线

- `sled-animation.ts`、`sled-rider-pose.ts` 计算骑手分段矩阵与橇体贴地。包括 0.4 s 上下橇、前倾、左右压弯回正、内侧脚刹、颠簸、腾空外张、落地与五秒待机。远端 22 个骑手部件和 6 个橇部件仍用一个实例批。
- `sled-ride.ts`、`sled-visuals.ts` 接真实刹车和转向与原翻滚/低速脸刹。雪沫按速度三档、脚刹扇形与落地成圈，沿用 600 粒子池。第一人称手脚并入已有本地橇批。
- `sled-tracks.ts` 为本地双轨痕，400 段环形池，深雪加深，20 s 内褪去。地形、碰撞和骑行数值沿用 B3。
- `viewer.ts` 接第一人称 FOV、曲线倾斜、60 ms 脚刹/落地反馈和 C1 中断。醉酒界面保留，骑橇时关醉酒晃镜。presence 发已有 yaw 字段的橇身朝向。`town-presence.ts` 和 `town-presence-motion.ts` 按现有插值时间从位置样本推断远端动作。
- 主窗口请在当前已实测 B3 分支上逐文件审阅 B3b，并保留集成线已有 C1、B1 等接线。测试文件 `town-blockout-sled-animation.test.ts`。

## 验证及性能

- 根与服务端 245/245，双方严格 TypeScript、实际小镇 `town-preview` 构建和 diff 检查通过。S1 地形读取仍为 226.715 m，最大采样下坡 28.508%。
- Windows Chrome 两页连真实本地 presence，长厅架位 E378/N303，用 E、W、左右转、S、空格和 E 走完动作冒烟。两端在线，观察端实际显示 28 实例，收到姿态 7，远端估算捕捉到脚刹。页面脚本异常 0。开发服务器另报旧酒馆样例缺 `tavern.json`，正式小镇构建通过。样本中第一人称最高 321 draws / 1,364,100 tris，观察机位 439 / 1,702,866。此为抽样帧，并非完整航线峰值。
- 雪痕满载 +1 draw / 1,600 tris。第一人称手脚 +0 draws / 144 tris，远端仅更新原矩阵。三分钟定步模拟 4,500 步持续写入，痕段未超过 400，停写后全部褪去。
- A1 本地五种动作的实景连续录像和穿模逐帧核验仍待做。低速脸刹、高速翻滚在专项测试复跑通过。A2 远端刹车基于速度变化和漂移推断，位置快照与现有 120 ms 插值限制输入边沿精度，未核销 ±1 帧。A3 定步容量过测，真机连续滑行三分钟帧账待做。未部署。
