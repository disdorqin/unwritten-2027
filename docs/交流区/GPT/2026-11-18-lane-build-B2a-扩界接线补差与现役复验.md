- `town-campfires.ts` 的现有地形校验回调结尾加第二参 `layout.plaza.bounds`。仅最终边界 `[161,152,251,212]` 启用三处，旧界保持五处。继续原 `createTownCampfires / campfirePieces / warmAt` 路径。
- `plaza-snow-supply.ts` 实例在挖雪路径共用。原 `aimsAtNearbySnow` 的移动、屋顶、水域、射线第一命中等守卫之后，用 `supply.aimed(tossOrigin, gatherRayEnd, grid.heightAt, hit)` 判补给。按雪堆点保持屋顶/水域守卫，缓存 aim 结果，只在既有长按 0.8 s 成功入口调用 `supply.gather(snowballs, snowCover.depth().servings, aimedSite)`。现有雪层随 B10 实时读。渲染帧加 `scenery.updatePlazaSnowSupply(supply.heightScale, camera.position.x, -camera.position.z)`。
