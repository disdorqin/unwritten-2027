# U-1 西壁裂缝滑道与防爆门侧廊预检

XJ 要求西壁滑道只下，抵达地表潭边碎石滩。爆破门半开，旧值守侧廊有两段侧身，出口在坑底东侧。R3-11 明确三路止于地表坑底，井盖开关只管入梦井，R3-18 要求地表潭与井底潭分开。L1 提到滑道约 40 s、侧廊约五分钟。下表记录地形实测，未将夹具速度、坡限或两路准确站位定为正式设计。

## 原始坑网实测

取窗 B 76d52af 的 `meteor-crater.ts`，blob 为 `4db1f757dbda686725c0e087b8d0f5e4d9d1042b`。以现役顶点、三角拓扑和同网重心查询 `heightAt()` 量西、东两侧地形。沿半径 55→20 m 测 N=0、±0.27 m，间隔 .025 m，每线 1,401 点，共 **8,406** 命中。取 60 Hz 的现役最大步幅 11.3/60 m 再采一组。坡度定义为相邻点高差绝对值除水平距离。

| 原始断面 | 中心峰坡 | 最大现役步幅高差 | 超 0.43 m 的边 |
| --- | ---: | ---: | ---: |
| 西向正径 | 200.001503% | 0.376669 m | 三条各 0 |
| 东向正径 | 506.448520% | 0.953811 m | 三条各 30 |

西向三线沿径向采样均无相邻超过 .025 m 的抬升。原网未给予该断面单向规则、站台、独立碎石滩或滑行控制，单靠步高不能证明只下。东侧中心原网入口高程 −0.924176 m、坑底接缝 −34.999504 m。东侧峰坡和步高超过普通步行能力，侧廊需按正式 ENY 布实体地面和净空，或避开原地形陡段。两条断面只作测量对照。井轴、螺旋、生产房位未改。

## 正式样本接入

```bash
node verify-u1-surface-approaches.mjs evidence.json
node --test verify-u1-surface-approaches.test.mjs
node --experimental-strip-types crater-mesh-probe.mjs
```

复跑坑网时，将随附 `crater-mesh-probe.mjs` 与源 `76d52af:tools/voxel-tavern/town-blockout/meteor-crater.ts` 复制到同一临时目录。核后者 Git blob 为 `4db1f757dbda686725c0e087b8d0f5e4d9d1042b`，再在临时目录执行第三条命令。

脚本接收正式世界实走日志。录制时逐个原生物理步记录已接受脚位和碰撞查询，供逐值对版。所有坐标统一在 B-01 已核的同一 ENY 坑体参考框架内，东为 +E。以下字段由场景及录制器提供。

| 数据 | 字段 |
| --- | --- |
| 坑体边界 | `frame.center.east/north`、`frame.floorY`、`frame.floorRadius`、`frame.shaft.east/north/radius`。井实际圆形占域，不填镜湖西 240 m 作坐标。 |
| 四次走查 | `routes.westSlide.covered/opened`、`routes.eastSideCorridor.covered/opened` 各一条 `feet` 数组。摄像机站位不能替代物理脚位。 |
| 每帧通用 | `east/north/y/tick/timeMs/supportY/renderY/support/sweptClear/relocated/mode/cover`。坡度脚位采用实际碰撞地面和同处可见面。脚位必须有支撑，间断、穿模或镜头直接换点须记录失败。 |
| 西壁单向 | 末脚的实地支撑分类 `dry-surface-gravel`。每趟在着陆点实测逆行，报 `reverseProbe.attempted/accepted/from/to`，两端带 `east/north/y/mode/cover/support`。 |
| 侧廊净空 | `blastDoor: 'half-open'`，每脚 `left/right/headroom`，值为到实际障碍或顶板的距离。 `constriction` 为现场两段编号，`movement: 'sidestep'` 搭配实际 `yaw`，脚位移动的侧向分量必须大于前后方向分量。 |

预检记录每线坡峰及边序号、步幅、高差、时长和数量。侧廊保留最小净宽、左余、右余、净高及两处侧身。两路在井盖开/闭时均走通，地面保持 `peace` 且绕井轴，西壁倒入拒绝。侧廊按现役半径 .27 m、身高 1.8 m、竖向 .025 m 容差与步高 .43 m 对版。滑道仅记录坡度并检向下，最终坡限与速度由宿主裁定和实际物理负责。结尾脚位须在所登记坑底层，允许地表上可踏的小台阶，禁止落入井/地下。侧身是实测运动，体型碰撞不因标签改变。脚本退出 0 表示所给记录均满足这些预检条件，1 表示条件未过，2 表示输入错误。测试数据是软件回归夹具。

真实资料缺坑心、坑沿高程、滑道入口、碎石滩边界、爆破门和两个窄段、侧廊东出口及可见地板/净空。生产锚确认后，接录制器、导出上述四条实走日志和两条西壁反向日志，再验 B-01 正典域变换、全景和首坠。预检、场景几何审查和真实步行分别留证。
