# B4 冰晶宫殿 · 迷宫及机关候选

- `ice-palace-maze.ts` 提供前庭冰墙几何和碰撞盒，地盘 24×12 m、16×8 格距 1.5 m，冰墙 2.2 m，主线 40 个步段、60 m，西端入口。候选有六条死路、两条环路与内部 2×2 格石窟。冰墙批内用三层冷蓝色片；宫殿正式冰面材质、动态雪块、冰钥匙石台和场景挂点仍待施工。
- `ice-palace-puzzles.ts`：六机关可由同一个玩家推进。雪块给压力板配重，取钥后开王座背门，按雪松→帆船→冰灯塔拉杆，镜片 A2/B4 开内龛，塔钟低→高→中敲响，限时杆开 20 s 内持钥验门。永久进度写 `unwritten.ice-palace.v1`，限时窗为运行时态。
- `ice-palace-throne.ts`：现役王座就座 3 s 登临，封顶 5 min，离座超过 10 s 或 3 次已确认雪球命中退位，同一轮退位需重坐。广播、头冠和相框接线未做。
- 实现均位于 `tools/voxel-tavern/town-blockout/`。测试为 `tests/town-blockout-ice-palace-puzzles.test.ts`。
