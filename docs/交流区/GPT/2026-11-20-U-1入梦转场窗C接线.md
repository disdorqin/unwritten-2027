# U-1 入梦转场 · 窗 C 接线

`mountUndergroundDescent` 接绞盘首坠订单和已受理的普通下降班次。给前端一个同一权威周期内递增的演出 ID。首坠可预留 ID 1，普通班次用物理班次 ID 加 1；重连只恢复尚未完成的订单。用同一同步时钟传 `departedAt` 和帧时刻。首坠时长取宿主的订单时长，原双向笼仍用 20–30 秒物理班次。

- 首坠依次呈现乘笼、渐晃、闪灯、尖啸和全黑。矿洞躺醒用 1.15 秒，坐起过渡用 0.95 秒。重复乘笼保留轻晃与短黑场；可跳过的后段从全黑开始。
- `requestMineLanding` 只有在必要黑幕已显示并到班次时点才触发。调用者使用 B-01 正典锚、域 resolver 和受理落脚。首次还须取得 `confirmFirstFallLanding` 的零伤结果，双向笼仍由该回执开放。传回本趟的矿域、演出 ID 和实际零伤。
- 加载中保持 Promise 等待。失败通知走 `onHandoffError`；宿主恢复网络或域资源后可调 `retry()`，退出或重连销毁本地表现。过时回执不进入新会话。锁定输入应使用宿主独立的过场锁原因。
- 镜头接口只给晃动角和躺到坐的比例，由矿洞实际机位应用。声音走既有 Web Audio 混音，减弱动态模式仍保留必要黑场。G-06 面孔只在该趟获准时短暂出现。

窗 A 的 [ZA-22 新坑口](https://github.com/disdorqin/unwritten-2027/commit/f30191e08fb02e21605e4adb8a388c9125a7bfae)已从出生点实走。`ensureWestCraterRoad().anchor` 给出实测坑体，坑缘 E−120、N185、Y10.7773。用 B-01 原锚变换核对，演示夹具井脚映到 E−120、N185、Y−24.2227。

`resolveUndergroundShaftRegistration` 接 A 的实测坑体、B-01 原坐标变换、宿主实录井线与 Y−90 落脚。应通过 `supportsFoot` 核验井脚、绞盘和落潭脚点，通过 `acceptsShaftHandoff` 核验正式跨域通路。井盖目前封闭，西域协议 Y 原点为 −64。矿洞需独立层域，井线、绞盘可交互点和正式落脚的水平坐标由分区二登记。登记完成后，复核出生点实走、正式落脚和公用门权威。
