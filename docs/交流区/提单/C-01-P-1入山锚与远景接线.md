# C-01 待总控｜P-1 入山锚与远景接线

P-1 局部域已能构建高度场、山门、粗模与雪梯度。绝顶局部 [50,1000,800]，门内原点 [0,0,350]。四向夹具相机的中心射线打到 Y799.928–799.932，距离 1,628.263–1,637.858 m。它只覆盖独立粗模的裁剪与命中，实际镇上云层、旗影与步行换域待验。

请明确前山云海台允许使用的入口站位、朝向、过门权威、异域重连落脚与镇面粗模挂接点，使用同一问题单与 B-01 对版层域。请分拣窗标明 P-1 以外的宿主文件负责人，已验前山场景边界、车线和老镇门册沿现役。
真实验收走云海台进门至行前坪，再返回原位，关闭独立近场后粗模仍常驻。远景实拍需从镇上核云缺口、近远平面、深蓝灰色和资源开销。请在未完滚动帖挂 P-1 宿主及实景。
