# D-01 · P-3 分段长度、主峰地表处理与 R2 并轨

归属：窗 D / 分区二初审，牵涉分区一既有 R2，报总控协调。源候选 `d63fc8b`；核图所用 P-1 高程 `bc397d9`。本窗继续持 P-3。

1. **分段长度待确认。** C-04 已确认 Y800→18 共 782 m。原三段约 2200/1400/2600 m 与 240/180/362 m 高差对应三维长度下约 10.97%/12.96%/14.06%，无法同时满足 12–16%/8–10%/10–14%。动力学样场采用 1590/1810/2615 m（合 6015 m），净坡 15.269%/9.994%/13.978%。请确定三段里程可否重分，或明确坡带哪些段落可作为局部目标。
2. **实体线路用地待确认。** 6 km 独立线路只用于验分段与动力学，对现 P-1 每米抽样，最大穿地 202.435 m、悬空 184.640 m，已排除作实体线。贴地优化再按 0.25 m 复采 20,099 点，最大切挖约 20.85 m、填高约 24.96 m（平面最小弯半径 40 m）。无平面自交，但仍有超常规填挖，东缘样点 E1099.97/N175.95/Y175 与地面错高约 7.6 m。请总控确认可改主峰地形的局部范围、填挖或桥隧许可与最小弯半径；本窗未把该解当成可施工件。
3. **R2 世界目标待一区复测。** 当前区内没有正式山脚 R2 接点可用。请发布一区实测入口 E/N/Y、通行方向、净宽、捕获范围及接回前山时的跨域方案。旧 R6 E425/N243/Y24.290956 已作废，Y18 为绝顶落差基面。C-01 正式联机宿主也是依赖。
4. **现役动力学报实测。** 压实雪样场使用现役步进器，从静止沿中心线全程 239.907 s；P-1 的实际雪深采样、越界外用压实雪时为 249.274 s。现阶段未过实际地表、手动转向和跨域联机全程验收。请一并确认可否在设计赛道压实雪，以及 3–4 分钟是发布硬门还是估程。
