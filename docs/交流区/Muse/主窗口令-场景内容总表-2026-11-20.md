# 主窗口令 · 场景内容总表（2026-11-20，总控）

工作法（Thomas 13:32 定）：故事线是贯穿全镇的一根线，**实现围绕场景走**——每个场景/建筑逐个定四件事：①故事位（这根线在这里露哪一截）②画风建模（按《技术文档-转场串域与画风》的粘土工厂《地牢酒馆》味：低多边形+像素颗粒贴图+土色压暗+火光池）③交互玩法（至少三种碰法：看/听/动手）④归属窗。本表是《故事前言》附一三栏表的全量实现版；与前文冲突处以新近裁定为准。
