# 任务书：拍照与合影系统细化（2026-11-19，分支窗口细节填充）

源稿：《拍照与合影系统细化-2026-11-19》。定位：系统细化任务书。合影文化的原则已由共创稿立过（全镇合影点、零点大合影仪式化、照片进自家屋相框墙），本单只做操作层细化：怎么拍、在哪拍、拍完去哪、什么不许拍；与共创稿四层寿命（临时/当日/永久陈列/载入镇史）对齐，不另立寿命体系。总口径一句话：**照片是朋友之间的纪念物，不是内容产品。排期门：今晚总装上线之后领单；分级拟 B（系统本体），其中零点大合影操作随庆典线 A 级同帧执行。**

**分支窗口职责登记（源稿 §2 点名）**：合影点清单的其余点位由分支窗口按四类形态补齐（见第 2 项）——联络窗口接单，产出《合影点清单补齐》登记文件（候选点从既有各书已落位机位中汇编：纪念馆 2 处、云海台观景台、山门、镜湖冰雕岛北沿、松林火塘、钟楼观景台、冰镜厅、列车车窗时刻位等，逐点标类别与出处）；**隐藏点补点先过主窗口审**（防与遗址禁区冲突），审过才入清单。

## 细节填充

1. **拍照模式的形态（三种）**：三脚架定时（主形态：玩家在任意平整地面放下三脚架——随身道具、不占背包格，设定 5 秒倒计时，跑回人群站好；镜头即三脚架视角；合影的本质是所有人都在画面里，此形态自带仪式感，与零点大合影共用同一套逻辑）/ 求人拍（社交形态：把「相机」交给另一名玩家代拍，代拍者用自己的第一人称视角取景、按快门，照片同时进两人相册；代拍者名字记入照片题注「摄：某某」、不可改）/ 第一人称自拍（降级形态：举相机拍自己与身后景物，臂展内构图，只做单人/双人近景，**不提供自拍杆拉远**——镇子是第三人称社交空间，自拍拉远会把合影降级成打卡）。快门与成像：按下快门即冻结当前帧成像，不做二次渲染、不等待全图精细层加载——**拍照不许触发加载**（性能红线，见第 5 项）；取景范围内有粗模未切换的地块，照片就按当时画面成像，不许为拍照强制拉高 LOD（与区块化口径并行）。HUD 处理：拍照模式进入后 1 秒，HUD 自动全隐（隐去准星、提示字、玩家名牌；名牌只隐不删、退出即恢复）；成像文件内不烧录任何 UI 元素；照片题注（时间、地点、拍摄者、在场者名单）在相框与相册里以文字层呈现、不压在画面上；在场者名单由系统按快门瞬间镜头内玩家自动生成——「谁那晚在场」的凭据，**不许手动增删**。NPC 入镜：NPC 静止时自然入镜无限制，岗位礼仪见第 5 项。
2. **合影点清单的构成（四类，官方口径只认十几处，宁缺毋滥）**：合影点不是系统标记点——不设打卡牌、不发奖励，清单是给玩家口口相传的「镇上人都知道的那几个地方」。制高点类（站在高处、镇子在身后；样例：云海台观景台边缘——登顶合影与登顶登记同帧完成，登记员入镜口径见第 5 项）/ 仪式点类（事件发生地，照片自带日期意义；样例：广场许愿树下——除夕零点大合影的官方机位在此，三脚架预设位地面有一块不显眼的石板标记，平时只是块石板；守岁星过顶、烟花同框都以此点为基准构图）/ 日常点类（生活气息取景，人比景重要；样例：集市收市前的吃食摊前；火塘边、站台、戏台下同属此类）/ 隐藏点类（不在任何指引里，靠探索与口传；样例：陨星原坑沿西侧一块半埋的旧金属板旁——往坑内拍能拍到坑底深井与碎石坡全景，是地面层唯一能把「地下」拍进画面的角度；照片题注的地点名只写「西边坑沿」、不写任何解释；此点是老玩家带新玩家拍第一张照片的口传成人礼，系统不提示、不计数）。清单纪律：隐藏点永不进任何图鉴/成就计数（与成就红线一致：探索的回报是照片本身）。
3. **零点大合影的仪式化操作**（除夕 23:55 起按庆典线节拍走，本单只定拍照环节操作）：传送与站位——零点全员传送广场后，许愿树前石板机位自动放下「镇子的三脚架」（全镇共用、除夕限定，平时不存在）；站位不做系统编排（朋友自己挤、自己让），NPC 按作息稿除夕覆写在广场两侧列队入镜（镇长站第一排边位、不抢中位——与作息书 I3、庆典书 J 单对接）。时点——大合影快门锚定庆典线节拍表的**守岁星过顶瞬间**（节拍以庆典稿为准，本单不另立时码）：星在画面上方、烟花在星下方绽开的那一拍，由三脚架「等这一刻」模式自动连拍三张（过顶前/正过顶/星没入云海），全员各得三张、自己留哪张自己定；倒计时由钟楼零点钟声承担，不另设 UI 倒计时。拍完去哪：三张照片自动进每位在场玩家的相册（在场名单即传送名单，迟到未传送者不补发——这张照片的意义就是「那一刻在场」，与成就书「守岁到天亮的」在场口径同向）；其中「正过顶」一张由系统挂上纪念馆留言簿旁的**除夕合影墙**（公共陈列层——纪念馆新增陈列面，与纪念馆书 JG4 对接登记）；玩家自家相框墙可再自选挂任意一张（相框墙 4 框口径从小屋书）；纪念馆那张不许撤下、不许替换，是镇史的一页。
4. **照片的生命周期（对齐共创四层寿命）**：存哪——照片存玩家个人相册（账号级、随存档走），元数据 = 时间（游戏日 + 钟点）、地点名、在场名单、拍摄者；原图分辨率按成像帧，不做云端图库、不做外部分享导出（外传由玩家自行截图，系统不提供也不阻止）。当日层：刚拍的照片在相册「最近」里，当日可在火塘、集市等日常点与在场朋友互相「亮照片」（举起来给对方看的小动作，只看不传）。永久陈列层：自家屋相框墙（容量以小屋稿为准——4 框；本单定换挂口径：换挂是把旧照片收回相册、不是删除；相册容量不设硬上限但设「精选」标记，玩家自选的精选照片才许挂相框；串门客人能看相框墙与题注——小屋社交的核心展品，与小屋书 XW2 对接）。载入镇史层：镇志补遗页收照片（每页可配一张照片作页眉图；除夕大合影自动占补遗的「除夕页」；照片一旦入补遗页即锁定版本，之后换挂相框不影响补遗页里那张——与共创书 Z 层对接）。删除：玩家可删自己相册里的照片，但删不掉别人在场名单里有自己的那张（那是别人的纪念）；除夕合影墙与补遗页内的照片不可删。
5. **红线（源稿 §5，验收口径）**：不做滤镜商城、不做贴纸/边框售卖（成像只有「当时画面」一种真实，允许的唯一加工是题注文字层）；不做点赞、不做排名、不做「最佳合影」评选（照片无任何计数指标对外显示，在场名单不是人气榜）；拍照不许挡主线动线（三脚架不许放在残页拾取点、碑文、锁门、绞盘、登记点等关键交互物的交互半径内——放下时系统静默拒绝并提示「这儿放不下」，提示句文另审；合影点选址避开主线必经路口，仪式点大合影只发生在庆典传送后的封闭时段）；拍照不许造成加载卡顿（快门不触发 LOD 拉升、不触发层集切换；地下拍照同理——梦境层照片题注地点只写层名俗称、不写深度数值，不许借照片剧透未达层段）；NPC 入镜礼仪（岗位 NPC 在岗时玩家可请其入镜合影——NPC 放下手中事、站到玩家身边一个身位，拍完即回岗，全程无台词；合影请求是动作交互、不触发对话系统、不新增任何信息量；**值守岗——守夜人、冰宫守卫、守亭人——在岗时不可离岗入镜**，只能在岗位原地入镜、玩家站过去拍；镇长在讲古/认账等剧情场合不可被合影打断；NPC 不许被要求摆指定姿势、不许被带离岗位点拍照）。
