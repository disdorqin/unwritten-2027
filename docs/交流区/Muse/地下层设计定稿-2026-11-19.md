# 地下层设计定稿（2026-11-19 晚，Thomas 批准三点，主窗口成稿）

定位：探险层。世界竖轴：山顶滑翔台 +350 → 地表小镇 → 地宫 −65，地下层位于北岭正下方。Thomas 已批三点：①怪不伤人、雪球杀怪；②地宫合并金羊宝库；③矿物用途三条（收藏 / 做灯 / 星港）。**本层为上线后阶段内容，不进今晚总装队列**；本稿为设计准本，施工另行派工。

## §1 三层动线（往下深入，回程不折磨人）

| 层 | 高程 | 定位 | 主要内容 |
|---|---|---|---|
| 矿洞层 | ≈−25 | 干活层 | 敲矿、矿车、雪团怪 |
| 水晶洞层 | ≈−45 | 奇观层 | 水晶簇墙面、矿物采集、晶蝠 |
| 地宫层 | ≈−65 | 终点层 | 地下宫殿、冰傀儡守卫、解谜、宝库 |

- 入口：主口 = 北岭山脚矿洞口；副口 = 冰宫旁冰窖。
- 层间：步行探险道往下；**矿车升降梯**只作回程快速直达地面（下去靠腿、回来坐车）。
- 全程单人可过（老规矩）；多人合作只是更快，不设人数门槛。

## §2 挖矿

- 机制复用砍柴家族：矿点交互敲击 N 下掉落、矿点按钟刷新，不新写系统。
- 矿点分层：越深越稀有；水晶洞层的簇墙可采但刷新慢（奇观不许薅秃，留观赏面）。

## §3 矿物图鉴（八种）

| 矿物 | 出处 | 用途 |
|---|---|---|
| 普通冰晶 | 矿洞层 | 做灯材料（基础） |
| 霜花石 | 矿洞层深处 | 图鉴收藏 |
| 月光石 | 水晶洞层 | 做灯材料（高级） |
| 紫晶簇 | 水晶洞层 | 图鉴收藏 |
| 粉晶 | 水晶洞层 | 图鉴收藏（呼应许愿树粉花） |
| 蓝晶 | 水晶洞层深处 | 图鉴收藏 |
| 星尘矿 | 地宫层前厅 | 星港兑换物（远期飞行线） |
| 金羊角矿 | 宝库 | 寻宝线专用（见 §5） |

用途三条定版（Thomas 已批）：护照图鉴收藏 / 做冰灯材料 / 星尘矿作星港远期兑换。不设货币、不设交易行。

## §4 怪物（三件，战斗规则定版）

- **雪团怪**（矿洞层）：滚行冲撞，雪球 1 击融化，掉普通冰晶。
- **晶蝠**（水晶洞层）：俯冲，雪球 1 击融化，掉霜花石 / 粉晶（低概率）。
- **冰傀儡**（地宫层）：慢速守卫，雪球 3 击融化，掉星尘矿。
- **怪不伤人（全层铁律）**：玩家无血条；被怪碰到 = 摔倒 + 被推开 + 手持物掉地，无其他惩罚。怪的压迫感来自封路与冲撞，不来自伤害。
- 怪按区刷新（确定性种子 + 时钟），玩家离开该区即睡（区块化模拟半径口径）。

## §5 地宫与金羊宝库

- 地宫 = 探险终点：宫殿厅 + 解谜路线 + 宝库。解谜骨架复用 B4 王宫已验的单人路线机制家族，不另起炉灶。
- **宝库即金羊寻宝线终点**（Thomas 已批合并）：寻宝线四缺口中的「终点」缺口由本地宫关闭——线索链终点指向地宫宝库，开库得金羊角矿与宝库陈列（小未金羊主题陈列，只用既有设定，不新编剧情文案）。
- 宝库一人可开；开库后陈列常驻可见（后来者能看、不能重复领核心物）。

## §6 性能与衔接

- 地下视距天然短，是三层里最便宜的一层；按区块化路线短稿的层集口径实现（地下层一组区块集，进层只建本层）。
- 与地面衔接只有入口两点 + 矿车井道，地面场景零改动。
- 灯光：矿灯（入口与主干道）+ 水晶自发光色块，不引入动态光源系统。
