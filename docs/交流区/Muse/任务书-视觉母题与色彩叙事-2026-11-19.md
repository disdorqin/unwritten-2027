## 色彩脚本（源稿 §2）

- **空间基调（不变层）**：地面雪镇 = 雪白 + 灯笼暖红 + 木色（暖，夜里靠灯笼与窗光）；地下梦境 = 岩青 + 水晶冷蓝紫 + 矿灯暖点（越深越冷）；云海之上 = 白与金（高亮低对比）；轨道舱 = 暗底 + 状态绿灯 + 一处舷窗星球蓝（太空章）。
- **进度滤镜（变化层）**：不改任何物件本体色，只动环境雾色、夜空星色、灯光色温三个全局参数，**按玩家个人集页进度在其客户端生效**（个人滤镜，非世界状态，与多人规则单的个人轨一致）。三档：集页 0 / 6 / 12，作用点为广场夜空（星数与紫意渐增 → 集齐后过顶尾迹见 §5 缺口）、钟楼（北侧雾色偏青 → 集齐后灯格呼吸见 §4 缺口）、西坑口（雾色带青蓝 → 集齐后坑底极弱冷光夜里概率一闪）。执行红线：三档变化必须是「回头看才发现」级别，相邻档截图并置不许一眼可见跳变；色温偏移不超过既有调色管线一个小档；性能零新增（只动已有全局参数）。

## 密度纪律（源稿 §3 现存部分）

- 每屏上限：任一正常游玩视角内，同系母题可见 ≤2、三系合计 ≤3；超限即拆，优先保留叙事位（碑牌、门环）、删装饰位。
- 场景配额：每处遗址只许 1 个母题点（碑牌）；勇士城全城羊纹带 ≤6 处且只在石构主构件上；地面全图圆环母题点（不含 UI 与残页）≤8 处，两道锁门占其二。
- 重复即贬值：同一母题在相邻 30 m 内不得重复出现；母题不做「收集计数」展示。（本条后半句起为源稿截断处，余文待补。）
