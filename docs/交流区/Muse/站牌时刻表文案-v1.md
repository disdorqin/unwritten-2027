# 站牌时刻表文案 v1（Muse 内容口，2026-11-18）

用途：还 GPT 精修回执三确认项之一——站牌时刻表的**文案、格式、发车规则**在此定版。运行模型依据《屋舍空间与火车烟花物理综合设计-v1》主题二（班车制：环线一圈约 4.6 分钟、6 站、每站停靠 12 秒、列车位置为共享时钟纯函数）；站名与既有牌面口径依据《站牌文案-v1》，不冲突、不改名。GPT 此前用功能名牌占位的时刻表，按本文案替换。

**总原则（先说死）**：时刻表上**不印具体钟点**。全镇只有一列车、一条环线，任何「几点几分到站」都会随实现参数漂移作废；时刻表只印**规则**（一圈多久、每圈停靠一次、停靠多久），一切实时数字（下一班倒计时、列车当前位置）由班次函数现场生成填入。

---

## 1. 时刻表格式定版

### 1.1 发车规则（全镇统一口径，所有牌面共用）

- 环镇线单向环行，全天循环运行，**无首末班**：小镇开放期间列车不停班，站台灯亮即可候车。
- 环线一圈约 **4 分 40 秒**（圈长与运行剖面以实现为准，牌面只写「约」数）；**每一站每圈停靠一次**，即本站约每 4 分 40 秒一班。
- 每站停靠 **12 秒**（牌面数字由实现停靠常量填充，见 §4，不在文案里写死第二份）。
- 错过一班，等下一圈：站台小牌与站厅大表都给「下一班」倒计时（班次函数生成，单位：分＋秒）。

### 1.2 站牌时刻表牌（每站站台各一块，版式统一）

自上而下五段，文字如下（`{}` 为班次函数/常量填充位，见 §4）：

```
环镇线 · {本站名}
顺环方向 · 依次经 {其余五站按本站起算的站序} 回到{本站名}
本站　下一站：{下一站名}
本线一圈约 4 分 40 秒 · 本站每圈停靠一次 · 停靠 {停靠秒数} 秒
下一班约 {X} 分 {XX} 秒后到站（动态行，见下）
雪天路滑 · 请在黄线外候车
```

- 「顺环方向」一段即本站视角的站序表：六站全列，**本站加「本站」标记、紧邻的下一站加「下一站」标记**，其余只列名。逐站的具体站序行见 §2 各站条目，施工时按表抄入，不要自行重排（站序以实现停站表为准，文案与实现同源于设计稿主题二 §2.3 的环线顺序）。
- 动态行只有一行：列车停靠本站时显示「列车停靠中 · 请抓紧上下车」；未停靠时显示下一班倒计时。倒计时归零前后如何切换由实现决定，文案只给这两句。
- 安全行沿用《站牌文案-v1》候车提示牌原文，一字不改。

### 1.3 站厅大时刻表（冬夜火车站站厅内一块，及站厅活动卡）

牌面标题沿用《站牌文案-v1》：**跨年特别时刻表**。版式自上而下：

```
跨年特别时刻表
环镇线 · 未写镇站站厅
全线六站（顺环）：未写镇站 → 火车站前站 → 森林木屋站 → 湖南岸站 → 城堡南站 → 温泉站 → 回未写镇站
一圈约 4 分 40 秒 · 每站每圈停靠一次 · 停靠 {停靠秒数} 秒 · 小镇开放期间循环运行，没有末班车
列车现在：{动态行}
下一班到火车站前站：约 {X} 分 {XX} 秒（动态行）
乘车请至站外站台（火车站前站）· 出站即小镇，广场往南
```

- 动态行「列车现在」只给三种句式（班次函数按列车状态选一，站名填实）：
  - 停靠中：`停靠{站名}，即将开往{下一站名}。`
  - 运行中：`正开往{下一站名}，距{下一站名}约 {X} 米。`
  - （无第三态：班车制下没有「候车中/未发车」状态，不要再出现旧文案「列车在站台候车」指代始发站的说法。）
- 站厅活动卡（现状 `railwayStationStops` 的时刻表活动）标题维持现状「环镇列车时刻表」；卡内正文改用上表后四段（规则两行＋动态两行），替换现状的「距回站约 X 米、预计 Y 秒」单站口径——班车制下「回站」概念取消，统一改为「下一班到本站（火车站前站）」。
- 站厅与站台小牌读同一班次函数：两处倒计时读数差 ≤1 秒为验收口径（设计稿主题二 §2.6 已有此条，文案侧不另立标准）。

### 1.4 首末班与跨年夜加班口径

- **平日**：无首末班。牌面不出现「首班/末班」字样；规则行只写「小镇开放期间循环运行，没有末班车」。
- **跨年夜（12 月 31 日）**：通宵运行不打烊；当晚 23:30 起班次配合广场跨年仪式（仪式班次的排班以《跨年夜仪式与中心广场设计-v1》与综合设计稿主题二 §2.4 为准，属期望衔接，**站牌上不预先承诺零点彩蛋时刻**）。大时刻表在当晚可加一行固定文案：`跨年夜通宵运行 · 23:30 起班次配合广场仪式，请留意站台广播`（是否显示由日期判断，文案先备好）。
- **末班提示**只在一种情况下出现：小镇收镇/维护广播时（见 §3.3），平日永不显示。

## 2. 六站逐站文案

站序（顺环，自未写镇站出发向北先行）：**未写镇站 → 火车站前站 → 森林木屋站 → 湖南岸站 → 城堡南站 → 温泉站 →（回）未写镇站**。六站站名全部出自综合设计稿主题二 §2.3，本稿不新拟站名；各站条目含：站名牌、时刻说明行（即 §1.2 版式中本站的站序行）、下一站提示、周边指引一行。

### 2.1 未写镇站（第 1 站 · 既有站台）

- **站名牌**：`未写镇站`（全镇站名常量 `TOWN_STATION_NAME`，副标沿用《站牌文案-v1》：`UNWRITTEN 2027 · 跨年小镇`）。既有「环镇线候车站」「上车点 · 环镇线」两牌保留为线名/功能牌，不与站名牌冲突（替换关系见 §4）。
- **时刻说明行**：`顺环方向 · 依次经 火车站前站、森林木屋站、湖南岸站、城堡南站、温泉站 回到未写镇站`
- **下一站提示**：`下一站：火车站前站`
- **周边指引**：`雪原过山车乘车口在旁 · 红牌是过山车，深牌是火车，别上错车`

### 2.2 火车站前站（第 2 站 · 站厅换乘站）

- **站名牌**：`火车站前站`（名义：本站是冬夜火车站站厅门前的站台——站厅在东、站台在西，步行一分钟换乘；以「前站」与站厅本体区分，避免两个「火车站」相混）。
- **时刻说明行**：`顺环方向 · 依次经 森林木屋站、湖南岸站、城堡南站、温泉站、未写镇站 回到火车站前站`
- **下一站提示**：`下一站：森林木屋站`
- **周边指引**：`往东一分钟到火车站站厅 · 售票、盖章、大时刻表都在厅里`

### 2.3 森林木屋站（第 3 站）

- **站名牌**：`森林木屋站`
- **时刻说明行**：`顺环方向 · 依次经 湖南岸站、城堡南站、温泉站、未写镇站、火车站前站 回到森林木屋站`
- **下一站提示**：`下一站：湖南岸站`
- **周边指引**：`出站即森林木屋区 · 林间雪深，沿灯走`

### 2.4 湖南岸站（第 4 站）

- **站名牌**：`湖南岸站`（站位在冰湖南岸、湖南岸与南河岸之间，取湖名定位，与北岸点位区分。）
- **时刻说明行**：`顺环方向 · 依次经 城堡南站、温泉站、未写镇站、火车站前站、森林木屋站 回到湖南岸站`
- **下一站提示**：`下一站：城堡南站`
- **周边指引**：`冰湖南口在北边 · 滑冰、冰钓从南口下冰，冰面滑，先扶稳`

### 2.5 城堡南站（第 5 站）

- **下一站提示**：`下一站：温泉站`

### 2.6 温泉站（第 6 站）

## 3. 车内 / 站台提示文案

口吻基准：短、准、报站腔（与站长钟铁生的人设同气质——他的人设原句即「信按时刻表送达、从不晚点」一路），但以下均为**广播/字幕文案**，不署名、不冒充 NPC 发言；NPC 本人的台词仍走 NPC 语料，不从这里取。

### 3.1 到站播报（每站一句，列车停稳时字幕/广播）

| 到站 | 播报文案 |
|---|---|
| 未写镇站 | `未写镇站到了。换乘过山车的乘客看清牌子——红牌过山车，深牌火车。` |
| 火车站前站 | `火车站前站到了。去站厅买票、看大时刻表的乘客请下车，往东一分钟。` |
| 森林木屋站 | `森林木屋站到了。林子里雪深，下车慢行，沿灯走。` |
| 湖南岸站 | `湖南岸站到了。冰面在南口，鞋底打滑的，先扶稳再下。` |
| 城堡南站 | `城堡南站到了。去城堡的乘客沿小道往北，灯亮着的那条。` |
| 温泉站 | `温泉站到了。泡汤的乘客请下车——车上不回暖，汤里回暖。` |

统一前缀规则：播报只报「{站名}到了」起句，不加「各位乘客您好」类客套；停靠中如有预约下车乘客，播报后可续一行字幕 `本站停靠 {停靠秒数} 秒`（数字仍走常量填充）。

### 3.2 预约下车提示（车内）

- 拉铃/按预约键后字幕：`下一站：{下一站名} —— 已为您预约下车`
- 未预约时的常驻小字（车厢提示牌/乘坐 HUD 一行）：`按动作键预约下一站下车 · 不预约，就陪您坐满一圈`
- 预约成功后到站前再提醒一次（列车减速进站时）：`列车即将到{预约站名}，预约下车的乘客请准备`
- 紧急结束（非站台下车口径已按设计稿废止 park 语义，落最近已停靠站）字幕：`已为您在最近的车站停靠：{站名}`

### 3.3 末班提示（仅收镇/维护广播时启用，平日不显示）

- 站台小牌动态行替换为：`下一班为本日末班车 · 过站不停候，请抓紧上车`
- 站厅大表加一行：`本日末班车开出后，环镇线停班至小镇下次开放`
- 车内播报（末班车停靠每站时）：`{站名}到了。这是本日末班车，下车后今晚不再有车。`

## 4. 给 GPT 的接入说明

1. **常量归口**：
   - 站名走单一数据源：建议 `RAILWAY_STATION_NAMES` 数组（顺序即环线站序：未写镇站、火车站前站、森林木屋站、湖南岸站、城堡南站、温泉站），与实现的停站表**同一份数据**，文案渲染与列车停站都从它取值，不许在牌面代码里再手写一份站名。
   - 第 1 站站名与全镇站名常量 `TOWN_STATION_NAME`（《站牌文案-v1》已定）指向同一字符串「未写镇站」，不要出现两个常量各写一份。
   - 停靠秒数：牌面 `{停靠秒数}` 一律引用火车实现的停靠常量（设计口径 12 秒，常量名以实现为准），文案文件里出现的「12 秒」只是设计注记，**不得**在牌面渲染代码里写死第二份数字。
2. **数字全由规则生成**：下一班倒计时、「列车现在」的米数/秒数、圈程「约 4 分 40 秒」中的近似值，全部由班次函数（共享时钟纯函数）按当前相位算出填入 §1–§3 的模板；**任何位置不得写死具体钟点或写死倒计时数字**。模板字符串收进文案常量表，函数只负责填空。
3. **与既有牌面的替换关系**：
   - 站厅内既有「时刻表」牌（`landmark-station.ts` 现有 sign）：牌面内容按 §1.3 换为大时刻表版式；既有「售票 · TICKETS」牌、售票盖章活动不变。
   - 站厅时刻表活动卡：标题「环镇列车时刻表」不变，正文按 §1.3 替换（取消旧「距回站 X 米」口径），数据源由 `railway.timetable()` 改读班次函数（与设计稿批 T1 的 API 替换同一步完成）。
   - 未写镇站既有「环镇线候车站」「上车点 · 环镇线」牌：保留（作线名牌与功能牌），新增 §1.2 版式时刻表牌一块；站房正面大字按《站牌文案-v1》为「未写镇站」（现状代码里的「冬夜火车站」是建筑/地块称呼，牌面大字以《站牌文案-v1》为准替换，二者不要并存于正面）。
   - 新增五站（火车站前/森林木屋/湖南岸/城堡南/温泉）：每站按 §1.2 版式立时刻表牌一块＋站名牌，文案逐站取 §2 对应条目；过山车消歧牌（《站牌文案-v1》：`雪原过山车 · 乘车口`，红底白字）口径不变，未写镇站的周边指引行已与之呼应。
4. **验收对文案的检查点**：六站牌面站序与实现停站表逐字一致；任一站牌倒计时与站厅大表同读数差 ≤1 秒；全仓搜不到写死的到站钟点；停靠秒数改实现常量后牌面自动跟随（改常量验一块牌即可）。
