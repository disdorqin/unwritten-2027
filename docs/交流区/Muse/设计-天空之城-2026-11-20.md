# 设计 · 天空之城（2026-11-20，Thomas 定案，总控焊合）

## 定位：四级台阶的第三级
地下 → 地上 → **天空之城** → 太空。四级四种过法：雪橇「跑」、电梯「坠」、飞行器「飞」、太空门「醒」（转场串域）。

## 是什么
一代人的云上观测站：船上拆下的浮空模块，岛基嵌巨型星尘晶（飞行石）浮于云海之上，缓缓漂移自转。等救援、向轨道船体发信号——等了一百年。本质：船摔成四层的一层；地面镇民看不见它（云海遮蔽），他们口中的「天空城」是山顶平台的误认。

## 形态（按宫崎骏《天空之城》语法，Thomas 提供的三张参考图同目录）
- 倒锥形浮岛，岛缘水帘（雪水）落入云海消散；全游戏唯一无雪、是春天的地方。
- 白石圆顶、拱桥、环廊，半裹绿意；观测站宿舍「太整齐」（杯子在桌、日志摊开，人像刚走）。
- 城心巨树：根须抱住城核；镇上许愿树是它当年带下去的枝条。
- 守城傀儡：不攻击，肩有鸟窝；第一个登岛者走近，它摘一朵花递过来（拉普达机器人兵的位置）。
- 岛腹：巨树根须中央悬巨型星尘晶（城的飞行石），还在转、还在哼；本章只可隔根须看，进岛腹是宇宙篇。
- 星台：城最高处观测塔，**太空门在塔顶**——与轨道舱的唯一衔接点（传送有距离上限，地面/山顶不设门；开门=讲古钥一 + 第十三声那一分钟，过门即「醒」在对接舱）。

## 到达
山上只有滑翔翼（雪翼，绝顶翼库、守天哨遗物，一百年只往下飞）；玩家自锻助推器装翼成飞行器（翼+助推器+导航芯三大件），自星港坪起飞穿云海登岛。第一次登顶穿出云海带时第一次看见它——全游戏最大 reveal，窗 D 专门做这一刻。

## 渲染三档（性能口径）
地面零渲染（不存在）→ 山顶低模剪影+缓漂（近免费）→ 飞行接近时全量加载（云海带作天然遮罩）。与镇子永不同屏。

## 本章范围（Thomas 14:28 定）
**先建模，交互后议**：浮岛与城的建模建出来、可飞上去逛；城内交互玩法下一轮再设计；太空门建好锁着；宇宙篇（五舱内景）只备概念图，不动工。

## 残骸分布梯度（同日定，并入总设计）
散落船件三处递增：山坡零星 → 地面集中于冰晶宫（宫即围着冷却系统残骸盖的，寒源与冰晶疯长皆因此）→ 天空之城成套仪器。地下无散落件（全是人迹工程），最深处是整体船头。船件碎片=高级合成材料（助推器喷口/飞行器关键件）。
