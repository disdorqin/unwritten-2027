# 任务书：自家小屋系统细化（2026-11-19，分支窗口细节填充）

源稿：《自家小屋系统细化-2026-11-19》。定位：52 户小屋是玩家的「家」，不是仓库页。本单只做体验与系统口径（屋主接线另有施工线）。前置定版：每户有门牌与室内虚拟空间、每户有床、睡过一次即绑床（未绑回广场）、NPC 不进玩家屋。**排期门：今晚总装上线之后领单；分房认领与首晚动线 N 单对接（见细节 1 注记）。** 母题核对：本单无三系母题物件，已核。

## 细节填充

1. **分房与认领**：先到先认领、一户一主、可带住一人。认领动作 = 在门牌前交互「挂上我的名牌」，无前置条件、无费用、无审批；认领后门牌底纹变色，全镇可见「这户有人住了」。屋主可登记一位同住人（同住人享床位绑定与陈列共赏，陈列架增删只归屋主）；**不设多人合租**。容量账：52 户对 20–30 名玩家，认领峰值用不到六成——**房子不许成为竞争资源**（红线 1），先到先得只决定住哪条巷子。未认领屋两态：样板屋（约 8 户，临广场与主巷，镇公所布置的「过年样板间」，门可进、陈列齐全，不可绑床、不可留物）与邻居屋（其余未认领户，门关着、院子层可达，烟囱有烟、窗有暖光、门口年货随节日微变——玩家认领任意一户邻居屋时即转为玩家屋、原邻居痕迹清场）。弃置与回收：屋主连续 30 天未上线转「托管」（门牌加封条样式、陈列原样封存、床位绑定保留，回来拆封即恢复）；**不回收、不转卖**。对接注记：首晚动线 N 单的「按入门顺序分房」与本单的自助认领，拟合读为——首晚由系统按入门顺序引导至一户待认领屋、玩家在门牌前完成认领动作（引导是动线、认领是动作），待主窗口确认。
2. **屋内功能清单**（无功能的家具不进清单）：床（睡觉过夜推进个人作息相位、回满状态，首次睡自动绑床；床头柜小灯是醒来第一眼）；陈列架（6 格、三类区：收集类=图鉴标本/矿物、荣誉类=奖牌/登记证书、心意类=朋友赠礼；只摆已获得物，来源全走经济闭环）；**工作台（C-12 落点：做冰灯、拓碑文拓片、修补小物——每户同款、不做等级）**；相框墙（**4 框**，大框居中给零点大合影——共创单旧口径 3 框以本单 4 框为准修订）；留言纸（串门朋友在门内留一句话，纸只许一句、只留最近 20 张，屋主可钉 3 张上墙进相框墙区；留言不进 NPC 口、不入镇志，纯玩家层）；门后挂钩（挂雪翼/放镐的固定位，进门自动归置外观装备）。
3. **串门礼仪系统化**：敲门——访客在门前交互「敲门」，屋主在家时听三声叩门并看到访客名，开门或不应答；屋主不在线时敲门只留一条「XX 来串过门」记录（并入留言纸汇总）。屋主不在时访客只能到**院子层**：看院里雪人/柴垛/灯笼、在门环上挂一枚预制小物（年货/鲜花/一颗糖三选一）、在门口留言纸外页留一句话——进不了门；设计目的 = 让「我来过」有痕迹。串门小游戏**围炉夜话**：屋主在家且访客 ≥1 人时火炉旁可开一局，轮流抽话题签（签池为镇子日常话题，源稿体例），每人讲一句（打字或选预制短句），全员讲完炉火旺一次，参与者各得一枚「炭火」小纪念（进陈列心意类）；无胜负、无计时、一局 3 分钟封顶。
4. **屋子的成长**：成长只走陈列、不走扩建（房子不大变、不加盖、不升级；进步外化为陈列架从空到满、相框墙从一张到四张、门口灯笼从一盏变一对）。门牌可改边界：可改名牌底色、门环挂件、春联内容（预制对子库选，或自写一句经敏感词过滤）、窗花样式；**不可改户号编号**（编号是镇子的坐标，邮差跑腿、NPC 指路、镇志记录都引用户号）。院子与灯笼散挂接口：屋主可从自家灯笼里选样式（红纱/冰灯/纸灯三选一），点亮状态跟随屋主作息，同住人与访客不可改；邻居屋灯笼镇公所统一款、样板屋展示款（与灯市散挂点位表、作息单黄昏点灯动作对接）。
5. **屋与故事线**：**原件禁入**（红线 2）——镇志残页、碑文原石、任务信物等一切主线物证不许进屋陈列，只走「拾取 → 交镇长/登记点」的公共通道（防主线私有化卡关）。复制品欢迎：工作台拓**拓片**（可入屋上墙、可赠友）、残页交付后图鉴留**影印页**（自家书桌可翻看）、boss 留**小像**（纪念品形态进荣誉类）。**一户老屋特殊处理（分支窗口落位职责）**：全镇只许一户老屋与矿工时代有关联，处理 = 「留痕不留线」——院墙根嵌半块矿工时代旧工牌、屋内梁上一道旧刻痕，纯陈设、无交互、无任务、不指线索、不进图鉴；**该户定为临松林一侧的老户，具体户号由分支窗口（联络窗口）在门牌表落位时选定并回主窗口备案**（本单先登记职责与判据：临松林、老户、非样板屋、非首晚引导户优先避让）；任何第二户出现同类痕迹按施工错误处理。
6. **红线（源稿 §6，验收口径）**：房子永不成为竞争资源（不抢、不卖、不回收）；主线物证原件不进屋、复制品随便放；NPC 永不进玩家屋（串门礼仪只在玩家之间）；留言与夜话内容只在玩家层流转（不进镇志、不喂 NPC）；成长只走陈列呈现、不走房屋数值与面积。
