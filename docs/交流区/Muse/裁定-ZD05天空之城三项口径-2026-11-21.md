# 裁定 · ZD-05 天空之城公共宿主三项口径

## 一、岛位
天空之城为独立空间域，**岛面高度 Y750 定版**，不迁就 Presence 的 Y 上限（655.35）。需变更的是服务器侧 Y 上限，随本件同一公共批提出。全线只许一个岛位，任何窗口不得另设第二岛位。

## 二、位姿权威
域内与地面同制：服务器权威、域内本地坐标。跨域永不连续飞行，一律转场「醒」；**星港坪为唯一交接点**。本批只登记岛侧到达点。

## 三、飞行状态机
状态机归星港坪侧所有（ZD-03 接口已入主干）：待装配 → 已装配 → 点火窗口（ZB-17 第一分钟旗标）→ 转场。本批只接转场端点；正式装配/扣料/点火逻辑仍候 ZB-22 + G-01 钥匙 + ZB-17，不挡本次挂载。

## 挂载登记
按分级登记：看得见（岛体入默认路径可达）/ 进得去（转场端点接通）分开写，不许合并升格。接线案照 ZD-03 代落先例（取件 + 宿主接线 + 自审三件：tsc / 定向测试 / 构建绿，构建产物含关键字面量）。
