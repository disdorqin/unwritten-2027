# 表 · 陨石坑区面积实测（2026-11-21，分支窗 A 测、C 窗核对）

- **测源**：主干现行坑体准本 `meteor-crater.ts`（B-01 审定形，`meteorCraterFixturePlan`，现网宿主 `town-za22-crater-road.ts` 以此挂载）；坑心世界坐标 **E−120 / N185**，坑沿高程＝镇西缘 N159 处地表高（宿主运行时定）。
- **测法**：剖面函数 `terraceHeightOffsetAt(r)` 逐点采样（步长 0.001 m 数值积分）与解析几何（圆环/圆台侧面积）双算互核，差 <0.1%。

## 注
1. 野地约定界取 r＝110 m（＝坑口径）为坑周管理外缘；任意外径 R 的野地平面面积＝π(R²−55²)，密度账改界时按此式重算。注：该环带东段与镇西填充带（B6）有重叠，跨区密度账勿重复计。
2. 此后坑区密度账（簇/千 m²、灯距覆盖）一律以本表各层平面面积为分母；暖光链灯距以坑沿周长与链路实长计。
3. 坑内各层由 C 窗核对本表数（剖面采样可复现：`createMeteorCrater(meteorCraterFixturePlan).terraceHeightOffsetAt`）。
