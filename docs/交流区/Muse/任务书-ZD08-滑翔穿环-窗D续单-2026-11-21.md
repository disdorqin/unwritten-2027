# 任务书 ZD-08 滑翔穿环（窗 D 续单 · 队列尾预挂 · 六件套版）

- 来源：《设计-交互玩法八案-2026-11-21》案六（Thomas 2026-11-21 批准）。
- 格式：设计书六件套，参照总控 ZB-33 模板；批 4 入仓后对模板再校。
- 准本条款：玩法细则以《设计-交互玩法八案》原文为准本（随批入仓），
  领书后先对原文再开工，冲突处以原文为准。
- 立项标准自检：**玩家手上在忙什么——操纵滑翔姿态对准光环、
  借山风调速穿环、在落靶区收速对准靶心。**

## 一、落点
云海台起跳点 → 主峰山坡环列航线 → 山脚落靶区。雪翼滑翔由
交通变玩法本体，落点全在既有山域，不新建场景。

## 二、场景构成
起跳点接线（云海台既有件，只接线不改本体）；光环列（沿山坡
成列，辉光有源）；落靶区（靶心环纹）；起跳点先人试飞刻记点。

## 三、玩法流程
云海台起跳 → 沿坡穿环计分（连穿加成以八案原文为准）→ 借当日
山风调速改线 → 落靶区收速对靶 → 按距靶心结算精度。失败落雪
无伤（地面和平口径），立即再跳。

## 四、交互规格
- 操纵：俯仰/转向姿态控制，穿环判定按环心通过；
- 环位随当日山风：环列按天气系统山风参数偏移改线，每日不同；
- 落靶：落点距靶心计精度分；成绩呈现守红线（不扩名次榜，
  口径以八案原文为准）。

## 五、系统结合
- 雪翼与滑翔：复用 ZD-02/F-1 与 `src/shared/flight.ts`
  （滑翔比 6:1 已测），只读不改。
- 山风：读天气系统同一风源（G-09 山地侧），不自造随机。
- 前言三栏：活人玩法＝穿环竞速、落靶精度、逐日新线重刷；
  灵魂痕迹＝环列沿先人巡天路线、试飞刻记；故事接口＝雪翼线
  玩法化收口，山风读数与天气线同源。

## 六、验收
快速构建三件＋四齐自查一行。实走：起跳→穿环计分→落靶结算
全程一次；换一日风参、环列改线再验一次。四齐文齐含起跳牌、
靶区牌识文字当场写定。参照物：《风格打造规范》＋云海台既有件
＋ZD-02 雪翼实现。
