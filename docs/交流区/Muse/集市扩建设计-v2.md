### 1.2 新增元素（规模感来源，不只是摊多）

1. **集市大门牌楼**：立于 connect 通道入集市口，E 154 / N ≈ 93.5，跨 3.6 m 通道，双柱横枋 + 「河畔年集」大字（复用现 `makeSign` 字口径、进图集），柱脚登记碰撞，净宽与净高按玩家身量留足（宽 ≥3.2 m、高 ≥3.4 m）。这是集市的「到了」信号：从南环路远远就能看见。
2. **灯笼街**：对街街面上空横贯彩灯串——沿 E 140–168 每 ≈6 m 一跨（`hangFestoon()` 扩量，全集市灯串总量 3 段 → 约 14 段：主街沿街 3、对街横贯 6、北巷 2、前广场围合 3），红/橙双色与现串同批。夜里整条街是一条光带，这是「灯红酒绿」的主载体。
3. **试吃长桌区**：前广场西区（E 140–150 / N 87–93），两条长桌 + 条凳，各摊试吃小碟的集中陈列点（与 §3 试吃台账联动：长桌是台账的「总台」视觉锚点）；桌凳并批、碰撞登记。
4. **小吃坐食区**：前广场东区（E 158–168 / N 87–93），4–6 组小方桌 + 凳，玩家可坐（登记进既有 sit 框架）、路人可坐（§2 静态坐姿位）；头顶 2 段灯串围合，夜里是集市最暖的一角。
5. **年货堆景**：牌楼两侧与前广场四角——年货箱垛、酒坛、红灯笼堆、干果麻袋（纯陈设、并批、逐项碰撞或明确无碰撞的矮件），把广场边角填满，消除「空地感」。

### 1.3 地块核查结论（施工前置，写死）

- **前广场区可用**：N 86–95 / E 136–172 一带不在 `market-stalls` 地块内（地块南界 N 95），是地块 door 与南环路之间的无地块草地，connect 通道 [154, 79.62] 纵贯其中。可用，但三条硬约束：①南环路中心线在 E154 处为 N 79.62、路宽 6 m，**带碰撞物件不得越过 N 84 线**（路北沿 ≈ N 82.6，再留 ≥1.4 m 路肩）；②connect 通道 3.6 m 宽全程净空，牌楼/长桌/坐食区只许在通道两侧；③施工时由 GPT 把该带登记为 `market-stalls` 地块南扩（footprint 南界延至 N 86）或独立 annex 地块，layout 变更在批一回执中报 Muse 核（只登记范围，不动任何既有地块与地标）。
- **东延带可用**：E 174–193 / N 104–115 无 plots、无 roads（southeast 路在 [218, 85]–[176, 74] 一线，远在南侧 ≥20 m）；与主街排同线同标高施工即可，逐摊仍走全盘可站立扫描。
- **北巷有条件可用**：春灯工坊地块（origin [126, 115]、footprint 17×24）东界 E 134.5 与集市地块西界 E 136 之间仅 1.5 m 缝隙，**巷体不得走两地块之间**；定版走法：巷体在集市地块内沿西沿北行（E ≈ 137.8），至地块北界后西折，借工坊地块东南角外缘接其 door 前空地。西折段须在施工时实测工坊建筑实体东墙与地块界的净距（footprint 是地块界、非建筑墙体）：净距 ≥3 m 则巷宽 3 m 落地；不足则巷体只做地块内段 + 北口小广场衔接，不硬挤。此项列入批二验收点，结论回执登记。

## 2. 人气层：路人 16–20 + 摊主补位

### 2.1 人群（沿 v1 §3 系统升级）

- **数量 16–20 名**（v1 为 10–14）：游逛路人 12–14 + 坐食区静态坐姿 4–6（坐姿位计入总数，不另加人）。规模判断：17 摊的街区配 10 人以下显空，20 人是现 InstancedMesh 规格下的舒适上限，再多先看真机。
- **路线**：四条环线——①主街线（E 138 ↔ 191，沿 N ≈ 105 街心往返，含东延带）；②对街线（对面排前 N ≈ 101 短环）；③北巷线（街面 ↔ 工坊 door，慢速、人数 ≤3）；④前广场环（牌楼 ↔ 长桌区 ↔ 坐食区小环）。停顿看摊点在每摊柜台前 1 个（与试吃触发点错开 0.8 m，防人墙堵触发）。
- **渲染与更新纪律不变**：并入 `town-npc.ts` 村民单一 InstancedMesh（42 方块/人、palette 换装），新增路人 palette 6–8 套（围裙/棉袄/学生装等冬装变体）；**draws +0**；只更新玩家 60 m 内路人矩阵，逐帧 CPU 预算上调至 **≤0.15 ms**（20 人 × 42 矩阵，须实测回执）；60 m 外冻结、地块卸载停转，与 v1 一致。

## 4. 性能账：先还债，再扩建

### 4.1 前置硬条件（不达标不许开扩建的工）

春灯工坊/集市街区是全镇最贵街区：工坊内景 **353 calls**、集市街景 **387 calls**，tris 141.9–149.4 万（室内性能画像基线 9cdc6e7）。按《建筑交互精修推进计划-v1》§4.2，该街区增量上限为 **0**，前置条件写死：

> **街区按 16 m 网格分批 + 道具实例化**（把现整街单一大批次按 16 m 格拆开，让视锥剔除重新生效；预计 calls −80~−120）**达标后才解锁扩建增量**。扩建的全部新几何**直接建进新的网格批次**，禁止并入旧整街大批、禁止逐件独立 Mesh；招牌/幌子走既有图集路线（`market-stall-banners.ts` 图集机制已在），禁止一物一纹理；发光全走 emissive，**新增常开光源 = 0**。

### 4.3 「大而稳」上限口径

- **街景视角**：网格分批 + 扩建全量后，集市街景 calls 目标 **≤300 参考线**（即分批省下的 80–120 必须覆盖扩建的剔除损耗还有余）；tris 街景视角增量 ≤ **+12 万**。
- **五视角夜测**：沿 v1 §6——广场 / 纪念馆 / 冰湖 / 酒馆室内 / 集市本地五处同机位夜测，任一处 draws 增量 ≤ +5。
- **裁决口径（Thomas 2026-11-18 12:13）**：以上均为**参考线非硬墙**——超线不自动回退，触发该机位**真机实测**，以真机流畅度为最终裁决；但测数与对账一分不少：每批回执必须带同机位 GL-hook 前后数与峰值机位，数字对不上不验收。
- **远处零成本**：地块卸载后 draws/纹理/缓冲区回基线，逐批抽查（覆盖规划验收第 4 条）。
