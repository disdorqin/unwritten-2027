# 未写镇建筑精修批设计 · 2026-11-19（Muse 设计，GPT 施工）

起因：Thomas 实测点名「3.0 的建筑和之前一模一样」（《Thomas 实测反馈-2026-11-19中午》第 9 条）。查证属实：3.0 主线是玩法/系统，真正新建只有冰宫殿与十二生肖像；原镇住宅 11-18 做过一轮立面回填（交流区回执《2026-11-18-D1原镇住宅立面回填回执》），但只动立面材质/檐口/门窗，**轮廓与室内未变**，玩家扫一眼无区别。本批按项目既定流水线「结构样件 → 外观细化 → 室内陈设 → 第一人称实玩修正」逐栋补课，验收必须含完整外观、完整室内、连续行走（仓库 AGENTS.md 口径）。目前完整走完这条线的只有体素酒馆与冰宫殿，本批的目标就是把这条线推到全镇。

## 二、精修分级与深度定义

### A 级 · 门面担当（玩家进镇第一眼与最高频路过面）

范围：广场环一圈（钟楼、戏台、邮局、酒馆周边、集市入口面）+ 中央区住宅 22 点 + 主街两侧临街面。

深度定义（逐栋全做）：
- **外观细化**：轮廓要有变化，不许只换材质——屋顶形制逐栋选型（见差异菜单）、檐口出挑与滴水、门窗花格实体建模、墙面分缝与勒脚、烟囱、雪檐与冰凌；
- **室内陈设**：可进入、全屋陈设（家具+生活杂物，见清单），灯光暖色点光源与窗透光一致；
- **院落与临街面**：篱笆/柴堆/水缸/晾晒/菜畦/招牌幌子至少三类，门牌必挂；
- **实玩修正**：第一人称从主街走过+进门+室内转身+出门，全程复查一遍并回改。

### B 级 · 次街与功能建筑

范围：其余具名公共建筑（长厅、灯笼作坊、温室、小屋群、灯塔）+ 集市/湖畔/纪念/森林四区住宅点位。

深度定义：
- **外观细化**：同 A 级清单，但屋顶形制可从区内已验样板复用（每区立 3 栋样板后推广）；
- **室内陈设**：可进入、主要房间陈设齐（生活清单至少 4 类），次要房间可简陈但不许空屋；
- **院落**：至少两类生活细节；
- **实玩修正**：连续行走抽查（每批全覆盖行走，逐栋进门抽查比例不低于一半，其余以截图位验收）。

### C 级 · 远端背景

范围：扩展区 58 地块 + 纪念区东端、湖畔北端等低频到达点位。

深度定义：
- **只做外观轮廓级**：屋顶形制与配色基调逐栋有别、门窗发光面、烟囱；**不做室内**（门不可进，但须有门面与窗透光假象，避免「纸片屋」感）；
- 验收以远景截图位（自主街/广场望向该区）+ 逐栋差异核查为准。

### 每栋必含生活细节清单（类别菜单，A 级 ≥5 类、B 级 ≥4 类）

灯具（灯笼/壁灯/窗灯）、炊烟与烟囱、柴堆、晾衣/晾晒物、水缸/水井、菜畦/花盆、招牌/幌子、门牌、货堆/陶罐/木桶、禽畜小景（鸡笼/狗窝类）、冰凌/雪檐、室内家具（桌椅/床柜/灶台）、室内杂物（书架/挂画/地毯/瓶罐）。

## 三、批次排期

### 与其他工作的先后关系

1. **广场二期扩容先行定界**：广场 bounds 若扩大（反馈第 11 条，目标约 2 倍），批 1 的临广场面栋范围必须在扩容定界后划定，避免扩容返工；戏台专项同理，在广场二期定界后开工（戏台在广场南沿正下方）；
2. **钟楼功能化另案并行**：功能（塔钟/敲钟/登塔）走钟楼专项设计，外观与体量（加宽、翼楼打通）与本批批 1 同步协调，一栋只施工一次；
3. **新场景扩图错峰**：北岭/镜湖先生图后施工，与本批不同地块、无冲突，但验收人力错峰——扩图施工周不排本批新批开工；
4. **总装树冻结期间**：本批全部在分支线施工，不进正午总装树，逐批验过后走总装流程上线。

## 四、每栋验收线（A/B 级逐栋适用）

1. **完整外观截图位**：街面行进视角 1 张 + 四向各 1 张（C 级以远景位替代四向）；
2. **室内**：可进入、陈设达本级清单下限、灯光与窗透光一致、无空屋（B 级次要房间简陈须在回执中逐间注明）；
3. **连续行走**：自主街/广场出发，步行到门、进门、室内一周、出门回街，全程无卡点、无穿模、门位与碰撞不回归（B2b 已验的门位/恢复口径不动）；
4. **逐栋差异 ≥2 处**：从差异菜单中选并在回执逐栋登记——屋顶形制（双坡/歇山/平顶加檐/带阁楼坡）、门窗样式（花格/板门/拱窗/推拉）、院落构成、招牌幌子、配色基调（墙面/屋面色系）、烟囱有无与位置；
5. **与邻居协调**：同街区保持该区 styles 主题基调（森林区 alpine 为主、集市区 shop/machiya 为主等），差异在菜单内变，不跳风格、不与相邻栋同形制+同配色连排；
6. **性能回填**：每批回执附同机位 draws/tris 增量实测（见五），超预估须说明去向。

## 五、边界

- **不改 layout 既有 plot 位置与门位**（含全部 plots 的 origin/door/connect 与住宅点位坐标、housePortals 口径），B2b 已验的门恢复/名册/场地保护不回归；如某栋精修确需动门位，单独报 Muse 裁定，不许先斩后奏；
- **不动已上线的玩法系统**：NPC 驻守锚点、集市摊位、雪仗/雪橇路线、百门通门网、仪式动线在本批范围内只许绕让，不许迁移；
- **性能参考线**：PC 450 draws / 2.2M tris 为参考线、真机体验裁定（既定口径）。逐批增量预估方法：每批先做 1 栋样板，用现有同机位称量口径（P2 称量法：固定机位读 draws/tris）实测样板增量，再按批内栋数与形制分布外推整批增量，写入批前说明；批后以同机位实测回填，对不上须逐项说明。住宅为 InstancedMesh 合批生成（district-layout 口径），精修优先走「换形制/加实例化构件」而非逐栋独立 Mesh，draws 增量主要来自室内陈设与院落构件——此为方法判断，实际增量以样板实测为准，本设计不预设数字；
- **不改已验数值与文案**：建筑名牌、NPC 台词、玩法数值不在本批范围；
- 本设计只定规格与验收，施工分工（GPT 主施工、分支窗口可领街区）由派工单另发。
