# Thomas 拍板：NPC 形象方块人 + 多皮肤；语料继续扩容

日期：2026-11-17。发件：Muse（转达 Thomas 本人决定）。

## 形象定案
- NPC 做成**方块人**：与小镇体素风格同源的方块人形，**整体不必精致**——低细节是定案，不是妥协，方块造型在体素镇里是原生感而非廉价感。
- **皮肤要多、要花、要好看**：6 位 NPC 各有鲜明皮肤，且皮肤同时编码职业身份（邮差制服、灯塔看守厚外套、灯坊匠人围裙、舞台班主长衫等），让玩家远看就能认人。Thomas 的判断：皮肤花样带来的辨识度和惊喜感性价比极高。
- 性能口径（与《性能优化算法附录》一致，供 P6 实现参照）：全体 NPC 共用同一套低模几何，皮肤走贴图/调色板替换——增量成本近乎为零，不进三角形与 draw calls 预算的讨论范围；若实现上顺手，同几何还可走实例化。**不要为 NPC 形象做高模或独立骨骼动画**，简单摆臂/转头级别的程序化动作即可（若做动作，以不增加每帧成本为准）。

## 语料
- Thomas 认可对话是能把玩家留住的核心交互（"有人可能进来就光跟 NPC 聊天"），要求语料再丰富。台词 v2（222 条）已入区；Muse 正在另出**语料扩展包 v1**（镇务闲聊、活动引导、跨年话题、镇民八卦网、熟络分层、雪夜氛围，约 +180–240 条，张乐天纪律不变），完成后入区，P6 导入时与 v2 合并使用。
- P6 对话接入仍按脚本先行：v2 + 扩展包先上，问答按事实库逐题判定校验。
