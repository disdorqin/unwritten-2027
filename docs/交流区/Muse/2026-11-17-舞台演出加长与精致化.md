# 舞台演出：加长 + 动作与人物精致化

日期：2026-11-17。来源：Thomas 22:02 指示（19:24 已提"演出加长、多编排动作"，本次加重：动作与人物都要更精致）。定位：P5 舞台共演的升级项，也是 P7 跨年仪式的预演场——跨年主秀将复用这套节目结构。

## 一、时长与节目结构
- 单场总时长目标 **5 分钟量级**（现版偏短），结构化为多幕：开场群舞 → 双人/独舞段 → 道具段（红绸/灯笼/扇子任选其二）→ 全员终幕；幕间有班主报幕停顿，观众共演入口保留在群舞与终幕段。
- 可循环连演；玩家中途加入共演、中途离席不打断节目时钟。

## 二、动作精致化
- 动作库扩容：除现有动作外，增加队形变换（横排→雁阵→圆阵等至少 3 种队形走位）、同步齐舞段（全员同拍）、独舞高光段；动作之间用插值过渡，**禁止姿势瞬跳/回弹**（验收逐段看）。
- 节拍与舞台灯光联动：灯光变色/追光跟随段落切换与独舞高光（用现有着色/自发光手段，不新增常亮动态光，守性能红线）。

## 三、人物精致化（仅限舞台班子，与镇民规格分开）
- 镇民 NPC 维持已定的"方块人 + 花皮肤"规格不变；**舞台演出者升一档为"演出级"**：仍是体素家族语言，但服饰与妆面用更细的体素密度/贴图刻画，角色行当可辨（班主柳三弦 + 旦角/舞者/乐师等，皮肤即行当标识，与镇民同一设计原则）。
- 人数有界（建议 4–6 人）、只在舞台区出现，三角形增量须计入舞台机位预算（calls ≤300、tris ≤150 万，A4 复测核销）；动画走程序化变换，不上骨骼系统。

## 四、验收（Muse 执行）
- 全程录测一场：总时长、幕数与队形变换次数达标；任一时刻无姿势瞬跳；
- 舞台机位性能复测不破预算；共演加入/退出不中断节目；
- 与跨年仪式的关系在回执中说明：哪些段落将直接复用为 P7 主秀。
