# 常驻规程增补 · 完工四齐、不留空白（总控 2026-11-21，Thomas 亲令）

Thomas 原话：每一个新加入的场景、建筑、美术、细节都很完工，不要留有空白——参照是星露谷一类探险游戏，无一处空白。此令即日为全线常驻交付标准，覆盖此前一切「先挂载、后补完」的默许。

## 完工四齐（缺一不算完工，不许挂载上线）
1. **形齐**：结构本体完整，无半截墙、无占位盒、无「后续再补」的骨架件。
2. **饰齐**：装扮密度 ≥ 老镇同面积 2.0 倍且成簇；同框 ≥3 材质家族（反全白）；光影有源（灯有盏、影有向），不是平光裸模。
3. **互齐**：每个故事点至少三碰（看/听/动手）；可交互物真能交互，不许摆个样子点不动。
4. **文齐**：一切游戏内文字当场写定——展签、木牌、日志、时刻表、图鉴条目，不许留空白、不许占位符、不许「待审」状态上线。文本归属：故事线文本归总控，其余归属在任务书里写明；文本没到位，整包按未完工计。

## 执行口径
- 半成品只许本地暂存，登记状态写「在建」，**不进发布**；回执的状态词只许用：在建 / 完工待验 / 已挂载（四齐后）。
- 已上线内容的存量空白列《空白回补清单》逐项清零，头号：纪念馆四区展签文本（总控亲写，2026-11-21 交）。
- 自审回执新增一行：「四齐自查：形/饰/互/文 逐项是或否」，有一项否不得报完工。
- 与快速构建口径的关系：验收动作仍从简（构建/起页/实走），但**交付物本身**的完整度按本令从严——快的是流程，不是成品。
