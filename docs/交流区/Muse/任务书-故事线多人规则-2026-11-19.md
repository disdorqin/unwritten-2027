# 任务书：故事线多人规则（双轨/拓片/大页开讲）（2026-11-19，分支窗口细节填充，前置口径）

源稿：《故事线多人规则-2026-11-19》。**定位：前置口径**——本稿是下游多份任务书的多人进度口径总闸：残页/讲古/世界状态在多人下怎么算，以本单为准；与批B《故事线章回与残页》、图鉴、地下线深化、家系、群像诸单冲突处，多人口径以本单为准（地点门控、章节结构等单人结构口径仍归各原单）。**排期门：今晚总装上线之后领单**；本单是规则层，挂各既有系统实现，不新建场景。台词全文一律不在本单（讲古/补讲文本回主窗口过目后填充）。

## 细节填充

1. **双轨数据模型**：世界轨 = 全镇镇志页数（服务端全局唯一值，0–12）；个人轨 = 每位玩家护照内该页「已听」标记（12 格独立）。残页碎片为个人拾取物、进拾取者背包，按人在来源处刷新（与 §2 拓片制同制），不存在被抢先拿走即消失。
2. **交页与誊抄纪念**：谁拾齐谁可交。首交者推进世界轨 +1 并触发该页既定广播；后交者不推进世界轨，照常听讲古、点亮个人「已听」，护照该页页脚标注「第 N 位交回人」（N 为该页全镇交回序号，服务端计数，荣誉向）。**旁听**：交页时在场玩家同步点亮「已听」——在场判定拟定为以镇长为中心 15 m 内且在线（对话范围口径，施工回执登记实测值）。
3. **拓片制**：碑、牌、铭文为世界陈设，永存永不被取走；交互产物为个人拓片（= 残页碎片），不限量、无冷却。遗址旁的一次性宝点是例外，走既有宝点规则，与碑文可拓性互不绑定。
4. **天降坠痕**：碎块本体（星尘矿）维持先到先捡；其上铭文页走坠痕拓片——碎块被拾走后落点留坠痕，后来者在坠痕存续期内可拓得该页。坠痕存续期拟定为**至次日 06:00**（与故事夜段 20:00–06:00 同界，施工回执登记）。分享口径：矿物可赠（沿图鉴稿），拓片不可赠。与图鉴单对接：90 秒第一触碰归属继续管「完整物」，碎块本体先到先捡、页走坠痕，三者互不冲突（此为本单对图鉴 C1 的叠加层，非改判）。
5. **大页/小页分级**：小页 8 页按当面讲（交页者听、在场旁听）。**大页 4 页 = 第 4、8、11、12 页**（页码依批B 对接表/梗概编号）走全镇事件：交回 → 镇长「留页」不当场讲 → 全镇广播（护照待办 + 广场钟声提示）→ 约定当晚一个整点开讲（或交页者选定的下一个整点）→ 开讲时在场者共同点亮「已听」并得「共听」纪念标；**世界轨推进时点以开讲为准**（交回只是预约）。开讲在场半径拟定为以广场开讲点为圆心 45 m（覆盖广场全域，施工回执登记）。没赶上者事后自己交页时由镇长单独补讲（内容一致，无共听标）。
6. **段位显示**：玩家名片与对话气泡只显个人「已听」段位、不显具体页内容。段位拟定五档，与镇长四档阈值对齐：0 = 未启卷 / 1–3 = 初听 / 4–7 = 听过半本 / 8–11 = 接近尾声 / 12 = 听全了。官方渠道（NPC、广播、任务指引）对未进度者只出未解锁口径（既有 NPC 分段口径）；系统不禁玩家口头剧透。
7. **引路人**：老玩家陪新玩家走已完成段（陪拓碑、陪下井、陪听补讲）计「引路人」荣誉计数（护照荣誉页 + 镇长处挂名），**不给任何数值资源**。陪跑判定口径拟定：与被陪者同场完成该段关键节点即计一次（施工回执登记判定实现）。
8. **世界状态层**：开井、宝库开门、勇士城锻造坊点火等世界状态为全镇一次性、永久生效；但每位玩家的首次通过体验按个人轨完整保留——入梦坠落仪式/模式切换/首见怪节拍按个人首次触发（与地下线深化单对接：井的开关是世界轨，「入梦第一次」是个人轨，两者解耦）；守库傀儡对每个首次挑战者按个人/小队刷新，宝库核心物不重复领（定稿口径）。纯机关型一次性谜题解开后保持解开，旁立署名「这是某某打开的」（记首解者名，荣誉向）。
