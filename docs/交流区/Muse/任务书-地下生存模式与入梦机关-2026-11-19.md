# 任务书：地下生存模式与入梦机关（2026-11-19，分支窗口细节填充）

源稿：《地下生存模式与入梦机关-2026-11-19》（Thomas 提案、主窗口成稿）。**覆盖登记（先读）**：本单**推翻**《地下层设计定稿》§4「怪不伤人、无血条」旧口径——新口径：地面和平、地下生存（Thomas 18:34 定版原则：下午讨论出的新东西可以盖旧）。地面规则一字不变。本单是地下链的总纲单：矿洞 KD、水晶洞 SJ、勇士城 YS、地宫 DG 四段书与地下线深化 U 书引用的模式口径一律以本单为准；四段书已按本单口径写就，施工时如有冲突以本单为准回执登记。**排期门：今晚总装上线之后领单；分级 B（首季补完，地下链总纲）。**

## 细节填充

1. **双模式**：和平模式（地面全域，含前山/主峰山域）——无血条、只摔不伤，维持现行全部口径。生存模式（地下全域）——血条开启；怪物会攻击，伤害来源只有两类：怪物攻击 + 深渊坠落（普通落差仍只摔不伤）；回地面自动切回和平，血条隐藏、状态清零。模式切换点 = 过井口深度线（见第 2 项）。回血：地下各层的篝火/营地点（矿工营地、勇士城广场、宝库前厅）站定回血；回地面即满；不设血药、不设饥饿（与矿洞书的营地火点、勇士城书的广场安全区 + 冷焰回血、地宫书的宝库前厅口径逐点对接）。
2. **入梦机关（地下入口的仪式）**：陨石坑底的井口原本**被遮盖**——盖板 + 碎石 + 陨石残块压着，封锁时代盖的；不知情的人只看到一堆陨石和碎石（与陨星原书 XJ 单的坑底构成对接）。机关：坑底绞盘（在断裂吊臂基座旁）转动 → 盖板滑开 → 露出黑井；**第一次触发者直接坠入**（落进井底深水潭，不扣血）——这一下就是「入梦」（合裁定 C-07：首坠为仪式）。机关开启后常驻：吊笼可用，后来者正常下井（仍是入梦，模式切换点 = 过井口深度线；合裁定 C-06：入口门 = 绞盘/盖板，三条下行路为开井后解锁）。叙事包装只到机制层：地下是镇子的「梦境层」，死 = 醒；不写剧情文案、不设 NPC 解说（文本纪律：本单零剧情文案位）。
3. **死亡与重生（醒梦）**：血空先**倒地 10 秒**——队友拍一下即半血唤醒（多人合作点）；无人救或单人 → **在床上醒来**。重生点二选一：默认中心广场；玩家在自家屋内床上睡过一次即绑床，之后醒在自家床边（每家虚拟空间的床就是为此——与小屋书 XW 单的床位对接）；首次下井前，井口绞盘旁立牌提示先绑床（通用短词，文本走短词口径、不写长文）。惩罚从轻（朋友局口径）：工具不丢；当次梦境背包的矿物**掉一半**（留在死亡点，可再下去捡回），另一半算「从梦里带回来了」；已合成/已领取的成果（助推器、雪翼、护照章、图鉴）永不回滚。
4. **难度递进（层层闯关）**：矿洞层——雪团怪群守关：1 击融化，数量取胜，单人轻松。水晶洞层——晶蝠群 + 雪团精英（大一号，2 击）：俯冲频繁，要走位。勇士城——冰傀儡 ×2 + 晶蝠巢：3 击融化，开始需要合作或走位拉扯。地宫门前——**守库傀儡（关底）**：巨型冰傀儡，血厚，三段攻击（横扫/投冰/召唤雪团），单人可过但要磨，是地下线的毕业考（与守库傀儡战专稿、地宫书 DG 单的触发口径合并执行：12 m 抬头线、3 m 手紧特写、总起身约 3 s 的拟合读以 DG 单登记为准）。闸门规则：《世界联系线》§3「清完本段怪闸门才开」保留，与本表一致。怪物数值红线：**任何一击不许秒杀满血玩家**（朋友局底线）；关底守库傀儡单人通关时长目标 3–5 分钟。击数口径与怪物图鉴、雪球书地下复用接口对齐（雪球克冰雪系、镐克硬体系的双工具骨架不变；雪球在地下不许克 BOSS 全程，守库傀儡只在投冰阶段吃雪球反制）。
5. **与既有稿件的关系（覆盖与保留清单）**：定稿 §4 除「怪不伤人」外（击数、掉落、刷新）仍有效，击数即第 4 项表内融化击数。探照塔「扫到只做视觉提示」不变（地面设施属和平区）。地宫一人可开的老规矩不变：关底单人可过即满足。地面一切既有口径（寒意、跌落、雪橇、堡垒）不因本单变更；地下与地面的语音隔离从语音书 YY 单（层集隔离硬口径），本单不另立。
