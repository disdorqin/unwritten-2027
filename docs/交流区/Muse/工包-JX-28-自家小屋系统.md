# 工包 JX-28 · 自家小屋系统

- 分区：分区一（地表）。来源：《任务书-自家小屋系统细化》（批 I，5edb20d）。拆包：分区窗口一转包批一（2026-11-20）。
- 依赖：无。接口：分房认领与 JX-27 首晚动线对接（拟合读：系统按入门顺序引导至待认领屋、玩家在门牌前完成认领动作；待主窗口确认，确认前按拟合读施工）。SN5 旧木匣落点为本包登记子项——选户待施工线门牌表（92 门逐户版）与主窗口确认，表到前不落点。
- 范围：认领=门牌前交互「挂上我的名牌」（无条件、无费用、无审批），一户一主、可登记一位同住人（享床位绑定与陈列共赏，陈列增删只归屋主），不设多人合租；认领后门牌底纹变色、全镇可见有人住。未认领两态：样板屋约 8 户（临广场与主巷，门可进、陈列齐全，不可绑床、不可留物）与邻居屋（门关、院子层可达、烟囱有烟、窗有暖光、门口年货随节日微变；被认领即清场转玩家屋）。托管：屋主连续 30 天未上线转托管（门牌封条样式、陈列封存、床位保留），不回收、不转卖。屋内功能清单按源稿逐项（无功能的家具不进）。红线：房子不许成为竞争资源。
- 验收：认领/同住/托管三流程实走；样板屋与邻居屋两态逐户登记（52 户状态表）；绑床与重生点对接验（与 JX-27 同口径）；NPC 不进玩家屋负例验。
- 常驻：永不停机+最高并发；回执带「区块自洽」行。本单无三系母题物件，源稿已核，施工保持。
