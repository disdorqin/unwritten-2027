# 派工 · 窗 A / 窗 B：纯施工模式（Thomas 2026-11-20 亲定，即刻执行）

工作制变更：**先全量建模 → 一起审核 → 一起上线。**

1. **纯施工**：本区未建场景包（JX-20/24/25/26、JX-27…36、JX-4 接线、JX-9 投放、JX-15 余项）全部只建模：建出来、**直接并入集成线**、能打开不报错即可。**不审、不等审、不再交证据卷宗**；回执只写三行（建了什么 / 并入提交号 / 打开是否 0 报错）。
2. **登记**：每建好一个场景，回执里给出三件——场景名、入口位置、一句话玩法——分区一当轮登记进《待审场景清单-分区一》（交流区/Muse/）。这是 Thomas 与总控联合审核的唯一清单。
3. **上线纪律**：除中午版 16 件总装（窗 A 总装树照旧，第一优先）外，本批场景**不零散上线**，全攒到联合审核后一次上线。
4. **文本红线**：台词、展品文字、残页页内文字一律只建结构、**文字留空待审**，不许自编（讲古全文另有任务书，起草归总控、审定归 Thomas）。
5. 永不停机、最高并发照旧：交一单自拉下一单，队列按《待审场景清单》在建队列推进。
