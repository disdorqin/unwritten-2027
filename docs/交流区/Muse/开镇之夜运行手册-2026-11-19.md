# 开镇之夜运行手册（房主手册）

> 写给 Thomas 本人。正式开镇：2026-12-31 20:00（北京时间），除夕夜。
> 这本手册管「房主怎么过这一晚」，不管游戏内容本身。当晚节拍以庆典线口径为准，本手册只做对齐与落地。

---

## 一、开镇前检查清单

### T-7 天（12-24 前后）

- [ ] **服务器续费确认**：朋友的腾讯云轻量到期日 2026-12-12，续费必须在此之前落地。确认方式：让朋友在控制台续完后发一张到期日截图，看到新到期日在 2027 年内才算数。没续上，这本手册其余部分都不用看了。
- [ ] **开镇构建已上线**：今晚总装的发布包已推 town-release 并通过 healthz 校验（版本号逐字对版），不是排练包、不是本地包。
- [ ] **邀请名单定稿**：首晚 5–8 人，名单写下来，谁用 PC、谁只能用手机，心里有数。手机党提前私聊提醒：「用手机自带浏览器或 Chrome 打开链接，别在微信里直接点。」
- [ ] **自己的号走完一遍第一晚动线**：按《新手第一晚动线》从进镇到睡下完整走一遍，卡点当场记，不等开镇夜现修。

### T-3 天（12-28 前后）

- [ ] **正式构建开关核对**：排练构建（rehearsal build）已关，正式构建为开镇版。核对项：零点仪式、烟花秀（102 发）、守岁星过顶、钩子一号（钟楼第九声）均在正式构建内开启。
- [ ] **链接自测**：用另一台设备（或无痕窗口）点开镇链接，从加载到进镇计时；超过一分钟还在转圈，记下现象，交给施工侧，不要自己猜原因。
- [ ] **真浏览器引导自测**：在微信内置浏览器里点一次链接，确认引导页正常弹出、话术说得清「请点右上角用浏览器打开」；QQ 内置浏览器同测一次。
- [ ] **群里预告**：在朋友群发一条：除夕夜 20:00 开镇，链接当晚发，先到先逛，不用准时，不用带任何东西。

### T-1 天（12-30）

- [ ] **服务器状态再看一眼**：站点能打开、能进镇、走两步不卡。顺手确认朋友那边当晚是否在线可联系（只留一个电话/微信即可，不预设出事）。
- [ ] **自己的设备**：主力 PC 充电/插电、浏览器更新到最新、关掉会抢带宽的下载与同步。备一台手机作第二视角，万一朋友说「我看不到你说的那个」，你能立刻切到手机视角对位。
- [ ] **自己的网络**：当晚用最稳的那条网（有线优先）。提前想好断网时的备用：手机热点名字和密码自己先连一次试通。
- [ ] **零点仪式流程默念一遍**：23:50 召集、23:52 守岁星露头、零点整点全员传送广场、烟花、00:09 守岁星没入——顺序在本手册第二节，不用背，放在手边即可。

### T-1 小时（12-31 19:00）

- [ ] 提前进镇，站在广场，把当晚要用的东西在心里过一遍：讲古开场在哪说、第一圈带逛的路线怎么走。
- [ ] 群里发链接，附一句话：「开了，慢慢来，卡住就喊我。」
- [ ] 本手册打开放在副屏或手机上，故障预案那节不用提前看，出事再翻。

## 二、当晚时间轴

| 时点 | 镇里发生什么 | Thomas 要做的事 |
|---|---|---|
| 19:00 | 开门（提前一小时放人进来适应） | 发链接，自己先进镇在广场等；谁进来就打个招呼，不用正式开场 |
| 19:00–20:00 | 自由摸索期 | 盯三件事：有没有人进不来、有没有人卡在加载、有没有人找不到路。问题攒着，别为一个人的小问题冷落全场 |
| 20:00 | 正式开镇 | 在广场做开场（口径见第三节），然后带第一圈：广场 → 钟楼 → 戏台 → 集市，一圈讲完就放大家自由活动 |
| 20:30–21:30 | 新手第一晚动线自然展开 | 不跟全程。去看看每个人的进度，谁落单了去陪一段，谁玩得正欢别打扰 |
| 21:30–23:00 | 自由探索 + 地下/主峰等长线内容自然分流 | 这是你自己也能玩的时间。朋友问路就指路，问剧情就给一句话版本（第三节），不剧透真相层 |
| 23:00–23:40 | 守岁氛围升温 | 开始往广场方向收人：路过谁都提一句「快零点了，回广场守岁」。不用强制传送，这个时点是软召集 |
| 23:50 | 全员向广场集结 | 主持位站定，做零点预告（第三节）：告诉大家整点会被一起传回广场看烟花，手里的事可以先放下 |
| 23:52 | **守岁星露头**（未央号轨道舱过顶开始） | 提醒大家抬头看天，点一句「守岁星出来了，这时候许愿最灵」——这是镇上的说法，照着说就行 |
| 00:00 | **零点整点：全员传送广场 + 烟花秀**（102 发） | 什么都不用做，和大家一起看。传送是裁定好的仪式，不要提前剧透传送本身，预告只说「一起回广场」 |
| 00:00–00:09 | 烟花 + 守岁星在头顶 | 许愿环节顺其自然：有人许愿就接一句，没人起头你先许一个，给个样子 |
| 00:09 | **守岁星没入**，庆典节拍收束 | 说散场词方向的话（第五节），不宣布「结束」，说「今晚到这，想留的继续逛」 |
| 00:30 | 软散场 | 还在线的人多半是自己想多玩的，不用陪全程。你可以先下，留一句约首周的话（第五节） |

补充：钩子一号（钟楼第九声）在当晚自然埋下，不用你做任何事，更不要向任何人解释或暗示。有人注意到了，笑笑说「钟一直有点毛病」就够了。

## 三、主持词口径

只给结构和分寸，不写死台词。照着方向说，用自己的话。

**开场三句（20:00，广场）**
1. 第一句是欢迎：除夕夜大家愿意来，这个镇就是为今晚开的。
2. 第二句是定调：这镇子没有任务逼着你，没有输赢，想逛就逛，想坐着看雪也行。
3. 第三句是给钩子：镇上有本没写完的镇志，缺的页散在各处——今晚不用急着找，先认识路。

**零点传送预告（23:50）**
- 只说三件事：快零点了、大家一起回广场守岁看烟花、手头的事放一放不会丢进度。
- 不说「传送」两个字的机制，不解释原理。整点人齐刷刷落回广场的那一下，惊讶本身就是节目效果。

**朋友问「这游戏讲什么的」——一句话版本**
> 「一座雪镇，镇子的历史没人写完，你们来一边过年一边把缺页找回来。」
- 就这一句。追问细节就往回带：「玩着玩着就知道了，镇长那儿能听讲古。」真相层（未央号）一个字都不提，那是太空章的事。

**讲古开场（如果你当晚亲自引一场）**
- 只引不讲：把人带到镇长面前，说一句「镇上的事，镇长记得最全」，然后退开，让 NPC 讲。
- 有人中途走开去玩别的，完全正常，不要挽留，更不要复述讲古内容替 NPC 补课。

## 四、故障预案

原则：先安抚，再判断，最后处置。当晚的目标是「大家过个好年」，不是「系统全绿」。

| 现象 | 判断 | 一句话处置 |
|---|---|---|
| 某人点链接进不来 / 白屏 | 多半在微信或 QQ 内置浏览器里打开，页面跑不起来 | 「点右上角，用浏览器打开再试」——还不行，让他换设备或用电脑，这晚先别耗在他一个人身上 |
| 某人卡在加载界面超过一分钟 | 网络问题或构建资源没拉全 | 让他刷新一次；再不行清一次浏览器缓存重进。两次都卡，记下他的设备型号和网络，当晚放行，事后排查 |
| 某人频繁掉线 | 他那边的网络抖动概率最大 | 让他靠近路由器或切有线；游戏进度有存档口径，掉线不等于白玩，跟他明说「进度在的，重进就行」 |
| 全员同时掉线 / 镇子进不去 | 服务器或发布侧问题 | 先在群里说一句「镇子歇一分钟，我看看」，然后联系朋友看服务器状态；自己不要凭猜测反复重启服务 |
| 服务器当晚需要重启 | 已确认是服务端问题、且朋友在线可操作 | 挑人少的时点，在群里预告「整点前重启一次，五分钟」，重启后自己先行进镇确认能玩，再喊大家回来 |
| 零点仪式或烟花没按预期触发 | 构建开关或时序问题，当晚大概率修不了 | **止损**：不解释技术原因，顺势说「今晚烟花改手动」，带大家去广场放现有的烟花/看守岁星过顶，把仪式感用守岁星和倒数补回来 |
| 某个新玩法/新区域明显坏了 | 单点故障 | 当晚直接绕开：宣布「那处今晚先封着，改天修好再去」，把人引回正常区域。不在开镇夜现场修内容 |

**止损总口径**：开镇夜修不了的东西，一律「记下来、绕开走、改天修」。判断标准只有一个——这个问题会不会让超过一半的人玩不下去。不会，就绕开；会，才动用重启这一级处置。任何情况下不对朋友解释技术细节，给现象级的说法就够：「镇子在打盹，马上好。」

## 五、散场与留人

**00:30 不硬留。** 除夕夜大家各有安排，能留到零点已经给足面子。散场只做三件事：

1. **留一句话**（方向，不写死）：今晚是开镇，镇子以后每个晚上都在，想来就来，门不上锁。重点落在「以后还在」，不落在「今晚多好」。
2. **约首周的一晚**：当场定一个具体的点——比如「初三晚上八点，还在这儿，我带你们下矿开井」。给日期、给时间、给一个没玩到的内容做由头（开井/登前山/冰上夺宝，任选其一，别全许）。约得越具体，回流率越高；「下次再约」等于没有下次。
3. **镇志补遗第一页由你起头**：散场前或第二天，你自己在镇志补遗里写下第一页——就记开镇这一晚：谁来了、零点烟花、守岁星。第一页必须由房主写，后面朋友的页才有人接。内容不用长，三五行即可，写完在群里说一声「镇志补遗我开了个头，你们的名字都在第一页里」。

散场后第二天在群里补一条：昨晚的合影/截图发出来，再重复一遍首周之约的日期。照片和日期，是唯二需要主动发的回访钩子，其余不用多说。
