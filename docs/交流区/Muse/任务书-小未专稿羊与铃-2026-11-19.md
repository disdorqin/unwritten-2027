# 任务书：小未专稿-羊与铃（2026-11-19，分支窗口细节填充）

源稿：《小未专稿-羊与铃-2026-11-19》。定位：吉祥物专稿。小未是未写镇的吉祥物、2027 丁未羊年的年度脸面，也是故事线里唯一「活着的文物」。本单定它的出没、互动、铃铛与故事位置；人物与来历以故事线章回结构、NPC 群像小传为准，本单不改来历、不写台词。**铃铛的系统位置就此定版：铃 = 小未的在场信号系统**（分支线批 E 已实现 mascot bell，本单为其补设计口径）。**排期门：今晚总装上线之后领单；分级拟 B（首季补完），待总清单增补时对齐。**

## 细节填充

1. **小未的一天**：小未不入 NPC 作息表——16 岗按钟过活，它按羊过活（饿了吃、困了睡、天黑回圈）；它的「日程」只给时段与地点倾向、不给钟点，玩家靠铃声和习惯找它。晨（晨钟前后）：羊圈门口等第一把菜叶（镇长上班顺路留菜叶是固定小场面；没等到就自己啃圈边草皮上的霜花——与镇长作息行对接）。上午：广场边 → 集市外围顺人流慢慢逛，在吃食摊下风口站一会儿（不讨食，只站着），偶尔钻进许愿树荫打盹。午后：许愿树下/湖畔西岸草坡睡午觉主场（湖畔时与垂钓翁同框：一钓一睡、互不打扰）。黄昏：自己往羊圈走——全镇唯一不用人赶的下班（黄昏钟一响，它沿老镇巷子慢慢回圈，路上玩家跟它走能走完半条「回家路」）。夜：羊圈里睡，夜段不在外游荡（夜里镇子是守夜人的，下井归来的人在坑口听不到铃——秩序感）。特殊日：除夕夜在广场边（专属一小块围栏花坛位，看烟花时它在场但不惊）；守岁星过顶时它也在广场——**全镇仰头那一帧，它低头吃草**（庆典构图里的小笑点，与庆典书 J 单对接登记）；暴雪封山日不出圈、圈里加棚。出没地纪律：它只在地面老镇生活圈活动（羊圈、广场、集市外围、许愿树、湖畔西岸、老镇巷子），**不进地下、不上主峰、不上前山、不进玩家屋、不进纪念馆与冰宫内部**——它活动的范围就是「镇子的日常」。
2. **玩家与小未的互动五件**：① 喂食——玩家手持菜叶类（集市生鲜摊领/换，生态稿羊食口径，与集市书、生态书对接）走近，小未抬头吃掉；亲近度只涨体感不涨数值（不设喂食次数奖励、不设好感度条；当日被喂满三把就只闻不吃，玩家立刻懂「够了」；菜叶之外不许喂——不许喂矿物、鱼、雪球）。② 跟随——玩家在它身边慢走超过几秒，它顺路跟一段，走到它不去的地方（镇界、屋门、水边深处）就停下回头；跟随不是宠物系统（不能召唤、不能命名、不能带走；它跟谁走纯看谁在旁边慢慢走，跑起来就跟丢——它不跑）；黄昏回圈路上是跟随体验主场（陪它走完回家路是没有任何奖励的一件小事，这正是设计目的）。③ 铃铛（听声辨位）——小未脖子上的铃是全镇唯一的可听声标：玩家循铃声的方向与疏密判断它的大致位置（铃响 = 它在动、铃停 = 它在睡或在吃）；铃声不做 UI 标记、不在小地图打点（耳朵就是雷达）；铃声音量随距离衰减、隔墙闷、风里断续（与声音书 Y 层对接）；铃与瞭望塔小钟、坑口信号同属「声音找人」一系，但只服务日常、不服务求救（与衔接书信号系统分工登记）。④ 合影——小未是全镇最上镜的居民：玩家在它身边停留摆拍，它不配合也不躲，拍到什么算什么；合影点体系里小未不设专属点位（它在哪，哪就是隐藏合影点——登记入《合影点清单补齐》的口径注记）；除夕大合影时它的位置在前排边上（构图口径从拍照稿，不许摆到 C 位正中——它是镇子的羊，不是道具）。⑤ 摸头——走近交互键摸头，它眯眼、低头蹭一下手，铃轻响一声，仅此而已；无次数限制、无冷却表演，每次反馈一致（体素羊的反馈靠眯眼/低头/铃响三个小动作轮换，不做夸张动画；连摸十下它就走开两步——羊的耐心也是设计）。
3. **小未的「羊群」**：小未不是镇上唯一的羊。羊圈在老镇边缘（与镇界过渡带的篱笆相连，与地表补完书镇界口径对接），群羊十来只，是镇子牲畜的全部：产奶的说法只许在集市吃食摊的体例里出现（羊奶点心），**群羊不做产出系统**（不挤奶、不剪毛、不计数，它们就是活着的背景与小未的同类——与生态书羊群口径一致）。小未与群羊的区别只有两样、都摆在明面上：① 铃——只有小未有铃，镇上人说铃是老辈传下来的（来历只许传说层一句，不许解释；铃的形态与冰上夺宝宝物大金铃铛同为老式样口径从群像稿——裁定 R2-01 后宝物已定版为大金铃铛，「同款」表述成立）；② 亲人——群羊怕生、见人散开，小未不怕人、认得常喂它的人（行为差，不设数值）。玩家分辨小未靠铃声与这两条，不靠体型放大或异色（它混在羊群里时，循铃找它本身就是玩法）。羊群的日常：晨放、昏归（黄昏小未带头回圈是固定画面），雪深档影响出圈远近，暴雪日全圈不出；羊群不入图鉴、不入收集（它们不是内容，是日子）。
4. **小未与故事线**：它什么都不知道，它只是活得久——传说层只许一句量级的话（「羊比镇子老」式），羊是老辈带到镇上来的，老辈是哪辈、从哪来，不许任何 NPC 说清。玩家在集页路上会在三处固定遇见它，每处只是一个小场面（无台词、无触发奖励）：场面一·纪念馆外墙根（小未在纪念馆后墙背风处打盹，身后墙上就是展线里那件「不对劲」展品对应的外墙位置——它不知道墙里是什么，它只是年年在这晒太阳）；场面二·陨石坑围栏外（玩家第一次去西坑口那天，小未站在围栏外望着坑的方向站很久，然后低头吃草——羊看远处是常态，但玩家会记住这一眼）；场面三·钟楼下（第九声响过的某个整点之后，小未在钟楼下抬头看塔——羊对声音敏感，仅此而已；钩子一号的味道靠这种「说不清是巧合还是不是」的场面攒，与钩子书 H 单对接登记）。三处场面共同纪律：不交互、不发页、不推进度，玩家路过看见即可（给二刷玩家和考据玩家的糖，不是任务系统的钩子）。**金羊与小未的关系口径留白**：金羊传说、小金羊摆件与小未之间是否有关系，本单不定——留给主窗口在终章方向里裁定；**裁定之前，任何下游单不许把小未写成金羊、不许让它在金羊终局里承担机关功能**；它到结局也只是一只羊。
5. **红线（源稿 §5，验收口径）**：不许骑乘、不许牵引过界、不许带入地下与主峰/前山；不许剪毛/挤奶式产出、不许把羊群做成养殖系统；不许死、不许病、不许被攻击（和平模式，怪物图鉴无羊；雪球砸中它只算玩家之间的玩闹误伤口径——它抖抖雪走开，与生态书「动物永不死亡」红线一致）；不许拟人台词、不许「小未好像听懂了」式暗示它通灵；不许把铃做成可摘下/可赠送/可佩戴的道具（铃长在它身上，是信号不是装备）。
