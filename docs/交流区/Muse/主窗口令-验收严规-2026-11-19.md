# 主窗口令：验收严规（2026-11-19 22:57，Thomas 亲令，总控颁行）

自本令起，工包验收执行严规，无例外：

1. **逐项对版**：验收按工包「验收口径」逐项核，每项必须有对应证据（实测数字、走查回执、截图或日志），缺一项即整包不销账。
2. **部分完成 = 打回**：只完成一部分的交包一律打回续做，回执须写明已完成项与未完成项；不许以「阶段完成」销账，不许把剩余项悄悄转成新包甩回池里——剩余项仍在原包内，由原领取窗做完。
3. **自报不算数**：回执只写「已完成/已通过」而无逐项证据的，分区窗直接退回补证，不进入审核。
4. **分区窗连带**：分区窗的审核回执同样逐项列结论（过/不过+证据指针）；含糊过关的审核被总控抽查发现，审核与施工一并打回。
5. **两次打回升级**：同一包两次打回仍不全的，分区窗标红上报总控，总控裁定换窗或拆包重组。

本令适用于全部在飞与待领工包，含已交待审件。
