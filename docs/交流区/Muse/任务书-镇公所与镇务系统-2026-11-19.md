# 任务书：镇公所与镇务系统（2026-11-19，分支窗口细节填充）

源稿：《镇公所与镇务系统-2026-11-19》。定位：镇公所是镇子的「办事处 + 客厅」——镇长守镇志、讲古在此，但讲古内容不在本单（讲古全文过主窗口审，本单只管场所与镇务系统）。与纪念馆分工先划清：纪念馆是「展出的记忆」（残本进柜、展线叙事），镇公所是「活着的镇务」（人还在用、事还在办）——残本原件不在公所展出，公所只留镇志的痕迹一处（见第 5 项）。全镇无货币、无市政数值：本单不设税收、不设政务模拟、不设好感度，镇务全部是仪式与信息，不是管理玩法。**排期门：今晚总装上线之后领单；分级拟 A/B 交界（落户仪式与留言板当日牌示随首晚动线 A 级先行，镇务全量 B），待总清单增补时对齐。**

## 细节填充

1. **镇公所的空间（五处，逐处答「玩家在这里做什么」）**：门厅（进门第一间：留言板、镇子平面小图——体素沙盘式、只标公共建筑与岗位点、一把长椅、一壶热茶氛围件；进镇先看这里：查当日牌示、看自己在哪、等朋友集合——公所门厅是天然集合点）/ 讲古位（门厅侧间的火炉旁座位圈：镇长的椅子与几张小凳，墙上挂一幅镇子老图（传说层画法）；交残页、听讲古的场所（内容另审）；不在讲古时这里是空的——椅子在、炉火在、人不在，氛围先于功能）/ 留言板（门口外墙的大木板，见第 2 项；查牌示、留话、看告示——镇子的信息中枢，不进门就能用）/ 失物招领角（门厅角落一张长桌 + 格子架，见第 3 项；找回自己掉的地面物品、围观镇民的乌龙失物）/ 镇务公告墙（公所外墙另一侧：告示区（见第 2 项）+ 镇子大事记木牌列——只记已发生的公共事：开镇日、首登绝顶者姓名牌位（记名口径接成就稿：须本人事迹、非排名，与成就书红线对接）；看镇子最近发生了什么、新玩家在此读懂「这镇子是有日子的」）。空间纪律：公所室内不设二楼、不设办公区深处——镇长的「办公室」就是讲古位，全镇务对外只有这五处；找镇长只有两个地方（讲古位、在岗时段的广场），与作息稿口径一致。
2. **留言板系统细化**：当日牌示（系统面）——留言板上半区是岗位牌示，按作息稿五段刷新（晨/上午/午后/黄昏/夜），每段换一次：写明此刻谁在岗、谁串岗去了哪、夜里谁值守（玩家查「人去哪了」先看板，不许出现跑遍全镇找人的体验——与作息书 I5 全镇留言板口径同件合并执行）；牌示是体素木牌翻页式呈现，翻页动作由镇长晨段上班时完成（作息稿：镇长开公所门时顺手翻牌——动作即系统）。玩家留言（共创面）——下半区是玩家留言区，寿命接共创稿四层里的「当日层」：留言以纸条形态挂上，当日可见、次日晨段由镇长收下归档（不展示归档内容，收走即清爽）；体例：一条一纸条、限短句、只能挂在留言区格内（不许贴到公告墙与失物角——区域纪律即防呆）；留言不设回复系统（回话靠当面或邮局信件——与邮局书 YC 单分工）。告示（NPC 面，只定体例）——公告墙上的告示只有四类、形态各异一望而知：封山告示（暴雪封山日晨段贴出，红边木牌：只写封山范围与火塘避雪点，落款守火人口径）/ 加场告示（戏台节庆加场，黄纸：戏名与场次时刻，落款班主口径）/ 值守告示（夜段值守变更时：当夜值守岗与岗位点）/ 镇务告示（镇长手书体例：只用于公共事——开镇、补史仪式日程类，一月难得一张）；告示全部只写体例与落款规则，正文由下游按核准口径填，本单不写告示原文；告示寿命：事件过即撤（镇长黄昏巡板时撤——与作息稿镇长黄昏广场散步一圈的动线咬合）。
3. **失物招领**：边界先划清——地下死亡掉落的半数矿物**不走失物招领**（那是死亡点自取的生存规则，任何系统不许代收、不许邮寄、不许在公所出现，与生存口径对接登记）；失物招领只管地面层的小遗失。收什么：玩家在地面掉落/遗落的非关键物品（手作、吃食、纪念小物类），由路过的岗位 NPC「拾到」后放到招领角（系统形态：物品在地面无人拾取超时后转入招领角格子架，保留至次日夜段；过期未领的化作氛围陈列——镇民的伞、围巾、单只手套，越攒越像个真角落）。关键物（残页、护照、图鉴本体、雪翼/助推器）永不进失物系统（残页不可掉落是多人规则既定口径，其余关键物与人不分离）。认领防呆（朋友局乌龙口径）：认领只认「物主标记」——物品入角时格口挂小牌写拾到地点与时段（体例信息，非物主名）；玩家认领自己物品直接取走（系统按归属放行）；**别人的东西可以看、可以拿起来端详，但放不进自己包里**（拿起三秒自动回格，配一个体素小动作：格口木牌晃一下）——把「顺手牵羊」做成无伤大雅的乌龙而不是纠纷；朋友间真要转赠走当面赠与或邮局（既有通道），不借失物角之手。氛围件：招领角常年有三件「永远没人领」的东西（长桌尽头：一把老伞、一只单手套、一本没封皮的旧本子）——只做陈设，NPC 零解释，玩家问到只许岗位口径的含糊（文案另审）；旧本子与第 5 项的镇志痕迹呼应但**不是同一件**，不许合并、不许暗示是残页。
4. **落户：新玩家的欢迎仪式（镇务的仪式面）**：新玩家第一次进镇，动线在此成环（与小屋稿、护照口径对齐，不重定规则、只编排仪式）：① 进门先到公所——新手第一晚动线把公所排在前段（进门厅、看沙盘、翻留言板；教学稿口径：30 秒内学会「找人看板」，与引导书 YD 单对接）；② 登记——在讲古位旁的登记册上留名（册子是体素大开本，玩家名字以牌位小字入册；「落户」的动作本体，一次完成；显示名口径从账号规则）；登记即触发镇长的一句欢迎（文案另审，只定有此一句）；③ 领护照——登记毕当场领护照（发放归既有设计，本单只定「在公所领、领时镇长盖第一章：**落户章**」——护照的第一页从此有镇子的印；落户章为仪式章、不计入 16 岗满章条件，与师傅章同属护照记录行口径）；④ 认领小屋——拿着护照去老镇认领小屋（认领规则从小屋稿：先到先认领、一户可同住），屋门牌挂上自己名字的那一刻落户完成（与首晚动线书 N 单、小屋书 XW 单对接）；⑤ 回公所挂牌（可选收尾）——公告墙大事记旁有一列「新户牌」，落户当日可自愿挂一块小木牌（名字 + 落户日），挂满一列换新列，旧列移纪念馆外廊（与纪念馆分工的接口：公所记「正在发生」，纪念馆存「已经发生」——与纪念馆书 JG 单对接登记）。仪式纪律：全程无强制——跳过落户照样能玩全镇，落户只给护照首章与新户牌两个纪念物，不锁任何功能；老玩家带新玩家走这条动线是默认形态（多人规则的老带新口径），公所门厅的长椅与热茶就是为等人的老玩家备的。
5. **镇公所与故事线**：镇志痕迹（一处，传说层）——讲古位的墙上挂着一幅装裱起来的**单页手抄镇志**（字迹工整、内容是传说层的开镇记事；体例：抄页而非原件、内容另审），页脚一行小字注明「原件存镇长处，此为抄件」——原件在镇长手里、残本在纪念馆柜里、抄件在公所墙上，三处分工不混；抄页只许这一页、不许多挂、不许随集页进度换页（换页即暗示公所在编史，与镇长守誓的人设冲突）。入梦开井日的站位：地下线关键日，黄昏段镇长不在讲古位、不在广场散步——他站在公所门口望西（陨星原方向），不拦人、不送人、不说话（作息稿已定行为，本单定站位：公所门廊台阶上、正对西向小路——与作息书 I4 对接）；玩家若在当晚下井前路过公所会看见他，下井归来若已过黄昏，他已回后宅、公所只剩门厅的灯。讲古的场所纪律：讲古只在讲古位发生（镇长坐他的椅子、玩家坐小凳），不在广场、不在路上——集页交页的仪式感由场所保证；大页之夜的全镇宣布在广场（多人规则稿），宣布的是「补完」，宣读页文只在讲古位（C-08 口径：认账私密、页文不公开——与修订登记口径一致）。
