# 设计 · 精选三案实现规格（总控 2026-11-21，Thomas 圈选 1/4/8 并亲令写法）

Thomas 令：设计书必须写到实现——放在哪、哪个场景、怎么玩、交互是什么、怎么与现有系统结合。自本单起立**设计书六件套**为常驻格式：①落点 ②场景构成 ③玩法流程 ④交互规格 ⑤系统结合 ⑥验收（第一人称实走）。概念单不再出仓；八案拆书时逐案按六件套补齐才许施工。

## 案一 · 钟楼报时人（拟 ZB-41；窗 B 系统＋窗 A 场景件）

**①落点**：大钟楼（ZA-19 场景）钟楼层＋维修间。楼层动线：登楼梯→钟室（钟、钟绳、更漏）→维修间（历代修钟记录本、齐更生工位）→登顶平台。

**②场景构成**（窗 A 补件，现 ZA-19 基础上加）：可交互钟绳（垂至钟室地面，带摆动动画钩）、大钟摆动动画钩、更漏（水钟，液面即时刻的实景读数）、维修间记录本（可翻页对象）、值守挂钩（挂玩家的外套＝值守状态的实景标记）。

**③玩法流程**（一夜值守）：
1. 夜幕初落时到钟楼，齐更生在维修间交班（对话触发，文本归总控另交）——他回家，玩家值守。
2. 夜里共四道报时：入夜钟、夜半钟、夜半二钟、晨钟。前三道由玩家亲手敲，晨钟自鸣（口径：晨钟唤全镇，不用人）。
3. 每道报时前，更漏液面接近刻线、钟室光影变化作预告（实景提示，非 UI 箭头）；玩家在刻线窗口内拉绳敲钟。
4. **第十三声分钟**（在夜半二钟之后、晨钟之前，由 ZB-17 漂移公式定其当夜时刻）：钟绳无人自摆——玩家此分钟内**双手离开钟绳、视线保持在钟上**（守的实景化），完整目击＝调查「守」步达成；碰绳或移开视线＝今夜作废，明晚再来（可错过口径）。
5. 天亮齐更生回来接班，维修间记录本多出一页玩家的值守记录（系统生成，记当夜四道钟的准点与目击与否）。

**④交互规格**：
- 拉绳：按住 E 蓄力（绳身下沉、钟口微张），松开落锤；蓄力过短＝闷响（敲漏），过满＝钟声带颤（敲过）——以钟摆摆幅条为唯一反馈面（实景 UI，不弹卡）。准点窗口＝更漏刻线前后各一段（约现实 6 秒），三档评价：准/漏/过，记入记录本。
- 目击：第十三声分钟内，视线判定＝准星保持在钟体包围内累计达八成时长；期间任何交互键输入（除移动微调）即破。
- 失败全软：敲漏敲过只记账不惩罚；目击破了明晚再来。单人可成，无多人锁（第二人同在钟室时，其视线不计入）。

**⑤系统结合**：时刻与漂移＝ZB-17 信标（单一公式，本案只读）；钟声广播＝现行全镇广播通道，四道钟与第十三声同源；调查旗标＝钟楼三步（听/守/验）既有设计，本案落地「守」，「验」仍走账本漂移推算；图鉴新增「报时人」条；齐更生作息＝ZA-24 活人表加一条交班动线。天气（ZB-20）大风夜：钟绳自摆幅度大，目击更难（视线判定同标准，摆幅只是视觉）。

**⑥验收**：第一人称完整值守一夜——登楼交班、四道钟逐道评价入本、第十三声目击判定触发、晨钟后记录本新页可读；另验一夜故意碰绳，目击作废且不报错。

## 案二 · 矿车轨道（拟 U-17；窗 C 主建，窗 B 协车辆手感）

**①落点**：矿洞一层（−90）主巷：营地遗迹（旧镐点）→矿门/水晶洞岔口（U-15）。全长按矿洞 200 m 尺度取主巷直线段约 120 m，轨道即深度梯度里已定的浅层装扮（矿车/轨道/木支架），本案把其中一段做成真能跑的。

**②场景构成**：轨道本体（双轨＋枕木，沿主巷贴地）、矿车 1 辆（服务器共享物）、三处破损点（塌枕木段/轨距偏段/锈死道岔）、两端站台木跺、两端各一具「唤车绞盘」（手摇把空轨拉回）、道岔扳手 1 处（中段岔口：往矿门/往深巷支线口，支线本期只到洞口景观位）。

**③玩法流程**：
1. 首次到营地端：轨道断着——依次修三处（换枕木：搬运就近枕木堆的枕木逐根放；正轨距：撬棍逐下撬正；通道岔：敲锈＋上油（油壶在营地工具架））。修通后全线可跑，破损不再刷新（永久修复，全镇进度）。
2. 乘车：站台上车（交互键），车沿坡自滑加速；下坡尽头是岔口与站台缓冲堆。
3. 行车中：刹车＝按住空格（闸瓦火花＋尖啸，减速）；道岔＝必须停车下车扳手（第一人称动手），再上车续行。
4. 运矿：车斗可装肩扛份的 3 倍矿石（装/卸在两端站台操作）；人走车不走时，另一端可摇绞盘把空车唤回（满车不可唤，须人押）。
5. 脱轨：超速过岔或不刹到底——车翻进缓冲雪沙堆，人无伤（地下死亡规则不触发），把车扶正推回轨（单人可）。

**④交互规格**：上车/下车 E；行车只有刹车一个主动输入（按住制，松开续滑）；速度三档体感（慢/常/险），险档有轨声变调与画面微震作警告；噪声＝行车全程大噪声（接 U-13 声系统：怪会朝轨道线聚，停车后散去）——快与险是同一枚硬币。单人全程可成；多人时车是共享物，位置服务器权威。

**⑤系统结合**：U-8 挖矿（矿装车）、U-13 生存（声/光：车头灯是移动光源，耗灯油同手持灯）、U-15 矿门（岔口即矿门前广场）、ZB-26 雪橇车辆代码范式（上/下车、速度分档、翻车不伤的口径平移复用，不另写车辆框架）；修复三件与缆车抢修（八案二）共用「维修动词」族（搬/撬/敲/上油），交互提示文案同源。

**⑥验收**：第一人称——修三处逐处可验；营地端上车、全程一刹一扳、到岔口端下车；装 3 份矿运回营地端入账；对端唤空车成功；故意超速脱轨一次，扶正复轨成功；行车噪声引怪、停车散怪各见一次。

## 案三 · 雪地追踪（拟 ZB-42；窗 B 系统，两区分区出地表件）

**①落点**（物种×区域定表）：狐——B4 西北缘（狐狸洞，第八版已上线）；兔——古松林缘；獾——B1 东北野地溪岸；羊（野山羊）——B3 山裙上沿；鸟群（雪雁）——镜湖南岸芦苇荡（第八版已上线）。每区一条链的起点带（区缘）＋终点窝点，链长 150–300 m。

**②场景构成**：足印链（实景贴花，非 UI 标记：兔＝Y 形跳印、狐＝直线小印、獾＝五趾拖印、羊＝双瓣印、鸟＝三趾印＋羽痕）、次级痕迹（树干爪痕/蹭痕、粪粒、啃过的枝条、窝点本身）、窝点（狐洞 3 处预置轮换；兔的凹窝；獾洞；羊的背风石窝；雁的芦苇深处巢）。

**③玩法流程**：
1. 触发：ZB-20 天气出「新雪」后，各区缘随机起 1–2 条新鲜链（全服同源，链头有小未偶尔驻足盯看的软线索）。
2. 跟踪：玩家沿足印步行跟进；足印新鲜度随游戏时衰减（边缘由锐转糊），大风提前吹散暴露段。
3. 断点三类，须用真办法接续：①过冻溪——对岸偏置处续印，要自己找；②针叶林地——印变淡，须慢走（潜行键）贴近才显（与地下慢走潜行同一输入）；③石砾带——无印，靠次级痕迹（爪痕/粪粒）指向下一段。
4. 终点：望见窝点与动物一面（动物在玩家进入其警戒距前逃离，只给望见——地面和平红线，不可猎不可伤）；该物种图鉴页点亮，窝点有一件「藏物」（狐狸藏的亮物：玻璃珠/铜扣/旧纽扣，收集品，进老宅储物箱陈列格）。
5. 链终结：动物搬家（狐洞在 3 处间轮换；其余物种换链路），图鉴页记本次的链长与断点接续数。

**④交互规格**：无专用键——走、慢走潜行、望筒（高点找续印/望窝点）即全部操作；跟丢无惩罚，回链头或等下一场新雪。单人可成；多人同跟同一条链时，藏物只有先到者一份（其余人图鉴照点）。

**⑤系统结合**：ZB-20 天气（新雪起链/大风散链，同源状态机）；足印链原为景物册装扮件（方向性），本案升级为可玩的实景引导——仍不设任何 UI 箭头与地图标记（故事暗线口径）；小未行为表（ZB-25）加一条：新鲜链头附近驻足；图鉴物种页五页；藏物接老宅储物（ZB-22 背包/储物箱口径，藏物占肩扛位）。

**⑥验收**：新雪后第一人称跟完 B4 狐链全程（区缘→过溪断点→狐洞），图鉴点亮、藏物入箱；回访见狐洞已轮换；大风日验一条链暴露段被吹散、靠次级痕迹接上；全程无 UI 标记出现。
