# 雪橇坡面行为包（对主干 `ec8ddce1`）— live 故障修复，Thomas 11:12 亲点

## 根因（两层，都在代码里实证）

1. **ride 层把上坡判成撞车**（`sled-ride.ts`）：旧条件 `curbRise > .25 且速度 < 8` 或 `|grade| > .55` 即 `crash()`——台阶地形上 0.8 m 内抬升 .25 m 是常态，爬坡速度一掉到 8 以下就翻车清零；陡面采样坡度 >.55 更是任何速度都撞。`crash` 在速度 >6 时是 tumble（滚转两圈）＝Thomas 看到的侧翻。
2. **motion 层动力学断崖**（`sled-motion.ts`）：推力只在坡度 ≤.25 时存在、上限速度从平地 22.6 在坡度跨过 .06 的瞬间跳变为 4 m/s 硬爬速；长坡永远 4.00 m/s，且台阶采样坡度抖过 .25 时推力整段消失。

## 修法（`sled-slope-behavior.patch`，3 文件）

- ride：撞车只留真台阶（curbRise > .9）；坡度/低速台阶不再判撞；唇口起跳加条件（前方 1.5 m 坡度 ≤.1 才跳，持续爬坡中的台阶只走 bump）。
- motion：可推坡上限 .25 → **.35**；低速档 4 → **5.5 m/s**；推力上限改为按坡度在 .06–.25 带内**线性混合**（22.6 → 5.5），断崖变斜坡；超上限速度的惯性冲坡段**免库仑摩擦**（只受重力与风阻），动量不再被吃干。
