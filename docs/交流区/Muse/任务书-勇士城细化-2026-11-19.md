# 任务书：勇士城细化（2026-11-19，分支窗口细节填充）

源稿：《勇士城细化-2026-11-19》。定位：地下第三段「勇士城」（−165）的场景细化。本单只做空间与体验设计，不改任何已定数值与规则。已定版前提：城在水晶洞（−140）与地宫（−190）之间；构成 = 城门、≈180 m 主街、石屋排房、铁匠铺、市场拱廊、中央广场（半倒持剑勇士像）、一段可走城墙；美学 = 巨石石构 + 中式石灯 + 石牌坊，与地面小镇同文化根；水晶从街缝长出，月光石街灯发冷光；飞行助推器在城中铁匠铺锻造（陨铁 + 星尘矿）；城内怪 = 石头怪、骷髅勇士、冰傀儡、晶蝠巢；三时代叠层以远古为主，矿工时代只留边角；羊形纹属原住民文明遗迹，NPC 对原住民零提及（原住民禁区在本城全域适用）。地下为生存模式，与生存模式单、地宫书 DG 单同批对接。**排期门：今晚总装上线之后领单；分级 C（太空章前长线，随 V1.2 地下贯通后段）。**

**母题核对**：羊形纹只出现在远古石构（像座基座、瓮巷壁刻）——远古层为视觉稿合法出场域，只刻形态、无文字无说明无交互发光，本单已核。

## 细节填充

1. **主街动线**：全城一条主街贯通，自入城门至往地宫的二道门，全长 ≈180 m，宽到可供两队玩家错身跑动。动线分五段，每段有明确的功能落点：第一段·城门与瓮巷（约 25 m）——玩家自水晶洞方向下行，穿过高大的石牌坊式城门（门楣无字，只有凿痕）；门内是一段微弯的短巷，两侧石壁有旧时刻度线（水位？身高？不解释）；玩家在这里做：减速、点灯、整队（巷口内侧设一处「城门火盆」长明点，是进城后的第一个可停靠光点；巷壁留一排方形凹槽（旧时插火把位），玩家可在此读到本城的第一处羊形纹小刻——只形态，口径见第 3 项）。第二段·主街前段（约 55 m）——石屋排房夹道，月光石街灯立起，街缝水晶开始出现；玩家在这里做：探索与清怪的第一战场（石头怪装睡混在街边残像里，晶蝠巢挂在两户屋檐下）；沿街三处可推开的石屋门（见第 4 项）是临时掩体与搜寻点；此段节奏 = 边走边打、边打边认城。第三段·中央广场（约 40 m 见方）——主街在此放大成广场，半倒勇士像占据中央（见第 3 项）；玩家在这里做：集结、回血、整补、定下一步路线；广场是全城的心理中点（来路与去路在此交汇，广场四角的石灯是全城最亮的四盏）。第四段·主街后段（约 40 m）——铁匠铺与市场拱廊分列两侧（见第 2、4 项）；玩家在这里做：锻造助推器（铁匠铺）、搜寻与绕柱战（拱廊，骷髅勇士的主场）、在拱廊阴影里处理冰傀儡；此段是「办事区」，目标性最强。第五段·二道门与下行口（约 20 m）——主街尽头是第二道石门（比入城门矮、厚、旧），门后即往地宫（−190）的下行道；门前一小块空地是出发坪；玩家在这里做：最后整队、确认血量与篝火补给、推门下行；此段不刷怪（安静是设计，让玩家自己听见脚步声变重）。
2. **铁匠铺细化**：铁匠铺在主街后段北侧，是全城唯一有「活火」的地方——炉火是暖色，与满城冷光形成唯一对照，这本身就是路标（玩家在城里任何位置，只要看见暖光，就知道铁匠铺在哪）。锻造流程（仪式化四步）：① 交料——玩家把陨铁与星尘矿放上铺前石台（材料以实体块形态呈现在台面上，不进菜单虚空消失）；台面随材料齐备亮起一圈刻纹光。② 开炉——玩家拉动炉侧的鼓风石柄（交互动作，有阻尼感的慢拉），炉火由暗红转白，整间铺子被照亮，街对面的拱廊都沾到暖光。③ 等待——锻造不是瞬时完成：炉上有一道「火候槽」以火焰高度呈现进度（约一小段时间），等待期间铺内陈设逐件被火光扫过（墙上挂的旧工具、半成品的刃、炉边水槽的蒸汽）；等待不许无聊：火候槽每涨一格，炉中传出一次低鸣，广场方向能听见（这是给同伴发信号——「有人在锻造」是全城事件）。④ 出炉——成品助推器自炉口缓缓推出（不是弹出背包），玩家上前双手取下，炉火随之回落到常火；出炉瞬间铺子烟囱口冒一股带星尘微光的烟，城墙上的人看得见。锻造配方与助推器口径从既有定版（陨铁 + 星尘矿，助推器合成正址在本铺——与经济书 E 层、飞行书对接；成就「勇士城的客人」以在此完成一次锻造为条件）。叠压痕迹一处：铺子后墙是远古巨石墙，矿工时代的人在墙脚砌了一道矮砖灶台基，砖已塌半边（两层砌法在一面墙上直接对撞——玩家交料时就站在这面墙前；不立牌、不解释，看见即知道这地方比矿工还老）。
3. **勇士像广场**：巨像构成——持剑勇士像原为立像、现半倒：上半身连同持剑臂斜倚在广场东侧，头颅落在像座前、面朝城门方向；下半身与像座仍立在广场中央；剑尖拄地，剑身完好；体素口径：像体用与城墙同色的巨石块，断面处不用新石（断口颜色更深，像在地下潮气里泡了很久）。广场功能口径（**地下安全区/集结点**）：广场是勇士城的指定安全区——怪不进广场（石头怪止步于广场边线，骷髅勇士绕柱但不入广场，冰傀儡不越广场石灯圈）；此口径是功能性的：玩家在地下需要一个「可以停下来商量」的地方，广场就是。篝火点在此的特殊形态：广场不设地面篝火，像座基座有一圈环形石槽，槽内是常燃的**冷焰**（月光石粉与星尘的青白火），玩家在此围槽回血——「冷火回血」只此一处，与矿洞、水晶洞的暖篝火区分（回血规则本体从生存模式口径，本处只是形态变体），让玩家身体记住「到勇士城了」；像座同时是天然的集结标记（任何队伍约「城里见」，默认就是像下）。羊形纹一处：像座正面基座上刻有一道羊形纹（羊角盘曲成环、身形以寥寥数道刻线带过，刻痕比像体本身更旧、更浅，被后来的修缮石条压住一角）；只刻形态：无文字、无说明、无交互发光；玩家可以看见、可以截图、可以猜，城里没有任何人会解释它。
4. **石屋排房与市场拱廊**：石屋排房——主街两侧排房共十余户，体量、门向、屋顶残损各有差异，但同为巨石砌法；**可进与不可进口径：可进约三分之一**——可进的屋 = 门是开着的或可推开的，屋内有一至两个功能点（搜寻点、临时掩体、短暂避怪的死角、通向隔壁的破墙洞）；不可进的屋 = 门被落石/塌方/石栅封住，封法各不相同，玩家一眼能读懂「此路不通」而非「还没做」；可进屋之间不许全连通，掩体要有代价（进得去的屋，出口只有一个）；屋顶不上人，防动线混乱。市场拱廊——主街后段南侧，一排石柱撑起的长廊，廊下是旧摊位（石台、石柜、倾斜的货架骨，全是石的，所以留到了今天）；**陈设不写字**：摊位上只有器物形态（罐、秤砣形石、叠放的石匣），没有任何文字招牌（玩家读到的是「这里曾经买卖东西」，读不到卖什么）；拱廊是骷髅勇士的主场：柱列即它的绕柱路线，玩家在此的玩法 = 利用柱列反绕、卡位、用镐（3 击）解决它（克制口径从图鉴）；拱廊尽头一间半塌的石屋是冰傀儡的固定刷新点，雪球（3 击）在此有回声（打中时整条廊都响）。
5. **城墙段**：可走范围——城墙只开放一段：自广场北侧登墙梯上墙，沿城墙顶部走至二道门上方为止，约 90 m，墙顶宽可供两人并行；墙其余部分以塌口、落石自然截断，不做空气墙。视野：上墙是全城唯一的高位视角——向南俯瞰：主街全线、广场冷焰、铁匠铺暖光三点成图，玩家能第一次看清这座城的形状；向北望地宫方向：二道门外只有下行道的头一段，再往下被黑暗吞掉，唯有极远处偶尔一闪的微光（地宫方向的提示，只给「那边有东西」——与地宫书 DG 单的氛围口径对接）；守夜或等人时，城墙是瞭望位（队友在街上的火光与走位尽收眼底）。守城痕迹：墙顶内侧有旧垛口与箭孔形凿口；一处垛口旁立着半截石矛，矛尖朝外；墙顶地面散着几块明显是「滚石」用途的圆石（两块还在位、一块滚到墙根）；登墙梯口有一块被磨得发亮的石阶（很多双脚踩过的亮）；痕迹只呈现、不解说（这座城守过什么、守住没有，玩家自己拼）。
