## 1. 病灶（Thomas 点名，Muse 核对定性）

| # | Thomas 口径 | 查证定性 |
| --- | --- | --- |
| 1 | 户外久了应有冰冻减速 + 屏幕花，「没有整出来」 | 系统在且已上线（H1），但**累积入口太窄**：仅暴露雪面（`dark-snow`）且雪强 ≥2 才增长，雪强 <2 时同一雪面反而自然消退——普通雪天永远攒不到 L2，减速与冻花等于不存在 |

## 2. 现行实测基线（源码口径，施工与验收对照用）

### 2.1 冰冻（town-frost.ts）

- 累积：`snowPressure = surface==='dark-snow' && intensity≥2 ? (intensity−1) × (depth≥.6 ? 1.5 : 1) : 0`；`exposureRate = 1/270`/s；湿冷 `wetPressure = max(1, intensity−1) × 2`（`wetColdMultiplier=2`）。
- 现行到级时长（由上式推算）：强度2 浅雪每级 270 s（到 L3 约 13.5 分钟）；强度4 深雪每级 60 s（到 L3 约 3 分钟）；强度 <2 或灯下：以 `naturalThawRate = 1/120`/s 消退。
- 消退门控：`naturallyThaws = surface==='lamp' || (surface!=='water' && intensity<2)`；有回暖源时优先按回暖速率消退；雪橇乘坐时增长清零并按自然消退回落（H1 豁免）。
- 等级样式 `frostLevelStyles`：opacity .35/.65/.90、band .10/.20/.34、tint .04/.13/.22（L1/L2/L3）；`blurByLevel = [0, 0, 2, 4.8]`（L1 无模糊）；`maskClear = [100, 74, 58, 40]`（霜向屏心爬行下限）；呼吸雾 `personal > 2.5` 才开。
- 速度 `walkingScale`：L1 ×1（无减速）、L2 ×0.90、L3 ×0.65；仪式豁免（relief）时 L3 封顶 ×0.90。等级为连续值 `personal`，`displayLevel = round(personal)`，样式按浮点插值——冻花实际从 personal>0 即渐入，减速档在 personal≥0.5 取整触发。
- 回暖（不变基准）：`exposureWarmRates` 火源 1/5、温泉 1/8、室内 1/10、热饮 1/10（每级秒数）；`drinkHot()` 立即 −1 级并挂热饮回暖；基线通道 `frostWarmRate = 1/20`、`frostWarmOffset = 2`。
- 仪式豁免（不变基准）：`hasFrostCeremonyRelief` 阶段内增长 ×0.5、L3 速度封顶 ×0.90。
- 个人等级 `personal = max(baselinePersonal, exposure)`：基线由仪式曲线驱动，本设计**只动 exposure 通道**，基线通道不碰。

### 2.2 眩晕（tavern-drink-effects.ts + .css）

- 计数：`sip()` 一杯 +1 unit；`level = min(3, units)`；消退 `unitMillis = 45_000`（每 unit 45 s 逐个过期，温泉浸泡 soaking 时消退速度 ×2）；举杯动画 480 ms。
- 摇晃（`apply()`，第一人称、动效开启时）：波形周期 `waveCycle = 2_400` ms；L1 仅 `rotateZ ±0.4°`；L2 `rotateZ ±0.9°`（移动时 ×1.5 → ±1.35°）、`rotateY ±0.20°`（移动 ±0.30°）；L3 `rotateZ ±1.3°`、`rotateY ±0.20°`，另有呼吸 FOV 脉冲（每 11 s、300 ms、+0.32°，首周期后起）。
- 暗角（CSS）：基础 opacity 0；L1 仅 `[data-still="true"]` 时 .22（见 §1 病灶②）；L2 .55；L3 .85（与 still 无关）；过渡 420 ms。
- 开关：设置内「饮酒眩晕」按钮（`mountSettings`），关后仅保留暗角、不动镜头，持久化键 `unwritten:tavern-dizziness:v1`；`prefers-reduced-motion` 时默认关镜头动效（用户显式开过除外），跟随系统变更。

## 3. 冰冻调强规格

### 3.1 累积口径放宽（核心项）

| 项 | 现值 | 新值（提案） | 理由 | 回归风险 |
| --- | --- | --- | --- | --- |
| 雪压公式 | `intensity≥2` 才起压，`(intensity−1) × (depth≥.6 ? 1.5 : 1)` | `snowPressure = (1.35 + (intensity−1) × 0.45) × (depth≥.6 ? 1.5 : 1)`，暴露雪面 intensity≥1 即起压 | 普通雪天（强度1–2）也要能缓慢累积，这是 Thomas「户外久了」的本义；强度梯度保留，深雪仍明显更快 | 玩家日常跑图穿越雪原会攒下低等级暴露——靠 §3.2 路面消退与回暖源密度兜底；若实测骚扰感强，优先下调基础项 1.35 而非恢复门控 |

| 湿冷 | `max(1, intensity−1) × 2` | 不变 | 落水本就是最快通道，现行量级已够（强度1 落水每级约 135 s） | 无 |

### 3.5 交互关系（写明，防施工误伤）

- **仪式豁免**：增长 ×0.5 与 L3 速度封顶 ×0.90 两条原样保留；豁免阶段集合（converge/approach/countdown/climax/afterglow 前半小时）不改。调强后豁免期外到级更快，仪式动线（传送集结→广场）多在路面上，路面消退门控正好护航。
- **雪橇豁免**：乘坐时不涨反退，原样保留；下橇后从当时 exposure 继续累积，不清零不清算。
- **基线通道**：仪式曲线驱动的 `baselinePersonal` 与 `frostWarmRate/frostWarmOffset` 不动；`personal` 仍取两通道较高值。
- **热饮**：`drinkHot()` 立即 −1 级是全系统最强的即时反馈，与酒馆热饮/温泉动线保持联动，不改。

## 4. 眩晕调强规格

### 4.1 摇晃梯度调强

原则：L1 第一杯就可感、但不晕车。单轴幅度上限控制在 ≈3.5° 以内、周期不短于 2.4 s（慢摆比快晃耐受好得多）；梯度靠「幅度 + 轴数 + FOV」三者逐级加，而不是单拧幅度。

| 等级 | 现值（rotateZ / rotateY / 其他） | 新值（提案） | 理由 | 回归风险 |
| --- | --- | --- | --- | --- |
| L1 | ±0.4° / 无 / 无 | **±1.2° / ±0.35° / 无** | 0.4° 在 2.4 s 慢周期下低于可感阈值；1.2° 双轴慢摆是「微醺」的最小可感量 | 对镜头晃动敏感者可能仍觉不适——§4.5 开关与减动效默认关为底线；若实测投诉，L1 先降到 ±0.9°，不砍双轴 |
| L2 | ±0.9°（移动 ×1.5→±1.35°）/ ±0.20°（移动 ±0.30°） | **±2.0°（移动 ×1.5→±3.0°）/ ±0.5°（移动 ±0.75°）** | L2 应是「明显醉了」的主力等级，移动放大保留（走路时晃得更厉害符合直觉） | 移动 ±3.0° 接近上限，验收须含连续行走 30 s 的耐受抽查（施工方自测 + Thomas 终审） |
| L3 | ±1.3° / ±0.20° / FOV +0.32° | **±3.2° / ±0.8° / FOV +0.6°**（周期与触发节律不变） | L3 是满级惩罚/娱乐峰值，与 L2 拉开差距；FOV 呼吸脉冲同步加深 | 晕车风险最高的一档——只出现在连喝三杯后，属玩家自选行为；开关关闭即完全无镜头运动 |
| 波形周期 | 2_400 ms | 不变 | 慢摆耐受好，不动 | 无 |

### 4.2 L1 暗角修复（CSS 缺陷，必修）

| 项 | 现值 | 新值（提案） | 理由 | 回归风险 |
| --- | --- | --- | --- | --- |
| L1 暗角 opacity | 仅 `[data-still="true"]` 时 .22，动效开启时实际 0 | **.30，且与 still 无关**（规则改为 `[data-level="1"]`） | 这是缺陷不是口味：设计本意 L1 就有暗角，被选择器写漏 | still 态（关动效）下 L1 暗角由 .22 变 .30，无感差异 |
| L2 / L3 暗角 | .55 / .85 | **.60 / .85**（L3 不变） | 与新摇晃梯度对齐，L2 略加深 | 无 |

### 4.3 持续与消退

| 项 | 现值 | 新值（提案） | 理由 | 回归风险 |
| --- | --- | --- | --- | --- |
| `unitMillis` | 45_000（每杯 45 s） | **60_000**（每杯 60 s） | 45 s 一杯的酒意在走回座位前就散了，与新梯度叠加后「醉感」留存太短；60 s 时 L3 满级总消退约 3 分钟，量级合理 | 罚酒局节奏变慢（见 §4.4 衔接）——B11 二期若做连局制，需按 60 s 重新核对局间间隔 |
| soaking 消退倍率 | ×2（温泉浸泡加速醒酒） | 不变 | 已是有趣的正反馈（泡温泉解酒），保留 | 无 |
| 举杯动画 / 杯子 | 480 ms | 不变 | 不在本批范围 | 无 |

### 4.4 与酒馆划拳罚酒（B11 二期）的衔接口径

- **共用同一计数**：罚酒与自饮都走 `sip()` → units → level，不许 B11 另起计数器或平行等级。
- **罚酒梯度**：按新口径，输一局罚一杯 = L1（可感微醺）；连输三局 = L3（满级）。B11 二期的免罚/封顶规则（如「酒意已满免罚」类）以 level==3 为判据，不以 units 为判据（units 可 >3）。
- **入口扩展不在本批**：新增饮酒入口（自饮菜单、其他 NPC 敬酒等）归 B11 二期设计；本批只保证「第一杯就有反馈」，解决 Thomas「没有」的观感，不扩入口面。
- **醒酒动线**：温泉 soaking ×2 消退与冰冻的温泉回暖（1/8）同点生效——泡一次温泉同时解酒回暖，属预期联动，验收时一并走查。

### 4.5 移动端（触屏）等效表现

- 摇晃作用于第一人称相机旋转，与输入方式无关，触屏端同值生效；`moving` 标志由 viewer 步行分支驱动，触屏行走同样触发 L2/L3 的移动放大。
- 暗角与举杯杯子均为 DOM 叠层（`position: fixed`，杯子已带 `env(safe-area-inset-bottom)`），触屏端天然等效，无需另写一套。
- 设置开关「饮酒眩晕」在设置面板内为普通按钮，触屏可点；持久化与减动效联动口径与桌面一致。
- 验收须含一台触屏设备实走（见 §5）。

### 4.6 开关与减动效（保留现行，不许回退）

- 「饮酒眩晕」开关（`mountSettings`）保留：关 = 镜头不动、暗角保留；持久化键不变。
- `prefers-reduced-motion` 联动保留：默认关镜头动效、用户显式开启优先、跟随系统变更；CSS 侧暗角过渡与杯子动画在减动效下禁用，现行已有，不动。
- 冰冻侧「仪式冻纹」开关保留（关则叠层隐藏且 `walkingScale` 返回 1，现行口径）；减动效时呼吸雾层隐藏，现行已有，不动。

## 5. 验收线（可测条目）

### 5.1 冰冻

1. **静站计时到级**：普通雪地暴露点（强度1、浅雪）静站，记录 personal 到 0.5 / 1.0 / 2.0 / 3.0 的时间，与 §3.1 目标表对照，允许 ±25% 校准带；深雪点（强度3、深度 ≥.6）复测一组。
2. **路面消退**：L2 状态走到已清路面静站，验证 exposure 按 1/120 量级回落、不再增长。
3. **速度系数实测**：tracker 单元测试断言各级 `walkingScale`：L1 0.95 / L2 0.88 / L3 0.65；relief 下 L3 = 0.90、L2 = 0.90；冻纹开关关闭时恒为 1。
4. **截图对照**：L1/L2/L3 各一张全屏截图——L1 边缘霜带肉眼可见且有轻模糊、中心 ≥70% 区域清晰、HUD 文字可读；与 H1 旧图同机位对照存回执。
5. **回暖回归**：L3 进火源点，计时回到 0（火源 1/5，约 15 s 量级）；热饮立即 −1 级复核。
6. **豁免回归**：乘雪橇 60 s，exposure 不增且回落；仪式 converge 阶段同点静站，增长速率约为非豁免期一半、L3 速度不低于 ×0.90。
7. **低端机抽查**：L2/L3 档位下 blur 开启时的帧率与改前对照（paint 去重在位、静止等级零重绘）。

### 5.2 眩晕

1. **摇晃度数实测**：`apply()` 单元测试/录屏采样各级 rotateZ/rotateY 峰值，与 §4.1 新值表对照（±10% 带）；连喝 1/2/3 杯各录 10 s 第一人称静站 + 30 s 行走录像存回执。
2. **第一杯可见**：喝 1 杯后截图——暗角 opacity .30 在动效开/关两态下均可见（重点复核 §4.2 的 CSS 修复）。
3. **消退计时**：末杯后计时 level 3→0 总时长 ≈ 3 分钟（60 s/unit 口径，±15%）；温泉浸泡时约减半。
4. **开关与减动效**：关「饮酒眩晕」后连喝 3 杯，镜头零旋转、暗角仍在；系统减动效开启时默认无镜头运动。
5. **触屏实走**：触屏设备第一人称喝酒 2 杯，行走时摇晃与暗角同现、杯子动画位置正常。
6. **B11 衔接走查**（B11 二期施工时）：罚酒一杯即 L1、三杯 L3、满级免罚判据为 level==3。

### 5.3 无障碍底线（两系统共同）

- 两系统均可关（冻纹关 = 无叠层无减速；眩晕关 = 无镜头运动、仅暗角），且关闭路径不超过设置面板一次点击。
- `prefers-reduced-motion` 必须同时压制：眩晕镜头运动、冻纹呼吸雾层、暗角/杯子过渡动画——任一项漏联动即验收不过。
- 摇晃幅度硬上限：任何等级单轴 ≤3.5°、周期 ≥2 s，写死在规格里，校准时只许向下调。

## 6. 边界与不变项

- **不动已验文案**：冻纹 L3 播报「冷得迈不开步了——找个火堆烤烤火。」、回暖播报「身上暖和过来了。」等既有文案原样保留。
- **不新增协议号**：两系统均为本地客户端表现层（冰冻 tracker 与眩晕效果都不经联机同步），本批不引入任何网络状态。
- **不改雪橇豁免与仪式豁免**：两豁免的机制、判据与既有数值（增长清零/减半、L3 速度封顶 ×0.90）原样保留，本设计只在其外围调累积与表现。
- **不碰基线通道**：仪式曲线驱动的 frost baseline、`frostWarmRate`、`frostWarmOffset` 不动。
- **改动面收敛**：冰冻只许动 `town-frost.ts` 的压力公式、消退门控、`walkingScale` 分档与等级样式常数；眩晕只许动 `tavern-drink-effects.ts` 的摇晃常数、`unitMillis` 与 `.css` 的 L1/L2 暗角规则。viewer 接线不动。
