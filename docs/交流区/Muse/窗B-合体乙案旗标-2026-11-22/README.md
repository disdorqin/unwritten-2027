# 合体乙案旗标（对主干 `2acc30f0`，实测 3/3、tsc 0）

按《设计-飞行器合体乙案实现规格-2026-11-22》分工，B 线只做旗标与判定（`src/shared/town-combine-flags.ts`，零自有钟表）：

- **搭手触发**：`forgeCompleted()` 在**首次锻成且从未装配**时恰好返回一次 `handsEvent: true`；日常时代再锻不再触发。锻成即触发、玩家不必喊人（规格第 1 步）。
- **四态**：awaiting-forge → forged → assembled → ignited；装配须先锻成，装配毕飞行器常驻星港坪。
- **点火窗口**：读信标单一来源——注入 `src/shared/town-night-window` 的普通夜调度 `scheduleAt`，窗口＝**第十三声那一分钟** `[beaconAt, beaconAt+60 s)`，另须讲古钥一在手（`hasStoryKey` 注入，账在故事线侧）。本模块不存漂移表、不自算时刻。
- **首/日常切换**：首次点火成功即永久切 daily；日常开启同走窗口＋钥判定、无搭手无抬运。错过窗口明晚再来，快照 `beaconAt` 供读账本预知。

抬运队伍/装配交互/点火演出归 D、锻成出口归 C、镇域路段归 A，本包不含呈现。验收按规格：太空章开章时第一人称两遍实走（首次全程＋日常独行）。
