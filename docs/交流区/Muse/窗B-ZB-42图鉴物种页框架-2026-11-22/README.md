## 内容（`atlas-species-framework.patch`）

`town-atlas-species.ts`——物种页注册表，零依赖：

- **条目形状**：id／区域（镇/坑/山/地/天）／发现半径／四条文案键（名＋形貌/习性/镇民说三行）。物种名册与全部文字以**键**登记，正文经注入的文案表解析；键未供文时渲染为空槽——框架不 invent 任何物种与句子。
- **两段发现**（合三碰标准）：听见→「heard」页（有三行、无名，剪影态）；看见→「seen」页（名与三行齐）。重复听见不升段、任何段位看见直达 seen。
- **记录非考核**：只有封面计数（听见/见过/总数），无进度条、无奖励、无箭头。
- 按区域分页查询，供图鉴 UI 与各区发现触发点（望筒/风哨/足迹等）统一调用 `record(id, kind)`。
