# 设计 · 飞行器合体乙案实现规格（2026-11-22，总控；Thomas 裁定）

**裁定（Thomas 2026-11-22）**：合体用**乙案「全镇搭手」**定版。结构按备选件总控建议落：**首次开启＝全镇搭手事件（一次性），此后日常开启＝独行**（装配一次成形、常驻星港坪，不重复搬运）。甲案降为日常形态、丙案（守岁夜装配）作废。背景与状态机以《备选-飞行器合体仪式玩家序列-2026-11-21》与裁定 304c2e38 四态为准（待装配→已装配→点火窗口→转场），本件只展开乙案的玩家序列与实现分工；施工排太空章前置队列，本章不施工。

## 玩家序列（首次）

1. **锻成**：助推器在勇士城铁匠铺锻成（冰晶片＋星尘矿，原石已归炉芯）。锻成即触发搭手事件旗标——玩家不必喊人。
2. **搭手**：活人镇民自发来抬——他们以为这是给除夕备的「大烟花架」。抬手面孔从在场逻辑出：石九斤（锻造在场）、温九（看热闹变主力）、赵满仓（力气）、罗大年（下山换班路过）。台词口径：只许烟花话、年节话，无人说得出这东西真是什么（双层红线）。
3. **抬运**：路线＝勇士城→（回程笼）→集结地→镇→北带→山口→盘山道→云海台星港坪。呈现法照讲古口径：**环境实演、不夺控制权**——队伍以常速行进，玩家可随行、可跑开再回来，队伍不等不催；沿途灵魂层可见：先人们站在路边看（只有主角看得见），魂镇长在山口站了一程。雪翼与导航芯由玩家自带（肩扛语法，一件一趟或随身），只有助推器走抬运。
4. **装配（玩家亲手）**：星港坪上三件对位，逐件一个小操作——翼面入卡槽（推正）、助推器上挂架（与抬手合力落位，落位后镇民散开）、导航芯嵌船徽凹位（玩家独自动手，芯入位时环面一闪——镇民只当是铜件反光）。装配毕，飞行器常驻坪上，状态进「已装配」。
5. **点火窗口**：须讲古钥一齐备＋第十三声响起的那一分钟（信标公式单一来源，读账本可预知）。窗口前镇民在坪下空地看热闹（有人带了瓜子——细节归场景件），玩家在坪上启动。
6. **点火**：一道光升起、门环亮满一圈；镇民欢呼「烟花开了」；魂镇长站在人群外看着主角（全场只有这一眼是对的）。转场进轨道域——太空章开场。

## 日常开启（第二次起）

独行：到星港坪→钥与窗口判定→启动。无抬运、无围观（镇民该干嘛干嘛），与甲案气质同。错过窗口明晚再来（自由口径不变）。

## 实现分工

- **D 线**：星港坪装配点与三件对位交互、点火演出、抬运队伍的路径与群体动画（主成本在此）、坪下围观位。
- **B 线**：旗标与判定——搭手事件触发（锻成∧首次）、点火窗口判定（读信标单一来源）、首次/日常形态切换。
- **C 线**：勇士城锻成出口与回程笼衔接（抬运起点）。
- **A 线**：镇域段抬运路线（集结地→山口）的路面与围观站位、山口魂镇长站位点。
- 文字件（总控后补入总表）：抬运号子一句（石九斤起头）、温九烟花话一句、坪口装配牌（只写「大烟花架 · 除夕用」——活人侧的误会要留在牌面上，这是乙案的题眼）。

## 验收（太空章开章时）

第一人称全程实走：锻成→搭手→随行抬运→亲手装配→窗口点火→转场；外加日常开启独行一遍。两遍都过才算乙案交付。
