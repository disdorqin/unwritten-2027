# 风格修订单-04 · 冰晶宫 + 镜湖（分区一，2026-11-21）

对图册与《风格打造规范》逐项过：冰晶宫 `landmark-ice-castle.ts`（599 行）+ 残骸 `landmark-ice-palace-wreckage.ts`，镜湖 `landmark-lakeside.ts` + 冰面活动组。本单无 A 级自改（无一处到「当轮可改且无争议」线），B/C 如下。

## B 级（回 ZA-18/冰宫线主人）

1. **冰面 Fresnel 辉光与粘土味的边界**：宫体三材质（mason/lanterns/core）均注入自研 Fresnel（`useCastleIceFresnel`）——全镇唯一的着色器级修饰。冰面冷辉本身合「晶辉」位，但请主人自查两点并在 ZA-18 余段回执里答：①辉光强度在昼/夜两态下是否压过图册的「大面切割、硬转折」读感（宫墙远观应先读体块、后读辉光）；②与地下水晶洞的自辉光（深度梯度终点）是否同一语言，避免两处各发明一套冷光。此项列入联合审核明查（同缆车老闸锈口径）。
2. **冷辉色收敛**：核心 emissive #a9d8e9、牌匾 accent #79b9cc，与色板晶辉青 #7fd4c8 同族不同值。请二选一：收敛到 #7fd4c8 系，或在本单回执里登记「冰宫青」为 sanctioned 变体（连同使用范围：仅宫体核心与牌匾），免后续窗口逐处质疑。
3. **残骸梯度在位记功 + 一处核对**：宫围冷却残骸有独立模块（`icePalaceFragmentSite` + mountIcePalaceWreckage）合残骸梯度正典（地面集中于冰晶宫）；请主人核对残骸金属的锈三件套是否齐（锈斑/剥落/锈水痕，#8a4a34 系）——船件是「老机器」，锈法同缆车老闸口径。

## C 级（设计件，结构先行）

1. **冰晶宫·宫门寒气**：宫门内侧一带「寒气可视」——低悬冰晶雾团（结构件，粒子/半透层二选一归主人），把引寒机关的「寒」从数值变成进门先见之物；与镜湖坚冰时段联动时雾团增厚（只结构与联动口，开关本体在 ZA-18/ZB-06）。碰法：看（雾）/ 听（机关声，候系统）/ 动手（引寒机关本体）。
2. **镜湖·静钓区冰洞环**：西区静钓冰洞排布收成一圈不闭合环（缺口朝冰雕岛），与镇公所星石环同为「未闭合圆环」母题的地面回声——只排布、无文案、无机关，属看得见的呼应，故事层不落字。回镜湖四分区维护段排布时顺手对齐即可。
