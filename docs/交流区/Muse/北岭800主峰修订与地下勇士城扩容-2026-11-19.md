# 北岭 800 主峰修订与地下勇士城扩容（2026-11-19 18:35，Thomas 正式裁定，主窗口成稿）

Thomas 裁定：山正式改 800 米（理由：500 只到云层，800 才能得雪翼）。本稿以**两段制**落地，与《北岭 350 米修订版施工规格》《世界联系线时间线》冲突处以本稿为准。

## §1 两段制：前山 350（在建不废）+ 主峰 800（新扩）

- **前山（南岭）**：正在施工的 350 米山体全部保留、零返工，改称前山；其山顶平台改称**云海台**——天空城、星港坪、太空门仍在此（350 米修订版 §7 不变）。
- **主峰山域**：前山以北另开**独立场景模块**（自有界约 2,200×1,800 m，与地下层同属「层/域集」口径），从云海台「入山门」衔接，不动现有帧面坐标。主峰基底高程 ≈150，绝顶 **800**，主脊 + 双次峰，平均坡面 ≈26°（是山，不是针）。
- **云海带上移**：高程 380–560 环主峰腰部。前山台（350）在云海下沿（云雾缭绕的天空城），主峰刺出云海——从镇上看：前山清楚，主峰只露峰尖、随时隐时现。《世界联系线》§2 的 260–420 云海数作废，以本节为准。
- **雪翼在绝顶**：主峰顶「绝顶台」设绝顶小屋，登顶登记后领雪翼（原时间线稿「山顶小屋领雪翼」改指绝顶小屋）；云海台的山顶小屋保留为前山登记点（登顶碑分两级：云海台碑 + 绝顶碑）。

## §2 主峰交通与雪橇

- **缆车二段制**：前山线不变（修订版 §3）；新增**主峰线**：云海台 → 绝顶，全长 ≈1,900 m，8 m/s，单程 ≈4 分钟，中途无站（云海穿越段就是景观本身）。仍为确定性按钟系统。
- **盘山道二段**：云海台 → 绝顶，坡度 ≤12%，长度 ≥5.4 km，2 个观云亭。
- **雪橇绝顶线（新 R1）**：绝顶 → 前山脚广场东，全程 ≥6 km 盘旋线，落差 ≈640 m，按新速度定版（上限 4×）估程 3–4 分钟——全图第一线，3.0 雪橇招牌。原 350 版 R1（2.4 km）降为前山线 R2，不废。
- **滑翔**：绝顶起滑，6:1 滑翔比理论航程 ≈4.8 km，覆盖全图；云海台起滑口径不变。
- 攀爬：主峰北壁 + 东壁新设岩壁带（规格沿《北岭补充定版》§4），红旗路线自云海台起插至绝顶。

## §4 地下扩容：四段动线与勇士城

动线由三段扩为四段（深度沿《世界联系线》§3）：矿洞层 −90 → 水晶洞层 −140 → **勇士城 −165（新增）** → 地宫层 −190。

- **勇士城**：一座废弃的地下城，夹在水晶洞与地宫之间。来历比封锁时代更早，谁建的留白（悬念加深一层）。规模：城门 + 主街（约 180 m）+ 两侧石屋群 + 锻造坊 + 市集拱廊 + 中央勇士像广场（持剑勇士像，半倒）+ 一段城墙可登。石构走纪念性尺度（高门洞、粗石柱、拱廊），混中式石灯与一座石牌坊（与地面小镇同根）；水晶簇从街缝墙角长出来，街灯位嵌月光石——整座城靠水晶与月光石的冷光照明，是地下最有「城」感的一景。
- **玩法**：探索 + 宝点密集区 + 晶蝠群与两具冰傀儡的巢（清怪开地宫门的前置）、锻造坊是助推器合成的正址（比松林工坊棚更有仪式感——《世界联系线》§4 合成地点改此）、城墙上是看水晶洞全景的最佳点。
- **矿洞层扩容**：主巷道网 + 矿工营地遗迹（宿舍排屋、食堂、塌方纪念碑——只刻通用短词，不编人名）。

## §5 历史感三时代叠层（全地下统一手法）

历史感不靠文案，靠三个时代的遗迹在同一空间叠压：
1. **远古**：地宫与勇士城（石构、雕像、牌坊）；
2. **矿工时代**：营地、老矿车、木支撑、纪念碑（粗粝木铁）；
3. **封锁时代**：栅栏、幕墙、探照塔、闸门（锈铁与混凝土色）。
玩家一路向下 = 一路往古老走，深度即年代。此条为地下全部场景的陈设验收口径。
