# 任务书：雪球战系统细化（2026-11-19，分支窗口细节填充）

源稿：《雪球战系统细化-2026-11-19》。定位：雪球是全镇第一玩具——地面和平层的核心互动、冰上夺宝的攻防手段、地下克冰雪系怪的武器，一套操作贯穿三层。本单只细化手感与涌现玩法支持，不改 v2 操作定版（全平台长按：按住掬雪 + 瞄准预告、松手满力投掷 ≈26 m/s、射程 ≈35 m、蓄力分级已取消、PC 鼠标长按）。**排期门：今晚总装上线之后领单；分级 A/B 交界（手感与涌现支持随首晚动线 A 级先行，地下复用口径随地下链 B）。**

## 细节填充

1. **雪球的手感**：掬雪与连掷节奏——一次长按 = 掬一团雪 = 一发，不设弹药数、不设背包；掬雪时长是唯一的节奏阀：站在深雪区（雪深档 3 以上）约 0.35 秒成团，浅雪区（老镇 1–2 档）约 0.6 秒，**冰面（0 档，镜湖）掬不到雪**——必须挪到湖缘雪带才能掬（这是冰上夺宝的天然补给动线，与镜湖书 B 单对接）；连掷上限约每秒 1.2 发（深雪）至 0.8 发（浅雪），不靠数值冷却、靠掬雪动作本身（玩家的「火力」由脚下雪况决定，站位即战术）。弧线预告的读法：预告弧 ≥24 点平滑曲线，颜色随状态变——全程通畅 = 白色虚点；落点落在人身上 = 该人高亮描边、弧线转暖黄；中途被墙/树/屋檐挡住 = 弧线在遮挡点终止并打出一个小的「砰」叉标记，落点圈落在遮挡物表面；玩家要学会的三读：一读落点圈（打哪），二读高亮（打中谁），三读叉记（别浪费这一发）；弧线只在按住期间显示，松手即掷，不给「瞄好了存着」的余地。打中人的反馈：命中玩家 = 爆一团雪花（十几粒方块雪屑、四散后落地即融）+ 被打中者一个「抖雪」动作（肩膀连抖两下、头顶掉雪）+ 一声闷「噗」；不掉血、不击退、不减速（和平模式），但抖雪动作的 0.5 秒里对方掬雪进度清零（这是雪仗里唯一的「压制」：打断，不伤害）；连中同一个人三次，第三次雪花里混一点粉花瓣（许愿树同款花色），纯彩蛋、无效果。打空与打墙的差别：打空落雪地 = 小雪团「噗」地陷进雪里、留一个浅坑（痕迹系统，片刻即平）；打中雪墙 = 闷响 + 墙面掉一层雪皮（视觉剥落，**不掉层数**——掉层是雪橇撞墙分档 8/15/22 的事，雪球不许拆墙）；打中建筑/树木 = 清脆一点的「啪」+ 雪屑顺表面滑落；三种声音三种落点表现，玩家闭着眼能分清打中了什么。
2. **自由雪仗的涌现玩法支持（只给三件小支持）**：堡垒已改自由形态（全图任意位置堆雪打仗、无正式对局——裁定口径），系统只许给氛围级支持，不许长成对局系统。三件：① 临时分队色带——玩家可在集市游戏摊领一条红或蓝布带（共创/集市口径的既有件形态，与集市书对接），系上即同色，摘下即散伙；色带只做两件事：同色者头顶小三角同色、雪球打中同色不触发抖雪打断（防误伤内耗）；无组队面板、无人数上限、无胜负判定。② 雪球补给点（大雪堆）——全图固定几处「雪堆」（松林火塘旁、广场角、镜湖湖缘、陨星原坑口），堆边掬雪速度翻倍（深雪档待遇）；它不发弹药（雪球本就无限），只提供「阵地感」（仗自然会围着雪堆打，补给点即是天然前线，攻防自己长出来）。③ 战报小黑板——广场戏台侧立一块小黑板，只记三行当日雪仗趣闻式计数：「今日全镇共掷雪球 N 个」「今日抖雪王：×××（被打中最多）」「今日最远命中：×× m」；只记好玩的、不记胜负、不跨日累计、次日晨钟清零（它是谈资不是排名，红线同成就系统：不许做成排行榜）。论证登记：三件分别管「分拨、阵地、谈资」——涌现玩法缺的从来不是规则，是这三样社会脚手架；再多给（计分、回合、出生点）就变回正式对局，违背自由形态裁定。
3. **雪墙建造细化**：操作与速度——对雪地长按（与掬雪同键、语境区分：准星对空地近地面 = 堆墙，对前方 = 掬雪投掷；具体键位口径由施工稿定，本单只定语境原则）；每长按约 1.2 秒垒起一格墙体（约 1 m 见方体素块），`WALL_MAX_LAYERS=4` 不变（层数指同格可叠高至 4 层）；垒墙速度慢于掬雪（筑墙是工程，掷球是打闹，节奏差本身就是攻防平衡）。层数呈现：墙体颜色随层数变深（新雪白 → 压实后微蓝灰），第 4 层顶面有一道压实的亮边（老远能数出几层）；受雪橇撞击按分档掉层（<8 m/s 不掉、8–15 掉 1、15–22 掉 2、>22 全穿）后，断面露出年轮似的层纹（废墟感也是战况记录——撞墙分档与字节口径从已验定版，ceil-46）。修补：对自家（任意）残墙长按即补层，修补速度是新建的 1.5 倍（鼓励守、不鼓励拆了重堆）；雪球打墙只剥皮不掉层（见第 1 项），墙的敌人只有雪橇与融化。寿命口径：与共创稿四层寿命对齐——雪墙属「临时层」（无人修补的墙按共创口径起融：48 小时起融/72 小时化尽的方向，松林雪人专稿的场景口径以其为准），暴雪夜野外墙「回林」式统一处理同口径；玩家在自家院内堆的墙走院落口径（地表补完稿），存续更久（与共创书 Z 单、松林书 SL 单、地表补完书 A 单的三套雪件寿命登记并行）。
4. **雪球的边界礼仪（软约束）**：安静区三处——戏台演出中（正场/压轴时段）、纪念馆内、镇长讲古时（镇公所/广场讲古圈）：不设禁掷墙、不弹警告，口径是**雪球在区内自动变「软」**（进入安静区的雪球速度衰减、落点只飘下一小撮雪粉，打中人也不触发抖雪，只留一句式的氛围反馈——台上演员一个眼神、守馆人竖手指「嘘」的姿态）；玩家自己就懂了：这儿的雪是绵的（用世界观消化规则，不用 UI 弹窗骂人——与戏台书 XT 单、纪念馆书 JG 单、镇公所书 ZG 单对接）。打到 NPC：NPC 被雪球打中 = 抖雪 + 一个岗位性格动作（站长扶帽、守火人护火、班主一个亮相式拍雪），不生气、不中断岗位功能、不触发对话；同一 NPC 短时连中三次，第四次他会「还手」（掷回一个必中但纯表演的雪球，玩家只抖雪、无其他后果——全镇最容易被打出隐藏互动的彩蛋位）；讲古中的镇长例外：走安静区口径，雪球变软，镇长连眼皮都不抬。雪橇与人群：镇内 NPC 遇高速雪橇退到路边（作息稿既定），雪仗不改变这条；玩家之间无任何礼仪惩罚（礼仪只对 NPC 与场合，不对玩家——朋友之间怎么闹是朋友的事）。
5. **雪球在地下的复用口径（只写接口）**：同操作——地下仍是长按掬雪瞄准、松手满力，零学习成本；但地下无处掬雪：掬的是洞壁霜雪与雪团怪活动区的积雪点（矿洞层雪源充足、水晶洞起雪源渐稀、地宫几乎无雪源，掬雪点本身成为要守的资源位，与生存模式咬合——与矿洞书 KD 单、水晶洞书 SJ 单、地宫书 DG 单对接）。不同后果：雪球在地下是武器——按图鉴克制表，克冰雪系（雪团怪 1 击、晶蝠 1 击、冰傀儡 3 击、守库傀儡冰掷阶段的反制窗口），打硬体系（骨/石/晶）只出雪花不出伤害（提示玩家换镐）；命中反馈沿用第 1 项的爆雪花 + 抖动，怪的抖动即硬直，是地面打闹手感的直接迁移。附带用途两件：① 掷雪球探路——雪球落在黑暗里爆开的雪粉有一瞬微光（只亮落点一格、不足半秒），是穷人版照明，与篝火/矿灯体系不冲突（不许做成照明弹）；② 雪球可打落洞顶冰锥与晶簇（水晶洞采集的远程手段之一，落下的晶簇即采集物，与图鉴矿物口径对齐）。边界：雪球在地下不许克 BOSS 全程——守库傀儡只有冰掷阶段吃雪球反制（红线：满血不秒杀、单武器不通关），双工具克制（雪球/镐）是地下战斗的骨架，本单不另开第三武器。
