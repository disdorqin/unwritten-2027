# 雪橇动作设计 v1（2026-11-18）

> Thomas 点名：雪橇要扩大，**现在没有动作**——B3 候选只有路线与速度，人坐在橇上是僵的。本稿给雪橇补一整套程序化动作（姿态 7 的动态层），列为 **B3b 批**：在 B3 候选之上续建，由次窗口施工、主窗口审合。原则不变：公式规则驱动、不上引擎、动作从已同步的橇状态（位置/速度/转向）本地算出，**零新增协议**——别人看到的动作和你自己的一致。

## 1. 骑乘者动作（体素小人分段旋转，无骨骼）

| 动作 | 触发 | 表现 |
|---|---|---|
| 上橇/下橇 | 进入/退出橇状态 | 0.4 s 跨坐过渡：单腿跨过、落座下沉 4 cm 回弹；下橇反向，不许瞬移换姿 |
| 滑行基姿 | 滑行中 | 坐姿双腿前伸搭橇头、双手扶橇沿，躯干随速微微前倾（10 m/s 时约 8°） |
| 转向压弯 | 转向角速度 | 人与橇整体向弯内倾斜，倾角 ∝ 转向率（上限 18°），出弯回正带 0.2 s 阻尼，不许跳变 |
| 脚刹 | 玩家刹车输入 | 单脚（近弯侧优先）伸出擦雪，脚下扬起扇形雪沫，躯干后仰 6°；松刹收脚 |
| 颠簸 | 速度 >4 m/s 且地面粗糙度高 | 座位上下小幅弹跳（幅值 ∝ 速度，≤5 cm）+ 橇身高频微震，雪沫断续 |
| 腾空 | 离地（坡口/小跳台） | 双腿微收、双臂外张平衡，橇头略上扬；落地压缩下沉 + 一圈雪溅，接既有脸刹/翻滚判定 |
| 待机 | 橇上静止 >5 s | 拍雪、左右张望小动作循环（与步行待机同规格，不新增资源） |
| 摔倒衔接 | 撞击/落坡超限 | 沿用已定口径：低速脸刹趴倒、高速翻滚两圈；起身后 1 s 内可重新上橇 |

## 2. 橇与环境动作

- **雪痕**：橇过之处留双道轨痕，存在 20 s 后淡出；全镇同时保留上限（回执给数，建议 400 段），超限先删最旧。深雪区痕更深（视觉加深，不动数值）。
- **雪沫**：橇刃雪沫量随速度分三档（<3 无 / 3–8 细沫 / >8 成扇），并入既有粒子池，draws +0。
- **橇身姿态**：俯仰/侧倾跟地形法线对齐（平滑 0.15 s），过坎不穿模、不悬空贴图。

## 3. 镜头（第一人称）

- 速度感：FOV 随速小幅放宽（静止基线 → 12 m/s 时 +6°），回落平滑；高速粗糙段加 ≤0.3° 的镜头微震，晕感红线内（与醉酒晃镜分开记账，不叠加超限）。
- 压弯时镜头随倾角同向倾斜 60%（人倾 18°、镜头倾约 11°），出弯回正。
- 脚刹/落地瞬间给一次 60 ms 的小幅下沉反馈，不许连续抖动。

## 4. 同步与成本

- 全部动作由橇状态（位置流 + 姿态 7 + 速度）程序化导出，观察者端同算同果，**协议零新增**；雪痕只在本机渲染（不要求全镇一致，省带宽）。
- 成本：分段旋转为既有体素部件的变换，draws +0；雪沫进既有粒子池；雪痕段数硬上限封顶，tris 增量回执实报（预算 ≤ +0.3 万）。

## 5. 验收（B3b）

- B3b-A1：全程录像自查——上橇过渡、压弯（左右各一）、脚刹扬沫、腾空落地、脸刹衔接，五段动作齐且无跳变/穿模。
- B3b-A2：双客户端互看：对方压弯倾角与脚刹时机一致（±1 帧级），观察者端雪沫正常。
- B3b-A3：雪痕留存与上限实测（连滑 3 分钟不掉帧，痕段不超上限）；性能账入回执。
