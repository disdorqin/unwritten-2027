# 设计 · NPC 活人表细化（G-02）（2026-11-20，分区一自建 ZA-24）

- 范围：活人六岗只做**岗位 / 日常动线 / 拦法机制**。名字与台词以《设计-NPC 名册-2026-11-20.md》第一版为准本，本件不拟一名一字；文中引号内均为名册已录原句。没记录的话施工时角色内挡回，真相层不落对话。
- 对位结构（名册）：一岗一家人世守，活人守白天、先人守夜里；本件只做活人侧，灵魂侧现身点位归分区二 G-03，两侧在同一岗位对位衔接。

## 全镇作息骨架（六岗共用）

- 一游戏日 = 现实 10 分钟（白天 6 分钟、夜晚 4 分钟；《故事前言》附三）。晨钟 = 上岗信号，六岗各就各位；入夜 = 归家信号，六岗离岗回家；第十三声（入夜约 1 分钟后）响时全镇同一时间熄灯，此时已无人值守——夜里能进山、能下坑靠的是「人不在」，不是任何时间闸（2026-11-20 17:17 门禁更正口径）。
- 白天岗位循环 = 岗位点位上的活计循环（守、修、卖、记、倒酒、劈柴），不是站桩：每岗一个工作小循环，玩家路过可见其在忙。
- 离岗留痕：岗位点留空岗痕迹（ZA-29 已建场景件：岗哨火盆、食盒、班次牌一类），玩家夜里到岗只见空岗与魂层痕迹，不见活人。

## 通用拦法机制（守位岗共用，ZB-28 已按此施工）

1. **在场**：守位者在岗点可见、在忙；玩家接近先有反应（抬头、停下手里的活）。
2. **开口**：笑着拦回——只用名册与前言已录口径（劝回理由限：路滑、封山、井口规矩、天晚了；配吃食或茶水岔开），不新编台词。
3. **硬闯**：拦截由人执行——对话 / 推回 / 浮字说明（ZB-28 逻辑已成），全程不许无声隐形墙；无守卫在场的路段不许存在静默碰撞拦截。
4. **夜里**：守卫不在岗 = 无人拦，机制整体不触发。

## 六岗细化

### 何守仁 · 镇公所主事（何家守环）
- 岗位：镇公所日常代管（门厅留言板、失物招领角）+ 星石环守环——环在镇公所内（ZA-11），归环、镶环、讲古仪式位都经他的岗位；镇长之椅空置、茶每日换新是所内日常的一部分，他照办不解释。
- 动线：白天镇公所内三点循环（门厅 → 讲古位 → 星石环前），间或到所前广场边；入夜归家。玩家白天办任何镇务都先撞见他。
- 拦法：**规矩拦**——不拦路、拦事：凡涉环、涉讲古位、涉所内深处的要求，一律「规矩是老辈子定的，我只管照着办。」挡回；问及镇长，按全镇口径绕开（名册已录）。他的拦截是事务型的：人可以进门厅，事办不出去。

### 赵满仓 · 樵夫（赵家守山口白班）
- 岗位：山口白班守卫（ZA-29 山口岗哨已建）+ 松林劈柴点（416.5 一带）樵活，两处是同一条白班动线。
- 动线：晨钟后先到劈柴点备柴，上午移山口岗哨值守，午后回劈柴点一趟再返岗；入夜归家，山口空岗。
- 拦法：**吃食拦**——塞一把炒花生把人劝回：「吃点，吃点再走，山上风大。」理由只说风大、路滑；硬闯走通用机制（对话 / 推回 / 浮字）。六岗里最软的一拦，靠人情不靠规矩。

### 石九斤 · 矿工头（石家守矿）
- 岗位：坑口守卫（ZA-29 坑口岗哨已建）+ 矿界巡守；石家守矿，祖训即家法。
- 动线：白天以坑口岗哨为心，沿坑口外围短巡（绞盘、坑沿、矿界桩）；入夜归家，坑口空岗——夜里入梦通道无人值守，与 ZB-28 夜段验收对位。
- 拦法：**祖训硬拦**——六岗最硬：「井口的规矩，比命大。」不递吃食、不陪聊，硬闯同样只许对话 / 推回 / 浮字，不许空气墙；白天玩家在坑口能做的只有看与听，绞盘与井口一律碰不了。

### 温九（九叔）· 酒馆老板（温家守全镇的耳朵）
- 岗位：酒馆（ZA-20）柜台后；守的不是路是话——全镇的耳朵。
- 动线：白天至入夜前一直在酒馆内（柜台、案台、门口三点小循环）；入夜熄灯归家，酒馆关门。醉话碎片（ZA-20 已建机制）只在他在场时段可触发。
- 拦法：**话拦**——不拦路、拦话：玩家打听坑、山、星石、镇长，他倒酒岔开：「喝酒的人不说谎，只是不全说。」机制上 = 对话话题到敏感处即被他的岗位动作截断（倒酒、擦杯、招呼别的客人），不给信息也不赶人；酒后碎片是唯一漏口，归 ZA-20 既有口径。

### 白晓棠 · 售票员（白家守站）
- 岗位：汽车站售票窗（ZA-21 领票子段已并线）；守站。
- 动线：白天售票窗内，间或到站台一头张望；入夜归家，站台空场（午夜站台归灵魂侧白望山对位，本件不做）。
- 拦法：**明日拦**——她不拦人，她卖明天的票：「明天就通车了，真的。」玩家今天走不了不是被拦下，是车永远明天才来；领票、图鉴打卡照 ZA-21 已建子段。她自己也想出去——六岗里唯一立场松动者，但机制上同样只给明天的票，不给今天的路。

### 齐更生 · 修钟人（齐家守钟）
- 岗位：钟楼（ZA-19 已建）维修间与塔身；记活人那本账——只记日常钟点（上工、集市、末班一类活人时刻），第十三声不入他的账（魂账归齐守夜对位，本件不做）。
- 动线：白天钟楼内上下两点（维修间 ↔ 塔上机芯），午间到塔下广场边透气一圈；入夜归家。第十三声前在钟楼下望天的是魂镇长（灵魂侧），与他无关、他也不在场。
- 拦法：**钟账拦**——信息型拦截：玩家问夜里的钟、问第十三声，他以活人账挡回：「钟老了，走得慢，你们别催它。」他的账上查不到第十三声——玩家要算今晚开窗时刻，只能去查维修间那本不属于他的账（故事接口，归 ZA-19 / ZB-17 既有口径，本件只登记岗位对位）。
