# 任务书：背包与物品栏细化（2026-11-19，分支窗口细节填充）

源稿：《背包与物品栏细化-2026-11-19》。范围：背包结构、物品呈现、死亡掉落、屋内储物分工、玩家间流转。源稿只定口径带与体例，不给死数——**施工时在口径带内定值并回执登记实际取值**（口径带汇总：采集格量级、矿物堆叠上限、星尘矿堆叠上限、屋内存量上限、文字提示停留时长；回执缺登记 = 退回）。红线前置：无货币、无交易系统；物品在玩家间的唯一流转方式是**赠予**。**排期门：今晚总装上线之后领单；分级 A/B 交界（四区结构与满包提示随开镇基础 A，死亡掉包呈现随地下链 B）。**

## 细节填充

1. **背包的结构口径**：背包分四区，不混格——工具带（镐、雪铲等工具；固定槽位，随领随占，不占采集格）/ 装备位（雪翼、助推器、飞行器；身外位，各占其位，不占采集格）/ 采集格（矿物、水晶、食物原料、手作材料；唯一的「容量」所在）/ 随身小袋（残页、拓片、护照、镇志补遗等收集物；不占格、不堆叠、不可丢弃）。**核心原则：工具与装备永远不占采集格**——玩家出门挖矿，背包空不空只看采集格，不会出现「因为带了镐所以少装两块矿」的憋屈；工具带与装备位是「身上」的东西，采集格才是「包里」的东西。采集格的量级感（口径带，供施工定值）：总格数取「一趟认真采集刚好要回一趟家」的量级（单人从坑底满载而归大约一趟走完矿洞一层半的收获，不许多到可以连穿三层不回头，也不许少到进洞十分钟就得折返）；矿物类堆叠上限取中等量级（一格装得下一小堆矿石的直觉量）；星尘矿单独计数（它既是矿物也是燃料，堆叠上限可比普通矿物略低，凸显其分量）；食物不堆叠或低堆叠（一条鱼就是一条鱼，烤物趁热，占格即提醒「该吃了或该送人了」）；手作（冰灯、灯笼）一件一格（它们是成品，是要拿去挂、去送、去展的，不是材料）。
2. **物品的去向可视化**：背包不是一张表格，是「这一趟的收获摊开给玩家看」。矿物：按类成堆呈现，堆角上带小字计数；星尘矿带极淡的微光边，与其他矿物一眼可分。工具与装备：画在小人剪影的对应位置上（镐在手侧、雪翼在背、助推器在腰后），玩家看背包先看见「我现在是什么装备状态」。食物：带热气/新鲜感的呈现区分（刚烤的和放凉的用图标温度感区分，不写数值，只给感觉）。收集物：小袋是册页形态，残页、拓片、护照章各有其位，缺哪页一眼可见（集页的进度感由小袋承担，不另做进度条界面）。「满了」的温柔提示（不许弹窗轰炸）：第一级——采集格边框轻轻泛起一圈暖色呼吸光，人物拾取动作末尾多一个「拍了拍包」的小动作（只提示，不拦截）；第二级——再拾取同类物品时，小人摇头、物品留在原地并微微弹回，头顶飘一个小小的包形气泡图标（无文字）；第三级（换类拾取仍满）——屏幕角落一行小字停留数秒即散（如「包满了，回家卸一卸吧」），同一次外出最多出现一次文字提示。禁止：居中弹窗、音效警告、红色闪烁、强制打开背包界面（满包是节奏提醒，不是错误）。
3. **死亡掉半矿的呈现细则**（地下生存模式：死亡 = 醒来回床，当前一趟所采矿物掉一半在死亡点，可回去捡——模式口径从生存书 SM 单，本项只定呈现）：掉落形态——掉落的矿物在死亡点结成一小堆「矿包」，外观是粗布扎口的小包，扎口绳结是玩家护照色带同色（远远一看就知道是自己掉的）。标记：矿包落点在玩家本人的小地图/罗盘上留一个仅自己可见的淡标记，文案口径只有「上次倒下的地方」，不写坐标、不写距离数字；抵达附近（一个身位圈）时标记自动消散。可见性口径：矿包**只有本人可拾取**；队友能看见它（看得见、帮得上忙——可以守、可以带路、可以清怪护送），但拾不起来（杜绝「朋友顺手捡走再还」的流转纠纷，也守住无交易红线）。存续时长：矿包在本次登录内一直存在，下线再上线仍在（同一服务器存档周期内——与存档书 CD 单对接）；只有被本人捡回或服务器版本重置时才消失（掉落不是限时惩罚，是「回去把东西拿回来」的钩子）。二次死亡：若未捡回又在别处死亡，新的掉落另成一包，旧包不覆盖、两包并存，各自标记；已掉落的矿物不计入「当前一趟所采」，不会被二次掉半。不掉的东西：工具、装备、收集物、食物、手作永不掉落；掉的只有矿物，且只有「这一趟新采的」那一半——惩罚的边界到此为止。
4. **屋内储物与背包的分工**：原则——**背包是「在路上」，储物是「过日子」**（与小屋书 XW 单的储物家具对接）。该存屋里的：富余矿物与手作材料（出门只带一趟的量，其余入库）/ 做好的手作（冰灯、灯笼、摆件——存着等节日、等送人、等展出）/ 换季/备用食物原料（鱼获可存，但存久了新鲜感递减，只影响呈现不影响可用）/ 不当季的装备（如暂时用不上的飞行器部件）。屋内储物不设格数焦虑：容量口径取「够一位镇民过完一冬」的宽裕量级，它是家底，不是第二个背包；储物界面与背包同一套视觉语言，只是背景换成屋内的柜架。跨层携带口径：**食物可进地下**（篝火回血是正道，食物是慰藉——可带、可吃、回复口径弱于篝火，不许食物替代篝火成为续航主力）；**灯具可上主峰**（冰灯、灯笼、月光石灯可携带上山，山顶小屋与歇脚点许挂自带灯；但主峰自有照明体系，玩家灯具是点缀不是必需，不许设计成「不带灯上不了山」）；**矿物不上天**（星尘矿/星尘粉是飞行燃料的原料与本体，随身小袋外的矿物不进入飞行载荷——飞行时背包采集格锁定为「已在地面封存」语义，避免高空掉落与载荷计算的麻烦；星尘粉（已制成的燃料）走燃料槽，不占采集格——与飞行书 F 单对接）；**残页不进地下深处的新增风险**（收集物永不掉落、永不损毁（已由死亡口径保证），下矿带着残页没有额外风险，不制造「要不要带下去」的焦虑）。
5. **物品与他人的关系**：流转总则——**赠予是唯一流转**；没有交易界面、没有报价、没有以物易物的系统入口；两个人之间东西过手，只有一件事：「我把这个给你」。递给朋友：面对面时，长按物品（或对人交互键）唤起「递出」（物品出现在自己摊开的手上，对方伸手接，接下即完成；对方不接，数秒后自然收回）；递出无确认弹窗轰炸，只有一道轻确认（防误触长按的二次点按即可）。展示：任意物品可「手持展示」（举在手里给人看，转一圈、凑近看都行，但所有权不动，松手即回背包）；展示是社交动作（晒新挖的星尘矿、给朋友看刚做好的冰灯），不是交易前置步骤，界面与文案不许出现任何交易暗示。赠予的留痕：被赠予的手作（冰灯、灯笼、摆件）在物品角落留一行小小的来历字（如「阿棠赠」——只留赠者名，不留时间不留价值；来历是纪念，不是账本）；矿物、食物等消耗品不留痕。不可赠予：残页、拓片、护照章、镇志补遗等收集物绑定本人，不可递、不可赠（它们是每个人的镇志之路）；工具（镐）为矿口公物，离矿归还，不进入流转。拒收与还礼：对方可拒收（摇头动作即可，不弹理由框）；收了想还，只能走一遍新的赠予流程当面还，不设「退回」按钮（还礼本身就是镇上的人情往来）。
