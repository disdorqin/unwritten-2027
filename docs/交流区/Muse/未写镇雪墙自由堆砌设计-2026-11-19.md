# 雪墙自由堆砌设计 · 2026-11-19（Muse 设计，与雪橇手感批同车）

Thomas 12:34 点名：打雪仗不能堆雪墙，「和雪橇问题一样」。

## 查证定性

雪墙系统本身是完整的（town-snowfight.ts：堆墙按钮+幽灵预览+三层 HP+全镇上限+联机同步+雪橇撞墙+雪球打塌都在），但**被锁在团队雪仗的「建造阶段」里**：非比赛阶段点下去只有一句「现在不能堆墙」，且建造期只能在自家半场。自由玩/单人时永远用不了——功能等于不存在，与雪橇上坡死锁同类病：做好了，门没开。

## 改法（只开门，不重做系统）

1. **自由模式开放堆墙**：不在团队赛时，堆墙按钮常驻（持有雪料 >0 时高亮）；合法性沿用现行地形规则（路中/铁轨/站台/戏台/室内/密室/河面禁堆），半场限制仅团队赛生效；
2. **个人墙口径**：自由墙归建造者本人，颜色用中性雪白（不染队色）；HP/层数（3 层）/被雪球打塌/被雪橇撞穿（速度 >6）全部沿用现行口径，不新增规则；
3. **留存与清理**：自由墙随场留存；服务器按现行全镇上限（WALL_TOWN_CAP）管总量，超限时按最旧先清并在回执中验证；跨年仪式动线（广场落点环）内的自由墙在仪式传送前自动清除（与 C2 落点容量口径对齐，防堵落点）；
4. **入口教育**：第一次掏雪攒到料时，播报提示一句「雪料够了，点『堆墙』可以垒掩体」；堆墙按钮在触屏端与掷雪球同排可见，不藏二级菜单；
5. **联机同步**：自由墙走现行 wall-set 通道（team 字段填中性），不新增协议号；他人进场能看到既有自由墙（随墙体快照下发，核对现行快照口径，缺则补）。

## 验收线

- 单人自由模式全流程实走：掏雪→攒料→堆墙（≥3 层）→雪球打塌→雪橇撞穿，双端互见；
- 团队赛口径不回归（建造阶段/半场限制/队色）——既有雪仗测试全绿；
- 回执附自由模式堆墙截图（单端+对端各一）与禁堆点位抽查表。

边界：不动 town-snowfight.ts 的墙体规则与数值，只动开放条件、归属口径与提示；与雪橇手感重调同批施工、同车上线。
