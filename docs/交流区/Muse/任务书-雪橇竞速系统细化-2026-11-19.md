# 任务书：雪橇竞速系统细化（2026-11-19，分支窗口细节填充）

源稿：《雪橇竞速系统细化-2026-11-19》。定位：玩法系统稿。雪橇是 3.0 的招牌动词，竞速是它最自然的朋友局形态。本单只细化竞速系统，不改速度口径：冲刺锚点 11.3 m/s、常速 2×≈22.6、中坡 3×≈33.9、顶格 4×≈45.2（按坡分档）；雪橇只下不上，上山靠缆车/火车/徒步；撞墙分档 8/15/22 不变。**排期门：今晚总装上线之后领单；分级：R1′/R2 计时框架随前山线 B，绝顶线随主峰 C。**

**对接注记两件**：① 镇碑成绩（全镇最快一趟、署护照昵称）与成就红线「不设排行榜」的边界——本稿体例是只刻一趟、不列二到十名、不跨线比较（是碑不是榜），下游施工不许把它扩成名次表或赛季榜；此边界口径随本单登记，成就书 CJ 单的红线按此读。② R1′ 终点门位置以施工规格与前山游览书 QS 单为准（北岭站—缆车山脚站之间的三路交汇处）；本稿 §2 的「尾段穿松林北门」指尾段走向（过松林北缘），不另设终点。

## 细节填充

1. **计时系统**：起终点形态——每条线起点立一副木牌坊门（与山顶小屋登记点同址或紧邻），门楣挂该线名牌（R1′ 前山线 / R2 半山线 / 绝顶线）；终点在山脚落点区立同款小门 + 一口小钟；出发判定 = 橇头过门线，到达判定 = 橇头过终点门线、系统自动撞钟一声（全线可闻的小钟声，与跨层信号体系同源——与衔接书 L 单信号系统对接）；中途摔出赛道不取消成绩，爬回赛道继续计时（朋友局不搞 DQ，只搞「完赛」）。检查点：沿途每 400–600 m 一面红旗门（与攀爬红旗线同制式，雪地里一眼可见）；过旗门不减速、不交互，系统在 HUD 角落小字滚动记分段时间（只给本人看，不广播）；漏过一面旗门，该段不记分段、总时照算，成绩单上标「漏旗 ×N」（漏旗是路线选择的自由，不是违规）。成绩呈现：终点门旁立成绩碑（体素石碑），只刻三样：本人历次成绩、本次同行小队成绩、该线「镇碑成绩」（开镇以来全镇最快的一趟，署名是护照昵称——边界见本单首部对接注记①）；玩家个人最佳同步进护照页与自家屋陈列（小木牌，可挂工作台旁——与小屋书 XW 单对接）；多人同行时，成绩单以「同行对比」呈现（谁先到、各自漏旗数），不生成名次奖惩。成绩带设计（绝顶线）：绝顶线 ≥6 km、落差 ≈780 m（裁定 C-04）、预估 3–4 分钟；按预估中值 3 分 30 秒（210 s）设四档成绩带，刻在起点牌坊侧面（让玩家出发前就知道自己在追什么）：云带 ≤3:10（顶格坡段全程压满、零漏旗才摸得到）/ 风带 3:10–3:40（设计中值，熟练者常态）/ 雪带 3:40–4:20（正常完赛带，首次完赛大多落此）/ 归带 >4:20 或中途步行段（只记完赛，不记时——「回来就好」）。R1′（≥2.4 km）预估 70–100 s，设三带（风/雪/归，中值锚 85 s——与北岭补充稿 R1′ 预期均速口径一致）；R2 半山线距离短、地势缓，只设完赛与个人最佳，不设带（休闲线的成绩压力要最低）。三条线共用一个原则：**成绩带是给自己看的靶，不是给别人看的榜**。
2. **三条线的性格分工**：R1′ 前山线 = 上手线——从云海台出发，落差温和，前半段宽直（练压坡加速），中段两个连续 S 弯（练转向），尾段穿松林北门回镇；性格：宽容、明亮、全程能看见镇子；名场面一处：**出林口**（穿出松林的瞬间，镜湖与全镇灯火在左下方整片展开，赛道在此特意留了一段直道，让人有空抬头看一眼）。R2 半山线 = 休闲线——沿半山台地绕行，坡度多在常速档，景色段最长（贴云海下沿滑行、过松林高台站、镜湖崖）；性格：慢游、可聊天，**允许中途在观景台停橇（停橇自动暂停本人计时，复滑续计——休闲线特权，另两线不停表）**；名场面一处：**云下段**（赛道短暂滑入云海带下沿的雾气里，十几秒只闻橇声不见路，出云时湖面在正前方）。绝顶线 = 毕业线——主峰绝顶出发，前段岩面带（雪深 1–2 档，速度快但转向硬），中段穿云海（380–560 m，视距骤降，靠红旗门连线导航），下段深粉雪区（4–5 档拖速，考验压坡维持动量），终点落山脚基面；性格：长、险、全图地理的一次总考；名场面一处：**穿云口**（从云海里冲出的那一秒，整座未写镇、镜湖、陨星原同时出现在视野里——全游戏海拔落差最大的一次「回家感」镜头，赛道在此后给了一段缓坡，专门留给玩家喘气和回头）。三线与前山书 QS 单、主峰书的线体口径一致，本单只定竞速层（计时/成绩/形态），线体走向从施工规格。
3. **朋友局竞速形态**：发车仪式——小队模式（2–6 人）在起点牌坊集合，全员橇头对齐门线后，任意一人敲响门边小锣，3 秒倒数（锣声三响）齐发；单人随时自发，不必等锣；发车不设发车格、不设碰撞惩罚（朋友局的挤挤挨挨是乐子，撞墙分档照旧 8/15/22）。接力形态——绝顶线与 R1′ 支持「分段接力」：小队在检查点旗门处预先站位，前段滑手过旗门瞬间，后段滑手从旗门旁出发（系统以过旗时刻为交接时刻，无实物交接）；总成绩 = 各段之和，成绩单逐段署名；接力的意义是让新手也能参与毕业线（老手滑岩面段，新手滑下段深雪区，各滑自己能滑的那一段）。让先制度（土办法口径）——不做系统级让分，只做镇子规矩：同行竞速前，个人最佳快的一方自报「我等你 X 秒」（在起点多敲 X 秒的锣间隔再出发——锣在起点，规矩在人）；系统只负责一件事：成绩单上如实标注「让先 ×s」（让赢的人赢得体面、输的人输得明白）；不设官方让分公式，不进成绩碑镇碑成绩（镇碑只收无让先成绩）。禁区：不做排位赛、不做赛季、不做全服榜、不做淘汰制（竞速的一切组织形式都是「今晚我们几个滑一趟」——与成就红线同族）。
4. **手感层（施工调参靶子）**：以下为体感口径，是参数验收的靶子，不是已测数值（验收时以实测手感对照本项描述，不以本项数字为已验值）：转向——转向速率随速递减（常速档（≈22.6）要「一压就转」，顶格档（≈45.2）转向半径放大到常速的约 2.5–3 倍，让高速段的过弯靠提前压坡而非临弯猛打）；**抱宝转向 ×1.5 的既有口径在竞速空橇下不适用，两套分开**（与镜湖夺宝口径分工登记）。刹车——雪橇刹车 = 侧滑蹭雪，减速率要「可预期地慢」（顶格档全力刹车到常速档约需 2.5–3 秒，刹车时雪沫量与音效随速放大，给玩家明确的减速反馈；刹车不是为了停，是为了进弯）。跳跃——赛道坡坎（旗门段与岩面段的天然坎口）以常速以上通过即离地，滞空时橇头可微调朝向，落地顺坡无惩（只摔不伤），落地角度过大则打滚卸速到常速档以下（跳跃是奖励熟练者的捷径，不是必修课：每处坎口旁都有平路绕行）。深雪拖速——雪深 4–5 档区段，巡航速度按档打折（体感目标：顶格进深雪区，3 秒内掉到中坡档附近），出深雪后动量恢复要快（压坡 1–2 秒回速），让深雪段成为「节奏变化」而不是「罚站」；峰顶岩面 1–2 档不打折，是绝顶线开局全速的来源（雪深档从生态书 O 单、北岭补充稿口径）。
5. **与故事线/收集的接口**：成绩换什么——只换两样：称号与陈列。称号按成就稿口径：完赛绝顶线得登顶线称号（与绝顶登记盖章互认，不重复发奖——成就书「头一个下山的」以个人首次完整完赛绝顶线为条件、由绝顶登记员授予，裁定 R2-07/R2-12，本单与之对齐）；三线全完赛、绝顶线进风带等事迹各对应称号一枚，均由登记员/守火人在终点或登记点授予（授予者口径与成就稿对齐）；陈列：个人最佳木牌（第 1 项）进自家屋；不换货币、不换材料、不解锁玩法（滑得快只带来荣誉，不带来权力）。赛道沿途的遗址与碑：绝顶线中段穿云口下方、云海带下沿设一处封锁时代遗址点（瞭望残台）——赛道贴其外侧过，碑面只刻一句碎句（传说层，与遗址四类口径一致），竞速中无暇读、赛后可徒步回访（它是给「滑第二遍的人」准备的：第一遍追时间，第二遍看风景，第三遍读碑）；R1′ 与 R2 不设碑点（上手线与休闲线保持干净）。与雪墙迷宫竞速的关系：迷宫竞速是邀请制的另一套成绩（既有），与山地三线共用成绩单呈现语言（个人最佳 + 同行对比），但成绩互不合并、不互通称号（一个是「镇里的游戏」，一个是「山上的毕业考」——与迷宫单的邀请制口径对接）。
