# 设计 · 天空之城双态建模规格（2026-11-22，总控）

批66 梦境章的施工预留件：天空之城本章只建模，但建模必须一次预留**双态**——梦中活城（玩家一生一次的造访）与醒后空城（物理层常驻）。本规格定死每件元素的双态差异与预留点，ZD-05 施工照此留口，免得梦境章开工时返工拆模。

## 总则
- **一套几何、两套状态**：双态差异只许落在材质/光/动画/在场四类开关上，不许建两套模型。
- 切换权威在域状态（presence 天空域），不在客户端本地旗标——梦境是一次性服务器事件（与信标同级）。
- 活城态只存在于梦境章那一夜；空城态是其余全部时间的常态。玩家醒后重登岛（物理层可达）只见空城，活城永不复现（批66 定版）。

## 逐件双态表

| 元素 | 梦中活城 | 醒后空城 | 预留点 |
|---|---|---|---|
| 城心巨树 | 叶冠全张、冠下暖光、落花缓飘 | 枝形在、叶冠收拢、无落花、只晶辉映 | 叶冠开合动画轴＋落花粒子开关 |
| 巨型星尘晶（飞行石） | 缓旋、内光呼吸（晶辉青明暗） | 静止、内光恒弱 | 旋转轴＋光强两档 |
| 观测站仪器 | 运转（碟面慢转、指示灯列闪） | 全停、指示灯灭 | 仪器动画组＋灯列开关 |
| 守城傀儡 | 巡游步道、向玩家递花（动作循环） | 立于城门侧、持花静止（花不谢） | 巡游路径点＋递花动作触发 |
| 街区灯火 | 全亮暖橙、窗有光 | 全灭、只留星台与门环微光 | 灯光组总开关（两档） |
| 灵魂居民（一代观测员） | 在场：陈星垣/罗望舒/沈望云等各守其位、可对话 | 缺席（无模型在场） | 各魂站位锚点＋在场开关 |
| 太空门（星台） | 门环光纹流转（认主前置氛围） | 门环在、光纹止（锁闭即设计） | 门环光纹材质两态 |
| 云瀑/岛缘 | 流速常速、白雾翻卷 | 同（物理常数，不随态变） | 无（明示不变，防误做） |
| 风声/环境音 | 风＋远处人声与仪器轻响 | 只风 | 音频层两轨（施工在音频线，本表登记） |
| 许愿树母树根系（岛底） | 根须微光脉动（与镇上许愿树同频） | 脉动止、根形在 | 根系光脉动开关 |

## 施工口径（ZD-05 及后续接手者）
1. 每件建模交付时在登记里逐件标注其双态预留点已留（对照本表），缺预留的件按未完工计。
2. 本章验收只验空城态完整＋预留点在位；活城态的动画/在场实现随梦境章工包另派，不在本章冒充完成。
3. 魂的模型与台词不属本规格（台词归总控 NPC 线，梦境章前出）；本规格只管站位锚点。
4. 岛体物理层（地形/建筑/星台/巨树枝形）两态共用，碰撞一套，不随态变。
