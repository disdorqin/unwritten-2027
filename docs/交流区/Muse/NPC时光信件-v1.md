# NPC 时光信件 v1（NPC_LETTERS 语料）

撰写：Muse，2026-11-18。用途：时光信箱 NPC 内置信件正文，供 GPT 填入代码中预留的 `NPC_LETTERS` 空表。
依据：`NPC事实库-张乐天-v1.md`（关于张乐天的唯一口径源）、`NPC人设与台词-v2.md`（主线 6 人口吻）、`集市NPC台词-v1.md`（市集 3 人口吻）、`时光信箱细化-v1.md` §1「NPC 投信」与 §4 存储层口径（NPC 信件为版本内置数据常量、**不入 localStorage**，开箱时与玩家信件合并展示，`fromNpc` 区分，`id` 以 `npc-` 前缀）。
口径：9 位 NPC 各 1 封；信中关于镇长张乐天的内容**只用安全事实集**（他张罗这座小镇给朋友们跨年聚），不涉其私人生活、情感、行程，不预设任何 NPC 与他的具体往事。

---

## 一、给 GPT 的接入说明

### 建议数据结构

```ts
interface NpcLetter {
  npcId: string;       // 与 town-npc-dialogue 现有 NPC id 对齐；若现有 id 命名不同，以现有为准改键
  authorName: string;  // 署名（信封面与读信页显示）
  recipient: string;   // 收信口径（信封面副题，如「未来的访客」）
  title: string;       // 信件标题（开启后在列表显示）
  body: string;        // 正文（纯文本，渲染走 textContent，与玩家信件同纪律）
}

export const NPC_LETTERS: NpcLetter[] = [ /* 下列 9 封 */ ];
```

- `npcId` 建议值（按英文名拼音连字符式拟定）：`luo-dajiang`、`su-xiaoman`、`gu-changming`、`qiao-mai`、`liu-sanxian`、`zhong-tiesheng`、`qian-mancang`、`ding-xiaodou`、`tao-erniang`。若 dialogue 数据里已有 id 体系，直接替换为现有 id，本表只供内容。
- 合并展示时按《时光信箱细化-v1》§4 在内存里补齐同构字段：`fromNpc: true`、`id: 'npc-' + npcId`、`kind: 'letter'`、`authorType: 'npc'`、`authorName` = 署名、`body` = 正文。

### 开启行为（与玩家信件完全一致）

- 同一开启常量：设备本地时间 **`UNLOCK_AT = '2026-12-31T20:00:00'`** 之后才可读正文，与玩家封存信共用同一判定，不另设时间。
- 开启前：NPC 信件在信箱里只显示信封面（署名 + 「封存中」状态），**不显示标题、不显示正文任何片段**（与细化 §2「不开正文、不给片段或首字提示」同口径，标题也留到开启后）。
- 开启后：与玩家信件合并成同一列表展示，可反复重读，不再上锁。
- **不入 localStorage**：NPC 信件只以代码内置常量存在，不写 `unwritten.timebox.v1` 键，不占玩家 5 封封存上限，不参与撤回/删除。

## 二、信件正文（9 封）

### 1. 罗大江（酒馆老板）

- npcId：`luo-dajiang`
- 收信口径：未来的访客
- 标题：炉子给你留着火
- 正文：
开箱的你，见字如面。我是酒馆的罗大江。这封信投进箱子的时候，窗外正下着雪，我的汤还在炉子上咕嘟着。乐天张罗这一镇子的跨年局，图的就是大家能凑一块儿，暖和暖和。你要是读到这封信，先别急着赶路，来我酒馆坐坐，第一碗热汤算我的。日子跟熬汤一个理儿，急不得，火候到了，自然就香了。愿你新的一年，家里炉火旺，心里有热乎气。镇子不大，可灯都给你亮着呢。

### 2. 苏小满（邮局邮差）

- npcId：`su-xiaoman`
- 收信口径：2027 年开箱的人
- 标题：这封信，我亲自送到明年
- 正文：
猜猜我是谁？邮局的苏小满，全镇腿最快的人——这封信，我可是提前一年投的，绕了个大圈，亲手送到你手里。送信这些年，我最大的心得就是：再远的路，一步一步走，总有送到的时候。你读到它的时候，跨年钟声该敲响了。这一年里你等过的信、盼过的人，但愿都有了回音。没等到的也别急，说不定就在下一趟邮包里。好啦，我还要去送下一封——新年快乐，替我向 2027 年问声好！

### 3. 顾长明（灯塔看守）

- npcId：`gu-changming`
- 收信口径：明年的自己
- 标题：灯还亮着
- 正文：
明年的我，见字好。塔上的灯，今夜又转了一圈。一年到头，我说的话不多，想的都在这几行里。守塔的规矩没变：灯别灭，人别走。这一年，镇子大了些，人也多了些，湖上的冰化了又冻。都好。我没什么大愿望。就盼明年的今夜，灯还亮着，雪还下着，你还能爬上塔来，陪湖坐一会儿。人这一辈子，守住一盏灯，也算守住了日子。钟声快响了。下塔吧，路滑，慢些走。

### 4. 乔麦（灯坊匠人）

- npcId：`qiao-mai`
- 收信口径：未来的访客
- 标题：愿你这一年亮堂
- 正文：
你好呀，我是灯坊的乔麦，扎灯的。写这封信的时候，我手上正糊着跨年夜广场那盏大灯，浆糊还没干透。扎灯的人最懂一个理儿：纸再薄，透了光就是亮的；日子再难，熬过去就是暖的。这一年你要是顺风顺水，我替你高兴；要是有过磕磕绊绊，也别往心里去——灯芯剪一剪，还能再亮。开箱这天，全镇的灯一起亮，你站在广场上抬头看看，有一盏是我扎的。新的一年，愿你心里有光，眼前有路，亮堂堂地往前走。

### 5. 柳三弦（舞台班主）

- npcId：`liu-sanxian`
- 收信口径：未来的看官
- 标题：好戏，刚刚开场
- 正文：
台下的看官，柳三弦这厢有礼了！这封信封进箱子的时候，我们班子正排跨年夜的压轴戏，锣鼓家伙都擦得锃亮。唱戏的人信一句话：没有过不去的场，只有没唱完的戏。这一年您要是唱过几段难的，也别往心里搁——落幕了，咱再开新场。今晚钟声一响，满台灯偶都给您拜年。愿您新的一年，台上台下都有人喝彩，日子过得比戏文还热闹。得嘞，锣鼓催了，我得上台——好戏，这才刚刚开场！

### 6. 钟铁生（火车站站长）

- npcId：`zhong-tiesheng`
- 收信口径：未来的旅客
- 标题：本站欢迎您，明年见
- 正文：
未来的旅客，你好。本人钟铁生，雪镇火车站站长。按本站时刻表，这封信应在跨年夜二十点整送达你手中——本站的信，从不晚点。过去一年，本镇的车次把每一位朋友都稳稳当当送到了新年跟前。我想说的是：人生如行车，偶有晚点，不必慌张，站台上总有人等你。愿你新的一年，出行平安，进站出站，皆有灯光。跨年夜本站所有车次只进不出，把朋友们都接进来过年。本人会在站台上，迎你。站长钟铁生，报站完毕。

### 7. 钱满仓（集市东家）

- npcId：`qian-mancang`
- 收信口径：未来的客人
- 标题：开箱大吉，和气生财
- 正文：
开箱的客官，钱满仓给您道喜啦！这封信投箱的时候，我的年集正热闹，糖炒栗子的香气能飘半条街。这集市、这镇子，都是乐天张罗着给朋友们跨年聚的局，我就是跟着沾光，支个摊子凑个热闹。我做买卖这些年悟出一个理儿：钱要赚，话要暖，买卖做到最后，做的是人情。新的一年，我的摊子照样支在老地方，好货给您留着，热茶给您备着。就盼您常来常往，日子红红火火——和气生财，这四个字，送您了！

### 8. 丁小豆（热饮摊跑堂）

- npcId：`ding-xiaodou`
- 收信口径：未来的访客
- 标题：一个准信儿，提前一年告诉你
- 正文：
嘿，读信的你，我跟你说个准信儿——我是丁小豆，集市上跑堂的，消息最灵的那个。这个准信儿我提前一年就知道了，一直憋着没说：跨年夜这天，你会特别开心！不信？你看，你这不是读到我的信了嘛。跑堂这一年，我端着托盘满街跑，听了满耳朵的新鲜事，就明白一个理儿：日子过得快，热乎气儿不能凉。新的一年，要是你路过集市，喊一声小豆，我请你喝碗热汤——说好了的，不许赖账。好啦，托盘还等着我呢，新年快乐！

### 9. 陶二娘（糖葫芦摊主）

- npcId：`tao-erniang`
- 收信口径：未来的客人
- 标题：甜的在后头
- 正文：
读信的你，我是陶二娘，卖糖葫芦的。先说好，这封信不甜，话糙理不糙。裹糖葫芦有个讲究：糖熬过了头发苦，熬不到又粘牙——过日子也一样，火候最难拿。可我见得多了，再难的日子，也没见谁被难住一辈子。你要是这一年过得有点苦，别急，甜的都在后头呢。开箱这天来我摊上，报这封信，我多给你裹一层糖，再多塞你一颗——别推，推了就是不给我面子。新的一年，愿你嘴里甜，心里也甜。

## 三、事实纪律自查

- 提及张乐天的共 2 封（罗大江、钱满仓），措辞只用安全事实集第 4 条「这个雪镇是他张罗着建给朋友们跨年聚的」，未提其职业、保研、籍贯等其余事实（信件体裁用不上，不硬塞），更未涉私人生活、情感、行程、联系方式。
- 其余 7 封不提张乐天，只写各自营生（酒馆/邮局/灯塔/灯坊/舞台/车站/集市）与跨年心愿，均为 NPC 自身的虚构镇民生活，不受事实库约束的部分按人设创作。
- 无任何一封预设 NPC 与张乐天的相识经过、往来时长、具体往事或亲疏关系；无对张乐天性格的评价性断言。
- 字数：9 封正文均在 120–220 字区间（逐封计数见撰写记录，交付前已逐封核过）。
