# 任务书：地面日常事件库（十个事件）（2026-11-19，分支窗口细节填充）

源稿：《地面日常事件库-2026-11-19》。定位：故事线第一章「地面日常」的可重复事件层——主线残页是骨，这十个事件是肉。**排期门：今晚总装上线之后领单。** 全事件和平模式、无惩罚、可单人可多人、单个 1–3 分钟；只许传说层与「不对劲」，不许剧透真相层。台词口径：源稿内已写出的引文（站长含糊话、守火人半句等）是主窗口稿内文，可直接用；**施工中需补写的任何新台词，一律回主窗口过目后填充**。

## 细节填充

1. **事件调度器（全库共用）**：每名玩家一份事件状态（每事件已遇次数 0–3，决定演第几段）。密度口径按源稿：日常轮换以「每名玩家每个游戏夜期望撞见 1–2 个」为准——调度拟定以游戏夜为单位：每晚从玩家所处区域的可触发事件中置 1–2 个为「今晚可触发」，经过触发点即演，未触发不结转到次晚。同一事件对同一玩家**每晚至多推进一段**，段间冷却 ≥1 个游戏夜，不许一晚刷满三段。与主线投放比约 3:1（每推进一段残页主线，体感已撞见约三个日常事件）——调度回执登记实际配比抽测。事件永不给残页、不给关键物；产出只限氛围向纪念（戏票存根、合影点之类）。
2. **首晚定向投放（开镇夜只放 3 个）**：事件五（小未望西，广场附近定向刷点，首晚可撞见）、事件六（第九声余震，与钩子一号同源：整点第九声落下后 1 分钟内、玩家在钟楼附近触发）、事件二（那出没人看懂的戏，戏台压轴固定场次）。其余 7 个首晚锁定，次晚起进日常池。
3. **分事件实现注记**（触发/咬合以源稿为准，此处只补参数与对接）：
   - 事件一（站长多开一站）：环线时刻表插入非公开停靠点，不进时刻表；二段换新采野花、三段起偶现旧行李箱（陈设，无人认领、不可拾）。
   - 事件二（没人看懂的戏）：戏台固定节目单压轴一出；看完得戏票存根（护照/背包纪念物）。二看班主补词版；**字幕残影只对个人已听 ≥6（过半，个人轨）的玩家可见**，一帧级闪过、不解释。
   - 事件三（夹在信里的旧纸）：混入邮差跑腿既有单池（town-mail-store），概率触发的特殊单；旧纸内容三段递进（清单一角 → 半张星图 → 邮差压低声音的话），纸面文字为陈设级短文，沿源稿稿内文，新写部分另审。
   - 事件四（集市上的外乡价）：集市摊主闲聊层 overhear；玩家此前拾过碎块并交镇公所登记过（与事件九登记册同源记录）时多一句「你是个懂规矩的」。
   - 事件五（小未不吃的草）：小未自由活动系统小概率触发，望西约 20 秒；二段与天降排期弱联动（天降前后望得更久、刨地）；三段玩家站其身侧顺视线可见极远一线微光（不可交互、不可抵达）。
   - 事件六（第九声的余震）：钩子的日常回声，**不另立新钩子**；三段递进：掩饰说辞 → 「拆了机芯」勉强笑 → 对高进度玩家只点头（点头判定拟定 = 个人已听 ≥8）。
   - 事件七（许愿树上的旧牌）：挂新牌时小概率翻出相邻旧牌；旧牌文字沿源稿稿内文（两块）；三段绳结与地宫门环纹样视觉呼应——只作视觉，不点破（原住民/真相口径不展开）。
   - 事件八（火塘边没讲完的故事）：松林火塘故事会既有场次新增一个固定故事，两次被打断；**最后半句的解锁拟定为：在场玩家中任一人个人已听 ≥8**（与镇长「犹豫」档对齐），说出后仍不解释。
   - 事件九（馅饼日的规矩）：天降事件的地面收尾层——碎块落点 10 分钟内触发；登记只记名、碎块照样归玩家（与多人规则单的坠痕/先捡口径并行不悖）；登记册记录供事件四联动读取；三段起名字旁注「第几次」。
   - 事件十（戏台后台的戏服）：非演出时段后台门口小概率；与事件二互为注脚，两事件都遇过的玩家得额外一枚合影点（纪念向）。
4. **红线（源稿复述，验收口径）**：十个事件合起来最多把玩家带到「这镇子藏着一件大事」的门口；任何单事件或事件组合不许提前拼出飞船、迫降、修船中的任何一个词——那是残页九页之后的事。每单回执须附一行红线自查（逐事件传说层断言）。
