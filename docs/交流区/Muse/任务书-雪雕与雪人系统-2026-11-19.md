# 任务书：雪雕与雪人系统（2026-11-19，分支窗口细节填充）

源稿：《雪雕与雪人系统-2026-11-19》。共创向小系统：玩家亲手堆的雪人、亲手凿的雪雕，是镇子里最没有门槛的创作——不用学、不用肝、堆完就有人看。已定版锚点（不改）：雪人造型语言以 M1 定版为准——**方块身 + 南瓜头**；松林营地有既有雪人场；冰雕小岛是镜湖四区之一；公共展品与每周投票走共创稿口径（批 F 投票已实现规则）；雪雕雪人适用共创四层寿命口径；冰宫是冰雕美学的上限参照；小未是羊，雪像可以有、必须可爱，不许拿小未做笑柄。**常驻条款（Thomas 2026-11-19 20:58）**：每次派工拆多路并行、按最高并发上限同时执行，无依赖条目必须并行、有依赖才排队——本单并行组已在施工拆分表预标。**排期门：今晚总装上线之后领单；分级 B（共创氛围件，随首季共创全口径）。**

## 细节填充

1. **堆雪人玩法**：滚雪球成身——堆雪人从滚一个小雪球开始，这是雪球系统的放大版接口：雪球在雪地上滚行时吸附积雪、体积渐长，滚过的轨迹留下一条压实的雪道；雪球越大，推它的人走得越慢、转弯越钝（这是有意的喜剧手感：滚到一人高时推的人几乎是贴在球上挪，朋友在旁边看着笑，是堆雪人乐趣的一半）；雪球的上限与雪深有关（深雪区（松林、山脚）滚得快也滚得大，镇内清扫过的路面滚得慢（选址即玩法））。三段式——一个成立的雪人由三段构成，系统只认结构、不评美丑：① 身：滚成的雪球落位即成底座，可叠第二球作中段，叠放时有轻微对齐吸附，歪一点不倒（歪雪人合法）；② 头：以 M1 定版为准——**南瓜头**是镇子雪人的正头（松林南瓜的去处之一），没有南瓜时小雪球头也可成立，但展览登记时标注「素头」；③ 装扮：见下，来路各异，是雪人个性的全部所在。装扮件的来路：胡萝卜（鼻子）——集市换物/自家菜窖，消耗品，插上即固定；围巾——衣着系统接口：玩家自己的围巾可摘下给雪人围（围巾是借的不是消耗的，雪人化后围巾回到原地（见第 3 项融化口径））；矿物眼睛——任意小块矿物（煤块最佳、水晶最亮、星尘矿慎用（会发光，引围观）），装上即消耗，化后留原地；树枝手臂——松林拣拾，随处可得，不消耗计数；帽子/桶——杂物类既有道具，与围巾同口径，借用制。装扮不设套装、不设图鉴格（装扮的意义是「这一只是我的」，不是集齐）。
2. **雪雕**：场与坯——雪雕只在两处成立：**镜湖冰雕小岛**（正展区）与**广场展区**（节庆临时展区，平日不开放雕刻）；两处都预置**预制雪坯**（压实的大方雪块，尺寸分大中小三档，由系统按展期补给，玩家不许自带雪块进岛（岛上冰面不产滚雪球的雪））。敲凿口径——雕刻是减法：玩家持凿（冰宫线杂工工具的民用版，展区入口借，还）对着雪坯敲，敲击按格点削去雪块，削落的雪在脚边堆成小堆；口径三条：只有粗凿与细凿两档（粗凿去大块、细凿修边），没有撤销键（凿过头了就是过头了，可以拿边角雪「补」一块（补块颜色略新，一眼看得出，是手作痕迹不是瑕疵））；雕刻不计时、不评分、不设熟练度；坯体崩塌只发生在削空底部时，塌了就是一堆雪，可以重领一块坯，NPC 展区管理员只摇头，不说教（反应口径见第 4 项）。题材白名单——展区立牌写明：只雕镇子里的东西；白名单题材：**钟楼、火车、小未、金羊、雪橇、灯笼、戏台、自家小屋、湖与山**；白名单之外不是禁止雕，而是**不进登记**（玩家私下在松林雪人场爱堆什么堆什么（雪人场不设白名单），但官方展区的登记、投票、展陈只收白名单题材）；金羊雪雕单列一条：金羊是传说题材，雪雕只许形态（白雪的羊形即可，不许上金色、不许配说明牌写传说内容，看见的人自己想去）。
3. **展览与投票**：入展流程（接口共创稿）——堆成/雕成的作品由作者在展区登记牌处登记：登记即生成一条共创展品记录（作者、位置、题材、一句作者自题（只许题名不许小作文）），进入共创四层寿命口径的「展品层」；未登记的野雪人不进系统，但照样立在原地给人看，寿命按共创稿野作口径走。投票（接口批 F 已实现规则）——登记展品自动进入当周公共展品池，每周投票按批 F 已落地的规则执行（票数、周期、防刷口径皆以该实现为准，本单不另设）；雪人雪雕在展品池里与冰灯、陈设等其他共创展品同池竞争，不单开品类奖；唯一的雪类专属荣誉是口头称谓级的「本周最像镇子的雪人」，由投票备注自然形成，不发实体奖、不带数值。展期与融化——雪人雪雕都会化，这是本系统最重要的温柔口径：寿命按共创四层寿命口径执行（展品层最长、野作层最短；冰雕岛因地处湖心低温，寿命为广场展区的两倍口径；松林雪人场居中）；**融化是渐变**（先塌肩、再歪头、最后只剩底座一摊，形态逐日变化，路过的人看得见「它老了」）；**化尽留痕**——雪人化尽后，**装扮件留在原地**（一根胡萝卜、一双矿物眼睛、借来的围巾与帽子，都好端端躺在那一小片湿雪印上；玩家路过拾起即可（围巾帽子自动回到可拾状态））；这是定版温柔口径：化了不是消失，是「它把东西还给你了」；拍照留存（接口拍照系统）——登记展品在融化前任意时刻可拍照存档，照片进作者相册并在展品记录里留一张「生前照」；展品化尽后，其共创记录转为纪念条目（照片 + 题名 + 存活天数），投票池退出，纪念墙（镇公所共创展陈位）可查（雪会化，照片不会）。
4. **雪人的故事性**：守夜雪人（传说层接口一处）——镇上有个老说法：每年入冬第一场大雪之后，广场角上会有一只没人认领的雪人（方块身、南瓜头、围着一条旧围巾，面朝钟楼，像在守夜）；镇民说不清是谁堆的，问谁都说「不是我，但我给它扶正过帽子」。系统落法只定形态：每年冬季首雪后的次日清晨，广场固定角位生成一只守夜雪人（无作者、不可登记、不可投票），它的围巾样式每年微差；玩家可以给它加装扮、可以拍照，但不能推倒登记成自己的；它化得比所有雪人都慢，化尽时只留那条旧围巾（第二年首雪，它又在了）；这条只到传说层：不解释、不出 NPC 长台词、不与任何主线残页挂钩。NPC 围观反应口径（只定类型，不写台词）——玩家堆雪人/凿雪雕时，在场 NPC 的反应只从下表取类型，具体台词一律留白给 NPC 内容侧填充，本单不写一句：雪人落成（第三段装上）→ 停步观看 → 鼓掌或竖拇指（二选一，按 NPC 性格域）；滚大雪球经过 NPC 身边 → 让路 + 笑（动作类，无台词亦可）；雪雕崩塌 → 摇头 + 帮忙扶坯（管理员岗专属）；看见守夜雪人被加装扮 → 默默再给它正一正自己加的那件（动作类）；看见星尘矿眼睛的雪人 → 驻足多看两眼（稀有装扮触发）。反应不打断 NPC 本职动线，看完即走；同一 NPC 对同一作品只反应一次。
5. **红线**：① 不带数值——雪人雪雕不产出任何资源、积分、加成；投票只定荣誉不定收益；滚雪球大小不折算任何东西。② 融化不是惩罚——融化不扣任何东西、不发失败提示、不催玩家回来续命；化尽留装扮件在原地是定版口径，任何实现不许改成「化了就没了」。③ 题材不出世界观——官方展区只登记白名单镇子题材；不许引入镇外 IP、现实人物、标语口号类造型进登记池。④ 小未体面——小未雪像必须可爱口径（圆、憨、铃铛要在）；不许做成搞笑丑角、不许给小未雪像配嘲讽题名，登记时题名含贬义直接不予登记。⑤ 不抢正事——堆雪人是路边玩法，不许设成任何主线、残页、成就的前置条件；展区雕刻不许占冰雕岛冰壶/夺宝动线（镜湖四区分工不改）。
