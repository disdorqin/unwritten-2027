# 任务书：设置与无障碍（2026-11-19，分支窗口细节填充）

源稿：《设置与无障碍-2026-11-19》（定版）。本单管五件事：画质档、操作无障碍、晕动症支持、信息冗余（听觉/视觉）、设置的存在形态。总原则：无障碍不是事后补丁，是「朋友局」的前提——进来的是主理人的朋友们，有人晕 3D、有人用微信内置浏览器、有人在被窝里静音玩；每一项设置都要能在不被注意的情况下救一个人的一晚。已定版口径：性能预算是参考线、真机体验为准；P4 自适应分辨率已实装（默认关，`?adaptive=on`）；BGM 音量独立控制是底线件；关键叙事信息不许只靠声音传达。与引导稿、小屋稿、攀爬稿、声音稿冲突处，以正典总索引覆盖链为准。**排期门：今晚总装上线之后领单；分级 A（第一晚三件与底线件属开镇基础）/B（抽屉全量细项）。**

## 细节填充

1. **画质档口径**：三档划分依据只认两个锚——**draw calls / 三角面数**与**粒子量**；不用「高清/流畅」这类形容词命名，档名直说用途。**镇景档**（高）：桌面真机、独显/近三年集显；以 PC 线为参考（450 draws / 2.2M tris 上限内全量呈现）——全密度装饰、烟花全粒子（≤15,000 上限照常）、云海全层、远山粗模常驻。**街市档**（中，默认）：多数笔记本与平板；draws/tris 约为镇景档六成——装饰密度降一档、粒子上限砍半、云海保留主层。**暖屋档**（低）：老设备、手机内置浏览器；以「能完整玩」为准——装饰砍到骨架、粒子只保留事件必需、阴影关或只保留近景 blob。自动档与 P4 的关系：**自动档 = 默认行为**——进镇先按街市档起步，P4 自适应分辨率在后台盯帧时间（持续掉帧则逐级降分辨率与粒子，恢复则逐级升回，但**升降不跨档**，只在当前档内微调）；P4 的开关参数（`?adaptive=on`）保持现行口径不变；设置面板里给玩家的不是技术参数，而是一条「画面自动调节」开关（开 = P4 生效（默认开），关 = 锁死当前档全量渲染）；自动档降级要**先降分辨率、再降粒子、最后才降装饰密度**（分辨率糊一点不伤玩法，装饰消失才伤「这是我的镇子」的认同感）。低端档的取舍顺序（铁律）：先砍纯装饰，再砍氛围冗余，最后才碰玩法件；**玩法件永不砍**。砍序：① 远景装饰密度（松林远景雪人、散挂小件）→ ② 粒子数量上限（烟花、雪花粒子——降数量不降事件本身）→ ③ 云海层数与旗云细节 → ④ 阴影（先降分辨率，后关远景阴影，近景人物阴影保底）→ ⑤ 非关键 NPC 的闲逛动画帧率 → ⑥ **永不砍**：玩法件本体（雪墙层数、钓位、碑点、信号件）、关键叙事物件（残页、宝库门、许愿树）、同屏玩家模型与名牌、字幕与提示 UI。判读口径：低端档里镇子可以「素」，不许「缺」——缺了任何一件能交互的东西，就是砍错了。
2. **操作无障碍**：视角——**视角灵敏度**滑杆独立成项（鼠标/触屏分开记值）；**Y 轴反转**开关（飞行与滑翔共用同一反转口径，不许滑翔单独一套——与滑翔书 HX 单对接）；**拖拽转视角灵敏度单独一项**（微信/QQ 内置浏览器没有指针锁定，全靠拖拽——这条路径的灵敏度、惯性与「拖动死区」单独可调，默认值按「拖满半屏 ≈ 转身九十度」的温和口径定，宁慢勿飘）。长按时长可调：全镇吃长按的操作不止一处，统一一个「长按判定」设置项，三档（短/标准/长）全局生效——雪球（按住掬雪 + 瞄准（松手投掷），长按时长影响「掬满」的判定点）/ 攀爬（贴墙交互的按住判定）/ 其余一切长按交互（开门、点火、领物）跟随同一口径；手抖、戴手套（冬天真有人戴手套玩手机）、触控不稳的朋友，用「长」档能把误触率压下来；高手用「短」档求手速；**不许某个系统私自写死自己的长按时长**。键位提示：键位/操作提示分两种形态——**常驻**（当前可做动作的最小提示，屏幕一角小字）与**淡出**（教学性大段提示，出现一次后淡出进手册）；设置里给「提示密度」三档：全提示（首周默认）/ 最小提示 / 关闭教学提示（常驻的动作小字不关，那是操作反馈不是教学）；内置浏览器路径（拖拽转视角、双指等替代手势）的提示文案独立一套，不许拿 PC 键位文案糊弄触屏玩家（与引导书 YD 单对接）。
3. **晕动症支持**：第一人称雪镇 + 雪橇俯冲 + 滑翔，晕 3D 的朋友是必然存在的；支持项全部默认向「温和」侧预设，老玩家可自行调烈。FOV 可调：FOV 滑杆（建议口径带：65–100），雪橇/滑翔的**动态 FOV 拉伸**（加速时视野变宽的速度感效果）单独一个开关，可关（动态 FOV 是晕动大户，关掉后速度感靠风声与粒子速度表达）。镜头晃动开关：一个总开关「镜头晃动」，关 = 下列晃动源全部归零，不许逐个藏在各系统里——雪橇俯冲/颠簸（路面起伏的镜头跟随抖动）/ 滑翔失速与穿云（机翼式横滚倾斜、失速下坠的镜头俯仰）/ 撞墙/落地（雪墙撞击、跳跃落地的冲击帧）/ 烟花与事件（零点烟花近距离的轻微震感）/ 攀爬（抓握交替的左右微晃）；另设「头部摆动」（走路 bobbing）独立开关，与晃动总开关分开（有人只晕 bobbing 不晕冲击）。转场与闪光：**传送/转场闪白可关**（关掉后转场改为渐黑—渐亮，不许任何全屏纯白帧（零点全员传送是全镇事件，这条必须生效））；烟花强闪给「降低闪烁」开关（开 = 烟花保留形态与颜色，削掉高频爆闪的亮度峰值；此条同时是光敏性兜底，不许只写在晕动症名下）。
4. **听觉与视觉信息冗余**：铁律——**关键信息不许单通道**：凡是「听到才知道发生了什么」的信息，必须有一份视觉对应；凡是「只靠颜色区分」的信息，必须加形状或文字编码；NPC 讲古与事件广播无论现行实现是文字 + 语音并行还是仅文字，本原则不变：叙事关键信息（谁、何事、去哪、何时）必须落成文字，声音只许是加分项。声音 → 视觉对应表（施工逐项验收）：钟楼整点钟声（时间信号）→ 屏幕一角钟点字幕条 + 钟楼方向图标闪烁一次；第九声（钩子事件，叙事关键）→ 字幕条明示「钟声多了一声」（不许让玩家靠数数才发现——与钩子书 H 单对接）；小未的铃铛（寻羊线索）→ 铃声方向的边缘微光指示（循声玩法给视觉等价物：近时羊圈方向图标亮起）；跨层信号（瞭望塔小钟、坑底呼应；社交信号）→ 信号图标 + 来源方向标记入小地图/罗盘；事件广播（讲古、庆典、传送仪式；全镇叙事）→ 全文文字广播条，停留时长可读完（不许语音播完字就消）；怪物临近（地下；生存信息）→ 屏幕边缘方向性暗纹提示（低血量提示同理不许只靠心跳声）；钓口咬钩（玩法反馈）→ 浮漂视觉下沉为主反馈，铃声只作冗余。色弱支持：**信号色不许红绿单编码**——红旗路线标是既定件（珠峰式红旗），其「路线等级/方向」信息必须叠加形状编码：**旗形分三式（三角旗 = 体验级、方旗 = 进阶级、燕尾旗 = 绝壁级，与攀爬分级对应）**，色盲玩家靠旗形读路（**接口修订登记：攀爬书 PB 单的旗帜口径为旗色深浅 + 旗距，本项追加旗形为第三编码，PB1 验收时一并核旗形**）；全镇信号体系盘点口径：凡出现「红 = 禁/绿 = 可、红 = 敌/绿 = 友」的地方，一律追加形状或图标差异（禁 = 叉纹、可 = 环纹之类），颜色只作强化；队伍色带、夺宝宝物高亮等临时标记同样执行：颜色 + 轮廓样式双编码；冰面/雪面高光下文字对比度保底：字幕条与提示 UI 一律带半透明深色衬底，不许白字直接压雪地。
5. **设置的存在形态**：存储与同步——设置**存本地**（浏览器本地存储），不进账号同步、不上传服务器（换设备重新调一次是可接受的，隐私与实现成本都划算）；唯一例外口径：无（音量、FOV 这类纯个人偏好没有跨设备一致的必要）。分层露出：设置不许进镇就甩一整页清单，按「需要时才出现」分两层。第一层 · 第一晚引导里只露三件（与引导书 YD 单对齐，在进镇动线里自然带出，不弹设置页）：① **音量**（BGM 与音效，BGM 独立滑杆——夙愿件，底线不让步）② **视角灵敏度**（含拖拽路径自动识别：内置浏览器进来的人，露出的就是拖拽灵敏度）③ **画质**（自动/三档，一句话说清「卡就选暖屋档」）。第二层 · 屋内「设置抽屉」：其余全部（FOV、晃动、长按、提示密度、闪白、字幕大小等）收进自家小屋的一个可交互家具——「设置抽屉」（与小屋书 XW 单的家具口径接口：抽屉是小屋常驻件，开镇版小屋建成即可达）；设计意图：设置是「回家慢慢调」的东西，不是进门考试（晕 3D 的朋友第一晚只被问三件事，缓过来之后想细调，抽屉一直在屋里等着）。紧急出口：任何时刻 Esc/菜单键可达一个精简版设置（只含音量、晃动开关、画质速降三件）——玩家晕到想吐的那一刻，不许让他先走回小屋开抽屉；此精简版与抽屉共用同一份本地存档，改哪边都算数。
