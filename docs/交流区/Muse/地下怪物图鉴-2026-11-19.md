# 地下怪物图鉴（2026-11-19 18:45，Thomas 点名扩充，主窗口成稿）

配套《地下生存模式与入梦机关》。战斗双工具就此定版：**雪球克冰雪系、矿镐克硬系**；矿镐是下井工具（矿洞口领取），既挖矿又防身，不另设武器系统。全体怪物走方块喜剧恐怖路线（圆头方块骷髅、穿旧矿工服的方块僵尸），不血腥、不惊吓——朋友局与新年镇的底线。

设计注记：
- 来历全部挂在三时代上：骷髅/僵尸是矿工时代的人，石头怪与骷髅勇士是勇士城的守卫，水晶怪是矿脉自己「长」出来的——怪物即历史，与《世界观故事线》同源。
- 强度递进沿生存稿 §4：矿洞教学 → 水晶洞走位 → 勇士城拉扯 → 地宫毕业考；任何一击不秒杀满血的红线不变。
- 水晶怪的伪装是全图鉴唯一「环境拟态」怪，验收要抽查：静止时与真水晶簇同模同色，只有轻微呼吸起伏可辨。
