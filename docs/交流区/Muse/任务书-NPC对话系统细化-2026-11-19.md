# 任务书：NPC 对话系统细化（2026-11-19，分支窗口细节填充）

源稿：《NPC对话系统细化-2026-11-19》。本单只设计对话机制，**零台词**：一切具体问答内容只许来自已记录事实的种子库，本单不写、不举任何 NPC 台词例句；需要示意形态时一律用占位符（如 `[回避：装忙型]`）表示。**常驻条款（Thomas 2026-11-19 20:58）**：每次派工拆多路并行、按最高并发上限同时执行，无依赖条目必须并行、有依赖才排队——本单并行组已在施工拆分表预标。**排期门：今晚总装上线之后领单；分级 A（对话是核心留存机制，随开镇基础）/ 长线（种子库只增不改、持续补种）。**

## 定位与铁律

- 对话是核心留存机制：有玩家专为聊天进镇，对话系统的地位与雪橇、雪仗并列，不当装饰。
- 岗位骨架已定：16 岗（地面 13 岗 + 主峰 3 岗），每岗只知与自己相关的一片段，镇长一岗负责汇总讲古；作息表已定（谁在何时在何岗），对话可用性跟作息走，不另设一套。
- **铁律一（事实种子）**：NPC 问答只许种子自已记录的事实。种子来源只有三类：主理人已记录的真实问答素材（张乐天为主理人自愿给出的问答对象）、已定版的设计事实（岗位职责、地名、节拍口径）、已过主窗口审的讲古与传说层文本。种子库之外的内容一律走回避机制（第 3 项），**绝不临场编造**。
- **铁律二（审稿关口）**：讲古全文与一切真相层文本，落库前须过主窗口审；本系统只管「何时、向谁、以何种形态说」，不管「说什么」——说什么永远以审定文本为准。
- **铁律三（小未不说话）**：小未是羊，没有对话入口；它的互动走铃铛、喂食、跟随等非语言件（见小未专稿），不许给它配任何拟人台词或文字气泡。

## 细节填充

1. **对话的形态**：触发方式——玩家走近 NPC 至交互距离，出现对话入口；进入对话后视角与移动按既有交互口径锁定/释放，不新设一套。对话界面只给一个话题菜单，**不给自由文本输入框**（朋友局封闭环境下，菜单式话题保证每一句问答都落在种子库内，是铁律一的技术前提）。菜单四层结构：岗位话题 / 镇子话题 / 故事话题 / 闲聊——四类各自独立维护，解锁条件与更新来源不同。话题条目的最小单位是「问答对」：一个可点的问法对应一段审定/记录过的回答；系统不做问答拼接、不做同义改写，点哪个问法出哪段原文。四类话题的内容来源与更新口径：岗位话题——该岗的职责事实与当班状态（在岗做什么、缺什么、忙什么），随作息与岗位事件刷新，只引用已定版岗位事实；镇子话题——全镇公共事实（地名方位、设施位置、节庆安排、天气与天象预报口径），随世界状态（节日、天象、事件）更新，**全岗共用同一份公共事实表，口径全镇一致，不许各岗说法互相打架**；故事话题——镇志残页线（每岗知一片段，镇长汇总），随玩家集页进度解锁（第 2 项），文本全部走审定稿，未审定不上菜单；闲聊——已记录的真实问答素材（以张乐天问答种子为原型扩散到各岗的人情话题），**只增不改**：新素材须先记录入库才可上菜单，没有种子的闲聊话题宁可不上，不许生成。
2. **话题的解锁与状态**：任一 NPC 在任一时刻的可聊话题集合 = 基础话题集 ∩ 下列维度的当前状态过滤结果。维度表：集页进度（玩家个人轨（已集页数、已听大页））——故事话题逐页解锁：集到某页，与该页片段相关的岗位话题才出现；镇长汇总话题按大页节点（7/9/11/12）分段开放。时段（作息表（当班/串岗/夜值守/休息））——不在岗时岗位话题关闭，只留最少量在岗外话题或直接无对话入口；夜值守岗的话题集与白班不同（以作息稿为准）。世界事件（天降、节日、开井、过顶等事件状态）——事件进行时与事件余波期（次日）各开放一组事件话题，过期自动下架。关系记忆（该 NPC 对玩家的记忆维度（第 5 项））——玩家做过的事达到对应维度后，开放「记得你」类话题。层域（玩家当前所在层（地表/地下/云海之上）与 NPC 所在岗）——跨层不设对话：NPC 只在本人岗位所在层出现，不存在远程对话。解锁原则：解锁只做加法提示、不做剧透（新话题出现时在菜单上以新标记提示存在，但标题只写问法方向，不预告答案内容）；故事话题的解锁严格跟着集页走（没集到的页，相关 NPC 的菜单里连问法都不出现（玩家不能靠对话绕过集页顺序提前听到后面的片段））；同一片段只由知情的那一岗讲，其他岗被问到同类话题时走第 3 项的「指向他人」型回避，把玩家导向正确的人（这是有意的动线设计，不是内容缺失）。
3. **回避机制**：触发条件——玩家的话题选择触及种子库之外的任何内容：未记录的真实人物事实、未审定的故事后续、真相层未开放部分、本岗不知的片段、尚未发生的事件；触发后不报错、不空白，按下述形态分类回应。回避形态分类（只定形态，不写台词）：装忙型——NPC 以手头岗位事务为由把话题带开，回应落在岗位事实上（适用：问到与本岗无关的杂事）；答非所问型——NPC 接住话头但答的是相邻的已种子内容（听岔了/理解偏了）（适用：问法与种子沾边但没有对应问答对）；指向他人型——NPC 明示这事该问谁，把玩家导向知情岗或镇长（适用：问到他岗片段、故事汇总类问题）；忘事型——NPC 以记性为由含糊过去（镇长专用形态须慎用：他的「忘」分真忘与守誓，口径见家系稿，本系统只登记此形态存在，不展开）（适用：触及未开放的故事层）。形态以占位符登记入库，如 `[回避：指向他人型 → 目标岗]`；具体文字由审定流程另行产出，不在本单。不穿帮口径：回避回应必须全程在角色内（只许用镇中人的认知说话，不许出现任何元层面的表述——禁用形态包括但不限于：提及数据/记录/系统/设定、「这个问题我没法回答」式的客服腔、直接承认自己是 NPC）；回避不许给出新信息（回避段落里出现的每一个事实性说法仍须是种子内的；回避是「不答」，不是「编一个温和的假答案」）；同一未种子问题反复问，回应形态可轮换（装忙 → 指向他人），但不许因为问的次数多就「松口」给出库外内容；回避频率自检：若某岗的回避触发率在验收走查中异常高，说明是种子库缺口而非玩家问题，登记为补种任务，不许用放宽铁律的方式解决。
4. **多人对话**：同场多人——多个玩家可同时与同一 NPC 对话，各自看到自己的话题菜单与进度（故事话题按个人轨解锁，A 玩家解锁的片段不会因为 B 在场就对 B 出现）。旁听形态——同场玩家能看到「有人在与 NPC 交谈」的在场表现，但问答内容默认只对提问者可见；闲聊类可设为同场可见（朋友局的热闹感），故事类与讲古类不走旁听扩散，各听各的轨（与语音书 YY 单的旁听半径口径分工：本单管对话内容可见性，YY 管声音）。讲古听众模式分两轨，与多人规则稿对齐：**大页讲古（围坐）**——集页到大页节点后在镇长处触发，全场玩家可围坐同听同一场；这是世界公告轨的场面，听完在各人个人轨上分别记账（在场者记，没在场的之后可单独补听小页版本，不许错过即永久缺页）；**小页私下场**——单人或小队在镇长不当众时单独听，内容为审定稿的小页版本；私下场不触发全镇公告。排队与占用：讲古进行中，镇长的其他话题暂时关闭并给出在场提示；其他玩家可选择旁听围坐或改时再来，不设强制等待。地下与主峰岗的对话同理：多人同场各自菜单，篝火点等集结点的 NPC 对话不设全场广播。
5. **对话的留存设计**：「每天来聊有新东西」的三源——作息轮换（岗位串岗、夜值守轮换使同一 NPC 在不同日子/时段给出不同的岗位话题与在场状态，按作息表的日/夜与轮换周期自然产生）；事件余波（天降、节日、开井、过顶等事件后，相关岗开放余波话题一至两日，聊的是「昨天那件事」，事件驱动、过期下架、错过不补（但不涉及故事主线信息，主线只走集页））；集页推进（玩家自己集页进度推进后，各知情岗的故事话题逐段开放，玩家节奏驱动，是长线主引擎）。三源之外不设签到式刷新：不许用「每日一句新台词」逼玩家打卡；新东西的产生必须挂在世界真实发生的变化上。话题耗尽的保底：NPC 记得你——当某岗的基础话题被聊尽，保底不是重复闲聊，而是开启「记得你」层：NPC 的话题开始引用玩家做过的事。记忆维度清单（只列维度，具体内容随各维度已发生的事实自动填充，不预写）：来访维度（来过本岗几次、常来的时段）；行动维度（玩家在本岗相关场景做过的关键事（送过什么、修过什么、帮过什么忙（只登记已定版玩法内的行为）））；进度维度（玩家的集页进度、登顶/下井等里程碑（只引用已解锁部分，不提前剧透未到之处））；同行维度（常和谁一起来（朋友局的熟脸识别，只记同场事实））；居所维度（玩家落户的小屋与床位绑定（镇长/镇公所岗专用，欢迎与落户话题的依据））。记忆只增不改、只记事实不做评价：NPC 可以「记得你做过」，不许「评价你做得好不好」，更不许拿记忆内容编造玩家没做过的事。记忆层话题同样受第 3 项管辖：维度内没有记录的细节被追问时，照常走回避形态。

## 验收要点（源稿自带，逐条入回执核对）

1. 任一 NPC 菜单中出现的每条问答，都能在种子库中找到来源登记（记录素材/定版事实/审定文本三类之一），无来源不上架。
2. 以未种子问题走查各岗：回应全部落在第 3 项四形态内，零出戏表述、零新编事实。
3. 集页进度 0 与集满两档对照：故事话题的可见集合严格按第 2 项维度表变化，无越级可见。
4. 讲古双轨走查：大页围坐与小页私下场各跑一遍，个人轨记账与世界公告口径与多人规则稿一致。
5. 小未无任何对话入口与文字气泡。
