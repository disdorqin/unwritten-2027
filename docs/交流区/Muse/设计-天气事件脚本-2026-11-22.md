# 设计 · 天气事件脚本（2026-11-22，总控）

天气底盘归 ZB-20 服务端单一状态对象（雪量三档/积雪三档/风三态/雾三态＋晴夜标记，全线只读不另算，《设计-系统层细化》第二节为准本）。本件在其上立**四种整夜脚本**——脚本不是新状态，是既有状态的整夜顶格组合与全图staging：玩家不看任何面板，靠实景信号就知道「今晚是哪一晚」。每脚本六件套简式：触发条件／持续／全图可读信号／玩法后果／故事层含义（只到公开层）／收束。

**红线**：不新立伤害/死亡规则；地面永远和平（一切「风险」只记现象与玩法后果——慢、看不见、到不了，不落到人身上）；真相层不落字；天气判断只认实景信号，无 UI 条。

## 脚本一 · 大风夜

- **触发条件**：ZB-20 风三态入夜即顶格「大风」，且预报信号在黄昏先行——旗云先撕、风袋先满（见可读信号），玩家黄昏就能预判今晚的局。
- **持续**：整夜（入夜至晨钟），夜里只盛不衰（系统层口径：风态夜里多转盛）。
- **全图可读信号**：主峰旗云被撕成缕（全镇抬头可读的风速表，大风形态）；云海台与山顶站风袋绷满、绷绳声紧；52 户灯笼整列同向摆动、绳吱呀声成片；桩铃阵风过铃列自响；缆车缆索风鸣可闻。老镇、山口、云海台三处同读一个大风，不分域打架。
- **玩法后果**：**滑翔停飞**（等风点读秒永远不满，风口木牌「风不起，不起飞」今晚读作「风太过，也不起飞」——穿环双线与云海四环线整夜关闭）；**雪橇冲刺停**（冲刺段不可用，常速滑行照常——第十三声跑图今晚自动变步行局，路线自选不变）；**缆车照行**（总控裁定：大风不停缆，缆车只归夜里停；时刻牌「风起缓发」指车行节奏放缓读感，不停发）；**足印链散**（ZB-42 既有口径：大风散链，追踪玩法今晚收工、等下一场新雪起链）；挖矿声、敲击声被风声盖过，地下循声找人的听觉半径缩短（只记现象）。
- **故事层含义（公开层）**：镇民口径只有一句「山风大的夜里，山会说话」——桩铃与缆索的风鸣就是这句闲话的实景，不解释。
- **雪人（只记现象）**：大风夜后，晨起可见沿街雪人围巾、帽子多被吹歪向同一侧；雪人朝向与姿态的既有观察（第十三声夜齐朝锚点）与风无关、照旧另记，两本账不混。
- **收束**：晨钟前后风态回落常风；散掉的足印链不自动恢复，等新雪；当晚因停飞错过的穿环、跑图不补发（可错过口径，明晚再来）。

## 脚本二 · 晴夜观星

- **触发条件**：晴夜标记成立（雾三态＝晴空、雪量轻档）之夜。本脚本是**标记型脚本**，不占主脚本位（互斥规则见文末）。
- **持续**：整夜；其中过顶之星只在第十三声那一程（约当夜窗一分钟量级，与信标公式同源）。
- **全图可读信号**：星空密度顶格、银河斜贯（云海册卡七夜星带）；云面承星光成暗银面（反光是天光，非云自发光——发光云带待裁项不在本脚本内）；镇灯火在晴夜里显得更疏、更沉。
- **观星点列**：钟顶（登顶平台，全镇最近的一处）、云海台（台缘，夜星带主场）、绝顶（带缘最高点）、星空营地（B1 东北野地地面观星点，星野观赏用）。**过顶之星的既定见证点仍为绝顶/钟顶/云海台三处**（系统层三条件：晴夜标记＋第十三声夜＋观星点在位，三者齐才见星）——星空营地只赏星野，不新立为第四见证点。
- **玩法后果**：晴夜＋第十三声夜叠加的那一分钟，过顶之星自云海带上缓行过顶，绝顶与钟顶同刻可见；同分钟即**太空门开启分钟**（夜窗第一分钟，既定口径：双钥匙齐备者于星港坪基座前候位开门——仪式本体归宇宙线分册，本脚本只记天象与分钟同源，不新立规则）；第十三声跑图今晚锚点微光之外多一颗星作方位参照（光序、规则不变）；图鉴事件页「走得最慢的星」今晚可记（景物册条目既定）。
- **故事层含义（公开层）**：止于景物册条目——「只在第十三声那夜出来。它走完一程，天就快亮了。看它的人都说，它像是在等谁回话。」镇民闲话止此，不解释。
- **收束**：星过顶后晴夜仍是晴夜，星野观赏整夜有效；阴夜（晴夜标记不成立）只闻钟声不见星，账本照记，不算错过惩罚。

## 脚本三 · 暴雪封山夜

- **触发条件**：雪量顶格「重」＋积雪冲「深雪」＋能见度显著下降，三者入夜齐至；黄昏信号先行——云瀑散乱、山口方向雪幕压境、归家的人流比平日早。
- **持续**：整夜；雪势后半夜渐缓，晨钟时多已转中雪。
- **全图可读信号**：雪幕横过灯链、灯火只剩光晕（与雾夜的区别：雪是落的、幕是动的，脚步声被雪面吃掉）；旗云没入雪幕不可读，风袋覆雪垂重；坑口与山口的岗灯提前熄灭——那是今晚最要紧的信号（见下）。
- **玩法后果**：**夜窗提前开启**——山口/坑口守卫因暴雪提前归家（公开层的人事理由：雪大，守夜的岗守不住，人先撤），两处岗口入夜即无人值守，比平日晚一截的窗口今晚提前敞开；**盘山道**：新雪覆道、辙痕全埋，道绳与里程桩是仅剩的路标，步行速度按深雪口径放缓（系统层既有红线：深雪减速只在雪夜/仪式日成立，本脚本正是雪夜）；**雪橇线**：绝顶线旗门覆雪只剩杆顶铃可闻、穿云段门序不可读——今晚不是刷新成绩的夜（只记现象，不设禁用）；**缆车**：时刻牌「雪大停发」在此夜兑现——暴雪停缆（与大风夜照行正相反，两条口径各管一轴，不许混读）；第十三声跑图今晚锚点光被雪幕压暗，步行入光的判定不变、难度自涨。
- **故事层含义（公开层）**：镇民说「封山的雪，是山把门关上」——但今晚恰恰是山口与坑口无人的一夜，关与开同在一场雪里，镇民不说破，玩家自见。
- **收束**：晨钟雪停，守卫回岗，道绳以上的新雪留给次日第一班登山的人读；提前开启的夜窗不追溯、不补偿，白天拦阻规则照旧。

## 脚本四 · 雾夜

- **触发条件**：雾三态顶格「浓雾」（只管地面域——主峰域能见度归云海渲染层，两不重叠，雾夜里山上是另一番天）。
- **持续**：多在昼夜交界成、入夜最浓，后半夜渐薄，晨钟前后散尽（系统层口径：雾多在昼夜交界成）。
- **全图可读信号**：远景层次全压平，钟楼只剩轮廓、云海横带不可见；52 户灯笼与主街灯列被泡成一串光晕——**灯链是今晚唯一的地图**；火车汽笛、整点钟声、绞盘绷索声传得比平日远、比平日清（只记现象：雾夜声传远）。
- **玩法后果**：**导引兑现**——52 户灯笼路的玩法价值在此夜全额兑现：沿灯走必到有人处，离灯即无路（不迷路三件今晚只剩灯链与人声两件，地标件失效）；**听碰放大**——循声辨位成为主导航：听汽笛知环线、闻第十三声知夜窗、地下循敲击声找同伴的半径在地面同理放大；第十三声跑图今晚锚点微光只在近身时可辨，跑图变「听钟—循灯—摸光」的慢局（规则不变）；滑翔与雪橇冲刺不受雾管（雾只管地面域），但落点坪在雾里不可见，等风点自会劝退（只记现象）。
- **故事层含义（公开层）**：镇民说「雾夜里，镇子只剩一条街」——就是灯链那条街；雾散后镇子又「长回来」，无人解释雾里别的街去了哪。
- **收束**：雾散无痕，不留状态；今晚靠灯链走过的路，次日白天玩家会发现比记忆里短得多（只记现象）。

## 互斥与叠加规则

- **主脚本至多一**：大风夜／暴雪封山夜／雾夜三者互斥，同一晚至多其一。判定轴不同：大风管风轴、暴雪管雪轴、雾管地面能见度轴——三轴同顶格的夜不生成脚本，按雪轴优先落暴雪封山夜，余轴只作当晚现象记账（风大、雾浓照写进现象，不升格脚本）。
- **晴夜标记可叠加**：晴夜观星是标记型脚本，可叠加于无主脚本之夜，亦可与大风夜同晚（晴而大风：旗云撕、星仍明，过顶之星三条件不含风，照常成立）。晴夜标记与暴雪、浓雾天然互斥——雪量重档或雾浓档成立时晴夜标记自动不成立，不另立规则。
- **与第十三声的关系**：四脚本都不动信标事件——第十三声每夜照响、夜窗每夜照开，脚本只改「今晚的夜长什么样」；暴雪脚本的夜窗提前开启是人事位移（守卫提前归家），不是信标位移，漂移公式与账本一字不改。
- **除夕夜让位**：除夕夜走真实北京时间，仪式雪势曲线为覆写层、优先于日常天气（既有口径）——四脚本在除夕夜全部让位，不生成、不叠加。

## 事件频率口径（12 晚漂移循环，只给量级）

以 12 晚为一循环的期望量级（实现按 ZB-20 状态权重自然生成，不设保底、不设连发限制，量级只作验收对表）：

| 脚本 | 每循环量级 | 备注 |
|---|---|---|
| 大风夜 | 2–3 晚 | 四脚本中最常；停飞停冲刺的夜要够多，等风玩法才有「等」的意义 |
| 晴夜观星 | 3–4 晚（晴夜标记成立之夜） | 其中与第十三声分钟叠加的过顶之星每晚皆有窗口，见星率取决于玩家在不在观星点 |
| 雾夜 | 1–2 晚 | 灯链兑现夜，贵精不贵多 |
| 暴雪封山夜 | 0–1 晚 | 稀有夜：一循环里可以一次都没有；出现即是全镇记得住的一夜 |

无脚本的平常夜为每循环余量（约半数）——脚本是调味，不是常态；平常夜的晴、阴、常风、中雪照 ZB-20 日常权重走。

（本件为设计规格，施工归属：脚本状态与广播归 ZB-20/B 线，staging 信号件归各域既有宿主；派工随各线队列由总控另行下发。）
