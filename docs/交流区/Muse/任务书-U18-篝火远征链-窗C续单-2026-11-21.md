# 任务书 U-18 篝火远征链（窗 C 续单 · 队列尾预挂 · 六件套版）

- 来源：《设计-交互玩法八案-2026-11-21》案八（Thomas 2026-11-21 批准）。
- 格式：设计书六件套，参照总控 ZB-33 模板；批 4 入仓后对模板再校。
- 准本条款：玩法细则以《设计-交互玩法八案》原文为准本（随批入仓），
  领书后先对原文再开工，冲突处以原文为准。
- 立项标准自检：**玩家手上在忙什么——拾柴备料、在险地亲手垒起
  前进营地、守火添柴整备，再以营为支点往深层推进。**

## 一、落点
地下各层平整地面可建营（玩家自选点）；首批随 C 链各层场景落点，
营地遗迹（U-2）为链首固定营。

## 二、场景构成
营地件：火塘、坐位、备料堆、营地木牌；前人残烬点（先人远征痕迹，
与新营并置）；守炉同源件（勇士城炉火状态的营地侧镜像）。

## 三、玩法流程
拾柴备料 → 选点建营 → 火起（安全区＋回血生效）→ 添柴守火维持
火候 → 以营为支点下潜、回营整备 → 火弱/熄火则安全区失效、
残烬可复燃。营地多点串联成远征链；死一次掉半矿（U-13 口径），
每次下潜是玩家自己的风险决策。

## 四、交互规格
- 建营：耗料交互，落点须平整地面；建成即注册火点。
- 添柴/复燃：燃料随时间消耗，手添维持；熄火停回血、停安全区。
- 坐位整备：坐下回状态（与火圈回血同源判定，不叠第二套数值）。

## 五、系统结合
- **规则复用 U-13 已入干权威**：固定火查询 `fireAt`（`ab13e03`）、
  火圈拒刷怪（`5e26595`）、半径 8 m——营地火点注册进同一查询，
  不另造回血/安全判定。
- **火状态机共用**：营地火与勇士城守炉（U-16/U-4）共用一份火
  状态机（燃/弱/熄/添柴复燃），同一状态源两处消费。
- 存档/死亡口径从 U-13，不另立。
- 前言三栏：活人玩法＝建营守火远征；灵魂痕迹＝前人残烬与守炉
  一线；故事接口＝深层推进支点链，接 U-2 营地守位。

## 六、验收
快速构建三件＋四齐自查一行。实走：建营→圈内不刷怪→回血→
添柴续火→熄火失效，各一次。四齐文齐含营地木牌文字当场写定。
参照物：《风格打造规范》＋图册篝火暖光池＋U-2 营地遗迹。
