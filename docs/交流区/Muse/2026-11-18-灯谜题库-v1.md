# 灯谜题库 v1

- 日期：2026-11-18
- 性质：春灯工坊「灯谜墙」可直接施工的题库与交互细化，对应《灵感池-v1》#22、《全镇交互覆盖规划-v1》春灯工坊行。
- 题量：共 **60 条**——简单 30 / 中等 20 / 困难 10。
- 题材限定：冬日、新年、小镇生活、自然四类；谜底以 1–3 字为主（个别活动类为 3 字）。
- 内容纪律：全部为民俗风格原创/传统谜语，**不使用任何真实人物信息**，不影射真人。

---

## 1. 交互细化（施工口径）

- **触发点**：春灯工坊灯谜墙，每盏挂着的灯笼注册一个触发点，走近按 E（移动端点按）翻开谜面纸条。复用全镇统一交互框架（邻近提示 + E 键），不另做一套。
- **出题面板**：DOM 覆盖层（零 WebGL 绘制调用）。简单档默认「三选一」点选；中等、困难档为输入式（输入框 + 提交按钮）。
- **机会规则**：每题 **3 次机会**。
  - 第 1 次答错：纸条晃动动画 + 「再想想」文案；
  - 第 2 次答错：给出一条提示（谜面下方小字，口径为谜主乔麦的提示语气，提示文案随题库附带方向词即可，如「往吃的上想」）；
  - 第 3 次答错：该题今日锁定，灯笼保持暗，次日刷新后可再猜。
- **猜对反馈**：该灯笼由暗转亮（emissive 贴图变体切换，**不新增光源**）+ 一声轻响（声音包）；谜面纸条翻面露出谜底。
- **收集计入**：每猜对一题计入**护照扩展收集页**「灯谜」计数（累计猜对题次）；当日一组全对额外记一枚「今日全亮」印记（按日期累计天数）。
- **整墙彩蛋**：当日一组全部点亮后，工坊门口放一发小烟花（复用既有烟花对象池，不新建粒子系统）。
- **每日刷新**：
  - 每日一组 **6 题**：常组 = 简单 4 + 中等 2；周末/节日组 = 简单 3 + 中等 2 + 困难 1；**跨年夜（12-31）专场** = 一组 10 题且困难档全开。
  - 题组按本地日期做种子轮换抽取，60 题约两周轮完一遍，不重复连出同一题（近 3 日出过的题降权）。
  - 次日灯笼复位为暗（收集计数不清零，只按累计口径计）。
- **存档**：localStorage 键建议 `unwritten.riddles.v1`，结构 `{date, groupIds:[], solvedIds:[], attempts:{riddleId:次数}, totalSolved, fullLightDays:[]}`；护照扩展页读同一计数，不另存一份。
- **性能纪律**：面板与纸条全 DOM；灯笼复用工坊现有实例化批次，点亮只切 emissive 变体；本地视角 draws 增量 ≤+5（预期 ≈0）；离开工坊地块后零常驻成本。
- **多人预留**：猜对发事件 `{type:'riddle.solve', actor, target:'lantern-workshop.wall', payload:{riddleId}, t}`，单机先行。
