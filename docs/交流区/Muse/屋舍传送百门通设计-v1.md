# 屋舍传送「百门通」设计 v1（2026-11-18）

> Thomas 提出、定性为亮点：全镇 92 扇装饰屋门共用一个屋舍空间，那就让玩家在屋里**选门出去**——进任意门，出任意门，屋舍网络即传送网。本稿是第 8 轮 B13 批的施工依据；屋舍本体口径见《屋舍空间与火车烟花物理综合设计-v1》，本稿只写传送层。

## 1. 概念

- 名称：**百门通**。镇内说法「一屋通百门」——镇上的屋子本就是通的，从哪扇门进、从哪扇门出，玩家说了算。
- 定位：与火车互补的第二交通网。火车是观光环线（慢、看风景、共乘），百门通是点对点直达（快、私密、要先进屋）。两者不互相替代。
- 世界观落点：镇志卷四·风物志预置条目「百门通」（文本见 §7），NPC 纪守信/苏小满各有一句讲解（§7），让设定有出处、不是凭空的系统菜单。

## 2. 玩法流程

1. **进门**：任意一扇装饰屋门进入共享屋舍（现状不变：口袋坐标 E626/N498/+150 m，14×12 m 内景）。
2. **选门**：屋内出门侧设「百门册」册台，走近交互打开选门界面（DOM）。
3. **出门**：选定目标门 → 0.3 s 淡出（雪白）→ 落在目标门门前 0.9 m 处、面朝外 → 0.2 s 淡入。全程无加载屏（纯本地切换）。
4. **不选门**：直接推门出去 = 回进门的那扇门（既有 per-player 回程锚，口径不变）。百门册是第二种出门方式，不替代回程。

## 3. 选门界面（百门册）

- **结构**：顶部标题「百门册 · 一屋通百门」；中部按五区页签（中央 / 集市 / 纪念 / 湖畔 / 森林 + 扩展区并入所属区）；每扇门一行：门名 + 一句方位小注（如「钱满仓摊后」）。当前进门那扇门标「刚从这儿进」并置顶于所属区首行。
- **门名生成（机械口径，不许手编）**：门册数据由代码里的门表自动生成——区名取门所属区，门名取最近命名锚点（摊位/建筑/NPC 岗位），无锚点时用「第 N 门（区内序号）」。施工回执须附生成清单计数：五区合计 = 实测门数 92（R6-H4 口径），多一扇少一扇都不通过。
- **操作**：点选即出门，不设二次确认（选错成本只是再进一次门）；Esc/关闭 = 留在屋里。支持搜索框按门名/锚点过滤（92 行手翻太慢）。
- **本版不做**：地图视图（画布点选）留二期；本版列表 + 搜索足够，且零贴图成本。

## 4. 落点与兜底

- 标准落点：目标门门前沿外法线 0.9 m，地面高度取门前地形，朝向背离门面。
- 落点被占/不可站（他人正站在门口、临时物件）：依次试左偏 0.6 m、右偏 0.6 m；仍不行 → 回落进门那扇门，屏幕轻提示「那扇门前正堵着，先回来了」（文案照抄）。
- 出门瞬间玩家处于口袋外 150 m 落差的传送是本地坐标切换，既有碰撞/地形贴合逻辑在落点重新取样，不许出现坠落或嵌墙。

## 5. 多人与同步

- presence / 服务端**零改**：出门是本机坐标切换，既有同步自然跟上。口袋在所有人可见半径之外，出门等于在目标门"出现"——与今天进出屋的可见性行为一致。
- 位置跳变处理：客户端对 >20 m 的位置跳变直接吸附（snap），不做插值拖尾，避免人影从天上划过去。仅显示层处理，不动协议与同步频率。
- 双人同屋：各自选门互不影响；屋外的人只在目标门处看到人出现（验收 B13-A3）。

## 6. 平衡与边界

- **测试期全开**：92 扇门初始全部可选。数据侧留口：本机记录进过的门（`unwritten.houses.doors.v1`），仅记录、不设门槛；正式版是否改"到访登记制"由 Thomas 试玩后定，本版不预埋限制逻辑。
- 只送到门前：生肖藏点、密室、机关的到达与解法照旧，百门通不替代探索（验收时抽查蛇件桥洞：最近门落点仍需步行最后一段）。
- 不可达状态：乘车/乘火车/雪橇滑行中本就进不了屋（既有进门规则），故不存在"载具里开册"的情况，不新设状态机。
- 与仪式夜零点全员传送**互不复用**：那是服务端广播的仪式行为，本功能是本地日常交通；实现与文案都分开，不许混写。

## 7. 文案（逐字锁定，GPT 不得改写）

- 册台标题：「百门册 · 一屋通百门」
- 册首小注：「镇上的屋子都是通的。进一扇门，出百扇门。」
- 落点受阻提示：「那扇门前正堵着，先回来了。」
- 纪守信（镇志/屋舍讲解）：「这镇子的屋子阿，都是通的。从前门进，后门出，落脚在哪儿，你说了算——出门前在本册上挑好就行。」
- 苏小满（邮局/新手向）：「迷路了就随便推开一扇屋门，翻翻里面的百门册，想去哪条街，从那扇门出去就是啦。」
- 镇志卷四预置条目「百门通」：「未写镇屋舍相通，一室而百门。镇民串门不走街，走屋——推门进去，挑门出来，落脚已是另一条巷子。外乡人初至多不惯，住久了都说好。」

## 9. 验收（并入第 8 轮 B13）

- B13-A1：随机抽 6 扇门进、每扇各选 3 个不同目标门出，落点全对、不卡几何。
- B13-A2：不选门退出仍回原门（既有回程锚回归）。
- B13-A3：双人同屋各选不同门出互不影响；屋外第三人只在目标门见人出现，无天上拖尾。
- B13-A4：门册五区合计 = 92，与生成清单一致。
- B13-A5：落点受阻兜底实测（门前站人）→ 偏移落点或回原门 + 提示文案正确。
- B13-A6：淡出/淡入总时长 ≤0.6 s，全程无加载屏、无掉帧尖峰（单帧 ≤50 ms 口径）。
