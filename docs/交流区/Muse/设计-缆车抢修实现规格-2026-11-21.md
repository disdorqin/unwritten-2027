# 设计 · 缆车抢修实现规格（2026-11-21，总控）

八案案二的实现规格，一线（A 窗，ZA-36 后续）与二线（D 窗，主峰全本 §四.18）共用本规格，差异处分线标注。正典前提（Thomas 定版）：缆车初始停在山上、居民口径不让上山；**事故震醒只算动一站**（雪橇撞/雪墙塌/大雪球硬冲击震松老闸，车自跑一站），**玩家亲手修通三故障点才算全线通车**，通车后居民改口「一直都开」。首次登顶主峰只能步行、二线须自绝顶侧放车下行——本规格二线段服从此序。

## ①落点（三故障点，一线）
- **锈闸**：山下站制动闸。闸面锈必须真读得出锈（锈斑/剥落/锈水痕，风格规范明查项）。
- **脱轨正缆**：一线中段塔架（中山站与山下站之间），缆绳脱出轮槽一段。
- **配重挂塔**：中山站配重塔，配重块脱挂散落在塔基。
二线段三点同型：锈闸与脱轨在二线下站机房及沿线塔架（主峰全本 §三.13），配重在二线下站配重井。

## ②场景构成
每故障点：故障本体＋工具件＋修复痕迹位。工具不进背包格——现场工具墙/工具箱取用（老扳手、铁锤、撬棍造型件），用完放回（交互动画即可，不做物品系统）。修复后留永久痕迹：新销钉发亮、缆绳入槽段缠新麻绳、配重块归位后塔身刻一道新划线（「修过这里」的可读证据）。

## ③玩法流程
1. 触发：玩家先以硬冲击震醒一线（或夜里自行弄醒，归夜窗口径），车动一站、居民惊呼改口一半。
2. 巡线：玩家沿线步行/雪橇巡三故障点，任意顺序；每点故障状态在远处可读（闸锈色、缆垂落、配重散落）。
3. 逐点修复（见 ④），三点全清 → 全线通车事件：车按点自跑一整程试运行，钟声一记（与信标事件同源广播的小用），时刻牌上字（见 ⑤）。
4. 二线：玩家步行登顶后在绝顶侧放车下行至二线下站，三点修复在下行后自下站侧完成，通车后二线按点自跑。

## ④交互规格（三点各一个动手程序，单人可成）
- **敲锈**：对锈闸按 E 连敲（每敲一下锈屑粒子＋声响分三段由闷转脆），共 9 下后闸面露新铁、闸把可拉动；拉闸＝该点清。
- **正缆**：撬棍撬缆入槽——按住 E 蓄力、进度条以缆绳形变呈现（非 UI 条：缆被撬起的高度即进度），中途松手缆回落一半；入槽后摇把收紧三圈（E 连点）＝该点清。
- **挂配重**：塔基散落配重块 4 块，逐块抱起（肩扛位占用，星石同语法）挂回塔钩，顺序不限；4 块归位后塔身划线出现＝该点清。
三点均无失败惩罚、无计时；多人时可分点并行修。

## ⑤系统结合
- 时刻表：通车后缆车班次挂 ZB-17 服务器时钟（白天按点自跑、夜窗停运——缆车归活人作息，与火车空跑准点形成对照：一个太守规矩、一个不守）。
- 时刻牌：山下站/中山站/云海台三站牌面在通车事件时同时上字（牌面全文总控另发，本规格先立牌）。
- 旗标：`cableLine1Open` / `cableLine2Open` 服务器旗标，居民台词切换读旗标（NPC 口径归总控名册线）。
- 与 ZB-35：第十三声跑图不经缆车（跑图是步行线），无耦合。

## ⑥验收
第一人称：震醒动一站 → 步行巡线三点逐个修（每点修复痕迹可见）→ 通车试运行全程乘车一遍 → 时刻牌三站有字 → 夜窗复访缆车停运、车站灯熄。二线同序在主峰域复验。
