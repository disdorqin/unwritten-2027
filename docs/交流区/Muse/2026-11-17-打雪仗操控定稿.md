# 打雪仗操控定稿（Thomas 亲定框架，Muse 定稿细节）

日期：2026-11-17。并入《打雪仗完整设计 v1》，与积雪弹药/预测弧线/打击反馈衔接如下。

## 手机版：长按是唯一的雪球动作键
屏幕中心为准星，系统按准星指向分工，长按触发对应动作：
- **准星对着地面长按 = 收雪**：按住持续攒球（每约 0.8 s 完成一次攒球、按雪深档 +3/+4/+5，带进度环），攒满 10 发自动停；松手即停。收雪范围：准星落点距玩家 ≤2.5 m 且为户外雪面（与设计 v1 的可攒区域一致）。
- **准星对着人长按 = 发射雪球**：按下即进入瞄准——**预测弧线立即显示**，蓄力随按压时长增长（0.6 s 蓄满，初速 12→26 m/s）；**松手发射**。短按松手 = 轻抛，长按满蓄 = 全力。无独立发射键，长按这一下就是完整的投掷动作。
- **一般情形（准星没对着人也没对着可收雪的地面）长按**：按投掷处理（同上，松手朝准星方向发射）。
- 防误触：按下后手指滑动超过小半径视为拖动视角，取消本次蓄力不发球；按压不足 0.15 s 松手不发球（防走路点按误触）。
- 弹药为 0 时长按投掷：空挥 + 提示"长按地面收雪"，不进入蓄力。

## 电脑版
- **Ctrl+E = 收雪**：按住持续攒球（节律与产量同手机版），松开停；同样要求面向近处雪面。
- **鼠标瞄准 + 点击发射**：准星方向投掷；按下左键进入蓄力（预测弧线显示、0.6 s 蓄满），松开发射——快速点击即发一记轻抛，与手机版同一手感逻辑。

## 与既有设计的衔接
- 预测弧线：只在蓄力期间显示（两端一致），点线 ≤16 点，沿用设计 v1 的性能口径；
- 攒球/投掷互斥、投掷冷却 0.25 s、命中事件形状、NPC 参战规则均不变；
- 验收追加两项：① 手机端单指完成"收雪→瞄准→发射"全循环且不与视角拖动冲突；② 两端蓄力时长—初速曲线一致（0.6 s 蓄满），快速点击的轻抛可达 8 m 外目标。

本定稿替代设计 v1 中一切与操控有关的未定表述；其余条款以 v1 为准。
