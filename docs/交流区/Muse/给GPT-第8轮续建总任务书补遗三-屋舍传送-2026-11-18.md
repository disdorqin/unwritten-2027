# 给 GPT · 第 8 轮续建总任务书补遗三：屋舍传送「百门通」（2026-11-18）

> Thomas 亲自提的点子，他定性为亮点：既然所有普通建筑都通向同一个屋舍空间，那就**进任意一扇门、在里面选全图任意一扇门出去**——屋舍网络即传送网。本补遗并入第 8 轮，批次编号 B13；仅动屋舍模块，可提前与 B1 并行，不等其他批。

## 玩法口径

- **进门**：全图 92 扇装饰屋门任意一扇进（现状不变），进的是同一个共享屋舍空间。
- **出门**：屋内设「百门册」（门牌图）：按五区（森林/纪念/集市/湖畔/中央）列出全部 92 扇门，选一扇 → 从那扇门出去，落在门前可站点，面朝外。
- **测试期全开**：92 扇门一开始全部可选，不做"到访过才登记"的门槛（正式版是否加登记制，留待试玩反馈后由 Thomas 定，本批不预埋限制逻辑，只留数据口）。
- **回程锚仍保留**：不选门、直接回头出门 = 回到进门的那扇（既有 per-player 回程锚口径不变），百门册是新增的第二种出门方式。
- **异常兜底**：目标门前落点被占用/不可站时，回落到进门那扇门，并在册上标该门暂不可达；不许把人卡进几何里。

## 边界

- presence/服务端零改：出门在本机完成位置切换，既有同步自然跟上；屋内（口袋坐标）对外不可见的现状不变。
- 不影响生肖/探索：门只送到门前，藏点本身的到达与机关照旧。
- 仪式夜零点全员传送是另一套口径（服务端广播），与本功能互不干扰，不许互相复用实现。
- 成本：百门册是 DOM 界面，WebGL 增量 0 draws / 0 tris；屋内至多加一册实体书模型（并入既有批次，不新开 draw）。
