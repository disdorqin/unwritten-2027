# 任务书：戏台与社戏节目单（2026-11-19，分支窗口细节填充）

源稿：《戏台与社戏节目单-2026-11-19》。定位：广场戏台是小镇年节的仪式中心，本单定「演什么、什么时候演、玩家怎么参与」。戏台本体（庙会社戏形态、看台做坡、横批「有戏」）已定版，本单只管节目与运营口径。所有戏目自创，不借真实剧目与真实剧团名；叙述口径按传说层，不出真相层词汇。**排期门：今晚总装上线之后领单。** 本单即地面日常事件库「事件二·那出没人看懂的戏」的正本细化（事件二的形态以本单 §2.1 为准）。

## 细节填充

1. **节目单结构（一个游戏日三场，全锚整点）**：垫场（午后首个整点起，暖场——锣鼓点、折子戏片段、班主报戏，约 20 分钟，开场锣与整点钟声叠响、钟落锣起）/ 正场（傍晚整点起，全本戏连排一出常备戏目，约 50 分钟，幕间休息卡在半点，全镇广播只报幕不报时）/ 压轴（入夜整点起，名段选唱 + 谢幕仪式，约 25 分钟，收场锣毕正赶上下一个整点）。排期纪律：垫场可缺、**正场必演**（哪怕台下只有一位玩家也照演）、压轴看天（遇暴雪/大活动顺延或并入庆典排期，不硬演）。报戏仪式：每场开演前班主（或徒弟）在台口念报戏词（只报戏名与一句引子、不剧透，词文另审），同时全镇飘一条系统字幕（远处玩家也知道开锣了）。散场不散场：压轴谢幕后戏台灯不全灭，留一盏台口灯到深夜（夜里广场地标光）。
2. **常备戏目六出（正场六日轮值，一日一出）**：《雪夜借灯》（待客之道，与松林火塘「陌生人敲门」传说同源）/《渡头送别》（侨乡气质最浓，老人最爱）/《钟楼守夜人》（直接唱钟楼，孩子接锤一段是全镇合影名场面）/《白羊引路》（小未与金羊的戏台版）/《冰湖夺珠》（镜湖的戏，与冰上夺宝同名不同事、会心一笑即可、不做联动任务）/《天门谣》（古戏，见第 3 项——**不进六日轮换**）。除夕、元宵等大日子不进轮换，走第 5 项节庆专场。
3. **古戏《天门谣》定形态（只定形态，不定答案）**：三条形态——① 唱词是旧话：全本用老派带海人口音的旧话，年轻演员只会照本宣科唱音，**字幕给「音译字」不是释义**；② 情节缺头少尾：全本四折现存只有第二、第三折，第一折「从哪来」与第四折「回哪去」的本子丢了，台上从「已经在路上」唱起、到「还没到」收尾；③ 只有老班主会唱全：每折各有一段「过门谣」，全班只有老班主一人会且从不教全——教到最后一句总停下（那句唱词的内容不在本单、也不在戏台线任何下游稿里写明）。内容口径：现存两折唱一群「坐着大屋远行的人」在「天上的水」里迷路、落到「白地」过冬、领头的把一本「路书」收起来——**变形说法红线：不许出现船、舱、返航、燃料一类明示词**，一律用「大屋」「天上的水」「白地」「路书」（与裁定 C-17 的口径同向）。演出地位：只在除夕节庆专场，以及老班主「想唱」的不定期垫场加演（低频随机事件，触发时全镇字幕只写「班主今儿加唱一段老的」、不点戏名）。与群像班主卡的对接读法：班主「从不唱的那出」以本单为准细化为**从不唱全**——唱的是残本、缺的永远缺（ playbill 空格与此对应）。
4. **玩家与戏台的互动**：占座——看台坡面无固定座位、先到先坐，长凳是场景件、坐下为既有坐姿动作；占座不锁定、不排队（给朋友占座是社交行为本身，不做系统占位）。带吃食——集市吃食（烤红薯、棉花糖类）携入看台不设限制；谢幕时台口撒糖是压轴场固定小仪式（台前刷新少量可拾取的糖，**不计入经济闭环产出**，纯节庆气氛）。合影——正场幕间与谢幕后 3 分钟，台口两侧演员站定「谢幕位」供合影；《钟楼守夜人》孩子接锤一段定格 5 秒为官方推荐全镇大合影时机（钟楼稿与拍照点清单同步标注，与共创单合影点清单对接）。客串口径——**不常开**：只在年节专场（除夕、元宵）开放「客串一段」，每场限 1 名玩家，经班主岗位 NPC 既有交互报名，上台站位跟一段集体身段（随众水袖、随锣鼓走圆场），无唱词、无对戏、无成败判定，结束时班主赠一朵台口红绸花（纪念品，陈列系）；日常场次玩家一律不上台——台口有无形的「第四堵墙」，走位到台沿自动止步，NPC 只一句带过、不做惩罚（句文另审）。
5. **非演出时间的戏台**：清晨班主徒弟在台上练功（压腿、走圆场、吊嗓，氛围 NPC 动作循环，路过玩家驻足时徒弟停下行礼再继续）；上午至午后台后半开放（戏箱、行头架、脸谱墙在后台口可见范围陈列，只看不取；班主在后台补戏服、勾脸，是其日常对话发生地，台词走既有 NPC 语料规矩）；午后垫场前，NPC 孩子们在台下空地模仿戏（披床单当水袖，唱的永远是《雪夜借灯》，唱错词、抢戏、笑场是常态——与《天门谣》「唱不错一个字」形成对照；玩家可围观、可被邀请当观众鼓掌，既有表情动作即可，不设任务；此件即支线小品集正午戏台后台一品的落点）；入夜散场后留台口一盏灯；戏台侧幕后小锣风大时自己响一声——只做环境音、不解释、不挂钩任何线索（**钩子归钟楼第九声，戏台不抢**）。
6. **与故事线/庆典的接口**：除夕专场——傍晚垫场《白羊引路》→ 正场《钟楼守夜人》（唱到孩子接锤、正接全镇守岁）→ 零点全员传送广场看烟花（既有仪式）→ 烟花毕、守岁星升起前，戏台补一段压轴夜场：老班主亲自唱《天门谣》现存两折的「过门谣」选段。**守岁星过顶对位（硬同步点）**：过顶发生在零点烟花之后、夜空最静的一段——此时台上正唱到第二折过门谣，老班主唱到最后一句照例停住不唱，就在他停住的那一拍，守岁星划过戏台正上方；口径：纯调度对位，**不做任何系统提示、不给玩家解释**；台下 NPC 只有老班主一人在星过顶时抬头看了一眼、又低头收腔；任何下游稿不许给这一幕加字幕、加旁白、加任务标记。对接登记：对位以庆典线 J 单时间轴为骨，压轴夜场嵌入烟花后段，逐秒对位表随主窗线 J2 回执一并给出（在册待办）。元宵专场：正场《渡头送别》，压轴开放客串，灯会散挂与戏台灯笼同批点亮、戏台是元宵夜收束点。故事线接口纪律：戏台线对主线的全部贡献就是《天门谣》一处变形暗示 + 除夕对位一幕，不再新增戏台专属线索、残页或碑文；**残页分布以梗概为准，戏台不占页**（与裁定 C-02 同向）；班主到底真不懂还是懂而不说，本单不定、留主线稿。
