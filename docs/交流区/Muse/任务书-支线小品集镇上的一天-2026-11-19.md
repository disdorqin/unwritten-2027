# 任务书：支线小品集·镇上的一天（素材取用登记）（2026-11-19，分支窗口登记）

源稿：《支线小品集-镇上的一天-2026-11-19》。定位：**素材库登记书，不派施工。** 12 个地点生活切片是叙事味道素材，供下游填 NPC 环境细节时取味——不是任务、不是台词。本单只定取用规则；切片被哪份下游单取用、取了哪一品，在那份单的回执里登记。

## 取用规则（硬口径）

1. **取味不取词**：切片是氛围与动作的素材（站长给车头擦霜、守火人添柴手法、班主压箱底戏服），下游可把动作、物件、场景习惯落进 NPC 环境细节与陈设；**切片里的对话句不是台词定稿**——NPC 要开口说话，仍走台词规矩（讲古出自核准稿、真人问答只用已记录素材、无素材只留动作与招呼）。
2. **每品最多一处埋点、只到传说层**：12 品的埋点已在源稿逐品标明（旧货棚锁比门新 / 半本老戏 / 第九声玩笑话 / 松林断轨 / 无字旧绸 / 送不到的旧信 / 坑口不说话的老规矩 / 登记簿只进不出 等）；取用时埋点原样保留、不许加重、不许互相勾连成线，更不许补解释。第 2、6、11、12 品是纯生活、无埋点，取用时不许自行加埋点。
3. **主要取用方**（登记备查）：群像单 Q3 习惯动作集与 Q5 关系网环境钩子（站长/守钟人/班主/守火人诸品）、地表补完单的邻居下班状态与偶遇点（自家窗/集市/许愿树诸品）、事件库各单的场景底色（火塘/戏台/邮差诸品与事件八/二/三同源，取用时以事件单的节拍为准、小品只供底色）、运营日历的故事会补课碑牌短句（火塘品只供味道，碑牌文字另审）。
4. **与既有口径的界**：第 4 品守钟人对第九声的玩笑话（「钟老了」）与钩子一号的递进口径同向，但玩笑话的具体句子仍属台词范畴——落进游戏时按钩子单的槽位与另审规矩走，不直接搬小品原句。第 10 品登记簿「只进不出」是气氛口径，与主峰单的登记员登记簿（前任字迹、高空目击页）是两回事，不许混写。
