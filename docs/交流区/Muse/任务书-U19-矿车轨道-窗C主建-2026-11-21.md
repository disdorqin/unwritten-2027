# 任务书 U-19 矿车轨道（窗 C 主建 · 队列次位预挂）

- 准本条款：六件套逐字继承《设计-精选三案实现规格》原文（随批入仓）；
  本书为施工单转写，细则冲突处以规格原文为准。
- 立项标准自检：**玩家手上在忙什么——逐处修破损、驾车行车、弯前刹车、
  岔口扳道岔、营地端摇绞盘唤车。** 写得出，故立。

## 一、落点
矿洞一层主巷：营地端（U-2 营地遗迹）→ 矿门岔口，约 120 m。
既有轨道/矿车存量为本体（存量判定：留），本件做修复＋行车化，不重建巷体。

## 二、场景构成
轨道段（存量）、矿车、三处破损点（断轨/塌枕/卡轮，各一处）、
扳道岔（矿门岔口）、弯道刹车段、唤车绞盘（营地端）、两端装卸点。

## 三、玩法流程
修三处破损（逐处动手）→ 全线通车 → 上车行车：弯道提前减速、
岔口扳道岔选线 → 运矿抵端 → 下车装卸；车在对端时于营地端
摇唤车绞盘唤回。脱轨＝摔停待复位（不自动下车口径见交互规格）。

## 四、交互规格
- 修复：三处各自动手交互（敲正/换枕/清卡），修一处亮一段。
- 行车：加速/刹车两档手感；弯道超速脱轨；道岔扳动改行线。
- **车辆范式复用雪橇 ZB-26/ZB-16 口径**：近身交互上车、按键下车、
  碰撞/脱轨不自动下车、下车后随地再上车；行车声响接 U-13 声权威。
- 唤车：绞盘持续摇动唤车回营地端（与 U-17 泵房摇泵同族手势，不混淆：
  绞盘只在营地端、泵只在泵房）。

## 五、系统结合
- 运矿 **3 倍**：单车运量＝玩家背负 3 倍，接 U-8 挖矿产出；
  装卸走既有库存事务只读接口，不自造第二套库存。
- 怪线：U-14 遭遇不压轨道行车线（细则以规格原文为准）。
- 营地端接 U-2 营地遗迹与 U-18 前进营地（火点/整备同端）。
- 前言三栏：活人玩法＝修轨行车运矿；灵魂痕迹＝一代人矿车与
  班次痕迹（车身刻记）；故事接口＝深层运矿快线，接 U-15 各层开路节奏。

## 六、验收
快速构建三件＋四齐自查一行。实走一趟：修一处破损→通车→行车过弯
刹车→扳岔→运矿抵端→绞盘唤车，全程默认路径可达。
四齐：形齐（轨/车/岔/绞盘齐）/饰齐（锈真读得出、矿灯串有源）/
互齐（修/驾/扳/摇四碰真能碰）/文齐（班次刻记、岔口牌字当场写定）。
