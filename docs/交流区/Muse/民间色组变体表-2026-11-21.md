# 民间色组变体表（总控 2026-11-21 批准立表）

九色正板之外，三处早于色板锁的建筑各带一组民间色——本表一次登记、三处共用，此后修订单只核「是否越出登记变体」，不再逐处请批。

## 表头边界（写死）

1. **压饱和上限**：变体色一律压饱和；红只许哑红/锈红系，禁高饱和纯色（全镇高饱和仍只许火光橙、晶辉青两处正板例外）。
2. **四族内**：色相不出土（黄褐）/ 木（深褐）/ 锈红（红褐）/ 夜蓝（蓝灰）四族。
3. **表外新变体仍须请裁**：本表只登记下列三组；任何新建筑、新色组先走九色正板，越板须另行请裁入表。
4. **适用范围**：仅登记建筑本体与其年节道具；新建筑走正板。
