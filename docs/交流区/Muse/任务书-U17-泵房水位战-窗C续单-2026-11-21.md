# 任务书 U-17 泵房水位战（窗 C 续单 · 队列尾预挂 · 六件套版）

- 来源：《设计-交互玩法八案-2026-11-21》案四（Thomas 2026-11-21 批准）。
- 格式：设计书六件套（落点/场景构成/玩法流程/交互规格/系统结合/验收），
  参照总控 ZB-33 模板；批 4 入仓后对模板再校一次。
- 准本条款：玩法细则以《设计-交互玩法八案》原文为准本（随批入仓），
  领书后先对原文再开工，冲突处以原文为准。
- 立项标准自检：**玩家手上在忙什么——持续摇泵抽水、盯水位标尺、
  泵卡壳时停手抢修；多人时一人摇泵一人趁水落采矿/过路。**

## 一、落点
矿洞一段（−90，营地遗迹下游）与水晶洞（−140）之间：泵房一间＋
一段可淹通路。两层连接段，不占既有层内平面。

## 二、场景构成
泵房（手摇泵、水位标尺、值班日志册、配管与阀件）；可淹通路
（水位分档淹没/露出）；通路侧采矿点（水落窗口可采）；抢修件
（清堵口/敲击点/复位杆）。饰齐口径：密度成簇、泵房暖光有源、
反全白（锈/木/铁/水四族同框）。

## 三、玩法流程
进泵房读值班日志知当日档位 → 摇泵排水 → 水位落至档线、通路露出
→ 趁窗口过路/采矿 → 泵卡壳：停手抢修（清堵/敲击/复位）→ 水位
回涨前撤回或续摇保位。多人：一人保水位、一人作业，真协作；
单人可成（窗口节奏放宽）。

## 四、交互规格
- 摇泵：持续摇动才抽水，停摇回涨；费体力（读 U-13 体力侧，不改）。
- 卡壳：按用量/随机触发，抢修三动作解除；卡壳期水位只涨不落。
- 值班日志：可读，**全文当场写定、零占位**（文齐硬项）；兼作
  水位档位与怪线变化的玩家内提示源。
- 水位标尺：刻度字写定，水位实时可读。

## 五、系统结合
- 怪线：水位分档改怪物巡游线与出没点，接 U-14 遭遇宿主（只读引用）。
- 权威：光/声/体温读 U-13 已入干权威，不自造；数值照 G-09 细化表。
- 前言三栏：活人玩法＝摇泵开路抢修；灵魂痕迹＝值班日志先人班次、
  守泵之位、泵房灯位随水位明暗；故事接口＝矿洞↔水晶洞通路开关。

## 六、验收
快速构建三件＋四齐自查一行。实走：入泵房→读日志→摇泵→水落过
通路→卡壳抢修→窗口内采矿，各一次。参照物：《风格打造规范》＋
图册地下光池＋已建矿洞一层＋营地遗迹值班痕迹件。
