# 太空章设计：轨道舱与传送门（2026-11-19 18:48，Thomas 定调，主窗口成稿）

核心定调（Thomas）：**不造可驾驶的飞船**。门 = 传送门，人过门直达天上的飞船；只做飞船内部；航行靠动画与画面变化表达，不做实时飞行模拟。本稿为太空章立项时的设计准本，当前版本仍只立两道锁门。

## §1 天上那艘船是什么

迫降时飞船解体三段（真相稿 §1）中的**轨道段没有落下来**：它留在云层之上的轨道上，几十年缓慢衰减、掉碎片（天降事件的源头）。太空章里玩家到达的，就是这截轨道舱——它一直在头顶上，只是没人上得去。两道锁门（星港太空门、地宫核心舱门）都是船员时代留下的传送门，另一端都在轨道舱的气闸舱。

## §2 轨道舱内部（唯一要建的太空场景）

独立室内层集（与地下层同口径，进门只建本层），五舱：

1. **气闸舱**：两道传送门的到达点，墙上有全船状态灯（大半是红的，只有传送与维生是绿的——船还活着，但只活了一点点）；
2. **驾驶舱**：主舷窗正对星球弧面与云海，全游戏最贵的一扇窗；控制台可交互（调出航行日志残页 = 镇志飞船页的原件）；
3. **观景舱**：整面舷窗 + 星图桌，纯观景与拍照点；
4. **生活舱**：船员铺位、餐桌、一件私人物品（不写名字）——祖先住过的地方，安静，不闹鬼；
5. **传送室**：下传枢纽（§3）。

## §3 传送网（太空章的系统产出）

- 轨道舱是全图传送枢纽：传送室可下传到已激活的地面锚点——星港坪、陨石坑底、绝顶、广场（镇长处登记）——太空章解锁后，全图移动从「腿和缆车」升级为「门网」，老交通不废（风景党继续坐缆车）。
- 锚点须玩家亲身到访过才能激活（探索不跳过），与镇志残页进度互不阻塞。

## §4 航行靠动画，不靠模拟

- 船不由玩家驾驶。轨道舱有缓慢的轨道漂移：舷窗外景色随时间变化（云海流动、昼夜交界线扫过星球、偶尔一块碎片擦过窗口）。
- 剧情性「航行事件」做成过场动画：船体轻震、灯光转红、广播杂音、窗外目标星球放大——玩家是乘客与见证者，不是驾驶员。动画在场景内实现（窗外景层滚动 + 光影 + 音效），零飞行物理、零外部船体模型。
- 这一章的情感落点不是「开船」，是「回到祖先的船上，替他们看一眼家」——与镇志补完、镇长认账在同一条情感线上收束。

## §5 与当前版本的关系

- 当前版本：两道门可见不可开，轨道舱不存在于构建中（零成本）。
- 太空章立项顺序：轨道舱内景 → 传送网 → 漂移动画 → 航行事件过场。
