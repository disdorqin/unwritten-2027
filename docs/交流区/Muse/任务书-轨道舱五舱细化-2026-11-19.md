# 任务书：轨道舱五舱细化（2026-11-19，分支窗口登记）

源稿：《轨道舱五舱细化-2026-11-19》。定位：太空章内景的设定层细化稿，**存档级——本单只登记、不下施工单**。太空章立项前，游戏内只许两道锁门存在（星港太空门、地宫核心舱门），五舱不实装、不预建（裁定 C-01/C-20）。本单定五舱的空间、玩法与情感口径，供太空章立项时直接拆单；分级 C（太空章版本，V1.3 方向——解锁时点未定版，从正典总索引）。

总纲登记：未央号轨道段从未坠落，悬在云层之上缓慢衰减，是天降碎块的来源。它不是一艘能开的船——零飞行模拟、零船体外观模型。玩家在这里能做的只有三件事：看、读、通门。「航行」只是舷窗外的景色动画加脚本事件（船体震颤、灯转红、广播杂音、碎片掠窗）。情感落点只有一句：替祖先回船上，看一眼家。船名与船徽从飞船志定版（未央号；半月 + 下坠弧线），本单不复述。

## 五舱登记（立项拆单底稿）

1. **气闸舱**：五舱的门厅，也是全船唯一与地面相连的舱。两道传送门在舱内对位而设——一门朝星港坪方向（门框纹饰取镇志圆环，呼应 C-11：锁门门环用镇志圆环——**母题核对：本门环为镇志圆环、合法出场，本单已核**），一门朝地宫宝库方向（门框素面，只刻深度记号）。两门之间是状态灯墙：整面墙的指示灯大半是红的，只有两盏绿——「传送」与「维生」；舱顶低、管线裸露，地面有经年未扫的浮尘，脚印只有旧的、没有新的。玩家在此做的事：进出船的唯一通道；读状态灯墙（灯的红绿比例随太空章进度缓慢变化，是全船状态的唯一仪表）；在两道门之间做去向选择（回地面走哪道门，本身就是仪式）。本舱的「不对劲」一件（与纪念馆「只许一件」同规）：状态灯墙最下方有一盏灯，既不红也不绿、是灭的，灯下小牌只写「三号泊位」；全船再无第二处提及三号泊位；它意味着什么，**本单不定答案，只定位置与形态**，答案权在主窗口（与纪念馆石板同纪律：下游不许赋予意义）。与镇子的呼应登记：灯墙的红绿比例，与镇长铜匣三件的保管状态互文（船还活着，只是勉强；镇子也一样，是船员在地上勉强活成的家）。
2. **驾驶舱**：全船最高处。正面整幅主舷窗对着星球弧面，弧面之下云海如盖，镇子只是一小片暖黄的灯火，嵌在雪原与山影之间。控制台呈弧形环抱船长位，台面按键大半漆面磨损、少数被摩挲得发亮（发亮的那几个，正是当年船长反复按过的）；舱内无座椅杂物，只有船长位一把，位前小几上倒扣着一只杯子。玩家在此做的事：调阅航行日志原件——日志不是菜单，是仪式（须站在船长位前，双手位（交互点左右各一）同时确认，控制台才逐页亮起船页原件）；读过的页同步点亮镇志对应残页的「原件已见」标记（只标记，不改残页收集口径——与故事线章回书、投放总表对接登记）；玩家在此还能触发舷窗景色动画（星球弧面缓转、碎片偶掠窗外）。本舱的小细节：日志最后一页只有半页，后半页的位置是空的——不是撕的，是从未写下（船长抽走的是船页，这一页却是他自己没能写完的航行记录）；玩家读到此处，控制台自动熄一盏灯。与镇子的呼应：镇志的缺页在此有了原件；镇长讲古里含糊带过的年份，在日志里是精确的日期（传说与真相之间，只隔着这面舷窗）。**原件文本属真相层，全文过主窗口审的关口在本舱同样适用，立项时文本位先留空。**
3. **观景舱**：全船最空的舱，没有设备，只有一整面侧舷窗和窗前一道长凳。窗框比驾驶舱的更旧，玻璃上有细密的划痕（几代人趴在窗上看地面留下的）；舱壁上有一排身高刻度线，从高到低，最矮的一道只到成人腰际（船员的孩子曾在这里量身高）。玩家在此做的事：看——从这里俯瞰，镇子的灯火、镜湖的冰面反光、前山与主峰的轮廓尽收眼底；除夕守岁夜在此看地面，烟花在脚下开，守岁星（轨道舱自身）过顶的传说在此闭环（镇民仰望的星，就是玩家脚下的船——与庆典线 J 单对接登记）；观景舱设全船唯一的「静坐」交互：坐下后不给任何奖励，只让景色动画完整放完一轮。本舱的小细节：长凳一端放着一副望远镜，镜筒上缠着褪色的红绳（和镇上许愿树的愿牌红绳是同一种结法；谁缠的，不定答案）。与镇子的呼应：镇民在地面守岁、望星许愿；船员当年在这里望地、望家（同一道目光，两个方向，隔了几十年）。
4. **生活舱**：船员铺位沿舱壁两列排开，铺位是体素块垒成的窄床，被褥叠得整齐，唯有一张铺的被褥是掀开的（像主人只是起夜未归）；舱中有小桌、储物格、墙上一排挂钩，挂钩空着大半；所有生活痕迹都是体素口径（方枕、方杯、方柜，不用贴图细节）。玩家在此做的事：走、看、**不许拿**——生活舱是全船唯一没有功能交互的舱（不设拾取、不设机关），玩家只能逐铺看过去；铺头小格里各有一件私人物品（书、水杯、折好的衣物），其中一件不写名、不给说明、不进图鉴。本舱的小细节：那件不写名的私人物品，是一只小小的、手工缝的布羊（针脚粗，羊角用金线盘了一圈多——和镇上的小未、和金羊的式样分明是一家人）；**本单只定其形态与位置（生活舱第三铺铺头格），来历不定答案**；布羊是船员私人物品（遗物级陈设），不是镇内物件，不受镇内母题配额约束，但下游同样不许给它加注、命名或编入收集（与地宫手痕同纪律）。与镇子的呼应：镇子是船员在地面重建的生活舱（铺位对着老镇 52 户，储物格对着集市摊位，连被褥掀开的那张铺，都像老镇某户人家出门未归的床）。
5. **传送室**：全船最亮的舱，也是太空章的系统产出所在。舱心一座环形传送台，台周五格锚点位：轨道舱自身为枢纽常亮，其余四格对应下行锚点——**星港、坑底、绝顶、广场**；锚点格的亮法不同：亲身到访过的锚点是暖白光，未到访的是暗格、只显示轮廓。玩家在此做的事：开通与使用传送网——规则照定版：锚点必须亲身到访过才能点亮，不许远程解锁（与衔接书 L 单红线一致）；在传送室可直达任一已亮锚点，从锚点回船须经当地传送门回气闸再至传送室（单向枢纽：去程直达、回程绕气闸，让玩家每次回船都再看一眼状态灯墙）；传送不收费、不设冷却（它是太空章的毕业礼，不是日常交通的替代品——老交通不废除，火车、缆车、盘山道照旧）。本舱的小细节：四格锚点全亮的那一刻，传送台中央升起一幅全图光点图（镇子、坑底、双峰、广场连成一线，形状恰好像一把钥匙——也像未央号船徽里那条下坠的弧线，终于落了地）。与镇子的呼应：传送网把天上、地表、地下第一次真正缝成一个世界；锚点里有广场（船员的船，最终通向的是镇子的中心）。

## 参观动线与纪律（立项时生效）

第一次登船流线：锁门开启 → 气闸（看灯墙，先知船况）→ 生活舱（先见人，再见船）→ 驾驶舱（读日志，真相在此交割）→ 观景舱（静坐，看地面灯火）→ 传送室（点亮第一格锚点，毕业）→ 回气闸出门。情感节拍：进门是敬畏（红灯满墙，船在勉强撑着）；生活舱转成亲近（被褥、布羊，这是人住过的地方）；驾驶舱是沉重（日志最后一页的空白）；观景舱放空（什么都不做，只看）；传送室收束为温暖（网通了，天上地下是一家了）。全程不设战斗、不设谜题门槛，第一次登船只许走这一条线，走完才开放自由参观。**当前版本纪律（重申）：五舱不实装、不预建；本单不产生任何施工单号；任何下游单不得以本单为据提前施工舱内陈设；两道锁门的当前呈现从地宫书 DG4 与前山书 QS 单（星港门）的既有口径。**
