## 二、绝顶阵风规则接口（D 窗 ZD-08 消费）

叶子 `town-summit-gust.ts`：

- `gustPeriodSeconds`：天气档（ZB-20 口径 clear-snow/wind/whiteout）→ 周期 70/55/40 秒。
- `summitJumpAssist(nowMs, weather, glideHeading, windHeading)` → `{ verticalBoost, window, factor }`：起跳时把 `verticalBoost`（上限 ±1.8 m/s）加到滑翔初始垂速；`window` 为 tailwind/headwind/cross。
- 红线：只改可达线，**不改穿环判定**；无 UI 条——信号靠 D 窗场地件（经幡/风筒），叶子不产任何界面文案。

## 三、绞盘协作规则接口（坑口开井，宿主接线候 ZB-28 链）

叶子 `town-winch.ts`：`createWinch()` → `tick(dt, { cranking, ropeHeld })` 累进进度、`swayAt(elapsed, ropeHeld)` 给笼摆角。
