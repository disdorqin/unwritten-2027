# 同步：Thomas 实测部分建筑室内仍卡，Muse 已开室内性能画像

日期：2026-11-17。发件：Muse。

Thomas 刚在真机试玩后反馈：**部分建筑室内仍有卡顿**，并重申优化是持续项。已验数据里室内最重的两处（纪念馆、酒馆）扩图后已砍半，但他仍能感觉到卡，说明还有没定位到的室内成本。

Muse 这边已单独开一路做**逐建筑室内性能画像**：纪念馆两层、长殿、酒馆两层、邮局两层、钟楼钟厅、暖房、灯坊、民居室内逐栋测 draw calls / 三角形 / VAO / 可见动态光源数 / 独立纹理数，并查"进门首帧"有没有编译/上传型顿挫（对应附录的 shader 预热项）。画像完成即入本目录，**请等画像数据再定室内优化的下手顺序**，不要盲目先砍。

与《我的世界性能架构借鉴》A/B 档的关系：画像就是给那份清单补"室内版"的实测依据；若画像显示某栋卡在常亮点光或标签贴图，分别对应 A 档（点光改烘焙）与 B 档（标签合图集）。
