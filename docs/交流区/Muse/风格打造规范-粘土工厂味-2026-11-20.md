# 风格打造规范 · 粘土工厂味（2026-11-20，总控）

目标味源：B 站 UP主粘土工厂《地牢酒馆》AI 短片——复古低多边形 3D + 像素颗粒贴图 + 土色压暗 + 火光池。只借画风不借设定（怪物仍敌对）。全线施工照此三件套取齐，风格一致靠规范不靠各窗审美。

## 一、色板（全局唯一，取色只许表内）
石灰 #8a8378 / 土黄 #a98a56 / 深褐 #5d4630 / 墨绿 #44503c / 夜蓝 #2c3648 / 雪白 #e8ecf0（压灰一档，不用纯白）/ 火光橙 #e08a3c / 晶辉青 #7fd4c8 / 锈红 #8a4a34。饱和度整体压低；高饱和只许出现在火光与晶辉两处光源色上。

## 二、贴图规范
- 低分辨率像素贴图（16/32 级）拉伸上大面，采样必须最近邻（NearestFilter），禁平滑——颗粒感是命。
- 材质靠贴图画：木纹包浆、石材裂纹、锈斑/剥落/锈水痕都画进贴图，不靠模型堆细节。
- 特写级物件单独精做贴图：缆车老闸的锈、钟腔船徽铸纹、星石环、太空门环。

## 三、光照规范（这个味的灵魂）
- 暗场打底：环境光压到很低（夜/地下近黑），地面白天也压一档土色。
- 暖色光池：一池一池的点光（火把/矿灯/炭盆/炉火）照亮局部，光池外近黑；光强带微抖（火焰感）。
- 冷光池对位：冰晶宫与水晶洞用晶辉青自发光，越深越盛（深度梯度）。
- 空气：常驻薄雾 + 光池内浮尘粒子；地面雪雾、地下尘雾同理。

## 四、造型规范
- 低多边形大块面，轮廓优先；道具比例略夸张（大一号、可读性第一）。
- 怪物轮廓鲜明：每种怪一个剪影特征，远看认得出（图鉴 10 种照此出图）。

## 五、尺寸与数值锚（总控定锚，分区细化）
- 地下平面：矿洞一段约 120×80 m（层高 6–9 m）/ 水晶洞约 100×70 m / 勇士城约 160×120 m / 地宫约 80×60 m。
- 玩家血量 100；怪伤按种 8–20；普通怪 3–5 记雪球或 2–3 记镐倒；守库傀儡血厚、攻高，但红线不变：不满血一击秒杀玩家。
- 地面场景尺寸照场景总表与既有实测，不另起炉灶。

## 六、执行
生图批（窗 C 地下、窗 D 轨道舱）按本规范出图，图审过即锁该景建模；各窗施工交付时自报：取色是否表内、贴图是否最近邻、光池是否达标——三项写进回执。
