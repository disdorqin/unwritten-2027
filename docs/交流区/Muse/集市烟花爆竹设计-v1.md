# 集市烟花爆竹设计 v1（2026-11-18）

> Thomas 提议并点名要做：在集市买（领）烟花爆竹，玩家自己放、全镇看得见。本稿为第 8 轮 B14 批施工依据。烟花大秀是镇里的，爆竹是玩家自己的——两条线分开：大秀走种子确定性系统，本稿走雪球同款事件层。

## 1. 摊位与货品

- **爆竹摊**：集市新增一摊，挂在钱满仓年货摊旁（兼营口径，不新设 NPC），红纸招牌「爆竹声中一岁除」。摊位几何并入 B9 集市部分施工，幌子文案见 §6。
- **三样货**：
  | 货品 | 玩法 | 时长/效果 |
  |---|---|---|
  | 呲花棒 | 手持挥舞，金色火花拖尾，跟着人走 | 约 20 s 自灭 |
  | 窜天猴 | 对空放，窜上约 25 m 后小爆一朵（单色随机） | 一次性 |
  | 挂鞭 | 放地上，2 s 引线后噼啪连响约 3 s，红纸屑落地 | 一次性 |
- **拿货口径（测试期）**：镇上还没有钱（雪花币未定案），测试期**免费领**，每人随身上限合计 10 件，放完回摊再领。数据侧留价格字段口，正式经济定案后只改数字不改结构。

## 2. 燃放规则

- **地点**：仅限露天——广场、街道、湖冰面、桥上、温泉外场都可以；**禁放区**：屋舍内、酒馆内、纪念堂内、温泉池中、火车上与车厢内、宫殿密室内。禁区内点火直接不响应并轻提示「这儿放不开，出去放」（文案照抄）。
- **操作**：背包小栏选货 → 点按使用。呲花棒点燃后自动持握（占用手部姿态，扔雪球前自动收起）；窜天猴朝视角方向略上扬发射；挂鞭放在身前 1.2 m 地面。
- **安全距离只是演出**：爆竹对人无任何伤害/击退（全镇无伤害红线），近处的人只会看到纸屑与听到响。

## 3. 联机与性能

- 走 **P2b 事件层**（与雪球同路）：发起人本地点火 → 服务端转发 → 附近客户端同帧复现（位置/种类/种子三要素，粒子本地生成，口径与烟花种子法一致的小型化）。
- 限流：每人发射间隔 ≥2 s；单客户端同时可见的个人爆竹效果 ≤8 个（近者优先，远的只闻声）；呲花棒火花粒子并入既有粒子池。
- 成本：draws +0（复用烟花粒子系统与合批），单朵个人爆 ≤ 大秀单发的 1/6 粒子量；服务端只转发事件，零状态。
- 声音：爆响/噼啪走既有音频总线，音量随距离衰减；BGM 仪式档期间个人爆竹声自动压低（不抢大秀）。

## 4. 与既有系统的关系

- 烟花台/种子大秀：独立，互不影响；仪式主段期间个人燃放不禁（年味就是要乱中有序），但限流收紧一档。
- 皮肤「烟花款」解锁口径不变（跨年夜在场或测试烟花全程），个人燃放不解锁。
- 镇志钩子：玩家首次燃放记一条本机卷五小记「第一次放炮」（本地事件口径，随 B7 数据源）。

## 5. 验收（B14）

- B14-A1：三货各领各放一轮：呲花棒拖尾跟人、窜天猴高度与小爆、挂鞭引线与纸屑均正确。
- B14-A2：双客户端互见互闻（含距离衰减），第三人在禁区看不到区内燃放（因为根本放不了）。
- B14-A3：禁区逐个实测（屋舍/酒馆/纪念堂/温泉/车厢）全部拒放且提示正确。
- B14-A4：10 人同时放挂鞭压测：帧率与出站带宽在既有红线内（单帧 ≤50 ms、350 KB/s 降级线不触发）。

## 6. 文案（逐字锁定）

- 摊招牌：「爆竹声中一岁除」
- 钱满仓领货句：「拿去放，响了算我的。过年嘛，这摊不收钱——放完了回来再拿，别一回抱走一筐。」
- 钱满仓提醒句：「离人远点儿，离柴火垛远点儿。响动是喜气，惊着人就不是了。」
- 禁区提示：「这儿放不开，出去放。」
- 背包空了的提示：「兜里空了，回集市爆竹摊再领。」
