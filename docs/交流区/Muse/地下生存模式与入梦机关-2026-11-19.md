# 地下生存模式与入梦机关（2026-11-19 18:40，Thomas 提案，主窗口成稿）

本稿**推翻**《地下层设计定稿》§4「怪不伤人、无血条」——新口径：地面和平、地下生存（Thomas 18:34 定版原则：下午讨论出的新东西可以盖旧）。地面规则一字不变。

## §1 双模式

- **和平模式（地面全域，含前山/主峰山域）**：无血条、只摔不伤，维持现行全部口径。
- **生存模式（地下全域）**：血条开启。怪物会攻击，伤害来源只有两类：怪物攻击 + 深渊坠落（普通落差仍只摔不伤）。回地面自动切回和平，血条隐藏、状态清零。
- 回血：地下各层的篝火/营地点（矿工营地、勇士城广场、宝库前厅）站定回血；回地面即满。不设血药、不设饥饿。

## §2 入梦机关（地下入口的仪式）

- 陨石坑底的井口原本**被遮盖**：盖板 + 碎石 + 陨石残块压着，封锁时代盖的。不知情的人只看到一堆陨石和碎石。
- **机关**：坑底绞盘（在断裂吊臂基座旁）转动 → 盖板滑开 → 露出黑井。第一次触发者直接坠入（落进井底深水潭，不扣血）——这一下就是「入梦」。
- 机关开启后常驻：吊笼可用，后来者正常下井（仍是入梦，模式切换点 = 过井口深度线）。
- 叙事包装只到机制层：地下是镇子的「梦境层」，死 = 醒。不写剧情文案、不设 NPC 解说。

## §3 死亡与重生（醒梦）

- 血空先**倒地 10 秒**：队友拍一下即半血唤醒（多人合作点）；无人救或单人 → **在床上醒来**。
- 重生点二选一：默认中心广场；玩家在自家屋内床上睡过一次即绑床，之后醒在自家床边（每家虚拟空间的床就是为此）。首次下井前，井口绞盘旁立牌提示先绑床（通用短词）。
- 惩罚从轻（朋友局口径）：工具不丢；当次梦境背包的矿物**掉一半**（留在死亡点，可再下去捡回），另一半算「从梦里带回来了」。
- 已合成/已领取的成果（助推器、雪翼、护照章、图鉴）永不回滚。
