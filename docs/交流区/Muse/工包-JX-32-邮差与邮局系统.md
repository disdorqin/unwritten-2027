# 工包 JX-32 · 邮差与邮局系统

- 分区：分区一（地表）。来源：《任务书-邮差与邮局系统》（批 J，9280e73）。拆包：分区窗口一转包批一（2026-11-20）。
- 依赖：JX-35 镇公所（邮局设在镇公所偏房、与镇长办公处同院、侧门独开；院落布局以 JX-35 为准，JX-35 未落成前本包只做邮差时段与信件层、空间件随 JX-35 合流）。跑腿件走既有 `town-mail-store`（12 个跑腿任务），本包不改其数据结构、只在其上加「信件」一层。
- 范围：邮局陈设定式——临街投递窗（窗内分拣格架、按街巷分格）、院内全镇唯一绿色立式信箱、墙上手绘「镇外线路图」（只画出山口一条线、另一端留白）。邮差一日：清晨开投递窗收昨夜投箱件并就地分拣（窗台摆当日「可寄出」牌）/ 午间镇内跑腿段（12 跑腿任务在此段派发与送达，邮差为活体入口）/ 黄昏一趟（当日玩家信件与镇外到达件统一送出，全镇每日唯一的「信到了」时刻）/ 入夜关窗、信箱落锁（通信隔夜）。玩家寄信与镇外来信流程按源稿；作息对接以本包时段表细化作息单邮差行（三趟=午间跑腿段+黄昏一趟+次晨收拣）。
- 红线：信件一律只写体例与结构，**不编造真实人物与真实信件内容**；源稿 §4 两件「建议接口」为建议级、未入正典，本包只登记待回执、不落单。
- 验收：邮差一日四段实走对版（与 JX-19 邮差岗登记一致）；寄信→黄昏送出→收信全链双端验；跑腿 12 件派发/送达回归（数据结构零改动证明）。
- 常驻：永不停机+最高并发；回执带「区块自洽」行。
