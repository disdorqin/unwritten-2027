# 设计 · 交互玩法八案（总控 2026-11-21，Thomas 同日批准）

立书背景：首批十案被 Thomas 毙——「不够有意思、不够交互性」（全是看/听/收，动手含量太低）。本八案全部从动词出发，建在现有系统上（雪橇物理/雪墙/体温/夜窗信标/滑翔/挖矿白名单/地下生存）。**常驻立项标准（Thomas 批准）：说不清玩家手上在忙什么的点子，不许进设计书。** 通用红线：单人可成、多人不锁、故事暗线不设箭头、地面永远和平。

## 一、环镇雪橇大奖赛（窗 B 系统，窗 A 赛道装扮）
- 玩法：全图检查点计时赛。赛道串山裙、坑沿隆起环外坡、镜湖冰面、古松林间道回广场；检查点为光门，漏门不计圈。
- 系统接点：雪橇 ZB-16 物理原样；个人最佳成绩存服务器，生成「幽灵车」影子陪跑（只自己可见）；多人同场为真车同跑，碰撞按现行雪橇规则。
- 奖励：成绩榜（复用雪仗榜机制）＋图鉴条目；除夕夜设正赛场次（不强制，自由报名）。

## 二、缆车抢修（窗 A 主建，线一）
- 与正典的衔接：事故震醒（Thomas 定案）只让车能动一站——震松的是闸，线路还有三处坏着。**玩家亲手修通全线**才是线一的完整开启。
- 三个故障点：①山下站锈闸——敲锈（节奏敲击，锈层逐块掉，须读得出锈，风格明查项）②半山脱轨缆段——把缆推回轮槽（持续推+对位）③中山站配重塔——搬配重块挂塔（负重移动，雪橇可运）。
- 每修一处，车多跑一段并当场可见（车从头顶过去）；全线通后时刻表空牌当夜被写上班次（甲4 设计联动）。单人可成，负重段允许雪橇代运。

## 三、雪堡攻防战（窗 B 规则，系统全现成）
- 玩法：两队自选场地（镜湖/广场/野地不限），限时筑堡期（雪墙系统自由堆）→攻防期：夺对方铃（抱铃转向惩罚同冰上夺宝），铃进自家圈得分；雪橇撞墙分档原样生效。
- 系统接点：雪团采集/堆墙/撞毁分档/夺宝规则全复用，本案只加队、圈、计时、计分与回合状态。
- 单人模式：NPC 雪人队守堡（雪人行为层 ZB-29 的延伸用法），一人也能开局。

## 四、泵房水位战（窗 C 主建，窗 B 协系统）
- 场景：矿洞—水晶洞之间设一代人抽水泵房，泵体、摇柄、压力表、水位标尺全可读。
- 玩法：摇泵降压抽水（持续操作费体力，体温/体力双耗）；水位实时改水晶洞通路与怪的巡逻线；泵会卡壳（异物），要拆盖敲出（挖矿式逐下敲）；水位几天内自然渗回。
- 协作：单人可摇可挖（慢），多人一人抽水一人采矿是效率解——协作是加速，不是门槛。
- 故事钩：泵房值班日志最后一页字迹未干（公开层，不解释）；泵是谁在维护，NPC 一律绕开。

## 五、第十三声跑图（窗 B，骑 ZB-17 信标）
- 玩法：夜窗内第十三声响起后，全镇转场锚点按漂移公式决定的顺序依次微亮，玩家跑图逐个触亮；顺序对则下一盏亮，错则已亮的灭一盏（不清空）；天亮晨钟前全亮=当夜达成。
- 系统接点：信标事件单一时刻源（ZB-17）；锚点=星港/坑底/绝顶/广场四处既有锚＋钟楼，共五盏。
- 产出：达成夜全镇广播一句（魂镇长的声音，只有戴图鉴「听全三步」者能懂指代）；个人达成次数入图鉴。单人可成（路线按单人脚程标定），多人可分头但触亮须同一人连贯——防代跑。

## 六、滑翔穿环（窗 D 主建，窗 B 协计分）
- 玩法：自云海台（及绝顶）起跳滑翔，沿山坡布光环，穿环计分、擦环半分、漏环断连击；落点靶心精度另计。6:1 滑翔比原样。
- 变量：山风由 ZB-20 天气系统当日决定，环位每日随风微调（服务器同源），逆风日环线更低更难。
- 安全：落雪坡缓冲，失败=陷雪堆+体温代价（爬树同口径），不死。

## 七、冰雕敲制（窗 B 机制，窗 A 冰雕岛场景）
- 玩法：冰雕岛备冰坯，玩家持镐逐下敲（挖矿白名单第四类：冰坯），敲击落点决定成形——做减法雕刻；有「凿痕」留存与崩裂风险（连敲同点过深会裂，裂了换坯）。
- 展示与评选：成品立岛上署名，全镇玩家可投一票（递东西系统变体：投一朵雪花标）；除夕夜展出，前三名入纪念馆未写之页旁的荣誉角（实景）。
- 单人可成；手残保底：工坊老师傅 NPC 可「修坯」一次（救回崩裂边缘）。

## 八、篝火远征链（窗 C 主建，扩 U-12/U-13）
- 玩法：地下篝火由固定点改为**可建前进营地**：玩家携柴与火种，在已探层段自选点建营（火光圈=安全区，怪不入圈）；营地存续烧柴，全服共享状态。
- 决策层：下潜深度由营地链长度决定；死亡掉半矿原规则下，营地是风险对冲——建营材料与采矿收益的取舍由玩家自排。
- 系统接点：U-13 生存（血/温/光/声）原样；营地火光接入「光」系统；勇士城守炉（炉火全城共享）与营地同为火状态机，一处代码两处用。
