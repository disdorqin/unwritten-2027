# 工包 JX-36 · 引导与教学

- 分区：分区一（地表/教学层）。来源：《任务书-引导与教学设计》（批 L，dc5e8e7）。拆包：分区窗口一转包批一（2026-11-20）。
- 依赖：页面层引导与 JX-18 入口技术件衔接（JX-18 已验候选为准）；分工——动线归 JX-27（管去哪），本包管「每个系统第一次遇见时怎么学会」；逐系统第一次接触场合随各系统包落位分批接入。
- 范围：教学总原则三条落地为验收总纲——①先给玩具、再给规则（第一次接触先无后果玩到核心动作的爽点片段，规则在玩过之后以一句话出现；先弹规则页再给操作权的教学不许）；②学会不靠提示框、靠世界给反馈（判定信号来自世界本身：雪球命中脆响与雪沫、坐对车按钟开走、攀爬抓对点手扣住；提示只在卡住时指方向，不宣布学会）；③兜底永远在场且不丢人（走路能到任何地方、错过车下一班按钟就来、找不到入口有岗位牌与留言板指路；兜底是日常、不是失败通道）。逐系统第一次接触设计表按源稿全量落地（九系统：场合/30 秒内学会的动作/学会的信号/学不会的兜底逐行实现）。第 4 项页面层引导（微信/QQ 内置浏览器）为开镇前先落件，与 JX-18 同口径。
- 铁律：不许强制新手教程关卡、不许长文本说明书、不许因为不会而受罚；老带新是主要教学通道（多人规则稿口径）。
- 验收：九系统逐行实测（新账号首遇全程录屏回执：30 秒内核心动作达成率、学会信号触发、兜底路径可达）；页面层引导在微信/QQ 模拟与 JX-18 恢复路径同帧核。
- 常驻：永不停机+最高并发；回执带「区块自洽」行。
