# 工包 JX-30 · 纪念馆展陈

- 分区：分区一（地表）。来源：《任务书-纪念馆展陈设计》（批 J，9280e73）。拆包：分区窗口一转包批一（2026-11-20）。
- 依赖：无。接口：矿道矿石标本铭牌与图鉴矿物条目同名同口径（图鉴侧口径以既有登记为准）。
- 范围：四区单向动线（进门左行、四区串联、出门回大厅、无回头岔口，全程步行约 3–4 分钟）；展品三档体例全馆统一——实物（展台/展柜）、复原景（半开放小景，可走近不可进入）、铭牌（标题一行+说明二至三行+年代一行，字体底色全馆一致），每区一处区铭牌（字号大一档、无年代行）。第一区·开镇（大厅悬复原陨石嵌星尘晶簇微光、建镇聚落沙盘、老物件 4–6 件，铭牌只记「何年何户所捐」格式、不记人名全文，全馆最亮）；第二区·矿工岁月（1:1 复原矿道可走十余米、木支架/轨道/矿车、道壁矿石标本八种各一、生活物 6–8 件只定品类、班次牌墙只记年月+班次、灯光暖黄、缓坡接第三区）；第三区·封锁与离别（复原封锁线木栅+布告牌、行李堆、一排空椅）及第四区按源稿逐项落地。展陈口径=镇民相信的版本（传说层）。
- 红线：全馆只许一件展品「不对劲」且不配任何解释文字；深层真相绝不明示；§3 石板刻痕为无义组合，**不许画成羊纹形制（羊角螺旋/方折回纹）**。
- 验收：四区动线实走（单向无岔口、时长）；展品清单逐件对版（三档体例、铭牌格式）；红线两项专项核（不对劲展品唯一性与无解释文字、刻痕非羊纹）。展品文字只定结构与体例，**全文不在本包**（另行过审）。
- 常驻：永不停机+最高并发；回执带「区块自洽」与「母题核对」行。
