# 设计 · 天空之城梦境章（2026-11-22，总控；Thomas 亲述定版）

**来源（Thomas 2026-11-22 亲述）**：天空之城要设计得像天堂、像梦境。主角上去后发现城里有很多「亡灵」——其实就是灵魂，是第一代航天员（观测站一代）未完成之夙愿的意愿所聚。主角如在梦中，在城里度过几天，与不同的人交流，最后从先祖的意志里找到方向；离开时回头，天空之城没有了，再也进不来了——因为本来就是先祖带他去的。

本章章定位由此定版：**天空之城不是一个可反复游览的游乐场，是一次性的梦境章**。此前「只建模、交互后议」的口径由本件接替：交互即本章，施工排太空章前置（抵达手段＝飞行器/滑翔，属后期内容），设计先行。

## 章结构

1. **抵达**：玩家首次登岛（飞行器首飞或滑翔抵岛）——落地一瞬，城「活」过来：无雪的岛上暖光如春、观测站灯火通明、巨树开花、傀儡迎客如生前。转场语法与入梦同源（黑场一瞬＝入梦），玩家只觉得「到了」，不觉有异。
2. **梦中数日**：梦内自有昼夜（金昼、星夜、再金昼……），与外界时刻脱钩——外界只过了一夜（信标与镇上作息照常，玩家归来时镇上是次日清晨）。梦内不设时钟界面、不催进度；玩家自由行走、自由交谈，顺序任意（故事是暗线，全章不变）。
3. **交流**：城里住着观测站一代的灵魂，各有一件未竟之事（见人物）。交谈不是任务清单：每人把自己那件没做完的事讲给主角听——没观测完的那片星空、没发出去的信号、没等到的接应、没写完的日志。主角能做的只有听、看、在城里替他们走到他们当年没走到的地方（观测台顶、星台、巨树根）。
4. **找到方向**：听全之后（以玩家实际走完、听完为准，不设计数界面），站长把最后一句话交给主角：他们当年没能把电话接起来——**上去把电话接起来**，从这一刻起是主角自己的事，不是先人的执念。太空门由此「认主」：双钥匙流程不变，但没有这一梦，门只是一只锁着的环（叙事前置，非新增机械门槛）。
5. **离开**：玩家走到星台，自行选择离开（入睡点/门环处长按）。醒来在云海台或岛上清晨——**城空了**：灯火熄、巨树花落如常、傀儡静止在递花的姿势里。
6. **再也进不来**：岛仍在（浮岛、观测站遗迹、巨树、星台与太空门都在，物理层照常可达、可再访），但活过来的城永不复现——先祖的意愿已经交完了手，他们不在了。图鉴事件页落一条「天空之城 · 梦」，记现象不记解释（人物志口径）。**空，是这一章的结局，也是它留给玩家的最后一件礼物：全游戏最壮观的地方，从此只剩安静。**

## 与既有正典的衔接

- **傀儡递花**：梦中傀儡是迎客的「人」；梦醒后静止递花——玩家这时才懂那朵花是给谁的。
- **巨树**：镇上许愿树是它的插条；梦中满树花，醒后玩家再看镇上的小树，会知道它在等什么。
- **太空门**：梦境章是开门的叙事前置；机械流程（双钥匙＋第十三声分钟）一字不改，执行点仍在星台。
- **时间**：梦中数日/外界一夜，与地下入梦的黑场转场同语法，全游戏时间不对等只此两处，互为镜像（一个向下、一个向上）。

## 施工口径

本章属太空章前置，设计先行入册；天空之城建模（已在行）按「梦中活城」与「醒后空城」**双态**预留：同一座岛两套灯光/在场状态，切换由首次抵达旗标驱动（B 线旗标、D 线场景双态）。验收：首次抵达全章第一人称走完一遍＋二次抵达验空城态，两遍都过才算交付。
