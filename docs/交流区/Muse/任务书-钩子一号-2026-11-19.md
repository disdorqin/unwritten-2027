# 任务书：钩子一号（钟楼多出来的第九声）（2026-11-19，分支窗口细节填充，优先单）

源稿：《钩子一号-开场不对劲-2026-11-19》（主钩子已定版：候选 A，下游只许调实现参数、不许换钩子）。**排期门：今晚总装上线之后领单，赶开镇首晚**——挂现役钟楼 M6 整点系统，不新建系统。镇长台词（致辞「听钟」句、三级递进的指向句）只定结构与触发，**全文回主窗口过目后填充**。

## 细节填充

1. **第九声本体**：每整点在八声正钟之后追加一声定向远景音效——方位自西（陨石坑方向）、音色闷而轻（隔雪隔山感）、全场同步播放；音量随夜深渐清（拟定三档：20:00 轻 / 22:00 中 / 00:00 后清，施工按现役整点音量基线回执登记相对值）。零点仪式整点同样有第九声（在烟花起之前落下，不被烟花声覆盖——排期上先钟后花，与首晚动线 N3 对齐）。
2. **一级（开镇 20:00）**：开场致辞节奏点——八声落、第九声响、镇长停顿一拍再继续（停顿时长拟定 1.2 s，NPC 动作点）。此拍只在开镇首晚 20:00 触发一次；此后每整点第九声照常、镇长无停顿。
3. **二级（个人第 3 次听到）**：按玩家个人计数（服务端记录已听整点次数，含第九声在场判定 = 整点时在线且在镇内）；第 3 次时第九声近一档、清一档（音量/混响参数切换），且**仅此一次**：钟楼倒计时牌在钟声落下瞬间闪过一个不对的数字再恢复（单帧级闪烁，拟定 1 帧错数后恢复，错数内容施工回执登记——只许是「不对的数字」，不许是文字或符号）；镇长在场时反应升级为抬头看西边（动作点，无台词）。
4. **三级（集齐 4 页后）**：玩家集齐残页 4 页后，再听整点第九声落下，镇长在散场人群里主动找到持页玩家（多名持页玩家在场时逐一或就近触发，人均只触发一次），说指向句（大意「那口钟，敲的不是时辰」+ 指向西边 = 下一页线索方向，**台词全文另审**），钩子在此递交第二章（与故事线任务书 S1 章节状态机对接：三级触发记为二章开启前置信号之一，不替代二章开启条件）。
5. **防呆四层**：①每小时重播（第 1 项本体即是）；②小未活指针——第九声响起时小未朝西抬头（动作点，拟定持续 2 s 后恢复，与故事线小未支线 S5 的环境暗示分开登记：此处为功能性指针，非支线痕迹）；③致辞「听钟」留口（结构位，文案另审）；④**第一封跑腿信兜底——细节填充决定：预置为待命单，首晚不启用**。理由：前三层已覆盖广场人群/路过者/羊指针三路，首晚再加一封卡整点的强制跑腿会稀释「自己发现」的质感；开镇后若主窗口按玩家反馈判定撞见率不足，再启用本单（目的地钟楼附近、整点前后送达）。
6. **第二钩子（候选 C）**：开镇首晚首个落入镇域的天降事件，镇长把落在广场边的一小块碎块收进袖子（动作点，只触发一次；其余镇民抬头—低头常态反应沿天降既有表现）。与天降排期联动：建议首晚首个天降窗口落在 19:30–20:30 排期内（见细节填充 §3 参数），施工回执登记实际触发时刻。
7. **陈设落点（候选 B/D，不抢主钩子）**：火车站环线站牌一站钉木板（只露半个字，字样另审——只许半字不许全名）、报站广播在该站位置留停顿空白；镇公所玻璃柜镇志展柜（缺页 spread 摊开陈设，断口整齐）——D 为第一张残页拾取点的实体承接（与故事线任务书 S2 对接）。
