# 任务书：主峰山域（2026-11-19，分支窗口细节填充）

源稿：《主峰山域设计-2026-11-19》+《北岭800主峰修订与地下勇士城扩容》。**上线后扩展：排今晚总装与上线之后，随主峰立项领单**；前山（在建 350）零返工、零改动。每单回执带「区块自洽」行；本域为独立场景模块（自有坐标系、进门只建本域、粗模常驻）。

## 细节填充

1. **域界与坐标**：自有界 2,200×1,800 m，域内坐标独立（原点取入山门内侧，施工回执登记）；与镇面零换算、零共用常量，只经入山门锚点衔接；老镇 bounds 不因本域增删改。
2. **五区布点（域内拟定，施工按地形复核回执）**：入山门区在域南缘（行前广场 ≈60×40 m，与云海台齐平）；云海腰区在 380–560 带缓坡（盘山道二段中段 + 观云亭 2 座）；绝顶区 760–800 台地 ≈70×50 m；北壁攀爬区在北壁（岩壁带坡度 ≥55°，红旗路线自云海台侧插至绝顶，岩台每 15–20 m 垂直距一个）；东坡区东坡缓脊 18–24° + 次峰肩 + 背风营地（篝火点 1 处）。
3. **绝顶台构成**：绝顶小屋（登记+领雪翼+避风）、绝顶碑（台地中央，护照盖章，与云海台碑成两级）、大旗（最高点，旗面单字「未」，见 16 问 #4）、滑翔台（南缘外挑，旁设领翼台）、观景台（东缘，固定望远镜陈设）。台地只用石木；峰顶岩面雪深强度 1–2。
4. **主峰线缆车四幕计时**（全长 ≈1,900 m、8 m/s、单程 ≈240 s、无中站、双厢对开、确定性按钟，复用前山按钟时钟模块口径）：出站爬升 0:00–1:10 / 入云 1:10–1:40 / 白茫茫段 1:40–2:10（**此段不许加 UI 提示、不许跳过**，回执须断言）/ 破云 2:10–4:00 缓速靠站。回程反向同表。
5. **雪橇绝顶线三段**（只下不上）：云上段 800→560、≈2.2 km、12–16%；穿云段 560→380、≈1.4 km、8–10%、无岔口单向单赛道、红旗+风铃杆加密；云下段 380→前山脚广场东、≈2.6 km、10–14%、与前山 R2 线并轨。总长 ≈6.2 km ≥6 km，落差 ≈640 m。速度档沿 §5 定版（上限 4×），穿云段落中速档口径施工回执登记。
6. **盘山道二段**：云海台 → 绝顶，坡度 ≤12%，长度 ≥5.4 km，观云亭 2 座（与云海腰区共用登记，不重复建）。
7. **NPC 岗位**（只定岗不定台词）：入山门门房、绝顶登记员、主峰线调度员（云海台站，前山侧）、观云亭守亭人（大观云亭）。
8. **雪深衔接**：同一梯度函数域内采样（高山区 4–5、峰顶带 1–2），山门接缝跳变 ≤一档。
