# 设计 · 小未行为表（2026-11-20，总控）

定位：小未是全镇唯一活着的「灵魂雷达」——活人看不见的层，她全有反应；玩家读她，就等于读这个镇子的第二通道。羊石伏笔（铃铛芯）另有裁定，本表只管行为。

## 一、白天日常（活人眼里就是一只羊）
- 固定巡游路线：羊圈→广场（晒太阳）→酒馆门口（讨吃的）→老宅附近→回羊圈，随游戏日循环。
- 可喂：干草/炒花生（樵夫同款）。喂过的玩家，她会跟走一段，到下个巡游点自动停——跟随是临时的，不做宠物系统。
- 白茫将至：她提前自己回羊圈——活的天气预报，比广播早半步。

## 二、雷达行为（触发器表，施工照此）
| 触发 | 她的反应 | 玩家读法 |
|---|---|---|
| 魂在附近（夜窗/旗标） | 停步、耳朵转向、盯着空处 | 顺她视线看，夜里能瞥见魂的痕迹 |
| 魂镇长在附近 | 铃铛偶尔轻响一下 | 他在附近 |
| 第十三声响起 | 铃铛无风自响（信标事件已定） | 夜窗开了 |
| 藏石处（半径内） | 停下盯看、轻叫 | 附近有星石（寻石五线索之三） |
| 夜窗·玩家在广场 | 有时往山口/坑口走几步、回头看玩家 | 「她想去那边」——跟不跟随意，非指引 |

## 三、红线
- 她是活物不是道具：不下地下、不进太空门、不受伤、不参与战斗。
- 她的反应永远只给「方向感」，不给坐标、不给箭头（自由优先）。
- 活人 NPC 对她的异常反应一律用「小未是镇上的吉祥物」带过（开镇伏笔口径）。

## 四、实现锚
巡游=点位序列+简单寻路；反应=触发器查表（魂近/石石近/信标/天气）；铃铛=短音频两档（轻响/自响）。施工归窗 B（系统），羊圈与巡游点位归窗 A 场景侧配合。
