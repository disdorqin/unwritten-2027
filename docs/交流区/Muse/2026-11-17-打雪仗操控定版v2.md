# 打雪仗操控定版 v2（Thomas 亲定，替代 v1 操控稿）

日期：2026-11-17。本稿**替代**同日《打雪仗操控定稿》的一切操控表述（Ctrl+E 方案作废），设计 v1 的其余条款不变。

## 一、全平台统一：长按一个动作
- **长按 = 拿雪/攒球并进入瞄准；松手 = 发射。** 手机与电脑同一套逻辑，不再有第二按键。
- 按住期间的行为由准星指向决定，是同一个按压的两个阶段、衔接不断开：
- 准星对着近处雪面（≤2.5 m、户外）→ **攒球阶段**：持续攒球（约 0.8 s/次、按雪深 +3/+4/+5，进度环，满 10 停）；
- 准星抬起对着人或开阔方向 → **瞄准阶段**：显示投掷预测弧（见第三节），松手即朝弧线方向扔出；
- 在一次按压中从地面抬到人身上，攒球自然转入瞄准，不松手不断档。
- **v2 取消蓄力分级**：固定全力投掷（初速约 26 m/s、射程约 35 m，与设计 v1 一致）；按压时长只决定攒多少球和瞄多久，力度不分级——新玩家不用学力度，靠弧线预瞄打准。这是手机端的核心优势：像投手榴弹的轨迹预瞄一样，先看见落点再松手。
- 弹药为 0 且未攒到球时松手：不发射，仅结束动作（攒球阶段松手同理，只停攒球）。

## 二、两端具体形态
- **手机版**：手指长按屏幕（非摇杆区）；指地面攒雪、指人瞄准，松手扔出。防误触沿用 v1：按后滑动超小半径视为拖视角并取消；按压 <0.15 s 不算动作。
- **电脑版**：**长按鼠标左键即可**（删除 Ctrl+E）；按住出预测弧，松手扔出。攒球同理：准星对着近处雪面按住即攒。

## 三、预测弧的精致度要求（本稿重点）
- 弧线**顺滑可读**：样条平滑的点线/光带（≥24 个采样点插值，不得有折角感），随准星移动实时更新、无抖动延迟感；
- **落点标记**：弧线末端有明确的落点标记（雪地光圈 + 小雪花图标），落在人身上时标记变色高亮（预告命中），被建筑/地形挡住时弧线在挡点终止并标记；
- 弧线只在按住期间显示，松手发射后即消失；颜色与小镇冬夜 UI 同色系，不抢画面。

## 四、验收追加（并入设计 v1 第八节）
1. 两端各走一遍"长按攒球→不松手抬起瞄准→松手命中 10 m 外目标"全循环，衔接无断档；
2. 预测弧落点与实际落点偏差 ≤0.5 m（静止、无风）；落点标记在命中人/被挡两种情形下状态正确；
3. 电脑版不存在 Ctrl+E 残留绑定。
