# 世界联系线时间线：陨星与太空章（2026-11-19 晚，Thomas 口述主线，主窗口梳理成稿）

本稿把全世界观串成一条线：陨石坑（地下）↔ 北岭（天空）↔ 太空章（未解锁）。与《地下层设计定稿》《地下层补充-陨石坑入口》冲突处以本稿为准。

## §1 时间线（世界背景，玩家靠探索拼凑，不设旁白文案）

1. **远古 · 陨星坠落**：一颗陨星落在镇西，砸出陨石坑；陨星核心碎块与星尘矿脉沉入地下深处。北岭在同一次造山挤压中隆起——山与坑是同一场天外事件的两面（此层只作环境暗示，不明说）。
2. **封锁时代**：有人把坑区围起来（铁栅栏、幕墙、塔楼、闸门、值班廊），挖过、研究过，然后撤走，设施废弃。撤走原因留白，是探索线的悬念。
3. **现在 · 未写镇**：镇子在坑与山之间过日子（地面章：四景、日常、庆典）。坑区是镇外没人去的废地，山是抬头能看见的日常。
4. **探索线（玩家）**：翻进废弃坑区 → 深井下潜 → 清怪、挖矿 → 水晶洞 → 地宫宝库（与金羊寻宝线交汇）→ 拼出陨星的来历：它来自天上。
5. **合成线**：地下挖到的料做助推器，登上北岭顶拿到雪翼，两件合成飞行器。
6. **太空章（未解锁）**：飞行器是钥匙。当前版本飞行器只能带玩家飞上云海之上（见 §4），通往太空的星港大门可见但锁死，明示「未解锁」——内容后置，门先立着。

## §2 云层与山（能见度设计）

- **云海带**：高程约 260–420 m 环绕北岭上部的一层流动云海，云块群缓移、有缺口。从镇上看：北岭下半截清楚、上半截没入云里，峰顶随云缺口时隐时现（神秘感来源）。
- **穿云能见度**：身在云中时视距压到 300–500 m，之外是白茫茫的虚空（雾色填满，不露未加载的空洞——与区块化粗模衔接：云层正好是加载遮罩）。
- **峰顶在云海之上**：山顶平台（347–350）晴空、脚下云海——天空城的名分由此成立，不靠建筑堆。
- 此节修正《北岭补充定版》§1 云带：原 290–320 环峰云带扩为本节云海带口径。

## §3 深井（陨石坑深度修订，兼作加载设计）

- 坑体（地表）：深 ≈35 m 不变（《地下层补充》§1）。
- **主井道**：自坑底向下，深井总落差约 −190 m，分三段下潜，每段之间一道闸门：
  - 一段井道（螺旋步道 + 吊笼）→ **矿洞层 −90**；
  - 二段斜井（矿车道，步行轨旁）→ **水晶洞层 −140**；
  - 三段直井（吊笼）→ **地宫层 −190**。
  （《地下层设计定稿》的 −25/−45/−65 三层高程作废，以本稿为准。）
- **深度即加载**：井道全程是转弯与闸门组成的气闸链——站在坑口望不见井底、站在任何一层望不见另一层；每过一道闸门，身后一层卸载、身前一层建出。深度越大、遮挡越彻底，深不是负担，是性能方案本身。
- **清怪开门**：每段井道尽头的闸门由该段怪物把守——雪团怪群（一、二段）与冰傀儡（第三段门前），清完本段怪，闸门才开。单人可清（老规矩），怪不伤人、雪球融化（定稿 §4 不变）。

## §4 合成线：飞行器（太空章的钥匙）

- **陨铁**：坑底陨石残块敲取（与星尘矿同源，只有坑底有）。
- **飞行助推器**：陨铁 + 星尘矿，在松林工坊棚（或山顶小屋工作台）合成——配方两件，不堆材料表。
- **雪翼**：登顶北岭、在山顶小屋登记后领取（登顶的实物奖励，与登顶碑护照章并列）。
- **飞行器** = 雪翼 + 助推器，在**山顶星港坪合成台**合体。形态：带助推的滑翔翼——起飞仍从滑翔台跃下，助推提供爬升，能穿云海、能在云海之上巡航与降落回峰顶/镇区。
- **当前章上限**：飞行器解锁「云海之上」空域（巡航、观景、峰顶↔高空交通）；星港坪尽头的**太空门**（通往轨道层的发光门环）可见、走近有「未解锁」提示，太空章内容不在当前版本。
- 飞行与区块化：高空巡航沿用滑翔口径（全图粗模常驻、精细层随高度切换），云海层正好掩盖切换。

## §5 与既有定稿的关系

- 地下三层内容（矿物八种、三怪、宝库、金羊线终点）不变，只改深度与开门方式。
- 北岭 350 米施工规格不变；云海带是氛围层增补，不动地形采样。
- 太空章只立门与钥匙，不做内容；星港坪预留地（修订版 §7）与本稿太空门是同一处。
