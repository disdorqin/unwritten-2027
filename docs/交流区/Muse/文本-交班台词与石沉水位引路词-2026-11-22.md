# 文本 · 交班台词（ZB-41）与石沉水位引路词（2026-11-22，总控出稿）

台词归口总控，本件为两处等接线的正文：ZB-41 坑口守卫交班词（B 线接线用）与石沉水位引路词（C 线批72 水位件用）。口径：活人只知其守位、问到坑内笑着绕开；石沉是魂，话落在水与路上，不落真相。

## 一、ZB-41 交班台词（坑口哨棚，三班交接时触发）

交接发生在哨棚前：下班者交钥匙牌，上班者接。一段交接四句，两人对说，玩家路过可听全（听＝三碰之一，不拦路、不弹框）。

**晨班交接（孙小山 → 罗大年，天亮）**
- 孙小山：「大年叔，夜里安生。栅栏那头塌口我又去看了一眼，没新脚印。」
- 罗大年：「嗯。塌口别自己下去，记上一笔就行。」
- 孙小山：「记了。就是……昨儿后半夜，坑底好像有动静，像谁在底下挪东西。」
- 罗大年：（笑）「风。坑里的风，夜里都这样。回去睡吧，娃。」

**午班交接（罗大年 → 田守义，晌午）**
- 罗大年：「守义，牌给你。上午来了两个后生想进去看稀奇，我请他们去镇上喝热汤了。」
- 田守义：「做得对。里头没什么稀奇，净是烂铁和黑石头，看了还压运气。」
- 罗大年：「补给站那边石九斤的人下午要过料，你放行，别拦错了。」
- 田守义：「放心。有登记的过，没登记的——天王老子也得在栅栏外头站着。」

**晚班交接（田守义 → 孙小山，入夜前）**
- 田守义：「小山，夜班还是老规矩——」
- 孙小山：「知道，夜里不入。我就坐哨棚里，灯笼挂高点，谁来也不开门。」
- 田守义：「对喽。夜里听见什么都别应，听见有人喊你名字，更别应。」
- 孙小山：（笑）「守义叔，你每回都说这句，我从小听到大了。」
- 田守义：「我也是从小听我爹说的。」

（设计注：三段各埋一颗「太整齐」的钉子——塌口无脚印、夜里别应声、话是一代代传下来的规矩，没人问为什么。活人侧到此为止，不解释。）

## 二、石沉水位引路词（地下引路，三态各一句＋通用一句）

石沉在 −90 入口附近现身引路时说，随今夜水位变（presence 水位状态驱动选句）：

- **涨夜**：「今夜水涨。低洼道别久站，水底下的矿是好矿，就是得憋着劲儿挖——挖两下，抬头喘口气。」
- **平夜**：「今夜水平。路是平常的路，矿是平常的矿。平常日子最养人，慢慢走。」
- **落夜**：「今夜水落。河床干出来了，那条近道只今晚有。脚步放轻，干河床上走路，声音传得远。」
- **通用（玩家在水中停留过久时）**：「水不咬人，水耗人。灯要是灭了，就往高处走，高处总有风，风能把灯再吹亮。」（按：高处篝火点，此句为玩法提示的魂侧说法）

（设计注：石沉认水是他的本行——矿工队长的话只落在水、路、矿上；「声音传得远」是落夜遭遇轮换的侧面提醒，不点破。）
