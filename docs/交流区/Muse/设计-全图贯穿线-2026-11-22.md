# 设计 · 全图贯穿线（2026-11-22，总控）

把七区缝成一条线的总设计：镇→山→坑→地下→云海→天空之城→宇宙线。既有各区设计与正典不动，本件只做**贯穿层**——路线、门与钥匙、叙事绳、状态账、验收动线。通则：故事是暗线、无箭头无强制引导；所有的「门」都是物理的或人事的（守卫、夜窗、材料），永不做 UI 锁。

## 一、贯穿总图（一根绳）
未央号一艘船摔成四层，玩家做的事本质上是**逆着坠毁的方向把船走一遍**：地面残件→地下船头→天上观测站→轨道舱。两条线在镇上交汇，交汇点是镇公所的星石环。

- **下行线（向地心）**：广场→西北动线→坑口（正门守卫/塌口）→补给站→集结地→坑底绞盘开井→乘笼坠落入梦→−90 营地遗迹→−140 暗河泵房→−165 勇士城（铁匠铺锻造）→−190 地宫宝库（导航芯）→沉船核心（本章锁闭）。
- **上行线（向天）**：广场→北带→山口（守卫白班）→盘山道→前山 350→缆车三站/步道→云海台星港坪→（转场）主峰域→绝顶小屋（雪翼）→滑翔穿环→云海→天空之城（巨树/观测站/太空门，本章锁闭）→（太空章）轨道域五舱。
- **交汇与闭环**：十二星石散在两条线与镇上（鼠·镇公所地窖／牛·松林／虎·镜湖冰雕岛／蛇·坑底绞盘旁／兔·前山半山／龙·云海台星港坪／马·矿洞营地／猴·水晶洞／鸡·勇士城冷焰／狗·宝库门前／猪·绝顶小屋／羊·小未铃芯），归环→原石凝出→飞勇士城落炉芯→锻造助推器（冰晶片＋星尘矿）→星港坪组装飞行器（雪翼＋助推器＋导航芯）→双钥匙（讲古钥一＋飞行器合体）齐备→第十三声那一分钟启太空门。**下行线产出上行线的钥匙，上行线抵达下行线够不着的门**——两条线互为前提，这就是贯穿。

## 三、叙事绳（贯穿的暗线读法）
- 玩家动线即阅读顺序：先在地面看见「不解释」（空屋亮灯、空车准点、守卫绕开），再在地下看见「一代人的工程」，再在天上看见「他们望着的东西」，最后在轨道舱听见「电话还在响」。四层的诡异感是同一个事实的四种影子——**贯穿的验收标准之一：任意一层的玩家回地面后，地面在他眼里必须变了**（魂层可见度随纵深进度涨：下过 −165 的人回镇能多看见一位魂的正脸，是石沉在地下认过他的回执——只记现象，不落文本解释）。
- 第十三声是贯穿的心跳：钟（镇）→坑底与绝顶同刻轻响（两线端点）→太空门开启分钟（天）——同一个信标事件把四层缝在一分钟里。
