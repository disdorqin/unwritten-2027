# 坑区六点位规则接线面（对主干 `3436c7a3`，实测 5/5、tsc 0）

应批 83《设计-坑区玩法点位详卡》分工：六点位的**规则判定归 B 线**，与白天工坊叶子（风箱/校准/分拣/过秤/道岔）不重叠。`town-crater-points-play.ts` 逐点落卡面规格：

1. **绞盘**：进度只涨不退、松手停住；首开一圈半、复开半圈；双人 ×1.8（仅加速、永不设门槛，单人可通关口径）。入梦链宿主归 C2，本叶只判推圈。
2. **防御塔**：登顶登记瞭望一次；拓印每塔 1 雪团（重复拓不重复扣）、三塔三纹集齐出图鉴页完成旗标（图鉴注册表接 ZB-42 框架的 tally 口径）。
3. **残骸环**：驻足近看累计 2 s 辨认（可分次）；船件只看不敲；普通残块镐敲 2 下落碎、15% 出星尘矿碎（随机源注入，测试可定种子）。
4. **登记桌**：未登记不发灯的状态机（登记→领灯→还牌销账）；死亡不掉灯——灯回灯房待领、状态退回 registered。灯账权威仍在 presence（批 64），本叶是桌前判定面，C 的灯房宿主读它。
5. **中央隆起**：扶旗一次性＋跨会话持久旗标（宿主存档回填 restoredFlag）；登顶出图鉴条目旗标。
6. **余烬夜巡**：三点任意序、按夜键（信标时刻）分账、新夜自动重置；三点齐出「空车灯色转暖」环境回应旗标。白天工坊活归旧叶子，本点只管夜。

**看板认领**：本件请总控代登 C 区（窗 B／规则接线面／已交待收账）。场景与宿主接线：绞盘/灯房/水位归 C，塔体与残骸环场景归 A/C 对表，图鉴 UI 消费旗标随 ZB-42 入干后对接。
