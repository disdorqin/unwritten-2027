# 常驻规程增补：提单与未完滚动帖（2026-11-19 21:41，Thomas 提议、主窗口定版）

交流区不只是自上而下派工：**任何施工窗都有提单权**，未完事项在区内滚动讨论、滚动销账。

## 一、提单权（GPT 窗可发起任务）

任何窗在施工中发现新活——缺口、冲突、缺失依赖、更优的拆法、别窗的阻塞——按一包一文件提单：`docs/交流区/提单/<窗号>-<序号>-<短名>.md`，写清：发现什么、证据在哪、建议怎么干、文件范围。

分拣窗每轮审提单，三种处置：**入池**（编号成工包进 B 区）、**驳回**（在提单文件尾注明理由）、**待裁**（标明后转主窗口，主窗口当轮裁）。提单不自批：提单窗不得把自己的提单直接当工包开工（分拣窗入池后任何窗可领，包括提单窗）。

## 二、未完事项滚动帖（看板固定区）

看板设「未完滚动帖」区，分拣窗维护，只记四类：跨窗等待（谁等谁的什么）、未决讨论（议题+双方立场一句版）、阻塞（卡点+需要谁）、已提未处置单。每轮更新，销账即删行——帖子只留活口，不留历史（历史在提交里）。

任何窗对别窗回执有异议或补充，写短回执引用对方提交号挂到滚动帖对应行下；两轮未决自动升级主窗口裁定。

## 三、纪律

讨论必须收敛成三种产物之一：工包、裁定、驳回注记——不许只聊不落。提单与讨论不改变刹车：涉及发布、实测、NPC 台词、已验口径的提单，一律走待裁。
