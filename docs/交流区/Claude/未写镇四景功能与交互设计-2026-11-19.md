## 1. 核心循环：环游册（四景章）+ 每日差事

### 1.1 环游册四景章（护照扩展区新增 4 枚；北岭章为主章）

现有护照：镇内 7 枚到访章 + 扩展 4 枚成就章。本稿在扩展区加**四景章**，每枚绑定一景的**招牌活动完成**（不是到访即得——到访章是老镇的口径，四景章要玩过才给，这是「功能优先」的落点）。北岭章列四景章之首、纪念卡版式居中位（版式调整只动 `town-passport.ts` 渲染序，不动存档结构）：

| 章 | 景 | 达成条件（单人） | 判定挂点 |
| --- | --- | --- | --- |
| **北岭纵走**（主章） | 北岭 | **大纵走完程落碑**，或**任意三条不同雪道各落碑一次**，二选一 | GP 计时状态机终点事件（按道 id 去重计数） |
| 镜湖渔获 | 镜湖 | 冰钓渔获登记第 1 条（图鉴从 0 → 1） | `ice-fishing-activity` 登记事件（与既有渔获图鉴章同源、不同章：图鉴章记集满物种，本章记首渔） |
| 林间篝火 | 松林 | 亲手生起营地篝火一次（砍柴→添柴→点火全程本人）或堆成雪人 1 个，二选一 | `town-forest-campfire` 点火事件 / 雪人成型事件 |
| 灯市集字 | 灯市 | 灯谜集满 4 字（v2 稿已定） | 集字进度面板集满事件 |

- 集满 4 枚四景章 = **环游完成**。反馈三件（全走现行通道）：①护照面板环游完成态 + 纪念卡导出（现行 PNG 导出自动含四景章）；②信箱收到「环游贺信」一封（town-mail-store 投递，文案进语料模板位待补）；③跨年夜仪式认可（§1.3）。
- 四景章不设时限、不设顺序；哪天玩、先玩哪景都行。未集满不惩罚、不提醒轰炸（护照按钮计数是唯一提示面，沿现行 `showStampCount` 口径）。

### 1.2 每日差事（邮局中枢 + 山脚大屋副枢纽，日期种子轮换）

- **入口**：邮局是差事中枢。玩家到邮局信箱（town-mail-activity）查收，当日有 1 件「镇民差事信」（信封样式沿信箱现行口径）；接不接在玩家，不接不惩罚、次日自动轮换掉。**北岭既是主目的地，山脚租赁大屋兼作差事副枢纽**：大屋公告板可查当日差事（与邮局同件，本地同种子计算，两处查收状态一致走信箱存档），免得玩家专程回镇接信再上山——差事的交付端仍以各景驻守 NPC 为准（§5.2）。
- **轮换**：按 `localRiddleDate` 同模式——以本地日期为种子，从差事模板表（§5.2）确定性抽 1 件；全端同日同件（本地计算，无同步）。差事模板首批 7 件（§5.2 表），其中 4 件以北岭为一端（主枢纽口径的落点）。
- **结构**（三段，全部复用既有判定）：接信（邮局/大屋公告板）→ 到目标景找驻守 NPC 交付/办一件事（对话判定，npc 对话系统）→ 回邮局或任意信箱点投回执 → 次日（或当场）收回信 + 报酬。
- **报酬不用货币**：三选一池——跨景材料（§3 的竹篾/新雪/烤鱼之一，按差事模板定）、灯谜提示一次（定向提示函数 `directionalRiddleHint` 现行可复用）、渔获图鉴天气口（当日冰钓等待窗口分布收窄，见 §7 推导）。报酬即领即用，不囤积。
- **距离口径**：差事两端必须是一景驻守 NPC 与另一景驻守 NPC（或邮局/大屋），单程动线按 §6 动线表 ≤3 分钟（门/列车/疾跑/索道任一组合达标），全程 ≤8 分钟含办事——算式见 §7。

### 1.3 跨年夜仪式认可（挂 C2 §3.4，不新增 cue 类型）

- 仪式 converge 阶段（`town-ceremony.ts` phase 现行枚举）开始时，本地检查环游完成态：完成者触发三件——`announceActivity` 一次环游者点名播报（文案模板位待补）、贺信若未领则补投信箱、本人许愿牌与雪人在 §3.4 点灯段同亮（v2 稿已定雪人灯芯与许愿牌同亮，本稿不改其口径）。
- 未完成者无任何负面提示。认可纯本地判定（护照存档在本机），不走协议、不新增 cue 类型。

## 3. 跨景流动线（连接组织）：一条轻物流，不做经济系统

### 3.1 承载口径：随身格（不是背包系统）

- 玩家有 **3 格随身格**（设计值，推导见 §7：跨景流最长链为 3 件接力——鱼→烤鱼→竹篾，格数 = 最长链件数）。随身格只装跨景材料四种：**鲜鱼、烤鱼、竹篾、岭上新雪**（外加成品灯 1 盏占 1 格）。不设堆叠数量、不设重量、不设售价。
- 存储沿护照同模式的本地存档（新存档键一条，命名沿 `unwritten.*.v1` 现行口径）；世界物件不落盘材料，材料只在玩家随身格与建筑寄存点（物料棚新雪寄存）之间流转。
- 任何材料都不是唯一来源：竹篾可领（工坊每日首盏免费领料）、可换（烤鱼）、可得（差事报酬）；新雪只产北岭但雪人主线不强制用新雪（见 3.3）——**跨景流是捷径与风味，不是卡点**。单景玩家在原地能玩完本景全部招牌活动。

### 3.2 流 A：镜湖的鱼 → 松林的火 → 灯市的灯（主链）

```
镜湖冰钓得鲜鱼（随身格+1）
  → 松林营地火塘烤制（挂烤架，烤制时长 = 篝火一轮口径，§7；得烤鱼，鲜鱼-1）
    → 两条出路：
      ① 自己吃：回暖（town-frost 温暖源 hot-drink 同级处理，数值沿现行）
      ② 灯市小吃摊收购：交烤鱼 → 得竹篾 ×1（制灯材料）
        → 灯笼工坊制灯 → 许愿树挂灯 → 跨年夜 §3.4 满树同亮
      ③ 集市出路：集市鲜鱼摊（集市驻守区）收鲜鱼/烤鱼 → 换当日灯谜提示一次
          （与灯谜墙提示同池，不叠加货币）
```

- 每段都是已登记建筑的功能步骤（§2），无野外凭空交互点。
- 链长 4 段、跨 3 景，单程动线按 §6 表累计 ≤10 分钟（含烤制等待），是 30–45 分钟会话里「一条差事之外」的自选长线（§6 节奏位 C）。

### 3.3 流 B：北岭的新雪 → 松林的雪人（风味链）

- 山脚大屋设「新雪筐」：玩家在北岭任一雪道旁长按掬雪得「岭上新雪」×1（随身格；动作沿掬雪现行交互，不新设采集系统）。
- 营地堆雪人时若随身有新雪，成型时多一步「新雪覆面」：该雪人登记为**灯芯雪人**——跨年夜 §3.4 点灯段亮暖光（v2 已定雪人灯芯同亮；无新雪的普通雪人同段只亮冷光提亮，差异即风味回报）。不带新雪照样能堆、能留名、能得章（§1.1 章条件二选一不依赖新雪）。
- 新雪可在物料棚寄存（寄存格 1 格/人，存档口径同随身格），防随身格占满卡链。

### 3.4 流 C：邮局差事网（全景连接，北岭为最密节点）

差事模板（§5.2）把四景驻守 NPC 两两相连，邮局为发信点、山脚大屋为副枢纽查收点；7 件模板中 4 件一端在北岭（大屋/岭顶/山腰）。差事与流 A/B 共用随身格（送信件不占格——信件走信箱系统不走随身格，此条写死防实现歧义）。

### 3.5 仪式总兑现（§3.4 同段三亮）

跨年夜零点 §3.4 点灯段同亮三件（全为 v2/总纲已定口径，本稿只汇总登记，施工对表用）：**许愿树满树牌灯 + 玩家挂的成品灯、松林雪人灯芯（新雪雪人暖光/普通雪人提亮）、灯市横幅（集字点亮者）**。环游完成者的点名播报挂同夜 converge 阶段（§1.3）。这是四景全部长线的共同 payoff 点，也是「明天还来」的最终锚（见 §6.3）。

## 8. 验收线（逐项可测）

**功能建筑（§2）**：四景每栋登记建筑走「进门→使用功能→离开」全流程实走（借橇/借具/领料/登记/开局各一次），无一步依赖未登记的野外交互点；兼岗关系（物料棚）时段轮值实测在岗。
