## 新窗入场（C/D 首轮必做）

1. 拉仓，读本文件 + 自助领单规程 + 流水线看板。
2. 认领窗号：在交流区 GPT 目录推一条登记回执「入场登记：窗（C 或 D）」——先落仓者得其号，后到者自动取剩余号，不许同号。
3. 在看板窗口登记区署名你的窗号与分支，然后按领单规则开工。

## 公共池领单规则

1. 池 = 看板 B 区，条目为**工包**：每包有编号、文件范围、依赖、验收口径。分拣窗负责把大任务拆成工包并保持池内待领 ≥6 包。
2. 领单 = 先拉仓查无他人已领，再推领单回执「领单：窗 X 领 <工包号>」后开工；两窗同领一包时以回执落仓时间早者为准，晚者立即释放、改领下一包。
3. 一窗同时只持一包；交包（回执+D 区登记）后立即领下一包。包内文件范围互斥是拆包纪律，越界改动先在回执里声明。
4. 有依赖的包标注前置包号，前置未交不许领。
