# 北岭与镜湖施工规格 · 2026-11-19（Muse 施工规格稿）

定位：把总纲 §1.5（北岭）与四景交互稿 §2.1/§2.2（北岭/镜湖）的功能设计落成可建规格——高程场、走线带、落位坐标、衔接处置。口径纪律：**与总纲冲突以总纲为准**；总纲标「提案/定线回填」的量级值，本稿给出定版建议并逐项标注；代码实测值注明出处文件；查不到的实现细节标「待 GPT 回执核对」，不编造。

坐标系：layout [x, n]，x 东、n 北，单位 m；高程为绝对高（广场 = 12）。世界框按总纲 §1.1 定版 **640×540**（若框架车最终选备选 640×576，多出的 36 m 全给岭背，本稿山体/湖体坐标不变，仅岭背带加宽）。

## 0. 实现总纲（先立机制，后给数字）

### 0.1 高度场现状（代码实测，`terrain.ts` / `town-extension.ts`）

- `terrain.ts::sample(x, n)` 是全图唯一的解析高程函数，合成顺序为：基础场（基底噪声 8.6±1.25 + 四个 `raisedHill` 高斯丘：(91,275,h16)、(65,353,h29)、(386,313,h30)、(418,369,h26)）→ 河道压低（`mix(3, ·, fade((r−6.8)/18)`）→ 东南湖压平（`layout.lake`，高 5.5、`fade(ld/13)`）→ 广场压平 → **plots 压平**（`mix(level, 1−fade(dist/5))`）→ **道路压平**（`mix(road.height, 1−fade(edge/5))`，道路段自带逐点高程）→ 纪念堂 apron → 水面截顶 3.4。
- 网格在 `createTerrainGrid()` 以 1 m 步长采样 `worldBounds`（现 640×512，框架车改 540）；legacy 框（x>448 或 n>384）外的格点改走 `sampleExtension(x, n, cell.elevation)`——注意它接收的入参正是 `sample()` 的结果，再叠加扩展道路/扩展 plots 的压平（混合带 24 m）。
- **关键推论**：只要山体覆盖与镜湖压平写进 `sample()` 的基础场阶段（在 river/lake/plaza/plot/road 压平之前），则：①legacy 与扩展两条采样路径自动同时生效（扩展入参已含覆盖）；②plots/道路/apron 的既有压平天然在覆盖之后执行——总纲 §1.4「覆盖层在 plot footprint 与路面内让行」**不需要新增让行代码**，是合成顺序的自然结果；③`groundHeightAt/heightAt/canEnter` 全部自动跟随。

### 0.2 施工口径三件

1. **山体覆盖 = 基础场替换**：新增 `mountainElevation(x, n)`（脊线场 + 台地/走廊整形，见 §1），在 `sample()` 基础场处按带混合：n < 262 返回现行基础场；262 ≤ n < 300 按 `fade((n−262)/38)` 混合；n ≥ 300 取山体场。带内四个旧 `raisedHill` 被山体场取代（其丘顶均 ≤ 场地场值，不再单独叠加——叠加会在道面走廊外形成未登记凸起，定线抽测以本稿场值为准）。
2. **走廊即道路**：七道与火车台地走廊一律复用 `segments()` 的段压平机制——把走线带登记为带逐点高程的段列（与 `layout.roads` 同构、独立常量表，不动 layout.json），压平口径 `1−fade(edge/5)` 与现行道路一致。坡度由此**逐段精确成立**，不依赖地形自然坡度凑数；这是本稿全部路线坡度数字的成立方式。
3. **镜湖 = 第二湖项**：`layout.json` 零改动（总纲 §1.4），镜湖常量（心/半径/冰面高）置于 `town-extension.ts` 导出 `mirrorLake`，`sample()` 在东南湖项后追加同构的压平项与冰面标记（`ice` 条件并入镜湖 `ld < −0.5`），`createTerrainGrid` 的 surfaces 编码（4 = 冰面）随之自动覆盖镜湖。

### 1.3 火车台地与既有 railY 的衔接（本节为全稿最要害的推导）

**代码实测的硬锚点**（`town-rail-stops.ts`）：既有站 railY/ground——森林木屋站 (112,420) railY **32.84** / ground 33.7；火车站前站 (477,320) railY **33.19**；过山车站 railY 19.68。导线包络（`town-railway.ts`）：轨面 = 地形 + 0.62（近站 35 m 内渐升至 +5.7 的进站抬升）+ **最大坡度 0.225 双向钳制** + 站台 railY 钳制；总纲 §3.3 定既有 6 站 railY **一字不动**。

由此推出三条不可回避的结论：

1. **台地不能整段 65–70**：森林木屋站处地形必须 ≤ railY − 0.62 ≈ 32.2（否则列车被埋）。总纲 §1.5.2 的「山腰台地 ≈65–70」只在**北岭站段**成立，台地高程必须沿导线爬升——西起 31.5（让行森林木屋站）、中段北岭站达 68、东段降至 47（向火车站前站 33.19 收束）。
2. **北岭站 railY 定版 72（提案）**：自森林木屋站沿导线弧长 ≈193 m（(112,417)→(175,442) ≈68 + →(242,448) ≈67 + →(300,449) ≈58），钳制上限 = 32.84 + 0.225×193 ≈ **76.3**；取 railY 72（= 台地 68 + 0.62 + 进站抬升余量），距上限留 4.3 m 余量。东向复核：北岭站 → 火车站前站弧长 ≈240 m，72 − 0.225×240 = 18 ≤ 33.19 ✓ 可达。
3. **台地走廊按 §0.2 第 2 条以导线段压平实现**，逐点高程（地形值，提案定版）：

### 1.6 冰宫 [484,65] 不在山上的边界处理

- 覆盖函数的**硬边界**：`mountainElevation` 混合带南界 n = 262，n < 262 时覆盖权重恒为 0——冰宫 plot（n 39–91，`ice-palace-site.ts`）距混合带南界 ≥171 m（总纲口径「逾 170 m」），覆盖对其采样值的影响**数学上为零**，不是「尽量不动」。
- 同理受保护：温泉 [548,158]、过山车站 [478,224]（南界以南 46 m，总纲定位山脚东口门户站）、东南湖、镜湖（n ≤ 240，见 §5）。
- 山麓台地带（n 270–310）内既有内容：纪念堂 [337,277]、长厅 [378,316] 的 plot 压平在覆盖之后执行（§0.1 推论 ②），地基高程以既有实测为准、零改动；山体场在其 plot 外绕行升起作背景峰面。北环路路面同理（道路压平在后）。
- 河流：`northernRiver`（`town-extension.ts`：[231,512]→[239,470]→[225,429]→layout.river[0]）在覆盖带内穿越南坡——河道压低在基础场之后执行，河道将切穿山体场形成峡谷（源头段在岭背北坡 n 470–512、穿脊口约 (235,495)、南坡段 (225,429) 向南接 legacy 河道）。总纲 §1.5.4「河道不穿南坡道面」的落法：**R1 横切走线带在河道带（x 218–246）收束为一处桥位通过**（§2 R1 注），其余各道不跨河。此项与代码现状（河道压低恒在基础场后）存在口径张力，列入 §6 待核对第 2 条。

## 2. 七道走线带（R1–R7）

通则（提案，沿总纲 §1.5.3 与 v2 口径）：

- **道宽**：走廊压平全宽 R1 = 10 m、R2–R6 = 8 m、R7 = 6 m；道面外 1.5 m 为雪墙/林带隔离带（道间隔离口径沿总纲 §1.5.3）；防冲出雪墙沿 v2，冲出入深雪减速（摩擦 0.45）沿重调口径。
- **坡度成立方式**：走廊逐点高程按下表锚点插值（段压平），锚点高程由总纲 §1.5.3 的分段坡度预算反推（段落差 = 段长 × 段坡度），时长以总纲巡航均速验算、不另立数字。
- **路径长口径**：下表锚点为走线带的骨架点，锚点间以 S 弯填充至总纲道长（填充系数 = 道长 ÷ 锚点折线长，各道已验算在 1.1–2.9 之间，林间道填充最大）；定线回执逐道回填实测道长/落差（总纲 §6 验收：时长偏差 ≤25%）。
- **终点门群**：R1/R3/R4/R5/R7 五门沿山脚台地坪南缘一字排开（n ≈ 312–314，见表），R2 终点在山脚东口、R6 终点在松林营地北口（总纲既定例外）。
