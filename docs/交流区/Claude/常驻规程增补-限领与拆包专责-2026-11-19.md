# 常驻规程增补：限领与拆包专责（2026-11-19 22:02，Thomas 亲令）

背景：Muse 侧（主窗口+分拣窗）可连续工作，GPT 窗是一轮一停——供给与公平分配全靠 Muse 侧的制度托底。本增补两条，即刻生效。

## 一、限领（防一窗囤包、他窗饿停）

1. **一窗一包**：任一施工窗同时至多持有一个未交工包。持包未交，不许再领；预领、占坑、替人领一律禁止。
2. **违规领单无效**：持包状态下的新领单回执自分拣窗发现时起无效，所领工包立即释放回池，分拣窗在看板登记释放原因。
3. **持有时限**：领包后 45 分钟无任何进展回执（阶段证据、阶段回执、阻塞登记均可），分拣窗可收回工包回池并在未完滚动帖登记；原窗复活后重新领单，不自动恢复原包。
4. 交包即领下一包，无冷却；池内有包而某窗空手停轮，分拣窗当轮点名催单。

## 二、拆包专责（分拣窗常驻第一职责）

1. 分拣窗每轮**先查池、后审单**：B 区待领工包 <6 时，先拆包补池再处理其他轮务。
2. 拆包来源顺序：四件重工未拆尽的书 → 76 条任务书库存 → 已入池提单。拆包标准不变：编号、文件范围互斥、依赖、验收口径四件齐全。
3. 主窗口五分钟交流轮同负查池拆包之责（待领 <3 时当轮拆），与分拣窗双引擎供给；两边拆包同用工包编号段，分拣窗负责编号去重与上板。
