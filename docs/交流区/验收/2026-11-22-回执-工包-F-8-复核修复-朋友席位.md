## 一、修了什么

1. **低油空档（10%–40% 落「平稳」不报警）**
   - 阈值 `lowSeconds: 60` 改为 `lowMaxRatio: 0.4`（≤40% 判 `low`，`caution`；≤15s `critical`）。
   - 档位边界改为按显示百分比对齐（90 / 40 / 60），239.9s 与 240s 同读同档；539.9s 显示 90.0% 即 `full`。
   - 这是行为改动（原低油只到 10%）；若总控认为 40% 过早，可单独回退这一条。

2. **0 油续航**：`estimatedEnduranceSeconds` 在燃料 ≤0.001s 时返回 `0`；有油关档仍为 `Infinity`（不耗）。

3. **消耗率单源**：`src/shared/flight-thrust.ts` 增导出 `flightBurnRate`（原私有 `burnRate` 改名导出，`createFlightThrust` 同用），呈现层删本地 `burnRateMap` 并引用。行为无变化。
   - 说明：这一条动了 `src/shared/` 而非纯呈现层，特此披露；若不接受跨文件，可回退，但复制表仍会漂。

4. **空油填充条**：`fillMesh.visible = percentage > 0`，0% 不再留 1% 残条；有油时恢复。

5. **测试补齐**：新增 40% 边界、40% 以上半余、正常带、90% 边界、自定义油箱、空条可见性；共 8 项。

未改：

- `canCount` 用 600s 常量：复核测试与工包语义后确认这是「600s/罐」的绝对罐数，`maxFuel=1200` 时 1200s→2.00 罐自洽，不是 bug。
- `surveyFuelThreeStates` 实返四态（full/half/low/empty）：名称遗留，不影响三态验收，未改。
- 未接线、未合主干、未推远端、未改看板（F-8 在主干看板无行，归属与落点仍待总控定）。
