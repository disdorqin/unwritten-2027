### 2. 替换 `viewer.ts:897-923` 的夜间硬切

保留 `nightMode`，但天空/雾色/环境光/太阳光改由 rig 每帧连续写入；`setNight` 只留离散对象开关：

```ts
let nightMode = false;
let clockNightApplied: boolean | null = null;
let ceremonyDim = 1;
const nightSky = createTownNightWeatherSky({ scene, ambient, sun, fog: weatherFog });

function setNight(night: boolean) {
  nightMode = night;
  summitSkylineMesh.material = night ? summitSkylineNightMaterial : summitSkylineDayMaterial;
  summitHutLight.visible = night;
  cloudRoute.setNight(night);
  timeOfDay.textContent = night ? '雪夜' : '白昼';
  timeOfDay.setAttribute('aria-pressed', String(night));
  scenery.setNight(night);
  westCraterRoad?.craterActions.setNight(night);
  productionRidge?.setNight(night);
  frontRidgeCloudBand.setNight(night);
}
```

- **删除** `applyCeremonyLighting()` 整段（含 `ambient.intensity`/`sun.intensity` 写入）与 `setNight` 内 `scene.background`、`scene.fog.color`、`ambient.color`、`sun.color` 五行；这些现在归 rig。
- `viewer.ts:1966` 的 `applyCeremonyLighting();` 一并删除，只留 `ceremonyDim = level`；仪式压暗通过 `update(..., { dim: ceremonyDim })` 继续生效。
- `viewer.ts:922` 的 `setNight(true)` 改为 `const initialNight = nightSky.update(presence.serverNow(), presence.getTownWeatherDawnEpoch()); setNight(initialNight.nightSide);`；若 presence 尚未 join，先 `setNight(false)`，首帧会自动纠正。
- `timeOfDay.onclick` 删除或改为只读状态（手工切换会形成第二昼夜权威，正是本次要消灭的突变源）。

### 3. 替换 `viewer.ts:4201-4216` 每帧块

- `snowfall` 的雾仍用 `weather.fogNear/far`，昼夜只乘 `skyFrame` 的两个缩放，不新增天气随机源。

### 4. 灯具（已备好接口）

`town-lights.ts` 新增 `setNightLevel(level: 0..1)`：只让自动 dusk 灯随昼夜连续起亮，**玩家亲手点亮的灯保持常亮**（进度反馈不被昼夜抹掉）。A 只需每帧调用上面那行 `townLights.setNightLevel(skyFrame.lampLevel)`。

推荐同时把 `setTowerDusk()` 的**灯具**接入从墙钟 17/18 点改为 `skyFrame.nightSide`（钟声/钟面时钟不变），否则游戏内深夜而墙钟是上午时广场仍可能不亮。该行为属 A 的公共客户端取舍，F 不越权改。
