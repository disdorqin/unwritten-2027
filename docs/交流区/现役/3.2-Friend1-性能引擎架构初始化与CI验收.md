# Friend1｜独立性能引擎初始化后实施令
本文件细化P32-1..5，不另开工程；lane-friend现役，基线以最新integration为准。先读原专项任务书、engine-perf/README.md、三项缺陷审计、AGENTS。总控已初始化核心目录、接口、可运行骨架、测试及CI配置。不要推倒重写，不要再做一轮纯规划，先运行基线检查再填充缺项。主线A/B/C2/D2仍独立建模，任何阶段禁止等待它们全部完成。
## 目标：以后新增任何场景都能复用
内容owner只输出Group/可分块数据/世界bounds/稳定ID/revision/静态分类和原碰撞契约。老资产可由宿主适配器读取，无须导入性能模块；新增模型走同一接口，无地区名、模型名特判。性能引擎只拥有显示/缓存/资源寿命和纯视觉更新，不拥有世界高程、碰撞、玩家运动、联机、缆车权威。核心禁止import宿主，Three仅在adapters/；由总控/A/D2单写viewer接入。低风险旧路径必须可回退，不能为了优化牺牲近景/路线/交互。Sodium为设计参考，不复制Java源码或把体素渲染假定成所有模型。
## F1 测量（P32-1）
从冻结生产入口和已有转向脚本入手。完善metrics/frame-profiler.ts，新增adapters/gpu-timer.ts及tools/verify-engine-perf-profile.mjs。记录每帧原始帧时、CPU各段、GPU异步计时（不支持/失效=null）、draw/tri、几何/纹理估算、缓存、字节、长任务；浏览器计时与真实GPU分开。冷启动/第一次转身/缓存复转、行走、雪橇、缆车、后山切换对照，至少3配对，交错AB/BA，不过滤停顿；同硬件/DPR/画质/天气/路径。若无法到某区，真实报告阻塞，冻结资产fixture用于算法，不替代实游。原因分层：机制（索引、上传、shader、culling、同步build），仿真（粒子、动画、物理、网络），数据（几何/材质/内存），浏览器/设备。先给一张按时间成本排序的证据表，然后做代码。
## F2 驻留与流水线（P32-2）
扩展core/engine.ts为真正执行器；保留现有PerformancePlanner纯逻辑便于测试。API建议 register/update/remove、prepareFrame、commitReady、dispose；由host传port/clock，不读viewer全局。registry增量空间索引，不能每帧遍历全世界；revision更新去重、移除取消旧任务。residency/planChunk按位置和预测移动而非yaw；必保地表始终有原始fallback，LOD ready交换；不要用视觉缓存删碰撞。cache/resource-cache.ts完善共享资源引用、CPU/GPU池与高水位、LRU、context loss；pinned不能被淘汰，重复释放不破坏计数。streaming/build-coordinator.ts接adapters/worker-mesh-builder.ts与mesh.worker.ts，支持typed array、Transferable、有限并发、优先级、取消/过期、失败恢复；同key共享Promise只允许单一协调者接收所有权。streaming/budget-queue.ts支持预算、分片、饥饿防护、优先级提升、错误回退，2–4ms与0.5–2MB仅初值；不可切割同步任务必须报告超预算。禁止无界任务、无界缓存、每次转身重新build、主线程await整山。先构造未知资产样例，登记不同尺寸/旋转/缩放/动态/透明模型，验证核心无需改变。至少新增版本交替、过期结果、预算、内存回收、LOD等待、掉线/取消测试。
## F3 渲染（P32-3/4前半）
实现adapters/three-render-port.ts、world-chunk-adapter.ts；已有three-object-descriptor仅世界bounds登记样例，不是GPU上传。Three实际BufferGeometry/InstancedMesh/material/纹理共享、world matrix、空间bounds、预热与renderer.info计数。rendering/batching.ts保持透明/交互/骨骼不安全对象回退；静态同材质按空间块合并，确定不可见内部面才剔除；按近中远HLOD及同源接缝，不合全图巨大batch。rendering/visibility.ts扩展保守视锥/山体遮挡或层级索引；proof key含scene revision+camera epoch，陈旧或未知一律fail-open，测试快速转身、贴边、摄像机俯仰和移动。GPU实际上传由Three渲染触发，不能把创建BufferGeometry的耗时当GPU耗时。每帧显示集合可以改变，但驻留/网格不能因yaw重建。F交薄接线补丁给总控，不改公共文件。
## F4 动态仿真（P32-4后半）
simulation/visual-scheduler.ts扩展纯视觉距离分频，按实测优先粒子/灯光/装饰动画/区域音效/NPC视觉。固定时间步及插值建议由owner实现；不能降低权威频率、停止附近碰撞或缆车时钟，不能远处模拟停摆导致剧情状态丢失。物理仅提独立空间索引候选与host适配，真实collision由A/C2/D2审核。必须记录仿真耗时与渲染耗时差，禁用功能换FPS不通过。
