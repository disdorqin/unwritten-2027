## P 四轮（性能与可玩性是本次P0）
P1：在当前正常游戏入口采样广场、坑沿、坑底、矿运道各固定机位与连续移动，同设备/分辨率/画质/昼夜/同浏览器，暖机后取帧时中位数/p95、FPS、draws/tris、可见对象、纹理/几何、CPU主线程与GPU瓶颈（可用时GPU timer），记录启动尖峰、地下不可见渲染/模拟、重复装配、透明粒子及碰撞查询。马上实施最主要的1–2个瓶颈修复（如空间块可见性、远区停渲染/停非必要tick、实例化），本轮必须有实际性能差分与前后实测，不只报告。保持同样坑体内容、交互、碰撞，避免一刀切清空画面。
P2：空间分块、视锥/距离剔除及滞回，近中远LOD，重复件实例化/按块材质合批、内部无用面剔除、共享纹理，地下只呈现当前域；昂贵初始化分帧，避免每帧全量扫描/创建对象；按测量优化碰撞索引、天气透明及光照，保真物理/联机权威，不把雾距当剔除。M代接公共帧钩子，P提供最小接口及自测；候选未接viewer不得称完成。连续移动和矿坑内外对比；优先改善p95卡顿，不只平均FPS。
P3：全图必要优化（坑区为重心），提供合理的流畅/均衡/精细档及自适应预算建议，保留用户显式画质选择；坑沿、坑底、广场与山脚同机实走，验证照明/粒子/玩法/雪橇/碰撞和场景切换。目标同正典：普通PC≥60FPS、中端手机≥30FPS、常用机位draws≤300、可见三角≤150万、坑口相对广场≥80%。同时目标坑口/坑底相同设备同档p95帧时较基线至少下降30%，不达继续定位并如实报告；不得将无真机或软件渲染FPS冒充用户拯救者实测。必须报告实际设备、分辨率和帧时，避免FPS推测。目标是验收门槛，不承诺固定轮数必达。
P4：联合树配对M、复测性能回退和真实玩法，提交可复现脚本、精确SHA与简短证据，未达目标继续集中修复，不新增玩法。P不得为提高数字删除核心模型、碰撞、联机任务，不能单纯调低分辨率冒充结构优化。
