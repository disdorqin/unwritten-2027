3. **云海宿主丢失正典步道净空**：`town-d2-r30-assembly.ts:138-143` 调 `createTownD2R30CloudTerraceHost({ heightAt, arrivalHeight })`，未传 `trailPoints`；生产默认 `[]` 使 cloud wall 与低地森林的步道避让关闭。须传正典 `createMainSummitTrail` 点列，并补生产路径上的净空断言，不能只在单包测试里注入点列。
