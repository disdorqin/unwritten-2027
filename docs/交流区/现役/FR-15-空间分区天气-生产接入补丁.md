# FR-15 空间分区天气场 · 生产接入补丁

2026-11-27 · F 线（lane-friend）核心天气专项 R2
基线 `5d3e2c61`（R1 连续昼夜）之后；本补丁不改服务端协议、不改白化玩法门槛、不改缆车运行规则。

## 1. 结论与边界

- **唯一权威仍是 Presence 的 `TownOutdoorWeatherState`**（`weather/startedAt/nextChangeAt/windEast/windNorth/windStrength`）。新场只读它，按玩家位置、真实高程、陨石坑距离、地图边缘距离生成局地视觉/物理参数，不排期、不写回、不另建天气状态。
- **同一时刻**：小镇雪势最小、山脚抬升、高山区与主峰明显加剧；陨石坑与地图边缘更恶劣。区域之间连续渐变，无逐点随机、无逐帧随机。
- **全局玩法判定不动**：白化（`whiteout`）门槛、缆车照常按钟运行、雪橇/告示等仍读 Presence 权威状态，不读本地场。
- 普通阶段不再使用本地 64 槽排期驱动天气；跨年仪式阶段继续走既有 `townSnowWeatherForFrame(ceremonyState)` 演出曲线，二者按 `ceremonyState.phase === 'ordinary'` 分流。

## 3. A 侧 viewer.ts 最小改动

### 3.1 import

```ts
import { townOutdoorWeatherFieldAt } from './town-weather-field-outdoor';
import { townWeatherAreaAt, townWeatherExposureFor } from './town-weather-exposure';
```

### 3.2 替换每帧天气取样（现 4209 行附近）

```ts
const outdoorWeather = presence.getTownOutdoorWeather();
const localField = outdoorWeather && ceremonyState.phase === 'ordinary'
  ? townOutdoorWeatherFieldAt(
      outdoorWeather,
      { east: shedEast, north: shedNorth, elevation: shedFeet },
      {
        exposure: townWeatherExposureFor(townWeatherAreaAt(shedEast, shedNorth)),
        // R1 连续昼夜已统一处理夜间雾距，传 Infinity 让 R1 的 fogNearScale/farScale 继续生效。
        nightFogFar: Infinity,
      },
    )
  : undefined;

const weather = localField ?? townSnowWeatherForFrame(ceremonyState);
const effectiveSnowIntensity = weather.intensity;
```

### 3.3 雾、雪、风、积雪接入

```ts
snowfall.setIntensity(effectiveSnowIntensity);
snowfall.setOutdoorWind(
  weather.windEast ?? 0,
  weather.windNorth ?? 0,
  weather.windStrength ?? 0,
  townWeatherExposureFor(townWeatherAreaAt(shedEast, shedNorth)),
);
snowfall.update(camera, dt, walking, sheltered || shedSheltered || roofSheltered || Boolean(homeReturn));

weatherFog.near = weather.fogNear * (skyFrame?.fogNearScale ?? 1);
weatherFog.far = weather.fogFar * (skyFrame?.fogFarScale ?? 1);

visualSnowCover = ceremonyState.phase === 'ordinary'
  ? advanceWeatherCover(visualSnowCover, dt, weather)
  : snowCover.amount();
snowCover.setWeather(weather);
```

- `skyFrame` 为 R1 `nightSky.update(...)` 的返回值；若 A 尚未合并 R1，先按旧硬切代码保留雾距，不阻塞本补丁。
- `townWeatherAreaAt` 需要地点上下文时按现有 `TownWeatherLocation` 传；缺省按坐标判定。
- 风只影响粒子/体感，不改变服务端权威或移动判定。R3 再把 `townAreaWindWalkingScale` 接到玩家速度。

### 3.4 删除/停用

- 普通阶段不再让 `townSnowWeatherForFrame(ceremonyState)` 作为 `weather` 来源（只保留给非 ordinary 仪式）。
- 不新开 `setInterval`、不每帧遍历地图对象；`townWeatherFieldAt` 为 O(1) 定点采样。

## 4. B 侧

无需改协议。只需确认：

- 各房间仍共用同一 `dawnEpoch` 与同一 `TownOutdoorWeatherState` 广播；
- 不在房间侧另写昼夜/天气字段；
- 重连快照照旧带 `townOutdoorWeather` 与 `townOutdoorWeatherDawnEpoch`。

## 5. 验收要点

- 同一权威状态下：广场雪弱、山脚增强、高山区/主峰强、坑/边缘能见度压到约 11 m；小镇白化仍约 78 m，不误伤小镇玩法。
- 1 m 步进采样连续，无逐点跳变；同一 `state + position` 在任何客户端得到同一结果。
- 普通阶段跨区移动时雾、雪粒子、风、积雪渐变；缆车照常按钟，白化门槛仍读 Presence。
- 性能：场采样 O(1)，无每帧全图遍历；粒子上限仍由既有 `snowfall` 预算控制。
