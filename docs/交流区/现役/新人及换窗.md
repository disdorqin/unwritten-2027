# 新人及换窗：3–5人小团队
沿用《协作-多人并发规范-2026-11-21》：一人一线一域、配对窗不限厂商，简便优先，不增加审批层级。朋友线 lane-friend 保留；新真人可只做实玩、美术资产或独立模块，熟手可直接领线。仓库权限由拥有者授予最小必要权限；不分享 PAT/服务器密码，发布仅总控/项目拥有者。
## 5分钟换窗
新窗从现役入口读本线任务；只读当前正典、图册和最近一份交接卡，不读归档历史。先查 git status/branch/HEAD、已推候选、dirty、锁，不创建重复工作树；有未结束任务先恢复。交接一张卡：角色/分支/D盘路径、当前集成SHA、分支SHA、在飞ID、领地、已实现/未接线/阻塞、下一可执行ID、已读入口。每次独立交付更新，不写长报告。临时对话不作为任务权威。
## 真人协作
新成员先裸链接试玩，可提交位置/截图/复现/期望四项；会建模者领独立场景或资产模块、技术成员领已有模块，配对审核窗协助。朋友现有分支不得擅自覆盖；总控登记一人一线四要素（分支、区域、命名空间、审核者）。共享入口/协议单写。每人仅推自己线，PR 指定任务和候选SHA，配对窗看实际画面/代码，跨域消费方确认契约，总控串行合入。小争议直接沟通，冲突保留双方成果，禁止强推/删除。朋友可参与夜间/手机/弱网实玩，不要求每个小件都走审批。80%施工优化、20%验证上限。
## 新窗可直接复制
你是 UNWRITTEN 2027 窗【线名】，分支【分支名】，现役入口 docs/交流区/现役/README.md。先核 HEAD/dirty 与在飞任务，读取任务看板、本线规格与接口，恢复现有工作。仅认领已激活本线任务；历史归档与旧续单链不可派工。先做独立可用包、及时推自有分支、配对审后总控串行合入。遇依赖仅停该子件、转无依赖任务。日常构建/0运行错误/真实实走，最终 P-OPT 不省。不要重置他人工作树或复制旧任务。

换窗后仍只使用统一「续建」指令，执行 [项目脑 §7](../../项目脑.md#7-统一续建闭环2026-11-25长期有效)。首轮恢复原分支、阶段、在飞任务、待审及下一项，不重复开工；日常每轮自动更新同一交接卡。只有满足收工门槛才输出【本线收工候选】并交总控核收。
