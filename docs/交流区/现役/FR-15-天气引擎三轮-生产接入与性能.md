## 1. 单一权威不变

```

        ├─ 全局玩法：白化门槛 / 缆车规则 / 天气事件脚本（只读 state，不读本地场）
        ├─ R1 天空：townNightWeatherAt(serverNow, dawnEpoch) → 天空/雾色/环境光/太阳/曝光/灯位
        └─ R2 空间场：townOutdoorWeatherFieldAt(state, 位置) → 本地雪强/雾/能见度/风/积雪目标
                              └─ R3 视觉预算 → 粒子密度/风向推送/移动阻力
```

- 普通阶段 **不再用** 本地 64 槽排期；跨年仪式仍走 `townSnowWeatherForFrame(ceremonyState)`，按 `phase !== 'ordinary'` 分流。
- 新模块全部只读权威；不写回、不排期、不改协议。

## 2. A 侧 viewer.ts 最终补丁（三件合并）

### 2.1 import

```ts
import { createTownNightWeatherSky } from './town-night-weather-sky';
import { townOutdoorWeatherFieldAt } from './town-weather-field-outdoor';
import { townWeatherAreaAt, townWeatherExposureFor, townAreaWindWalkingScale } from './town-weather-exposure';
import { createTownWeatherVisualDriver } from './town-weather-visual-budget';
```

### 2.2 初始化

```ts
const nightSky = createTownNightWeatherSky({ scene, ambient, sun, fog: weatherFog });
const weatherVisual = createTownWeatherVisualDriver(snowfall, { qualityScale: particleDensityScale });
```

`setNight` 只保留离散开关（峰顶材质、山屋灯、cloudRoute、按钮、scenery、坑路、productionRidge、frontRidgeCloudBand）；删除天空/雾色/环境光/太阳光的整体写入。

### 2.3 每帧（替换现 4201–4223 的昼夜 + 天气块）

```ts
const skyFrame = nightSky.update(presence.serverNow(), presence.getTownWeatherDawnEpoch(), { dim: ceremonyDim });
if (skyFrame.nightSide !== clockNightApplied) {
  clockNightApplied = skyFrame.nightSide;
  setNight(skyFrame.nightSide);
}
townLights.setNightLevel(skyFrame.lampLevel);

const outdoorWeather = presence.getTownOutdoorWeather();
const area = townWeatherAreaAt(shedEast, shedNorth);
const exposure = townWeatherExposureFor(area);
const localField = outdoorWeather && ceremonyState.phase === 'ordinary'
  ? townOutdoorWeatherFieldAt(
      outdoorWeather,
      { east: shedEast, north: shedNorth, elevation: shedFeet },
      { exposure, nightFogFar: Infinity },
    )
  : undefined;

const weather = localField ?? townSnowWeatherForFrame(ceremonyState);
weatherVisual.update({
  intensity: weather.intensity,
  visibilityMeters: localField?.visibilityMeters ?? weather.fogFar,
  windEast: localField?.windEast ?? 0,
  windNorth: localField?.windNorth ?? 0,
  windStrength: localField?.windStrength ?? 0,
}, dt, performance.now(), exposure);

snowfall.update(camera, dt, walking, sheltered || shedSheltered || roofSheltered || Boolean(homeReturn));
weatherFog.near = weather.fogNear * skyFrame.fogNearScale;
weatherFog.far = weather.fogFar * skyFrame.fogFarScale;

visualSnowCover = ceremonyState.phase === 'ordinary'
  ? advanceWeatherCover(visualSnowCover, dt, weather)
  : snowCover.amount();
snowCover.setWeather(weather);
```

- 下一行 `skyClouds.update` 仍只读 `presence.getTownOutdoorWeather()`，不新增第二来源。
- 删除手工 timeOfDay 按钮的切换逻辑；按钮可保留为「锁定预览」调试，但不能改权威。
- 删除 `applyCeremonyLighting()` 及 1966 行调用；`ceremonyDim` 继续经 `nightSky.update({dim})` 生效。

### 2.4 风速对玩家移动的物理参数（R3）

在 `viewer.ts` 3909–3914 的移动速度合成处：

```ts
const moveEast = Math.sin(yaw) * forward + Math.cos(yaw) * right;
const moveNorth = Math.cos(yaw) * forward - Math.sin(yaw) * right;
const outdoorNow = presence.getTownOutdoorWeather();
const moveArea = townWeatherAreaAt(walkCurrent.x, -walkCurrent.z);
const windWalkScale = outdoorNow
  ? townAreaWindWalkingScale(outdoorNow, moveArea, moveEast, moveNorth)
  : 1;
const speed = (sprint ? 11.3 : 7.5) * snowballWalkFactor * landingFeedback.walkingScale() *
  windWalkScale / Math.max(1, Math.hypot(forward, right));
```

- 顺风/逆风按服务端单位风向量与曝光系数连续缩放，不改变碰撞、雪橇、缆车或联机权威。
- `walkCurrent` 在该块之前已是当前世界位置（x=east，-z=north）；不依赖后面才初始化的 `shedEast/shedNorth`，避免 TDZ。

## 3. 粒子与更新频率

- `townWeatherParticleScale`：晴朗 1.0，小镇暴雪约 0.92，主峰暴雪约 0.76；再乘玩家画质档（smooth .5 / balanced 1 / fine 1.25），下限 0.4。只做削减，不替换画质选择。
- 密度以 0.45 s 时间常数缓动、按 1/32 量化后再写 drawRange，避免跨区时粒子数跳变。
- 风向以 0.7 s 缓动、10 Hz 推送；`snowfall.setOutdoorWind` 不再每帧调用。
- 雪强仍由 `setIntensity` 写 storm uniform，内部已有相同值早退；粒子位置积分仍在 `snowfall.update` 每帧执行，避免运动卡顿。
- 场采样 O(1)，无每帧全图遍历、无数组分配。

## 4. 同钟与多人一致

- 天空：`townNightWeatherAt(serverNow, dawnEpoch)` 纯函数，同 `dawnEpoch + serverNow` 同结果。
- 空间场：同 `TownOutdoorWeatherState + 位置` 同结果；测试覆盖两客户端同帧深相等。
- 粒子视觉：两个客户端以同一场样本驱动时，密度/风向目标一致；只允许本地画质档不同（既有可选项）。
- 服务端无需新增字段；重连快照继续带 `townOutdoorWeather` 与 `townOutdoorWeatherDawnEpoch`。

## 5. 性能证据（本机，非承诺）

`node --import tsx tools/bench-fr15-weather.ts`：

- 场地采样：约 **0.21 µs/次**
- 权威适配器：约 **0.71 µs/次**
- 场 + 粒子预算：约 **0.20 µs/帧**
- 60 FPS 下天气场 CPU 开销 < 0.001 ms/帧（相对 16.7 ms 预算可忽略）

粒子削减只在重天气发生，且风暴增量仍由 `snowfall` 的 storm 区段补齐；没有新增每帧对象创建。

## 6. Friend2 / Friend3 接口（接收但不等待）

- F2 天空色板：直接读 `nightSky.current().sample.skyColor / fogColor / cloudColor / starLevel`；R1 已输出 `cloudColor`，无需 F2 自算时钟。
