## 怎么读这张图

- **入度高＝枢纽**：被很多模块引用，改它影响面大。当前枢纽前五：`town-activity.ts`（51）、`landmark-kit.ts`（39）、`terrain.ts`（29）、`town-za22-crater-road.ts`（16）、`museum-kit.ts`／`main-summit-block.ts`（12）。动枢纽先读它的引用者清单（在 JSON 里反查 edges 的 to）。
- **入度 0＝136 个**：没人引用的模块——可能是入口文件、宿主直挂件，也可能是**写了没接线的**。这正是本项目的高发病（「做了没接入」）：看到入度 0 先别下结论，对《最新进展-全图接入状态》的账再动它。
- **前缀＝归属**：模块名第一段是它的家族/辖区（`underground-` 76 个＝地下，`main-` 57 个＝主峰域，`za36/za22`＝坑区工程，`zb` 系在文件名中段，完整前缀表见《项目地图》）。找某个区代码，先按前缀筛节点。
- **四层结构**（与《技术文档-技术栈建模与交互实现》的分层一致）：规则层 `src/shared` → 权威层 `src/presence` → 活动/场景层 town-blockout 各模块 → 接线层 `viewer.ts`。图里跨层边最密的地方就是耦合点，改一处先顺边看两端。

## 红线（图上看不见、但必须知道）

- `viewer.ts` **单写**：只有 A 线/总控能改，任何线不许整文件覆盖。
- `src/presence/` 的 import 只许引 `src/shared`（带 `.js`）或本目录——图上若出现 presence→tools 的边，那是发布事故的前兆（第十版曾因此卡死 35 分钟）。
- `terrain.ts` 冻结：高度函数不许改，路面走覆盖层（盘山道即此法）。
