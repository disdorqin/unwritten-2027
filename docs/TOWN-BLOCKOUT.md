# UNWRITTEN 2027 小镇初搭任务书

两人从包含本任务书的最新 `main` 拉独立分支。参考 [48 张概念图索引](../assets-source/concept-art/README.md) 和 [中央广场总图](../assets-source/concept-art/central-square-plan.png)。施工坐标集中在 [layout.json](../tools/voxel-tavern/town-blockout/layout.json)。冲突时先按坐标表，G01 定量感，M04 定山谷高差，B 组定建筑造型。第一轮交付可走通、可替换的灰盒。

## 共享坐标与文件

- 俯视图上北右东。表内 `origin` 为 `[东, 北, 地坪高度]`，`footprint` 为 `[东西宽, 南北深]`，`door` 是入口中心的平面坐标，`connect` 是主助手道路接点及其标高。Three.js 世界坐标换算为 `[东, 高度, -北]`，每单位一米。
- 主助手维护本文件、`town-blockout/layout.json`、预览入口、道路、碰撞集成。新助手只写 `tools/voxel-tavern/public/town-blockout/buildings/`。如需挪地块，先报现有值、建议值和影响的路/门；同步后再按新值施工。
- 建筑以地坪中心为局部原点，Y 向上，西东和南北世界方向已在模型内表达。直接导出 GLB，以免重复缩放或旋转。钟楼南门通广场、塔顶高度目标 96 米（从地坪算）；邮局和酒馆分别退到两侧。
- 建筑目录交付 `index.json`，格式如 `[{"id":"tavern","file":"tavern.glb","colliders":[{"min":[-10,0,8.5],"max":[-1,3,9]}]}]`。ID 对应坐标表。文件名用小写 ASCII，与清单同目录。碰撞是局部轴对齐盒，包含实体墙和阻挡物，门洞保持开放。建筑内多层地面或台阶由新助手在同一目录 README 记清尺寸与路线，由主助手集成实际地面碰撞。
- 暂无模型的地块保留地坪与边线。广场的礼台、树、灯具与建筑装饰均落在净空外。施工预览只用于灰盒对齐。

## 地形施工预览

地形施工分支为 `town-blockout-ground`。在仓库根目录运行：

```sh
npm ci --prefix tools/voxel-tavern
npm --prefix tools/voxel-tavern run build
cd tools/voxel-tavern
node node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 5192
```

打开 `http://127.0.0.1:5192/town-blockout.html`。默认雪夜俯瞰，可切换白昼。点击「第一人称」从广场南侧出发。电脑点击画面锁定鼠标，WASD 或方向键行走，Shift+W 或连按两次 W 疾跑，空格跳跃。触屏可以滑动转头、轻点场景转向，连推两次摇杆前方向疾跑。广场和桥头已铺装，四条短路配路灯，雪林避开地块及道路。第一人称只启用附近三盏灯的实时照明；远处路灯用发光材质。西北、东北、西南、东南的短路分别约 105、136、109、145 米。各区和 12 个建筑地块都有独立入口定位。

模型清单可放到 `tools/voxel-tavern/public/town-blockout/buildings/index.json`，重新构建后预览自动读取。提交建筑时保留资产文件及清单。西南至东南的短路绕开木马地块西侧，之后从南侧短接线进入。地块位置和入口维持共享坐标。

## 验收顺序

1. 俯视核对广场、桥、冰湖、上坡地块和首轮每栋建筑朝向。
2. 在第一人称里，从西北木屋、东北纪念馆、西南年集、东南游乐区各走一条短路回广场，再走完外环。上坡、桥面、入口和地坪不能突然掉落或卡死。
3. 钟楼、酒馆、邮局逐栋验证门洞和楼梯。其余建筑验证入口、通道、台阶、前场留白及碰撞。逐层测试以两边交付都到齐为开始条件。
4. 现有酒馆样板与预览分别构建。联机跨年同步、手机性能和最终灯光在集成后按原项目计划验收。

### 地标

- **中央钟楼**。广场 → 南门 `[226,216]` → 钟厅东南角 → 木楼梯 → 表盘层 75.31 米 → 钟室 83.19 米 → 最高可达观景层 100.13 米 → 原路回广场。去回检查点全部通过。塔尖保留在观景层上方。钟厅向北冲跳到 `[226.0,227.7]` 被实体墙挡住。
- **纪念馆**。前庭 → 正门 → 一楼两侧月份展柜 → 东梯 → 二楼放映台 → 东梯回街。另一条路线从二楼展柜走到西门、露台、外梯和前庭，再进正门。展柜、年度索引、北窗和阅读座位均实测。基线在 `[343.21,255.99]` 附近从前庭踏到路上会突然下降约 1.06 米，现已补齐标高，复验出馆未出现无输入腾空。
- **长殿、灯坊、木屋**。长殿前阶进殿后到东窗再出门。灯坊从西门到工作台并返回，出现春灯制作提示。木屋从 `[103,255]` 沿街进屋至 `[101,271.5]` 后返回，基线在 `[101,264.2]` 挡在封闭外墙处。三处均验证了开窗、关窗。
- **年集、舞台**。年集从 `[154,79.6]` 走到 `[154,104]` 再返回。舞台从广场观众区走上台面 `[238,155]` 再回前场，经过开演和鼓掌提示点。
- **暖房、灯塔**。暖房走西侧门槛 `[365.76,96]` 进到东侧步道并出门，东侧玻璃可挡人。灯塔从东环 `[374,129]` 沿支路到正门，经入口右侧通道和四跑楼梯到 24.06 米观景台，再回东环。首跑原卡点 `[405.84,80.60]` 处窄化了砖墙碰撞范围，上部拐角同步调了楼板边缘和扶手。
- **酒馆、邮局**。酒馆由南门到大堂及一楼座位，经东梯至二楼阅览长凳后折返。邮局从南门到盖戳台，经东北楼梯至二楼档案区后折返。邮局二楼档案桌与新增护栏曾在 `[265.17,214.25]` 夹出窄角，档案桌已向墙侧移动，留出约 1.4 米过道。

按上列路线复测未再碰到通行阻断。两栋封闭木屋仍作为街景，住店尚无独立室内。触屏点按、滑动转向、摇杆双推疾跑和跳跃已在 Chrome 手机视口验证。真机性能、其余外环路段的完整连续走查、新联机和公网部署仍列在后续验收中。
