## 已定版决定（不再讨论，直接执行）
1. 目标设备底线：中端安卓（骁龙 7 系）+ 近五年 iPhone + 普通核显 PC；预算：中端手机全镇漫游 ≥ 30 FPS、PC ≥ 60 FPS、draw calls ≤ 300、可见三角形 ≤ 150 万、首屏可玩 ≤ 5 s（4G）。
2. 画质：流畅优先，高/中/低三档 + 自动降档，任何档位不许持续卡顿。
3. 玩法优先级：先戳册/点亮，再信件/祝福墙；跨年仪式是全镇主线，一切机制为它蓄势。
4. 旋转木马删除；游乐设施只做**全图环线过山车**一个。摩天轮不做。
5. 舞台演出加长并扩充动作编排；酒馆补**调酒**；**中央钟楼放大并补互动**（敲钟、表盘层观景、瞭望台合照点）；核心地标必有真交互。
6. **NPC 居民专答"关于张乐天"**：怎么认识他的、关系怎么样、日常喜好、只有亲密的人才知道的问题。不讲纪念馆、不当导游。对话路线见 P6（脚本优先混合制，Muse 定）。
7. 地图扩容；四区风格定位（森林原木 / 湖岸北欧石玻璃 / 集市砖拱廊 / 纪念馆区现代），在新图上重构，部分现有建筑按新定位重建；GPT 先出概念图选方向。
8. 新增标志建筑：火车站、温泉浴场、冰雪城堡。
