# 项目文档 · 经验教训与协作规范（2026-11-21，总控维护）

本文管「人和流程」：开发中踩过的坑（教训篇）与多人协作的规范摘要（规范篇）。仓库根目录《项目文档》是开发总则（流程与分工），本文是它的经验侧 companion；规范细节以《协作-多人并发规范》与《协作-朋友接入方案》为准，本文只给可执行摘要。

## 一、教训篇（每条都是真金白银换的）

1. **部署卡死：presence 引了 tools/（2026-11-21，第十版卡 35 分钟）**。仓内 tsc 是 bundler 解析、放行无扩展名跨界 import；presence 镜像用 NodeNext 严格编译且构建上下文只有 `src/`，引 tools 必失败，部署脚本对同一目标无限重试、站点停在中间版。→ 规矩：`src/presence/` 只引 `src/shared`（.js）或本目录；切版前必跑镜像编译模拟（worktree 取发布树→`cd src/presence && npm ci`→以 NodeNext 参数编 `index-rehearsal.ts`→零报错才放行）。
2. **「候选式交付」是头号隐形欠账**。功能挂 opt-in 旗标默认关、测试全绿、玩家根本看不见，也报完成（远景坑体调色板、昼夜系统都栽过）。→ 质量门：默认启用＋主构建可达＋第一人称截图，缺一不算交付。
3. **平行重建必成事故**。同功能另起一套（lane-a 坑外平行重建整套退役、浪费一整轮）——发现正典与旧作冲突，停手报裁，不许另起。
4. **本地好看 ≠ 线上好看**。雾距补丁在本地软化了惨白斜坡，真机近景仍是整屏白墙；本地无头帧率、云端浏览器重载假象都误判过传送故障。→ 验收以真机 live 第一人称实走为最终判据；本地证据只作旁证，且必须注明证据等级。
5. **审批与推送要攒批**。逐文件推送产生海量审批卡，淹没真人。→ 一任务一批量一卡；Muse 侧云端暂存、总控统一批推；真人/GPT 线走自有通道。
6. **有价值的不能删**。重组与退役只许「已在新位置验证落地的旧路径」被删；含糊或独立价值的文件归档，不直接删；动完保留全量本地副本至验证完成。
7. **数字要机械生成、逐行可溯**。普查/登记类成果曾出现凭记忆编造条目。→ 登记行必须由源数据文件机械生成，交付前做可溯性检查（每行能在源文件里找到）。
8. **本机出口 ≠ 站点状态**。总控 VM 直连站点 curl 空回复是出口老毛病；站点存活只认真浏览器读 healthz。
9. **接线是独立一步**。「建好了」但没挂载、没接 currentAction，等于没做（76 个未达模块审计的教训）。→ 交付口径报「已挂载/未挂载」，接线独立成包、独立验收。
10. **设计不许急着焊死**。故事线未定处先行施工会返工（镇志残页主线被十二生肖星石取代即是一例）。→ 未定案只登记 ideation，不落裁定、不压施工；已定大块先行。

## 二、规范篇（多人协作摘要，泛化版）

适用对象：总控、GPT 四窗、Muse 分支四窗、真人协作者及其各自的 AI 窗口——**智能体厂商不限**，能读仓、能审包、能复走即可担任配对验收。

1. **组织**：四窗↔四分支↔四域满编＋朋友线（lane-friend）；一人一线一域，一线＝分支＋域＋模块前缀＋配对验收窗，四要素在《项目地图》对位表登记。
2. **新人三阶**：观察（只读＋试玩）→验收员（真机实走，回执入 `docs/交流区/验收/`）→线主（领分支与起步域）。入线先读上下文包（《项目地图》→PLAN/故事前言→四柱总纲→质量门与本线任务书→AGENTS.md→本线近三份回执），并留《入线确认》。
3. **并发纪律**：分支隔离／认领登记（先占位后开工）／接线单写者／命名空间隔离／合并串行过质量门／新书为准／回执五段／服务器与凭据只经总控与 Thomas。
4. **工作循环**：拉集成线→读交流区新增→查认领避撞→施工→自验→回执→配对窗验收→总控合入→攒齐切版→真人 live 销账。队列未清空不停等（三种停手情形见《协作-多人并发规范》）。
5. **分歧处置**：口径分歧双方把依据（文件＋行）写进交流区，总控当轮裁；验收分歧以真人第一人称实走为最终判据。
6. **质量门（批37，全线）**：交付三件套（代码＋定向测试＋昼夜截图注机位）；禁候选式交付；禁平行重建；回执五段（已读新文件／改动清单／测试结果／截图机位／未完成项如实列）；先自查表后新工。
7. **完工四齐（Thomas 定）**：形齐／饰齐（密度≥老镇 2 倍成簇、≥3 材质家族、光有出处）／互齐（每故事点≥3 碰法）／文齐（游戏内文字当场写定、零占位）。缺一不挂载不上线。
